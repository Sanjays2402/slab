### Slice 1 — rquickjs sandboxed runtime (`bd00df0`)

Embedded QuickJS via `rquickjs = "0.11"`. New module hierarchy:

```
src-tauri/src/plugins/runtime/
├── mod.rs       # Runtime, execute_script, RuntimeError, ScriptOutput, classify_error
└── sandbox.rs   # console.{log,warn,error} wiring, LogEntry, LogLevel
```

**Key design choices:**
- Fresh `Context` per `execute_script` call (verified by `each_script_gets_fresh_context` — cross-Runtime AND intra-Runtime).
- 16 MiB memory cap (`set_memory_limit`).
- 1-second wall-clock interrupt via closure capturing `Instant + Duration` deadline. QuickJS polls between bytecode ops.
- `console.*` args coerced via `Rest<Coerced<String>>` — JS's native `String(x)` semantics, space-joined.
- Buffer is `Arc<Mutex<Vec<LogEntry>>>` shared via closure capture; the JS side never sees the Rust-side buffer (Tauri IPC will surface it via Slice 4 emit events later).
- `RuntimeError::Syntax` vs `::Thrown` discriminated via `Exception.as_object().get(PredefinedAtom::Name) == "SyntaxError"`.
- `MemoryLimit` and `TimeLimit` tagged when the caught error message contains "out of memory" / "interrupted" markers.

### Slice 3 — capability grants backend (`5c9533a`)

New module `src-tauri/src/plugins/grants.rs`. Distinguishes:
- **Declared** capabilities (`Manifest.runtime.capabilities` — what the plugin author *asks for*; upper bound)
- **Granted** capabilities (`PluginGrants` — what the *user* approves; persisted in `~/.slab/plugin-grants.toml`)

`enforce(declared, granted, request) -> Result<(), DenyReason>` is the runtime gate. Both must permit; returns `NotDeclared` if the manifest doesn't even list the capability (manifest is the contract), `NotGranted` if the user hasn't approved, `GrantTooNarrow` (e.g. read-write declared but only read granted), or `HostNotAllowed` (net specific allow-list miss).

`PluginGrants::covers(declared)` detects plugin escalation on update — when false, Cabinet must re-prompt.

`GrantStore` is a flat map persisted as TOML. Missing file = default-deny empty store. Corrupt file = same — no panic, no lockout (user re-grants on next prompt).

**Tests (21, all pass):** 6 PluginGrants tests, 6 GrantStore tests, 9 enforce() tests covering each capability axis + the cross-product of declared-vs-granted denial paths.
