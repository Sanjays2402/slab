## Decisions

- **Rasterize, don't crack XObjects.** Re-use existing
  `ai::vision::render_page_image` (which we already trust + tested)
  rather than decoding /XObject /Subtype /Image streams. Same pixels
  → same SHA-256 → stable cache hit across reboots.
- **Cache by content hash, not by figure id.** Path
  `~/Library/Application Support/Slab/cache/alt-text/<sha>.txt`.
  Reruns are O(1) and survive any tree mutation.
- **Per-figure errors absorbed into stats.** A flaky llava call on
  figure 7 of 200 must not abort 8-15.
- **min_area_pt = 200.** Skips icons / bullets / 14×14pt logos.
