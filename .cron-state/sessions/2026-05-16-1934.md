## Gotcha discovered this tick
- Initial `cargo test --lib` run showed **86 failures** all with `PathError NotFound`. Diagnosed: my own earlier smoke test had `export TMPDIR=$(mktemp -d)` and that temp dir got `rm -rf`'d at the end, but `TMPDIR` was still exported in the shell. Every `tempfile::tempdir()` call then tried to create subdirs under the deleted path and failed. **Fix:** `unset TMPDIR` before running tests. Documented in STATE.md QUICK REFERENCE so future ticks don't waste time on this.
- One small clippy violation (`clippy::derivable_impls` on `SanitizeOpts`) snuck through a prior tick's commit `a52f707` — that tick was the aggressive sanitize ship and the clippy run there must have been on a stale cache. Fixed in `cb1b00f` as part of the version bump. Lesson: re-run full quality gates from a clean `cargo clippy` after merging multiple feature commits, even if each commit passed at the time.
