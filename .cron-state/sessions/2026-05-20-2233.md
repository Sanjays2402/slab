## Codebase-discovery decisions baked into the plan
- `Annotation` Rust enum confirmed at line 27-29 of
  `src-tauri/src/pdf/annotations.rs`: tagged-union, snake_case.
  Adding `Ink` variant is a straight enum extension, no struct
  redesign, no Tauri command signature changes.
- `build_annotation_dict()` is a single match — the new `Ink` arm
  emits PDF spec §12.5.6.13 `/Subtype /Ink` with `/InkList`, `/BS`,
  `/Rect` from the polyline bounding box + width/2 pad.
- `AnnotateLayer.svelte` already has `mode: "off" | "highlight" |
  "note"` — extending to `"draw"` is a type extension.
- pdfjs `eventBus.pagerendered` is the right hook for painting
  persisted ink strokes on initial render + zoom changes (same as
  v2.0.6's highlight overlay; ReaderPanel.svelte:677-688).
- Vim-style single-letter `d` mirrors v2.0.6's `h` and the existing
  `src/lib/vim/keymap.ts` pattern.
- Onboarding step math: 6 → 7 (v2.0.3) → 8 (v2.0.4) → 9 (v2.0.5)
  → 10 (v2.0.6) → **11 (v2.0.7)**.
- i18n namespaces `annotations.draw.*` / `palette.draw.*` /
  `settings.annotations.draw.*` / `onboarding.draw.*` all
  greenfield (slice 0 includes a JSON-collision pre-flight).
