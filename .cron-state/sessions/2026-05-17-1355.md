### Commit `91561da` — Slice 4 (all 3 tasks combined)
**feat(cabinet): persist + restore detached windows to ~/.slab/windows.json**

Three tightly-coupled tasks landed as one commit because they don't
ship independently:

1. **Persistence helpers** — `windows_json_path()` honours
   `SLAB_HOME_OVERRIDE` + `SLAB_CONFIG_DIR` for tests, falls back
   to `$HOME/.slab/`. `save_windows()` writes via temp+rename
   (atomic-ish). `load_windows()` returns `Ok([])` on missing file.

2. **Autosave** — extracted `wire_window_events()` shared by both
   `slab_window_open` and the new `restore_windows`. Persists on
   `Destroyed`/`Moved`/`Resized` events. `flush_to_disk()` swallows
   IO errors with `eprintln!` so disk hiccups never block detach.

3. **Launch restore** — new `setup(|app| { ... })` hook in `lib::run`
   calls `windows::restore_windows(&handle)`. Re-spawns each saved
   window at its persisted geometry, re-wires the same event
   handlers. Re-flushes registry so failed-to-restore entries are
   dropped from disk.

Plus `MAX_DETACHED_WINDOWS = 6` cap (RSS ceiling).

5 new tests with an `ENV_LOCK` mutex for env-mutation isolation:
- `save_then_load_roundtrips`
- `load_returns_empty_when_file_missing`
- `save_creates_parent_directory`
- `save_overwrites_previous_contents`
- `load_returns_error_on_corrupt_json`
