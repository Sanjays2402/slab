## Architecture decisions made on the fly
- `bootI18n` `<style>` literal in comment broke Svelte's HTML parser
  → reworded the comment to plain prose. Caught by pnpm check.
- For plugin theme CSS, used `tag.textContent = css` not innerHTML
  → defence in depth against malicious plugin CSS payload (parsed
  as CSS, never HTML).
- `lastSeen` Set in `bootI18n` short-circuits redundant bundle
  refetches on every `pluginsStore` emit.
- Reader toolbar button hidden entirely (not just disabled) when
  zero plugin PDF actions exist → no empty dropdown.
