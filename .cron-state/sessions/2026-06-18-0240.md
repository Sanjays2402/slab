## What
- `registry::set_tag_color(tag_id, Option<&str>)` — update or clear a tag's
  color, returns the updated row. Errors on unknown id; errors on invalid color
  without touching the row.
- `valid_tag_color()` guard — only persists `#rgb/#rgba/#rrggbb/#rrggbbaa` hex
  and `hsl()/hsla()/rgb()/rgba()` functional notations. Functional body limited
  to digits, dots, %, commas, spaces → no `;`, `{`, `url(`, quotes, `<>` can be
  stored (CSS-injection safe, since the value is dropped into a style property).
- No schema bump: the `color` column already shipped with `library_tags`.
- Tauri command `slab_library_set_tag_color` (emits library-changed), registered.
- TS `setTagColor(tagId, color)` client.
- UI: tag-rail per-row filled-dot button (beside delete ×, hover-revealed) opens
  a "Tag color" modal — live preview swatch + existing palette + a "Default"
  option that clears to the deterministic pastel. Save swaps the updated row
  into the rail + every doc card in place (no refetch).
