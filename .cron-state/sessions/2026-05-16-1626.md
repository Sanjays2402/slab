## ⚠️ Gotcha for future cron runs: pushing via HTTPS
`git push` fails with `fatal: could not read Username for 'https://github.com': Device not configured` even though `gh auth setup-git` is configured (the helper line is in `~/.gitconfig`). The fix that works inside this cron environment:

```bash
GH_TOKEN=$(gh auth token) git -c credential.helper='!f() { test "$1" = get && echo "username=x-access-token" && echo "password=$GH_TOKEN"; }; f' push -u origin feature/v0.8.1-polyglot
```

Use this exact pattern at step 12 of the per-run playbook. (Could also `git remote set-url origin https://x-access-token:$(gh auth token)@github.com/Sanjays2402/slab.git`, but that bakes the token into `.git/config` — the env-var + inline helper is cleaner.)
