## Process notes

- Drilldown CSV arc (88-91) follows the same four-layer cadence as
  rounds 15/16/17/18: pure-data primitive → Tauri command → TS client
  + suggest helper → demo-able UI. Slice 92 compressed click-to-filter
  into one composite UI commit because the backend axis already
  existed (slice 73's `plugin_id_substr`).
- The `RuleSample` `Default` derive in slice 88 is the only schema
  touch in the batch — purely additive (every field already had
  `serde(default)`) and lets the new test code spread
  `RuleSample { filename, ..Default::default() }` without listing the
  zero fields.
- The Tauri command in slice 89 takes `rule_names` as a parameter
  rather than reading from the registry server-side because the
  popover's `bucket_name` should match what the user SAW on screen
  even with unsaved name edits — same reasoning as slice 84's
  caller-supplied `candidate_rules`.
- Slice 90's slugifier deliberately NFD-strips diacritics (`café` →
  `cafe`) rather than transliterating (`café` → `caf` would silently
  drop info) — standard ASCII-fold pattern. Falls back to bare
  `rule-N` when nothing survives.
- Slice 91 ships the in-state drilldown verbatim to avoid racing the
  600ms `scheduleSave` that ripples into a drilldown refresh — a
  background rule edit could otherwise sneak in a different bucket
  between click-Export and click-Save. Snapshot-on-click matches
  what the popover renders.
- Slice 92's toggle-clears the plugin axis ONLY (not the action axis)
  because action chips are independent narrows; clearing both on a
  single bar click would feel like an undo'd batch operation.

## Design notes

- Export button placed BETWEEN Reload and Close (Reload → Export →
  Close reads as "refresh this view → save this view → done").
- Disabled-when-empty-bucket prevents a "the export failed silently"
  reading — an empty bucket would write just the header row otherwise.
- 4s toast duration matches the install-log export toast and the
  install-log retention toast — one duration across audit-export
  surfaces.
- Histogram row `.active` is accent-tinted (not check-marked) because
  the bar IS the row; a check mark would fight the bar visually.
- Click-row-twice-to-clear matches the slice 86 popover toggle pattern
  — the user's last action on the same surface should reverse itself.
