## Root causes (both subtle, both in v2.1.0 first cut)

1. **Docker workflow** `26271002054`: Dockerfile referenced
   `rust:1.83-bookworm-slim` — that tag does not exist on Docker Hub. The
   correct ordering is `rust:1.83-slim-bookworm` (variant BEFORE distro).
   Split `DEBIAN_RELEASE` into base `bookworm` so the runtime stage can
   append `-slim` independently.

2. **Tauri build workflow** `26270991776`: bundler tried to copy
   `target/x86_64-apple-darwin/release/server` and failed —
   `src-tauri/src/bin/server.rs` was auto-discovered by Cargo's autobins
   feature as an implicit bin named `server`, **in addition to** the
   explicit `[[bin]] name = "slab-server"` declaration. The desktop
   workflow doesn't pass `--features server`, so the binary was never
   built, but Tauri's bundler still listed `server` as a sidecar to
   copy. Moved the source out of `src/bin/` → `src/server_main.rs` so
   Cargo no longer auto-registers it; kept the explicit `[[bin]]` we
   control.
