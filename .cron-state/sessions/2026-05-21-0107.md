## Codebase-discovery decisions baked into the plan

- `selection.ts` refactor from `Writable<SelectionRef | null>` to
  `Writable<{ path, ids: Set<string>, primary }>` is a pure shape change;
  every v2.0.10 call site migrates mechanically via TS compiler errors.
- `#[serde(default)]` on the Rust `rotation: f32` field keeps every
  v2.0.6–v2.0.10 sidecar file readable without migration.
- TS migration writes v2 sidecar at rest on first v1 read — no extra
  Tauri commands; reuses existing `writeJsonFile` from sidecar plumbing.
- PDF `/Rotate` integer for true 90° multiples; non-multiples bake the
  rotation into Slab's on-render quad math (same as Acrobat). Documented
  as a known limitation in release notes.
- Mod+A collision with browser select-all: guarded by focused-element
  check (input/textarea → native; else → AnnotSelectAll).
- Mod+D no longer ambiguous (v2.0.10 already wired AnnotDuplicate vs
  BookmarksToggle via selection-null guard).
- Composite-command pattern from v2.0.10's `history.ts` scales to
  alignment + distribute + rotate without new history primitives.
- Live guide rendering via SVG `<line>` with 80ms keyframe pulse;
  respects `prefers-reduced-motion`.
