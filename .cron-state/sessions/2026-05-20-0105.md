## Codebase-discovery decisions that landed in the plan

1. **`CmdResult` is a tagged serde enum, not a Result alias.** Plan was originally written with `{ status, error }` shape; corrected mid-write to `{ kind, value/message }` in 4 places after grep'ing `src/lib/types.ts` + `src-tauri/src/lib.rs:124`.
2. **`.into()` on `Result<T, MyError>` requires a `From` impl.** Plan opens Slice 2 by adding `impl From<Result<T, IntrospectError>> for CmdResult<T>` next to the existing `From<Result<T, AiError>>` impl at line 498 — matches how 6 other error types already plug in.
3. **`mockito` is already a dev-dep** (line 123 of `src-tauri/Cargo.toml`). Slice 1 needs no new deps.
4. **Backend round-trip preserves the whole SlabConfig.** Frontend reads `SlabConfig`, mutates `.beacon`, writes the whole blob back. Slice 4 carries an opaque `fullConfig: unknown` to avoid modeling `ui`/`keymap` sections it doesn't touch — they round-trip verbatim.
5. **Insertion point in `SettingsPanel.svelte` is between Language (line 105) and Theme (line 129).** Plan uses surrounding-line anchors, not absolute line numbers, so it survives drift.
