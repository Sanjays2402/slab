### Commit 3 — `feat(press): color_normalize pass — install ICC DefaultRGB/Gray/CMYK on every page (Slice 2)`
- `src-tauri/src/pdf/press/color.rs` (548 lines incl. tests).
  - Strategy: install `/DefaultRGB` + `/DefaultGray` + `/DefaultCMYK`
    in each page's `/Resources/ColorSpace` per ISO 32000 §8.6.5.6.
    Avoids content-stream rewriting (no risk to ExtGState / Type 3).
    Same approach Adobe / PitStop / callas use.
  - Shared `/ICCBased` stream uploaded once and referenced by every
    page's DefaultCMYK — keeps PDF size flat under 1000-page input.
  - `CalRGB` / `CalGray` synthesized with sRGB-equivalent params for
    RGB / Gray defaults.
  - ICC header parser reads `acsp` magic + bytes 16..20 colour-space
    tag to derive `N` for the ICCBased dict.
  - Idempotent under double application; preserves existing Default*.
  - 10 unit tests covering happy paths, errors, idempotency,
    cmyk_only mode, empty-doc, shared-stream identity.
