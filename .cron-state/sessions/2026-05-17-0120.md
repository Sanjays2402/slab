### Commit `3e93038` — Slice 3 backend
New composite kernel `pdf::pages_build` + Tauri commands `slab_pages_build`, `slab_outline_starts`.

The `pages_build` kernel handles **every cell mutation in one Tauri call**:
- arbitrary source multisets (duplicates allowed)
- blank-page inserts at arbitrary positions
- per-cell rotation in {0, 90, 180, 270}

Pipeline composes existing primitives:
1. `extract_pages_to` for the non-blank source multiset
2. `insert(InsertSource::Blank)` for each blank cell at its 1-based index
3. `rotate_pages` grouped by angle

14 unit tests:
- `build_pure_reorder`, `build_subset_deletion`, `build_with_duplicates`
- `build_with_blank_at_start`, `build_with_blank_in_middle`, `build_multiple_blanks`
- `build_with_rotation`, `build_combo_dup_blank_rotate`
- `build_custom_blank_size`
- Validation: `build_rejects_empty_cells`, `build_rejects_all_blank`, `build_rejects_out_of_range_source`, `build_rejects_bad_rotation`, `build_missing_input`

206 → 220 lib tests (+14).

### Commit `5807fe4` — Slice 3 UI
`PagesVisualPanel.svelte` was scaffolded by a previous tick but its `applyChanges()` was a 100-line apology essay — chained `slab_delete_pages` + `slab_reorder_pages` + `slab_rotate` calls with explicit error messages saying "blanks and duplicates won't work, use the other panel, sorry, v0.11.1 will fix it."

Rewrote it as a single 30-line `slab_pages_build` call. Removed all the user-facing limitations. The visual panel now lets you do anything the grid suggests.

Sidebar:
- `▦ Pages` → `PagesVisualPanel` (new default, drag-reorder grid)
- `≣ Pages (list)` → `PagesListPanel` (renamed from old `PagesPanel.svelte` for keyboard workflows)

Also corrected the blank-page sizing logic — uses the first rendered cell's aspect ratio scaled to a Letter-width baseline, falls back to US Letter when no cell has dimensions.

### Commit `3393697` — Slice 4 SplitPatternPanel
`SplitPatternPanel.svelte` (~370 LOC) wraps the chapter-splitter backend shipped in Slice 2.

Features:
- Two modes: **By regex** (default) and **By outline** (TOC-based)
- 5 preset chips covering 80% of real books (Chapter N / CHAPTER N / Part N / Section N / numbered headings)
- Live **Preview** button — runs `slab_find_matching_pages` or `slab_outline_starts` without writing any files, then renders match pages as mono-font chips
- Special "p1 (cover)" pill when the first match isn't page 1 — visually communicates the backend's preface-bundling rule
- Friendly regex error mapping (`invalid regex: …` → `Invalid regex: …`)
- Empty-state hints: regex with zero matches suggests switching to outline mode; outline with no entries suggests switching to regex

Sidebar nav `✂ Split by Chapter` between Split and Pages.
