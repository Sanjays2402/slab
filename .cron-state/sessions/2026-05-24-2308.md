## Notes

- The mod.rs `tests` integration block builds its own tiny AcroForm
  PDF in lopdf (no fixture file) to avoid touching the shared
  `pdf::test_fixtures` module. Pattern mirrors the existing forms.rs
  `build_fixture` test helper.
- Mapper handles model "creativity" gracefully: ```json fences are
  stripped, malformed JSON becomes a warning (not an error), numeric
  and boolean JSON values are coerced to strings for `forms::fill`,
  and unknown extra keys are surfaced as a warning so prompt drift
  is debuggable.
- Confidence scoring: 1.0 if the suggested value is a substring of
  the source text (the AI literally pulled it out), 0.85 if it
  came from somewhere else (could be a hallucination, low priority
  for the UI), 0.0 if missing/empty.
