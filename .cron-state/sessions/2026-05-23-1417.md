## Notable engineering choices
- ECDSA signing deferred to v3.10.1: cms 0.2 builder bounds don't compose
  cleanly with `ecdsa::SigningKey`. ECDSA *identities* still load and
  return a clear `UnsupportedAlgorithm` error at sign time.
- DER outer-length trim on `/Contents` bytes before parsing — strips the
  trailing zero padding from the hex placeholder.
- `/Contents` locator skips occurrences whose value isn't a `<hex>` string
  (avoids the page dict's `/Contents` array).
- Trust store load-with-fallback in the verify Tauri command so users
  without `~/.local/share/slab/signet/trusted/` still get useful results
  (SelfSigned for self-signed test certs, Untrusted for unknown).
