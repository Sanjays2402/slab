## What shipped (3 commits on `feature/v1.0.0-glass`)

  - Backend: `UiConfig { theme, accent, density }` extension to
    `SlabConfig`, lowercase serde rename, `#[serde(default)]` for

    (`slab_ui_config_read` + read-modify-write `slab_ui_config_write`).
    7 new unit tests (14/14 ai::config passing).
  - Theme runtime: `src/lib/theme.ts` 175 LOC (writable store +

    MQL listener for auto-mode).

    `[data-density]` attribute selectors. Light palette, 5 accents,
    compact density tokens. Zero-flash for v0.x upgraders.
  - `SettingsPanel.svelte` 274 LOC — Linear/Arc-quality 3 settings
    rows, swatch grid for accents, live apply, Reset button.
  - Wired into `+page.svelte` nav (⚙ Settings) and Command Palette
    (Theme/Accent/Density quick-switch under new "Appearance" group).
  - bootTheme() called from `+layout.svelte` onMount.

- **Slice 2 (9fe816c)** — Keyboard Shortcuts overlay:
  - New `ShortcutsOverlay.svelte` — 5 groups (Global, Reader tabs,
    Reading, Beacon, Navigation), platform-aware mod key, two-col
    grid, Esc + backdrop close.
  - `?` global binding (suppressed in input/textarea/contenteditable).
  - Command Palette gained "Help" group with "Keyboard shortcuts"
    entry.

- **Slice 3 (9b0f638)** — Global toast notification system:
  - New `$lib/notify` — typed API
    (`notify.success/error/info/warning`), kind-specific durations,
    sticky-on-zero.

    detail subline, manual ×.
  - SettingsPanel save errors now raise toast with detail; reset
    fires success toast.
