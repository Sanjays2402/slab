## Key technical decisions
1. **Auth model for plugin AI providers**: `bearer_auth` is skipped when
   api_key is empty, so plugin-contributed providers default to
   header-only auth (`Authorization = "Bearer $TOKEN"` via headers map).
   This is cleaner than introducing an api_key_env to AiProviderContribution.
2. **Env var syntax**: whole-value `$VAR_NAME` only (no braces, no
   concatenation). Predictable, hard to mis-template. Resolved at
   request time so transient env unsetting fails cleanly instead of
   permanently breaking a provider.
3. **30s default timeout for command runner** — matches PDF action
   runner default for consistency.
4. **URL command sentinel pattern**: `command_runner` returns
   `CommandOutcome::Url { url }` rather than calling opener from Rust.
   Keeps the module testable and runtime-free. Frontend dispatches.

## Lessons / gotchas
- Lint runner mis-reports `async fn` as Rust-2015 errors (Cargo.toml
  is edition 2021). Real `cargo build`/`cargo test` succeed. Ignore.
- `mockito::Matcher::Missing` matches absent headers — used in
  materialiser test to confirm no `Authorization` header is sent for
  plugin providers with no auth configured.
- `OpenAiCompatibleProvider` doesn't derive `Debug`, so `unwrap_err()`
  on a `Result<provider, _>` doesn't compile. Pattern-match instead.
