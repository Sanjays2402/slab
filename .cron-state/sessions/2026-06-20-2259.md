PluginDetailDrawer Activity section + RecentInstallsDrawer. The closing notes

## Design notes

- Two timestamp columns in the CSV (unix + ISO) — developers join on
  unix-seconds in shell pipelines, paralegals read ISO in Excel. Both
  cost almost nothing per row; picking one and being wrong is friction
  every time someone opens the file.
- JSON envelope schema_version starts at 1 (not 0) — v0 = "draft", v1 =
  v1.0.0 contract; additive changes stay at v1, breaking changes bump.
- Export menu in the footer (not the header) because header = "what am I
  looking at", footer = "what can I do with it". Clear/Close were already
  there; adding Export keeps the action vocabulary in one place.
- Export menu uses subtitles surfacing the window scope so the user sees
  what they're about to export BEFORE clicking; this matches Notion's
  pattern of "make the obvious choice obvious".
