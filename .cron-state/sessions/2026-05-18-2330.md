## What's live now
`await slab.fetch(url, init?)` works inside runtime plugins:
- Returns `Promise<Response>` matching the web Fetch spec subset
- `Response.{status, statusText, ok, url, headers, text(), json()}`
- 4xx/5xx resolve with `ok=false` (Fetch semantics — only network failures reject)
- Capability gated synchronously: `NetFetch { host }` against `net_allow_hosts`
- 30s default timeout (clamped `[1, 120_000]` ms), 16 MiB body cap, 10-redirect chain
- Process-shared `reqwest::Client` (rustls, cookies off)

## Key design decisions
1. **Worker-local PendingFetches map** keyed by `request_id` instead of stuffing
   `Persistent<Function>` callbacks into `RuntimeCmd` directly. `Persistent`
   wraps `*mut JSRuntime` which is `!Send`; `RuntimeCmd` MUST stay `Send +
   Clone` (channel + Tauri state). Solved by carrying only `(request_id,
   FetchRequest)` over the wire.
2. **`reqwest::Url` re-export** instead of adding `url` as a direct dep.
3. **`execute_pending_job` drain loop** after Promise settlement so awaiting
   `.then` bodies fire in the same dispatch tick.
4. **Promise via `rquickjs::Promise::new(&ctx)`** returns `(promise, resolve,
   reject)` triple directly — way cleaner than building executor closures.
