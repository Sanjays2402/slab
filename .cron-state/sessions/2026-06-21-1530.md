## Arc A — Hopper sample drilldown (slices 83-86)

Closes the round-17 "Hopper sample-set explorer" candidate. The
coverage panel could show per-rule bars but clicking a row was a
dead affordance. Now clicking opens an in-panel popover with the
files in that bucket.

- **7fc3463 — slice 83: drilldown primitive** (389 LOC,
  +15 tests, coverage.rs).
  Pure-data `compute_sample_drilldown(rules, samples, bucket,
  preview_cap)` returning `SampleDrilldown {bucket, samples,
  total_in_bucket, truncated}`. `SampleBucket` enum tagged
  `{kind: "rule"|"fallthrough"}`. O(rules*samples) — same shape as
  compute_coverage; deliberately separate primitive because
  winners aren't carried in the coverage report's count-only
  shape. Cap clamps [1, 5000]. Out-of-range index returns empty.
- **80e03bc — slice 84: Tauri command** (+130 LOC,
  +5 helper tests, cmds.rs + lib.rs).
  `slab_hopper_sample_drilldown` mirrors `slab_hopper_rule_coverage`
  on every input axis so a click drills into the EXACT same
  sample set the report counted. `clamp_preview_cap` default 25,
  clamped [1, 1000]. Test pins drilldown default <
  coverage default so a future tweak that breaks the ordering
  is loud.
- **6c4fa84 — slice 85: TS client + helpers** (288 LOC across
  hopper.ts + hopper.test.ts, +19 tests).
  `SampleBucket` discriminated union. `FALLTHROUGH_BUCKET`
  singleton + `ruleBucket(i)` constructor (throws on negative/
  non-integer — client-side bugs deserve loud failures).
  `slabHopperSampleDrilldown` wrapper. Three pure helpers:
  `sampleBucketEquals`, `describeDrilldown` (singular/plural/
  truncated copy), `describeBucket` (named rule / "Rule #N"
  fallback for missing/empty/whitespace/out-of-range names).
- **e38a358 — slice 86: clickable rows + popover** (421 LOC in
  HopperRulesEditor.svelte).
  Coverage rows now `<button>`s with button reset; `.open`
  accent tint + focus-visible ring + chevron column. Shared
  `{#snippet renderDrilldownBody}` for rule + fall-through.
  Popover header: bucket label + live summary + previewCap input
  + Reload + Close. Body: monospace file list (max-height 260px,
  scrolls inside popover not editor). Bucket-specific empty-
  state copy. scheduleSave refreshes open drilldown so bucket
  reshapes live. Window-level Escape closes. ~135 lines scoped
  CSS.

## Arc B — Per-plugin install histogram (slice 87)

Closes the round-17 "install-log drawer's coverage-like aggregate"
candidate. One composite slice (backend + cmd + TS + UI) because
each layer is small and they're tightly coupled by one new data
shape.

- **a0504dc — slice 87** (783 LOC across install_log.rs +
  lib.rs + marketplace.ts + RecentInstallsDrawer.svelte,
  +13 tests).
  Backend: `PluginHistogramRow` {plugin_id, installs, updates,
  uninstalls, failures, total, last_occurred_at}. New
  `plugin_histogram(since, until, limit)` method with ONE indexed
  GROUP BY (plugin_id, action) + in-memory sort by total DESC
  (tiebreak ASC on plugin_id). Conservation invariant test.
  Tauri: `PluginHistogramResult` envelope with grand_total +
  echoed limit_used. TS: wrapper + `summarizeHistogram` helper.
  UI: collapsible "Top plugins" section between retention block
  and events list. Per-row stacked bar scaled relative to top
  row's total — install green / update accent / uninstall
  amber / failed red. Counts cell with action-glyph chip strip.
  Auto-refreshes on window change.
