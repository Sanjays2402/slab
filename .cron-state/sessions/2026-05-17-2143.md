## Decisions worth flagging

- **Signing tool placement**: spec said `tools/sign-plugin/src/main.rs`
  (separate crate). I made it a second `[[bin]]` in `src-tauri/`
  instead, matching the existing `slab` CLI binary pattern. Simpler,
  no workspace conversion needed, lets the tool reuse `slab_lib`
  directly for byte-identical canonicalization. Documented in commit
  message.

- **Path-traversal tests**: the `tar` crate's encoder refuses to even
  set unsafe paths on a Header, so I can't easily round-trip a
  malicious tarball through Builder. Switched those two tests to
  hit `sanitize_entry_path` directly — same coverage, less brittle.

- **README badge**: a sibling subagent updated the test count to 581
  (matching exactly what `cargo test --lib` now reports). Folded
  into the polish commit.
