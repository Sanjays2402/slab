## What shipped
- **Backend** (`src-tauri/src/windows.rs`, ~440 LOC): `WindowState`,
  `Geometry`, `WindowRegistry` (thread-safe with Mutex), three Tauri
  commands (`slab_window_open`/`slab_window_close`/`slab_window_list`),
  `default_geometry_for_panel`, `encode_doc_param`, `title_case`.
  Registry self-cleans on `WindowEvent::Destroyed`. 12 unit tests
  cover roundtrip, CRUD, label generator, geometry presets, URL
  encoding, title casing.
- **Capability** (`capabilities/default.json`): `windows: ["main",
  "panel-*"]` so detached windows inherit slab_* permissions.
- **Frontend chrome** (`src/lib/components/DetachedShell.svelte`,
  75 LOC): thin 32px titlebar + flex body. Svelte 5 Snippets for
  children.
- **Frontend route** (`src/routes/+page.svelte`): URL param parsing in
  onMount, `{#if detached}...{:else}{/if}` wrapper around the whole
  existing UI. Supported detachable panels: Beacon, Library, Search,
  PII, Reader (with initial doc).
