## What shipped
Rename a tag everywhere it is used, with an inline edit on the tag rail.

- **Backend (44444f8):** `LibraryDb::rename_tag(tag_id, new_name)` — one
  UPDATE on library_tags. Doc links live in library_doc_tags keyed by tag_id
  (not name), so the rename propagates to every document + live tag
  co-occurrence with no migration and no orphans.
  - trims; same-name = no-op returning unchanged row
  - pure case change (research->Research) is a valid distinct rename (BINARY collation)
  - collision with a *different* tag's name is REJECTED (UNIQUE col) — no silent merge; both rows left untouched
  - empty name + unknown id error without touching any row
  - 8 new registry tests; 1 Tauri command `slab_library_rename_tag` (returns updated TagRecord)
- **UI (161dfbb):** `renameTag` TS client + inline rail edit. Pencil glyph
  (beside color dot + delete x) swaps the row label for an auto-selected text
  input (`focusSelect` action). Enter commits, Escape/blur cancels,
  unchanged/empty short-circuits with no round-trip. Success swaps the row
  into the rail + every doc card in place (no refetch, mirrors v3.42.0 color
  editor). A rejected rename keeps the row in edit mode with the backend
  reason shown inline so the user can fix + retry.
