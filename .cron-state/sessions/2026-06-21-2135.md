## Notes

- Round-19's closing notes flagged "drilldown JSON export envelope
  (mirror the install-log JSON envelope so the CSV + JSON pair
  stays symmetric across audit surfaces)" as the lead candidate;
  slices 93-96 close that arc end-to-end with the same four-layer
  cadence as five prior arcs (round-15 bulk-update 68-72,
  round-16 install-log filter 73-77, round-17 hopper coverage
  79-82, round-18 hopper drilldown 83-86, round-19 drilldown CSV
  88-91).
- The schema_version=1 alignment with the install-log envelope
  is intentional - a downstream consumer reading either audit-
  export JSON recognises the v1 contract by name. Parallel-
  versioned (each envelope bumps independently) not joint-
  versioned because the bodies are unrelated.
- The bucket_csv_labels helper from slice 88 was the seam that
  let the JSON envelope reuse the CSV's exact bucket-name
  fallback chain. Both formats now agree byte-for-byte on the
  label.
- The ext slot on suggestDrilldownExportFilename is the smallest
  possible surface-area extension - one new key in the opts bag
  rather than a parallel suggestDrilldownJsonExportFilename
  helper. Default "csv" preserves every existing call site
  verbatim.
- sortHistogramRows returns a NEW array deliberately - in-place
  sort on a Svelte 5 $state proxy surfaces reactivity bugs, and
  the server payload should stay untouched so a later sort-axis
  switch sees the original rows.
- No uninstalls sort axis: uninstall-heavy plugins are an
  antipattern users spot via the bar's amber segment, not via
  sort. Four count axes + recent timestamp axis = five lean menu
  items rather than seven.
