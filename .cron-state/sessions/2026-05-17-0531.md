## Backend (`pdf::table_extract`)

- Shells out to `pdftotext -bbox-layout` (poppler) for per-word XHTML bboxes.
- Hand-rolled XHTML scanner (pdftotext's output is mechanically simple; no
  need to pull in quick-xml as a dep).
- Row clustering: y-band overlap ≥50% of word height → same row.
- Column clustering: 1-D x-min gap > 12pt → new column.
- Each word snaps to the nearest column center.
- RFC-4180 CSV serializer (every cell quoted, inner `"` doubled).
- 16 tests: parse_attr, parse_bbox_xml (2-word + entity-unescape + non-word-line skip),
  cluster_1d (multi-group + single-cluster), cluster_rows y-overlap grouping,
  detect_tables on synthetic 3×3 grid + below-min + empty rejections,
  CSV RFC-4180 + empty-table, Table JSON round-trip, 2 end-to-end via the new
  `make_table_pdf` fixture (gated on pdftotext availability).

## Frontend (TablesPanel.svelte, ⊞ Tables → CSV)

- File picker + page input + min-rows/min-cols knobs + Detect button.
- One card per detected table:

  - Header row visually distinguished
  - Copy CSV (clipboard) + Save CSV… (save dialog) buttons
- Toast notifications for copy/save results (auto-dismiss 2.2s).
