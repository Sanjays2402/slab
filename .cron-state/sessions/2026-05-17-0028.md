## Gotchas learned this tick
- A `pnpm-lock.yaml`-only conflict resolution will silently desync from `package.json` if you run `pnpm update <pkg>` after. CI catches it with `frozen-lockfile`, not pnpm itself. **Always re-check `git diff package.json` after running pnpm during a merge.**
- `OutlineNode` field is `page_index: Option<u32>` (0-based!), not `page`. I almost shipped a bug here — caught by `cargo check` immediately.
- `make_n_page_pdf` test fixture stamps "Slab page {n}", not "Page {n}". Two tests had to be updated after first run.
