## Design decisions worth remembering
- **No SummaryStrip route** — summary results live in the chat panel as assistant turns so users can ask follow-up questions ("clarify bullet 3"). One panel, one mental model.
- **Buffered chat, not streaming** — v0.10.0 ships single-shot responses. Streaming is a polish item for v0.10.1; the trait signature stays compatible.
- **No cache for summaries yet** — local Ollama is free + fast; cache lands when we add sqlite-vec for semantic search (Slice 6).
- **In-memory MockProvider over mockito for chat/summary tests** — chat & summary are higher-level than provider plumbing; we don't need HTTP fixtures, just a captured-messages stub.
- **Citation parser is hand-rolled** — handles `[pN]`, `[p N]`, `[page N]`, `[pages 2, 5, 9]`, `[pp 3]`; rejects footnotes `[1]` and dates `[2026-05-01]`. Fully unit-tested.
