## Slice 66 — `ec2b9ac` — auto-prune install log on app startup (36 LOC)

- Wired into `.setup(|app| { ... })` callback right after the Hopper bootstrap.
- Best-effort + non-fatal: open failure logs to stderr, Slab boots normally.
- Outcome handling:
  - Pruned + rows_removed > 0 → stderr audit line ("marketplace install-log:
    auto-pruned N event(s) older than M day(s)").
  - Pruned + rows_removed == 0 → silent (clean log shouldn't add boot noise).
  - Skipped → silent (dominant case on healthy log).
- Honours the same debounce the UI button uses.
