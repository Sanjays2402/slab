# v0.13.0 "Lens" — OCR + Vision

> Image-only PDFs become first-class citizens.

**Goal:** Make Slab handle scanned PDFs as naturally as it handles text-native PDFs — auto-detect, auto-OCR if the user wants, extract tables → CSV, equations → LaTeX, ask vision questions in Beacon, auto-tag on import.

**Architecture:** Layered on top of existing `pdf::ocr` (Tesseract sidecar). Add a *scan-audit* layer that classifies each page as text/image/mixed, then a *triggers* layer (Reader banner, Library auto-OCR queue), then vision (llava/Ollama) and table extractors.

## Slices

### Slice 1 — Scan-Audit Backend + Auto-OCR Banner (THIS TICK)
Detect whether a PDF is text-native, fully scanned, or mixed. Expose `slab_scan_audit` IPC. Reader shows a banner offering one-click OCR for image-heavy PDFs.

- Backend `pdf::scan_audit` module
  - `PageClassification { Text, Image, Mixed, Empty }`
  - `ScanAuditReport { pages: Vec<PageClassification>, text_pages, image_pages, mixed_pages, empty_pages, recommended_action: Recommendation }`
  - Heuristic: extract_text per page; if non-whitespace chars >= 40 → Text; if page has XObject Image references and no text → Image; if both → Mixed; else Empty
  - 8+ unit tests with synthetic fixtures (text-only, image-only, mixed, empty, multi-page combos)
- 1 new Tauri command `slab_scan_audit(input: PathBuf) -> CmdResult<ScanAuditReport>`
- TS client binding in `src/lib/lens.ts`
- ReaderPanel: on open, call scan_audit in background. If `recommended_action == OcrAll` show a dismissible banner "This PDF looks scanned — make it searchable?" with [OCR Now] [Dismiss]
- Quality gates green on this slice.

### Slice 2 — Library Auto-OCR Queue
- Library scanner records `is_scanned` per doc.
- `slab_library_ocr_queue_list`, `slab_library_ocr_queue_run` — background worker (Tauri command spawns task) that OCRs queued docs sequentially.
- LibraryPanel shows OCR status pill per card; bulk-action "Run OCR on N scanned docs".

### Slice 3 — Table Extraction → CSV
- New `pdf::table_extract` module using `pdftotext -layout` plus a simple column-aligner heuristic.
- `slab_extract_tables(input, page) -> Vec<Table>`; Table → CSV.
- Reader sidebar: Tables tab with copy-as-CSV / save.

### Slice 4 — Equation Extraction → LaTeX
- Vendored `pix2tex` (or `latex-ocr`) python sidecar (optional preflight check).
- User drags a rect over equation → `slab_equation_ocr(input, page, rect) -> String`.
- Reader: selection action "Copy as LaTeX".

### Slice 5 — Vision Q&A in Beacon
- `ai::vision` module: `VisionProvider::ask(image_bytes, prompt) -> stream<String>` backed by Ollama `llava`.
- BeaconChatPanel: when user uploads a page region (rect or full page rasterized), enclose as image part in chat turn.
- Streaming via existing chat event channel.

### Slice 6 — Auto-Tag on Import (Library)
- After Library OCR completes, run a one-shot LLM prompt to suggest 3-5 tags.
- LibraryPanel: "Auto-tag" button per doc + bulk auto-tag.

### Slice 7 — Vision Auto-OCR Trigger Improvements
- When auto-detect flags `Mixed`, offer "OCR image regions only" (keep vector text intact). Requires per-page rasterize + invisible-text-layer overlay (the harder path from the OCR module).
- Defer to v0.14 if too heavy.

### Slice 8 — CLI Surface
- `slab lens audit <file>` → prints report.
- `slab lens ocr <file>` → existing ocr but with progress bar.
- `slab lens tables <file> <page>` → prints CSV.

- Version bump 0.12.0 → 0.13.0 across Cargo.toml, tauri.conf.json, package.json.
- Release notes `docs/release-notes/v0.13.0.md`.
