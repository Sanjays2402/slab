# v3.32.0 "Atlas" — Collections & Smart Library

> **For Hermes:** Use subagent-driven-development skill to implement task-by-task.

**Goal:** Turn Slab's flat document library into a workspace with user-curated
**Collections** (manual groups) and **Smart Collections** (saved searches that
update live), reachable from the sidebar and command palette.

**Architecture:**
- New SQLite tables `library_collections` + `library_collection_docs` +
  `library_smart_collections` (saved-search definition JSON).
- Rust commands: `slab_collection_create / list / rename / delete / add_docs /
  remove_docs / list_docs`, plus `slab_smart_collection_*` variants.
- Frontend: new `CollectionsSidebar.svelte` rail on Library panel; collection
  detail = filtered Library view; Cmd+K palette entries to jump to / add to a
  collection; drag a doc onto a collection node to add it.

**Tech Stack:** rusqlite (existing `LibraryDb`), svelte 5 runes, Tauri 2,
Lucide icons, existing Liquid Glass tokens.

---

## Buy-Button justification

- **Pick-us test:** PDF Expert has "Folders" but no smart/saved searches.
  Acrobat's collections are cloud-only. Slab gives both, offline, free.
- **Notice-it test:** Library sidebar gains a "Collections" section with
  user-defined entries — visible the first time they reopen Slab.
- **Tell-a-friend:** "Recently scanned & untagged" smart collection that
  auto-fills as you import — magic.

## Wow moment

**Animated count badges** on each collection that tick up live as new
matching docs arrive via the scanner. Pulse highlight when a new doc lands.

**Files:**

**Step 1:** Write failing test `collections_table_exists_after_open`.

**Step 2:** Run `cargo test -p slab --lib library::registry::tests::collections_table_exists_after_open` → FAIL.

**Step 3:** Add to migration:
```sql
CREATE TABLE IF NOT EXISTS library_collections (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  icon TEXT,
  color TEXT,
  created_at INTEGER NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0
);
CREATE TABLE IF NOT EXISTS library_collection_docs (
  collection_id INTEGER NOT NULL REFERENCES library_collections(id) ON DELETE CASCADE,
  doc_id INTEGER NOT NULL REFERENCES library_documents(id) ON DELETE CASCADE,
  added_at INTEGER NOT NULL,
  PRIMARY KEY (collection_id, doc_id)
);
CREATE TABLE IF NOT EXISTS library_smart_collections (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  icon TEXT,
  color TEXT,
  query_json TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0
);
```
Bump `SCHEMA_VERSION`.
