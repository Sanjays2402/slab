# v1.2.0 "Glass II" — Vim Bindings, A11y, i18n

> **For Hermes:** Plan is intentionally compact. Each slice is a vertical, shippable chunk. Ship one or two slices per tick. Slice 1 → Slice 6.

**Goal:** Round out Slab 1.x with three accessibility / power-user features that 1.0 deferred — modal keyboard navigation (Vim), screen-reader / contrast / focus accessibility (a11y), and runtime locale switching (i18n).

**Architecture:** Three orthogonal subsystems, each implemented as a self-contained TypeScript module under `src/lib/` plus a small Svelte store. No backend changes for Slices 1–4; backend touched only for i18n catalog loading (Slice 5) and a11y label fixes (Slice 6).

**Tech Stack:** Svelte 4 + TypeScript, no new runtime dependencies. We hand-roll the Vim machine (other libs are too heavy + commercial-license). For i18n we use the existing `Intl.*` APIs + a simple ICU-lite catalog.

## Slice 2 — Vim Bindings in Reader Panel

**Objective:** Wire the Vim machine to the Reader panel (scroll, page nav, jump-to-page, search).

**Mappings:**
- `j` / `k` — scroll down/up by 80px
- `gg` / `G` — first / last page
- `<C-d>` / `<C-u>` — half-page scroll
- `n` / `N` — next / prev search match
- `/foo<CR>` — search "foo"
- `:42<CR>` — jump to page 42
- `:q` — close current doc tab

**Tasks:**
1. Add `VimController.svelte` wrapper component.
2. Wrap `<ReaderPanel>` with it (opt-in via `vimEnabled` user setting).
3. Wire keydown → `dispatchKey`.
4. Translate `VimAction` → reader operations (scroll, page change, search store mutate).
5. Visual mode indicator (small pill bottom-left of reader).
6. Tests for the action-translation layer.
7. Commit set.
