# v3.9.0 "Quill" — PDF Forms Inspector + Round-Trip Fill

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a complete forms workstation that inspects AcroForm fields in any
PDF, exports them as a JSON template, accepts a filled-back JSON and round-trips
it into a new PDF with field values populated (NeedAppearances=true so viewers
regenerate appearances). Enterprise-grade. Acrobat charges for this; we don't.

**Architecture:**
- `src-tauri/src/pdf/forms.rs` — lopdf-based AcroForm walker: enumerate fields
  (with /T name, /FT type, /V current value, /Rect, page index), set values,
  set /NeedAppearances=true on `/AcroForm`, write a flag report.
- Two Tauri commands: `slab_forms_inspect(input) -> FormsReport` and
  `slab_forms_fill(input, values, output) -> FillReport`.
- Front-end panel `FormsPanel.svelte` — table of fields + value editor + Inspect
  / Export JSON / Import JSON / Fill buttons. Cmd+Shift+F shortcut.

**Tech Stack:** lopdf 0.40 (Rust backend), Svelte 5 + Tauri 2 (frontend).
