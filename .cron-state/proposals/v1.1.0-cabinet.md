# v1.1.0 "Cabinet" — Multi-Window Floating Panels (proposal stub)

**Status:** Plan promoted to `docs/plans/2026-05-17-v1.1.0-cabinet.md`.

**One-liner:** Detach any Slab panel into its own native window with
persisted geometry. Beacon next to your reader, Library on a side
monitor, two PDFs side-by-side.

**8 slices, ~20 tasks, ~3-4 ticks if aggressive (Slices 1+2 in one tick,
3+4 in the next).**

See the full plan at:
- `docs/plans/2026-05-17-v1.1.0-cabinet.md`

Key tech choices:
- `WebviewWindowBuilder` + URL params (`?panel=&windowId=&doc=`)
- New `windows.rs` module with `WindowRegistry` + serde
- Persistence: `~/.slab/windows.json`
- Capability glob `panel-*` so detached windows can invoke `slab_*`
- Hard cap of 6 detached windows for sanity

Next step: tick 1 implements Slice 1 (backend registry + Tauri commands).
