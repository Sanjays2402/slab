# v0.10.0 "Beacon" — BONUS Slices (11-15)

Original spec had 10 slices (chat, summary, search, PII, selection, release prep).
These 5 BONUS slices extend Beacon into a "kitchen-sink AI" release that locks in the
"chat with your PDFs without sending them anywhere" pitch.

**All bonus slices reuse already-built infrastructure**: `AiProvider` trait, chunker,
sqlite-vec index, BeaconChatPanel. Zero new external deps unless noted.

Ship order: 11 → 12 → 13 → 14 → 15. Each ~1 cron tick of work.

---

## Slice 11 — Smart Outline (regenerate TOC from content)

**Why:** Half the PDFs in the wild have no outline, or a garbage 3-line one. Beacon
proposes a meaningful hierarchical TOC from the *actual content* via the chunker.

**Backend:** `src-tauri/src/ai/outline.rs`
- `propose_outline(pdf_path) -> Vec<OutlineNode>` — chunk the doc, ask provider for
  H1/H2/H3 candidates with page numbers, validate citations exist, dedupe by similarity.
- Reuses `Chunker` from Slice 6. Low-temperature (0.1) JSON-mode prompt.
- Tauri commands: `slab_beacon_propose_outline`, `slab_beacon_apply_outline` (writes
  to the PDF's `/Outlines` tree using existing outline editor from v0.8).

**UI:** New action button in OutlinePanel (existing): "✦ Suggest outline (Beacon)".
Shows diff (current vs proposed) with accept/reject per node.

**Tests:** 4 — chunker output, JSON parse, citation validation, dedup.

## Slice 12 — Citation Extractor & Bibliography

**Why:** Academic / legal / longform readers always need this. Beacon walks the doc,
finds every citation, dedupes, and emits a clean bibliography.

**Backend:** `src-tauri/src/ai/citations.rs`
- Detect inline citation patterns (`(Author, Year)`, `[1]`, `[Smith2020]`, footnote refs).
- Extract reference list section from doc (last 1-3 pages usually).
- Resolve inline → full reference via fuzzy match.
- Export: BibTeX, RIS, plain text, markdown.

**UI:** "Citations" toolbar action in BeaconChatPanel. Opens side-sheet with list,
per-citation context popover, copy-as-{bibtex|ris|md}, "Open DOI" buttons.

**Tests:** 6 — regex coverage, fuzzy match scoring, BibTeX format, RIS format.

## Slice 13 — Study Mode (Q&A flashcards)

**Why:** Slab's already great for reading. Make it great for *learning*. Beacon turns
the doc into a deck of Q&A flashcards with spaced-repetition scoring (SM-2 lite).

**Backend:** `src-tauri/src/ai/study.rs`
- `generate_deck(pdf_path, count) -> Vec<Flashcard>` — chunk-by-chunk Q&A generation
  with a strict "must be answerable from this chunk alone" guardrail.
- Sqlite table `study_cards` (id, pdf_hash, q, a, page, ease, due_at, last_seen).
- SM-2-lite review scheduler.

**UI:** New "✦ Study" view in Beacon sidebar entry. Card front/back flip, 4-button
ease scale (again/hard/good/easy), session stats.

**Tests:** 5 — card generation, dedup, SM-2 scheduling, due-card query, session stats.

## Slice 14 — Glossary Builder

**Why:** Technical / domain-specific PDFs have unfamiliar jargon. Beacon mines the
doc for technical terms and proposes definitions (in-context, with citations).

**Backend:** `src-tauri/src/ai/glossary.rs`
- `build_glossary(pdf_path) -> Vec<GlossaryEntry>` — find candidate terms (defined-on-
  first-use patterns, acronyms, italic-emphasized terms, low-frequency capitalized
  multi-word phrases). Ask provider for definitions using doc context. Filter by
  confidence + dedup.
- Per-term page citations.

**UI:** Side-sheet in BeaconChatPanel. Alphabetical list, search-filter, click-to-jump
to first-use page. Export as markdown.

**Tests:** 5 — candidate detection, acronym resolution, dedup, confidence filter, export.

## Slice 15 — Voice Mode (local STT + TTS)

**Why:** Hands-free study + accessibility. Ask Beacon questions by voice, hear answers
spoken. 100% local: whisper.cpp for STT, macOS `say` for TTS (no API calls).

**Backend:**
- `src-tauri/src/ai/voice.rs` — record from default input (cpal crate), pipe to
  whisper.cpp via FFI, return transcript.
- TTS: shell out to `say -v Samantha -o /tmp/...aiff` then play via afplay. Tauri-only
  feature (cfg-gated on macos).
- New Tauri commands: `slab_beacon_record_start`, `slab_beacon_record_stop`,
  `slab_beacon_tts_speak`.

**UI:** Mic button in BeaconChatPanel composer. Hold-to-talk OR toggle. Reply auto-
spoken if voice mode is "active session". Settings: voice selection (list from `say -v ?`).

**Deps:** `cpal = "0.15"` (audio capture), `whisper-rs = "0.13"` (or shell out to
whisper.cpp binary if FFI is messy).

**Tests:** 3 — mic permission gate, transcript parse, voice list parse. (Audio
roundtrip is integration-tested manually — CI just verifies compile.)
