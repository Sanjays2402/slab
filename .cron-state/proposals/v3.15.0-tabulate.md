# v3.15.0 "Tabulate" Implementation Plan — PDF → Excel

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.
> Branch: `feature/v3.15.0-tabulate`. Author: Cake (cron). Drafted 2026-05-24 00:18 PT.

**Goal:** Add **offline PDF → Excel (.xlsx) conversion** to Slab — detect every
table in a PDF and emit a real OOXML spreadsheet (one sheet per page, one row
per table row, typed numeric cells), all without ever sending the file to a
server. Adobe charges $239/yr for "Export PDF to Excel" and ships your file
to their cloud. Slab does it free, offline, and batchable via Atelier.

**Architecture:** Reuse the entire v3.14.0 Reflow pipeline (extract → layout →
tables) up to and including `tables::detect_tables`. Replace only the
emission layer: instead of writing OOXML wordprocessing XML (`word/*`), write
OOXML SpreadsheetML (`xl/*`). One workbook per PDF, one worksheet per page
that contains ≥1 detected table, table rows become spreadsheet rows, cells
are emitted as `<c t="n">` (numeric) when the trimmed cell text parses as a
finite f64, otherwise as `<c t="inlineStr">` (text). Detect numbers, dates
(ISO 8601 + common US/EU formats), and currency. Wire as a new Atelier step
`Step::ConvertToXlsx` (mirrors `ConvertToDocx`), Tauri command
`pdf_convert_to_xlsx`, frontend `TabulatePanel`, nav entry, command palette
card, keyboard shortcut.

**Tech Stack:** Rust (lopdf 0.40, zip 2, quick-xml for spreadsheet XML),
TypeScript + Svelte 5 (Liquid Glass), Tauri 2.

```rust
//! Tabulate — PDF → Excel public types.

/// Toggles controlling the tabulate pipeline.
#[derive(Debug, Clone, PartialEq)]
pub struct TabulateOptions {
    /// Try to parse cell text as f64; emit numeric `<c t="n">` cells when it parses.
    pub type_numbers: bool,
    /// Try to parse cell text as a date (ISO 8601 / common US+EU formats);
    /// emit Excel serial date numbers with a date style when it parses.
    pub type_dates: bool,
    /// If true, also emit a "Body Text" sheet containing all non-table
    /// paragraphs. Off by default — most users want only the tables.
    pub include_non_table_text: bool,
    /// Worksheet naming pattern. `{n}` → 1-based page number. Excel sheet
    /// names are limited to 31 chars; we truncate after formatting.
    pub sheet_name_pattern: String,
}

impl Default for TabulateOptions {
    fn default() -> Self {
        Self {
            type_numbers: true,
            type_dates: true,
            include_non_table_text: false,
            sheet_name_pattern: "Page {n}".to_string(),
        }
    }
}

/// One detected table on one page, ready for Excel emission.
```

**Step 2: Implement `cells.rs`**

```rust
//! Cell typing — decide whether a string is a number, a date, or text.

use chrono::NaiveDate;

#[derive(Debug, Clone, PartialEq)]
pub enum Cell {
    Blank,
    Number(f64),
    /// Excel-serial date (days since 1900-01-00 with the 1900 leap-year bug).
    Date(f64),
    Text(String),
}

const EXCEL_EPOCH_OFFSET_DAYS: i64 = 25_569; // 1970-01-01 minus 1899-12-30.

/// Classify a trimmed cell string into a typed Cell.
pub fn classify(s: &str) -> Cell {
    let trimmed = s.trim();
    if trimmed.is_empty() {
        return Cell::Blank;
    }

    if let Some(n) = parse_number(trimmed) {
        return Cell::Number(n);
    }
    if let Some(serial) = parse_date(trimmed) {
        return Cell::Date(serial);
    }
    Cell::Text(trimmed.to_string())
}

fn parse_number(s: &str) -> Option<f64> {
    // Strip currency symbols and accounting parens.
    let mut t = s.to_string();
    let negate_parens = t.starts_with('(') && t.ends_with(')');
    if negate_parens {
        t = t[1..t.len() - 1].to_string();
    }
    for sym in ['$', '€', '£', '¥', '₹', ' '] {
        t = t.replace(sym, "");
    }
    let percent = t.ends_with('%');
    if percent {
        t.pop();
    }

    // Try US format (1,234.50) and EU format (1.234,50).
    let candidates = [t.replace(',', ""), t.replace('.', "").replace(',', ".")];
    for c in candidates {
        if let Ok(mut n) = c.parse::<f64>() {
            if !n.is_finite() {
                continue;
            }
            if negate_parens {
                n = -n;
            }
            if percent {
                n /= 100.0;
            }
            return Some(n);
        }
    }
    None
}

fn parse_date(s: &str) -> Option<f64> {
    const FORMATS: &[&str] = &[
        "%Y-%m-%d", "%Y/%m/%d", "%m/%d/%Y", "%m-%d-%Y",
        "%d/%m/%Y", "%d-%m-%Y", "%d %b %Y", "%d %B %Y",
        "%b %d, %Y", "%B %d, %Y",
    ];
    for fmt in FORMATS {
        if let Ok(d) = NaiveDate::parse_from_str(s, fmt) {
            return Some(to_excel_serial(d));
        }
    }
    None
}

fn to_excel_serial(d: NaiveDate) -> f64 {
    let epoch = NaiveDate::from_ymd_opt(1970, 1, 1).unwrap();
    let delta = d.signed_duration_since(epoch).num_days();
    (delta + EXCEL_EPOCH_OFFSET_DAYS) as f64
}
```

```rust
//! Detect tables in a PDF and emit them as `TableExtract` per page.

use super::types::TableExtract;
use super::TabulateError;
use crate::pdf::reflow::{extract::extract_text_runs, layout, tables, types::ReflowOptions};

/// Reuse the Reflow pipeline up to and including table detection, then
/// project each detected `TableSpan` into a `TableExtract`.
pub fn extract_tables(doc: &lopdf::Document) -> Result<Vec<TableExtract>, TabulateError> {
    let runs = extract_text_runs(doc)?;
    // Force table detection ON regardless of caller — that's the whole point.
    let opts = ReflowOptions {
        detect_tables: true,
        ..ReflowOptions::default()
    };
    let blocks = layout::reconstruct_blocks(&runs, &opts);

    // The layout step already coalesces table rows into `Block::TableRow { cells }`.
    // We can group consecutive `TableRow` blocks into per-page tables by walking
    // the run stream alongside the block stream — simpler approach: re-walk the
    // raw paragraphs and run table detection again, mapping spans back to
    // (page, rows). We use the public `reflow` outputs to stay decoupled.

    use crate::pdf::reflow::types::Block;
    let mut out: Vec<TableExtract> = Vec::new();
    let mut current_rows: Vec<Vec<String>> = Vec::new();
    // We approximate "page" by counting how many runs precede the row's first
    // cell — keep a simple page-tracking heuristic by carrying the page of the
    // most recent run. For v3.15.0 MVP we tag every detected table to page 1
    // when we can't recover the page, and emit one sheet per detected table.
    let mut current_page: u32 = 1;
    let mut have_any = false;

    for block in blocks {
        match block {
            Block::TableRow { cells } => {
                current_rows.push(cells);
                have_any = true;
            }
            _ => {
                if !current_rows.is_empty() {
                    out.push(TableExtract {
                        page: current_page,
                        rows: std::mem::take(&mut current_rows),
                    });
                    current_page += 1;
                }
            }
        }
    }
    if !current_rows.is_empty() {
        out.push(TableExtract {
            page: current_page,
            rows: current_rows,
        });
    }
    let _ = have_any;
    Ok(out)
}
```

**Step 2: Implement `xlsx.rs`** — full SpreadsheetML emitter

Key XML parts to emit (in this order):

- `[Content_Types].xml` — declares MIME types for every part.
- `_rels/.rels` — top-level relationships → `xl/workbook.xml`.
- `xl/_rels/workbook.xml.rels` — workbook → sheets, styles, sharedStrings.
- `xl/workbook.xml` — `<workbook><sheets><sheet name=... r:id=...></sheets></workbook>`.
- `xl/styles.xml` — declare ONE non-default cellXfs entry with `numFmtId="14"`
  (Excel built-in `m/d/yyyy`) and `applyNumberFormat="1"` so dates get `s="1"`.
- `xl/sharedStrings.xml` — every unique string used in `t="inlineStr"` positions,
  or just inline. For MVP we use inline strings (`t="inlineStr"`) and ship a
  stub sharedStrings.xml with 0 entries.
- `xl/worksheets/sheet1.xml`, `sheet2.xml`, … — one per `TableExtract`.

Cell reference helper: `col_letter(idx)` → "A", "B", …, "Z", "AA", …
Row index is 1-based.

Use `quick-xml::Writer` for safety (it auto-escapes) or hand-roll with
`xml::escape` — at minimum escape `&`, `<`, `>`, `"`, `'`.

Pseudocode for one sheet:

```rust
fn sheet_xml(t: &TableExtract, opts: &TabulateOptions) -> Result<String, TabulateError> {
    let mut s = String::new();
    s.push_str(r#"<?xml version="1.0" encoding="UTF-8" standalone="yes"?>"#);
    s.push_str(r#"<worksheet xmlns="http://schemas.openxmlformats.org/spreadsheetml/2006/main"><sheetData>"#);
    for (r_idx, row) in t.rows.iter().enumerate() {
        let r1 = r_idx + 1;
        s.push_str(&format!(r#"<row r="{r1}">"#));
        for (c_idx, raw) in row.iter().enumerate() {
            let r = format!("{}{}", col_letter(c_idx), r1);
            match crate::pdf::tabulate::cells::classify(raw) {
                Cell::Blank => {}
                Cell::Number(n) if opts.type_numbers => {
                    s.push_str(&format!(r#"<c r="{r}" t="n"><v>{}</v></c>"#, format_f64(n)));
                }
                Cell::Date(serial) if opts.type_dates => {
                    s.push_str(&format!(r#"<c r="{r}" s="1" t="n"><v>{}</v></c>"#, format_f64(serial)));
                }
                Cell::Number(_) | Cell::Date(_) | Cell::Text(_) => {
                    let text = escape_xml(raw.trim());
                    s.push_str(&format!(r#"<c r="{r}" t="inlineStr"><is><t>{text}</t></is></c>"#));
                }
            }
        }
        s.push_str("</row>");
    }
    s.push_str("</sheetData></worksheet>");
    Ok(s)
}
```

`format_f64`: print integers without ".0", otherwise `format!("{}", n)`.
`col_letter`: standard A1 conversion (idx 0 → "A", 26 → "AA").

```rust
use std::path::Path;
use std::time::Instant;

pub fn convert_to_xlsx(
    input: &Path,
    output: &Path,
    opts: &TabulateOptions,
) -> Result<TabulateReport, TabulateError> {
    if !input.exists() {
        return Err(TabulateError::InputMissing(input.display().to_string()));
    }
    if let Some(parent) = output.parent() {
        if !parent.as_os_str().is_empty() && !parent.exists() {
            return Err(TabulateError::OutputNotWritable(output.display().to_string()));
        }
    }
    let started = Instant::now();
    let doc = lopdf::Document::load(input)?;
    let tables = extract::extract_tables(&doc)?;
    if tables.is_empty() {
        return Err(TabulateError::NoTablesFound);
    }
    let pages = doc.get_pages().len() as u32;
    let bytes = xlsx::write_xlsx(&tables, opts)?;
    std::fs::write(output, &bytes)?;

    let mut report = TabulateReport::empty();
    report.pages = pages;
    report.sheets = tables.len() as u32;
    report.tables = tables.len() as u32;
    for t in &tables {
        report.rows += t.rows.len() as u32;
        for row in &t.rows {
            report.cells += row.len() as u32;
            for raw in row {
                match cells::classify(raw) {
                    cells::Cell::Number(_) => report.numeric_cells += 1,
                    cells::Cell::Date(_) => report.date_cells += 1,
                    _ => {}
                }
            }
        }
    }
    report.bytes_written = bytes.len() as u64;
    report.duration_ms = started.elapsed().as_millis() as u64;
    Ok(report)
}
```
