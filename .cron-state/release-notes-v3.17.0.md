# Slab v3.17.0 — "Markdown"

**Drop a PDF, get Markdown. Or HTML. Offline. Free.**

Slab now converts any PDF to clean Markdown (`.md`) or semantic HTML (`.html`)
— no cloud, no signup, no $239/yr subscription. The AI-era file workflow,
finally on every desktop.

## What's new

- **PDF → Markdown** — GitHub Flavored or CommonMark, with detected tables,
  bullet/numbered lists, headings preserved. Drop your research paper into
  Slab, paste the output into Obsidian or ChatGPT.
- **PDF → HTML** — semantic HTML5 (`<article>`, `<h1>`, `<table>`) with an
  embedded stylesheet that reads beautifully out of the box.
- **Batch via Atelier** — drop a folder of 200 PDFs into a recipe, walk away
  with 200 Markdown files. Chain OCR → Redact → Convert to Markdown for the
  full paralegal / researcher workflow.
- **Same offline-first wedge** — your files never leave your machine.
