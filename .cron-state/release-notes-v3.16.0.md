# Slab v3.16.0 — "Slide" 🎞

**Turn any PDF into an editable PowerPoint deck. Offline. Free. One folder at a time.**

Sales engineer with 40 one-pager PDFs to convert into a pitch deck before Monday? Drop the folder into Slab's Atelier, add the **Convert to PowerPoint** step, hit run. You get back one editable `.pptx` per page — title, bullets, and (optionally) speaker notes pulled from the PDF's text annotations. No upload, no subscription, no Adobe Export PDF add-on.

## What's new

- 🎞 **PDF → PowerPoint (.pptx)** — native, offline, batch-capable
- 🧠 **Title + bullet clustering** — Slab reads each page's text layout and groups it into a proper title and body bullets, not a flat dump
- 💬 **Speaker notes from PDF annotations** — `/Text` annots become slide notes (toggle in the step editor)
- 📐 **Page-size preserved** — landscape, portrait, A4, US Letter — your deck matches the source
- ⚙️ **First-class Atelier step** — palette card 🎞 "Convert to PowerPoint (.pptx)", drop into any batch pipeline
