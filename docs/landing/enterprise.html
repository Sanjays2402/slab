Deployment

macOS

Signed and notarized DMG for arm64 and x64. Drop into /Applications via Munki, Jamf Pro, or Mosyle. No first-launch quarantine prompt.

installer -pkg Slab-3.0.2-arm64.pkg \
  -target /Applications

Windows

MSI and NSIS installers, both code-signed. Deploy silently via SCCM, Intune, or GPO software-install.

msiexec /i Slab-3.0.2-x64.msi /qn \
  ALLUSERS=1

Linux

AppImage for any distro, .deb for Ubuntu / Debian / derivatives. SHA-256 sums published with each release for chain-of-custody.

apt install ./slab_3.0.2_amd64.deb

Security & compliance checklist

  • Source code under AGPL-3.0. Your security team can review and self-build every release.
  • Reproducible builds. CI pipeline pinned to commit hashes; tag-triggered GitHub Actions produce identical artifacts from clean checkouts.
  • Code-signed installers. Apple Developer ID notarization, Authenticode on Windows. Linux .deb is detached-GPG signed.
  • Zero outbound network traffic. No telemetry, no analytics, no crash reporter. tcpdump-verifiable on a fresh box.
  • Beacon AI runs locally. Models live in ~/.ollama; nothing leaves the machine — including PDFs you chat with.
  • Audit-ready outputs. Loupe inspector exports Markdown reports that compliance officers can paste into procurement reviews and 508/EAA filings.
  • No forced cloud account. The app launches and opens files without a sign-in, ever.
  • Plugin sandbox. Foundry SDK plugins are signed and run in a typed boundary — they can't read or write outside their declared scopes.
