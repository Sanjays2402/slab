# Slab v0.14.0 — Stack 📚

**Diff & Compare** — see what changed between two PDFs at a glance, export
a publishable change report, or ask Beacon to explain the changes in plain
English.

This is the eighth major Slab release of the road to v1.0 — and the first
that lets you treat PDFs like code: with `diff`s, summaries, and provenance.

---

## ✨ Highlights

### 📑 Line-level text diff
Pick an old PDF and a new PDF, hit **Compare**, and Slab walks every
page side-by-side using a Myers diff over extracted text:

* `+N` added lines, `−N` removed, `~N` modified per page and per doc
* Toggle **Changes only / All pages** to switch between signal-first
  and full context
* Toggle unchanged context lines on/off for either review mode
* Old/new line numbers shown in a fixed gutter, color-coded markers
  (`+` green, `−` red, ` ` muted) for accessible scanning

### 📤 Change Report export
One click and Slab produces a fully-formatted PDF report:

* Per-page sections with summary pills
* Inline blockquotes showing added/removed lines
* Skips unchanged pages entirely — signal-only output
* Uses the same Markdown→PDF pipeline as the Beacon AI summary tool

### 🤖 "Explain Changes" (Beacon AI)
The headline feature. Click **Explain Changes (AI)** and your configured
Beacon provider (Ollama local-first by default, OpenAI-compatible secondary)
gets a budget-truncated, prioritized view of the diff and writes a
natural-language summary:

* "The contract's payment terms were tightened — net-30 → net-15, and a
  late-fee clause was added to section 4.3..."
* Shows model name, pages included vs total, and a `truncated` badge
  when the diff was too large to fit in one prompt
* Smart truncation drops unchanged pages first, then equal lines, so
  the AI never wastes context budget on noise

### 🛡️ Diff that respects your privacy
Diff runs 100% locally. The AI summary only sends the diff text (not the
PDF contents) to your provider — and if you've kept the default Ollama
setup, nothing leaves your machine.

## 📦 Under the hood

* New `pdf::diff` Rust module (~540 lines, 15 tests):
  - `DocDiff` / `PageDiff` / `LineDiff` types
  - Page alignment v1: strict 1:1 by index (content-similarity v2 deferred)
  - Markdown report builder + PDF renderer
* New `ai::diff_summary` module (~360 lines, 5 tests):
  - Pluggable across any `AiProvider` (Ollama, OpenAI-compatible, future)
  - Budget-aware truncation with `truncated` flag
* New Tauri commands: `slab_diff_pdfs`, `slab_diff_export_report`,
  `slab_beacon_diff_summary`
* New Svelte panel: `DiffPanel.svelte` (~550 lines) — Linear/Raycast
  minimal, summary pills, AI card with model/pages metadata
* New dependency: `similar = "2.6"` (Myers/Patience diff engine)

**Total: 5 commits, ~1,400 LOC across 7 files, 376 lib tests green.**

## ⚠️ Known limitations (planned for v0.14.1)

* **No visual diff yet** — pages are aligned 1:1 by index. If you insert
  a page in the middle, every page after will look "changed". v0.14.1 will
  add content-similarity alignment.
* **No patch/merge** — you can see and explain changes but not yet apply
  them. The `apply diff from A onto B` operation is on the v0.14.1 roadmap.
* **Side-by-side rendering** — the current panel is text-only. Rendered
  page thumbnails with highlighted added/removed regions are coming in
  v0.14.1.

These limits are scoped, not blockers — the core diff loop works and
covers contract revisions, paper edits, and spec evolution today.
