# Slab v1.2.0 — Glass II 🪟²

_Released 2026-05-17_

**The keyboard-first, accessible, multilingual release.**

Glass II is what 1.0 should have been if we'd had the time. We took the
post-1.0 stability promise as license to slow down on new feature
surface and pay back the foundational debt: a real modal keyboard
layer, a real a11y baseline, and a real i18n mechanism. Three pillars,
all shipping together, all working today.

If 1.0 Glass was about polish, 1.2 Glass II is about **reach** — making
Slab usable for people who don't drive PDFs with a mouse, people who
need screen readers, people who don't read English. Same Slab, more
hands on the wheel.

## Three pillars

### 1. Modal Vim mode 🎹

Built from a clean, pure state machine — no hacky keybindings, no
hidden modes, no surprises. Toggle on from Settings or the Command
Palette and Slab learns to speak Vim:

| Mode      | What it does                                                  |
|-----------|---------------------------------------------------------------|
| **Normal**    | Motions + actions. Bottom-left pill shows the mode.              |
| **Insert**    | Every keystroke passes through to the focused input.             |
| **Visual**    | (Reserved.) Selection mode placeholder for future range ops.     |
| **Command**   | After `:` — type a command, `<CR>` executes, `<Esc>` aborts.    |
| **Search**    | After `/` or `?` — incremental find, `<CR>` confirms.           |

**Reader bindings**: `gg`, `G`, `j`/`k`, `Ctrl-d`/`Ctrl-u`, `Ctrl-f`/`Ctrl-b`,
`[`/`]` (prev/next page), `/foo<CR>` + `n`/`N`, `:42<CR>` (jump to page),
`:q<CR>` (close tab). Count prefixes work — `10j` scrolls ten times,
`3]` skips three pages.

**Library bindings**: `j`/`k` move between cards, `gg`/`G` jump to
first/last, `<CR>` opens the focused doc, `dd` removes it, `h`/`l` for
horizontal nav. Focused card gets an accent-coloured ring.

**Beacon bindings**: `j`/`k` scroll the chat transcript, `i`/`a` jump
into the input, `Esc` blurs it, `dd` resets the conversation.

The state machine is a pure `dispatchKey(state, event) -> {state',
action}` reducer — testable, deterministic, and small. The
`VimController` Svelte wrapper sits above each panel and translates
actions into panel-specific calls. **Cmd/Ctrl shortcuts are reserved
for the app** — Vim never eats your Cmd-F.

### 2. Accessibility audit + fixes ♿

A new `pnpm a11y:audit` script (zero deps, plain Node) walks every
`.svelte` file in the tree and flags three classes of issue:

1. Icon-only buttons missing `aria-label` or `title`.
2. Form inputs (`<input>` / `<select>` / `<textarea>`) without a
   visible or associated label.
3. `<img>` tags missing `alt=`.

Baseline run found **0 icon-button issues, 40 input-label issues, 0
img-alt issues**. All 40 input-label issues are now resolved — 15
panels touched (RedactPanel, PageLabelsPanel, NupPanel, GrayscalePanel,
MarkdownPanel, AutoRedactPanel, BeaconChatPanel, BeaconSearchPanel,
ConvertPanel, EditTextPanel, LibraryPanel, ReaderPanel, SignPanel,
OutlineEditor, CommandPalette). The audit is now **CLEAN** and runs
in CI on every push via `pnpm a11y:audit:strict`.

Other a11y wins this release:

- **Global `:focus-visible` ring** using `--accent` so it auto-themes.
  Keyboard users finally see where focus is. Mouse users see nothing.
- **`<nav aria-label="Primary">` + `aria-current="page"`** on the
  sidebar so screen readers correctly announce the active panel.
- **`prefers-reduced-motion`**: `*`-level overrides drop animation +
  transition durations to 0.001ms and force `scroll-behavior: auto`.
  Vestibular users get a still UI.
- **`prefers-contrast: more`**: borders darken (1px → 2px), focus
  rings thicken (2px → 3px), `--border` and `--muted` derived via
  `color-mix()` to hit AA contrast everywhere. `--accent` deliberately
  left alone — it's the brand colour, not a contrast hazard.

### 3. Internationalisation foundation 🌍

Glass II lays down the i18n plumbing. Four locale bundles ship in
1.2.0:

| Locale | Coverage |
|--------|----------|
| **English (en)** | Canonical fallback — every key lives here. |
| **Spanish (es)** | Settings, sidebar, palette, window toasts. |
| **French (fr)**  | Settings, sidebar, palette, window toasts. |
| **Arabic (ar)**  | Same coverage **+ RTL** mirroring of the shell. |

The `t()` function is a tiny, zero-deps resolver — flat dotted-key
JSON bundles (~3 KB each, all bundled eagerly because the wait cost
beats the bundle cost), `{var}` template interpolation, English
fallback for missing keys, key string fallback for missing-everywhere
keys (so developer typos are visible at runtime). Reactive lookups go
through a `tStore` derived store; one-shot lookups (logs, toasts) use
the `t()` function directly.

**Right-to-left**: Selecting Arabic flips `<html dir="rtl">`. The
sidebar moves to the right edge, directional glyphs (← → ⤢ ↺ ▷)
mirror via `scaleX(-1)`, and code/PDF canvases are forced back to LTR
because source code reads left-to-right universally.

**Language picker**: New row in Settings + four Command Palette
entries ("Switch to English / Español / Français / العربية"). The
choice persists to `localStorage` and is honoured on next launch.

Today only ~38 strings translate — the sidebar feature labels,
Settings panel headers, and window detach toasts. The infrastructure
is there for the rest of the app to follow.

## Upgrade notes

This release is **fully backwards compatible** with 1.1.0.

- **No new permissions** — i18n is entirely client-side; Vim is
  entirely keyboard-event-side.
- **localStorage growth**: ~50 bytes for the locale choice + ~10
  bytes for the Vim on/off flag.
- **No DB migrations**. `chats.db`, `library.db`, and `windows.json`
  are untouched.
- **Existing keybindings unaffected** when Vim is off (default).

## What's next

**v1.3.0 "Foundry"** is the long-planned plugin/extensibility release.
The accessibility + i18n + Vim foundations shipped here are exactly
what an extension API needs underneath it — third-party panels need
working a11y, working i18n, and predictable keyboard semantics. We
spent four ticks paying down that foundation specifically so Foundry
can build on solid ground.

## Stability promise (renewed)

Slab 1.x is a stable API. Settings persistence shape, exported PDF
fidelity, AI provider trait, library schema, and now i18n key shape +
Vim action shape are all under semver. We won't break any of those in
1.x.
