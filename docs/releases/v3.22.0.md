# Slab v3.22.0 — Hopper Loop

**Already have a folder full of PDFs? Hopper will catch up.**

Until today Hopper was a forward-looking creature. You set up a watched
folder, you wrote your rules, and from that moment on every new file that
landed got sorted. The 4,000 PDFs already sitting in `~/Documents/Scans/`?
On their own.

v3.22.0 closes the loop. Point Hopper at any folder — watched or not — and
it will run your rules across every file already there, show you exactly
what's about to happen, and let you commit when you're ready.

## Backfill, with a dry-run table that actually shows the work

Open the Rules Editor on any Hopper watch and click **Test on this folder…**.
You now get the v3.22.0 centerpiece: a Liquid-Glass overlay that plans the
entire backfill before touching a single file.

For each PDF in the folder, the dry-run table shows:

- The **filename** as it sits today
- The **winning rule** (or *no match — skipped*)
- The **recipe** that will run
- The **destination folder** the file lands in
- The **new name** after the rename pattern is applied
- A **conflict badge** if a file with that name already exists at the
  destination

You read the whole plan before anything moves. Adobe AutoActions doesn't do
this. Hazel doesn't do this. Foxit doesn't do this. Slab does — for free.

When the plan looks right, click **Run backfill** and Hopper processes the
queue in the same engine that handles live drops. When it doesn't, close
the dialog, edit the rules, and try again. Zero files moved.

## Recent runs, persisted

Every backfill (dry-run or executed) is logged to the local sqlite history.
The overlay's **Recent runs** disclosure shows the last 20 with timestamps,
file counts, and outcomes. Re-open Slab a week later — your audit trail is
still there.

## The "Hopper: Backfill folder with rules" command

The new command palette entry surfaces backfill from anywhere in the app —
no need to drill into the watch editor first. The global shortcut
**⌘⇧H** (Ctrl+Shift+H on Windows/Linux) does the same.

## What's under the hood

- New `slab-hopper::backfill` module — plan + execute APIs, fully unit-tested
- Three new Tauri commands — `slab_hopper_plan_backfill`,
  `slab_hopper_execute_backfill`, `slab_hopper_list_backfill_runs`
- Sqlite migration for `backfill_runs` history table
- Cmd/Ctrl+Shift+H global shortcut + command palette + Shortcuts overlay entries
