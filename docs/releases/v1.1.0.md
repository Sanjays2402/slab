# Slab v1.1.0 — Cabinet 🗄️

**Released:** 2026-05-17

> **Your panels, your way.** Detach any of 11 panels into its own native
> window. Drop Beacon on the second monitor while the Reader stays on the
> first. Open three Library views, each filtered to a different folder.
> Run a Diff window next to two side-by-side Readers. Slab's UI no
> longer assumes "one feature at a time" — it embraces the way you
> actually work.

This is the first feature release after **v1.0.0 "Glass"** stabilised
the API surface. Cabinet adds capability without breaking the stable
contract: every change is additive — new Tauri commands, new events,
new IPC payloads — never a rename or a removal. Anything you built
against 1.0.0 still works.

---

## TL;DR

- **🪟 Detach any of 11 panels** into its own native window with
  `Cmd+K → "Open <Panel> in new window"`, or the new detach button on
  detachable panels.
- **🔁 Cross-window coherence.** Add a folder in the main Library, and
  the detached Library window refetches in milliseconds.
  Double-click a doc in a detached Library window, and the *main*
  window opens a new Reader tab for it.
- **💾 Persistent geometry.** Window positions, sizes, and which
  panels were open survive app restart (stored in
  `~/.slab/windows.json`).
- **📋 Sidebar Windows menu.** A new "Detached" section in the main
  window's sidebar lists every open detached window. One click to
  focus, one click (×) to close.
- **🍞 Toast confirmations.** "Detached Beacon AI" and "Closed
  detached window" so the affordance never feels like it did nothing.

11 panels detach today:

| Panel        | Why you'd want it floating                              |
|--------------|---------------------------------------------------------|
| Reader       | Two PDFs side by side, on two monitors                  |
| Library      | Catalog open while reading something specific           |
| Beacon AI    | Chat the doc on your laptop screen while reading on TV  |
| Search       | Cross-doc search while a Reader stays loaded            |
| PII Redact   | Run a continuous scan in a corner window                |
| Pages        | Page-grid while editing in another panel                |
| Pages (list) | Same idea, list flavour                                 |
| Diff         | Old vs new in one window, the result Reader in another  |
| Slides       | Presenter view on monitor 2, notes on monitor 1         |
| Tables       | CSV preview while reading the source                    |
| Markdown     | Live-rendered Markdown next to the PDF it'll become     |

The one-shot wizards (Encrypt, Compress, Merge, Split, OCR, etc.) are
intentionally *not* detachable — you close them right after running
them, so a floating window adds nothing.

## Why this matters

Glass made Slab feel like a real app, but it was still a *single-window*
real app. If you wanted Beacon's chat next to a research PDF, you had
to switch features (and lose the Reader's state). If you wanted to
catalogue your library while reading a doc from it, same problem.

Cabinet kills that constraint. Slab now respects the simple fact that
**screens are bigger than they used to be** and **you have more than
one of them**. A detached Beacon AI on monitor 2 is finally just a
WebviewWindow — not a feature request, not a roadmap bullet.

## What ships in v1.1.0 (Cabinet — 8 slices)

### 🧱 Slice 1 — Window registry backend

A new `WindowRegistry` in Rust tracks every detached window: label,
panel id, geometry, target document. Persisted as JSON at
`~/.slab/windows.json`. Three new Tauri commands cover the lifecycle:
`slab_window_open`, `slab_window_close`, `slab_window_list`. Fully
unit-tested on the Rust side.

### 🖼️ Slice 2 — Detached route + chrome

`+page.svelte` reads `?panel=…&windowId=…&doc=…` from the URL and
flips into "detached mode": no sidebar, no tabstrip, no command
palette — just the single requested panel filling the window, wrapped
in a thin `DetachedShell.svelte` titlebar.

### 🧬 Slice 3 — First panel detaches end-to-end

Beacon Chat became the proving ground: detach button → backend spawns
window → URL params → DetachedShell → BeaconChatPanel renders, fully
functional, in its own native window. Validated the whole pipeline.

### 💾 Slice 4 — Geometry persistence

Window move/resize events update the registry. On app start, the
registry replays the saved window set, restoring positions across
launches. Multi-monitor friendly (saves screen-absolute coordinates).

### 🎯 Slice 5 — All 11 panels wired

Every panel in `DETACHABLE_PANELS` now renders in detached mode,
including Library, Search, PII Redact, Pages, Pages-list, Diff,
Slides, Tables, Markdown, and Reader (with `?doc=` seeding for the
"detach this specific doc" flow). Command Palette gained an "Open
<Panel> in new window" entry per panel, all gated on `isInTauri()` so
the dev shell stays clean.

### 📡 Slice 6 — Cross-window event bus

The first cross-window coherence guarantee. Backend emits
`slab://library-changed` (no payload, just a poke) after every library
mutation in any window — folder add/remove, scan, tag changes, OCR,
auto-tag, doc delete. All LibraryPanel instances listen and refetch.

Detached LibraryPanel doc activation routes through the new
`slab_request_open_in_main` command, which emits `slab://open-doc`
targeted at the main window only — so a detached Library can ask the
main Reader to load a PDF without having to spawn yet another window.

### 📋 Slice 7 — Windows menu + toasts

Sidebar footer gains a "Detached" section listing every open detached
window. Click the label to focus, click `×` to close. Polled every
2s. Toast confirmations on detach + close (`notify.info`).

### 🚢 Slice 8 — Release

Version bump 1.0.0 → 1.1.0 across `package.json`, `Cargo.toml`,
`tauri.conf.json`, and the sidebar pill. This file. STATE.md flipped
to DONE → MODE A merges → MODE B releases.

## Upgrade notes

**Nothing breaks.** Cabinet is purely additive:

- A new `~/.slab/windows.json` is created the first time you detach a
  panel. Delete it any time to reset geometry.
- All previous keyboard shortcuts, panels, and config behave exactly
  the same when you never open the Command Palette's new "Windows"
  group.
- The Tauri capability glob `panel-*` was added; pre-existing
  capabilities are untouched.

---

## Stability

Slab's stable-API promise from v1.0.0 still holds. The eight new
Tauri commands (`slab_window_open/close/list`,
`slab_request_open_in_main`) and two new event names
(`slab://library-changed`, `slab://open-doc`) are stable surface as
of this release. If we ever change them, it'll be a 1.x → 2.0 bump.
