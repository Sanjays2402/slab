# Slab v0.15.0 — Theater 🎭

**Released:** 2026-05-17

Slab can now present a slide deck like Keynote — and bake your live ink
back into the PDF when you're done.

This is **Theater**, the second-to-last release before v1.0 "Glass". It
takes the unassuming PDF viewer and turns it into a serious presenter
app: detect slide decks automatically, open them in a fullscreen
single-window presenter (current slide + next slide thumbnail + speaker
notes + timer), draw on top of slides live with a laser pointer / pen /
highlighter / blackout-whiteout, jump anywhere via a thumbnail grid, and
when the talk is over, **save the marked-up deck as a new PDF**.

No other open-source PDF tool has all of this. Most don't have any of
it.

---

## What you can do now

### 🎭 Present any PDF deck (Slices 1–4)

Open a PDF. If Slab thinks it looks like a slide deck (16:9 page ratio
+ low text density per page + presence of speaker notes, weighted into a
0–1 score), you'll see a green banner at the top of the reader:

> ▷ This looks like a slide deck. **24 slides · 16:9 widescreen · 18 pages with notes**
> [▷ Present]

One click and you're in fullscreen presenter mode. Or just navigate to
the `▥ Slides` panel on the sidebar to see the analysis up close —
every page gets a 16:9-true thumbnail, a speaker-notes drawer, and a
small badge if it has notes.

The presenter overlay shows:

- **Big current slide**, rendered at devicePixelRatio for crisp text
- **Next slide thumbnail** in the corner, with "End of deck" sentinel
- **Speaker notes** for the current slide
- **Session timer** with start/pause/reset (T/R keys)
- **Keyboard navigation:** ← → / space / PgUp / PgDn / Home / End / G grid

### ✎ Annotate live on top of slides (Slice 3)

While presenting, you can draw on every slide. Switch tools with:

| Key | Tool | Behavior |
|-----|------|----------|
| `L` | Laser pointer | Red glowing dot that fades into a 600ms trail |
| `P` | Pen | Opaque red freehand ink |
| `H` | Highlighter | Translucent yellow swipe (`multiply` compositing) |
| `N` | None | Pointer mode |
| `X` | Erase | Wipe ink on the current slide only |
| `B` | Blackout | Full-screen black overlay (audience attention) |
| `W` | Whiteout | Full-screen white overlay |
| `G` | Grid | Slide picker — 4–12 cols, 16:9 tiles, click to jump |
| `Esc` | Escape | Cascades: picker → blackout/whiteout → tool → exit |

Strokes are stored **per-page** and survive resize because coordinates
are normalized to `[0,1]` and re-rendered against the live canvas
dimensions. Switch slides and back; your ink is still there.

### ⤓ Save the annotated deck (Slice 5 — new!)

Hit **`S`** (or click the ⤓ button in the presenter toolbar) and Slab
will:

1. Pick a default output path (`<original>-annotated.pdf` right next to
   the source) and open a native save dialog with a `.pdf` filter.
2. Snapshot every pen and highlighter stroke across every slide.
3. Bake them into a new PDF as a transparent overlay — one `q ... Q`
   graphics-state block per stroke, layered on top of the original
   content stream without mutating it.
4. Show a toast: **"Saved 47 strokes → /Users/you/talk-annotated.pdf"**.

The output is a real, parseable PDF. Highlighter strokes ride a per-page
`/ExtGState` dict at 42% alpha; pen strokes are opaque. Both use round
line caps + joins for clean ends. Drop the file into any PDF viewer —
Preview, Acrobat, Chrome — and your ink is right there on the slides.

Powered by the new `pdf::stamp_annotations` Rust module: 585 lines, 13
unit tests, exposed via the `slab_theater_export_annotated` Tauri
command.

## What's still ahead

Theater intentionally ships **before** the dual-monitor audience window
(Tauri multi-window plumbing is a larger lift, scoped for v0.15.1).
What's here today already covers the most common use case: one laptop,
one projector, mirrored display, you fly the deck and ink on it live.

Up next: **v1.0.0 "Glass"** — floating panels, multi-window, command
palette (⌘K), Vim bindings, a11y, i18n, frozen public API. The roadmap
to v1 is in `.cron-state/proposals/roadmap-to-v1.0.md`.

---

## Upgrade notes

- No schema changes; opens v0.14.0 documents transparently.
- Theater is purely additive — none of the existing reader / editor /
  diff / library / OCR features changed.
- Annotated PDFs are interoperable with any standard PDF viewer (we use
  vanilla `q/Q` graphics-state blocks, no proprietary annotation types).
