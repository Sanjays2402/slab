## Slice 6 — Markdown → PDF in browser (THIS TICK)

### Task 6.1: Pure-function md→pdf module

**Files:**
- Create: `src/lib/try/mdToPdf.ts` (~200 LOC — lexer + pdf-lib layout)
- Create: `scripts/test-mdtopdf.mjs` (~80 LOC — node-side smoke test, mirrors `scripts/test-pdfops.mjs` pattern)

**Supported subset (v1, YAGNI):**
- `# H1` `## H2` `### H3` headings
- Paragraphs (wrap at page width)
- `**bold**` and `*italic*` inline
- `` `code` `` inline (mono font swap)
- `- bullet` and `1. ordered` lists (single-level)
- `> blockquote`
- Triple-backtick code blocks (mono font, slight bg)
- `---` horizontal rule
- Auto-pagination on page overflow

NOT in v1: tables, images, links rendering, footnotes, nested lists, GFM tasks, math. (Each opens a `<DownloadWall feature="markdown">`.)

**API:**
```ts
export interface MdToPdfOptions {
  pageSize?: 'A4' | 'Letter' | 'Legal';
  margin?: number;       // pts, default 54 (0.75")
  fontSize?: number;     // body, default 11
  lineHeight?: number;   // multiplier, default 1.45
  title?: string;        // document title metadata
}

export async function mdToPdf(markdown: string, opts?: MdToPdfOptions): Promise<Uint8Array>
```

**Step 1:** Implement lexer (regex-based block split, then inline pass).
**Step 2:** Implement renderer (track y-cursor, wrap text via `font.widthOfTextAtSize`, page-break when y < marginBottom).
**Step 3:** Smoke test via node script using `node --experimental-strip-types scripts/test-mdtopdf.mjs`:
- empty input → 1-page PDF
- 50-line input → multi-page PDF (assert `getPageCount() >= 2`)
- headings render larger than body
- metadata title round-trips
**Step 4:** Commit: `feat(try): mdToPdf — pure-function markdown to PDF (StandardFonts, no deps)`
