# v1.2.0 "Glass II" — Slice 5: i18n Scaffolding

> **For Hermes / Cake:** This is a single-tick slice. Ship it all in one go.

**Goal:** Lay down a minimal but production-quality i18n surface — pure
`t(key, vars?)` function backed by JSON bundles, reactive locale store,
persisted choice, `<html lang>` + `dir` updates, language picker in
Settings + Command Palette, and a proof-of-mechanism RTL stub. Wire ~15
of the most-visible English strings through `t()` to prove the loop.

**Architecture:**

- `src/lib/i18n.ts` — pure `t(key, vars?)` plus a Svelte store
  `locale` (persisted) plus a `setLocale()` setter that re-applies
  `<html lang>` + `<html dir>`. Boot path called from `+layout.svelte`
  alongside `bootTheme()`.
- `src/lib/i18n/<lang>.json` — plain JSON bundles, dotted-key shape
  (`"settings.title": "Settings"`). Three at launch: `en`, `es`, `fr`.
  Stub `ar` (Arabic) for direction switching.
- Strings wired through `t()`: sidebar feature labels (38), settings
  panel headers (~6), reset button, "Saved", "Saving…", a few status
  lines. Anything not yet wired stays English — `t()` falls back to
  English bundle, then to the key itself.
- Settings panel grows a "Language" row (segmented control: English /
  Español / Français / العربية). Command Palette grows four "Switch to
  X" entries grouped under Language.
- CSS scaffold in `app.css`: `:dir(rtl)` block flips sidebar to the
  right, applies `text-align: start`, mirrors arrow icons. Minimal —
  enough to prove the mechanism for future translators.

**Tech Stack:** TypeScript, Svelte 5, JSON modules (Vite native), no
external i18n library. Vitest for the resolver tests.

**Step 1: Write the four locale bundles.**

Each is a flat dotted-key map. English is the canonical fallback —
every key the app uses must exist in `en.json`. Other bundles can be
partial; missing keys fall back to English, then to the key string.

(Bundles enumerated in execution.)

**Step 2: Write `src/lib/i18n.ts`.**

```ts
import { writable, get, derived } from "svelte/store";
import en from "./i18n/en.json";
import es from "./i18n/es.json";
import fr from "./i18n/fr.json";
import ar from "./i18n/ar.json";

export type LocaleId = "en" | "es" | "fr" | "ar";
export type Bundle = Record<string, string>;

export const LOCALES: { id: LocaleId; label: string; dir: "ltr" | "rtl" }[] = [
  { id: "en", label: "English",  dir: "ltr" },
  { id: "es", label: "Español",  dir: "ltr" },
  { id: "fr", label: "Français", dir: "ltr" },
  { id: "ar", label: "العربية",  dir: "rtl" },
];

const BUNDLES: Record<LocaleId, Bundle> = {
  en: en as Bundle,
  es: es as Bundle,
  fr: fr as Bundle,
  ar: ar as Bundle,
};

const STORAGE_KEY = "slab.i18n.locale";

function loadLocale(): LocaleId { ... }
function persistLocale(v: LocaleId) { ... }

export const locale = writable<LocaleId>(loadLocale());
locale.subscribe(persistLocale);

export function resolve(bundle: Bundle, key: string, vars?: Record<string, string | number>): string {
  let raw = bundle[key] ?? BUNDLES.en[key] ?? key;
  if (vars) {
    for (const [k, v] of Object.entries(vars)) {
      raw = raw.replace(new RegExp(`\\{${k}\\}`, "g"), String(v));
    }
  }
  return raw;
}

export function t(key: string, vars?: Record<string, string | number>): string {
  const id = get(locale);
  return resolve(BUNDLES[id] ?? BUNDLES.en, key, vars);
}

export const tStore = derived(locale, ($l) => {
  const bundle = BUNDLES[$l] ?? BUNDLES.en;
  return (key: string, vars?: Record<string, string | number>) => resolve(bundle, key, vars);
});

export function setLocale(id: LocaleId): void {
  locale.set(id);
  applyLocaleToHtml(id);
}

export function applyLocaleToHtml(id: LocaleId): void {
  if (typeof document === "undefined") return;
  const def = LOCALES.find((l) => l.id === id) ?? LOCALES[0];
  document.documentElement.setAttribute("lang", def.id);
  document.documentElement.setAttribute("dir", def.dir);
}

export function bootI18n(): void {
  applyLocaleToHtml(get(locale));
}
```
