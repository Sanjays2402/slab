# v2.7.0 "Signet" — PKCS#7 Digital Signatures Implementation Plan

> **For Hermes:** Use `subagent-driven-development` skill to implement this plan task-by-task. Fresh subagent per task, spec-compliance review then code-quality review, proceed only on dual green.

**Goal:** Ship cryptographic PDF signing + verification — a user picks a PDF, picks a `.p12`/`.pfx` certificate (or generates a self-signed one), draws or types a visible signature, clicks **Sign**, and Slab embeds a real PAdES-B-B compliant PKCS#7 detached signature with a `/ByteRange` digest covering the whole file. Adobe Reader, macOS Preview, and Foxit open the result and show ✅ "Signed and all signatures are valid." Verify panel parses any signed PDF and shows signer name, signing time, cert chain, hash algorithm, and tamper status.

**Architecture:**
- **Wedge:** Adobe Sign is $20-$60/user/month ($240-$720/yr). DocuSign is $25-$45/user/month. Both ship every signed file to their cloud. macOS Preview can sign visually but produces **no cryptographic signature**, only a flattened bitmap. PDF Expert ($79/yr) does not sign at all. Slab does PKCS#7 detached signatures, fully offline, free.
- **Crypto stack:** pure-Rust — `rsa 0.9` (RSASSA-PKCS1-v1_5 with SHA-256), `p256 0.13` (ECDSA P-256 with SHA-256 — modern default), `x509-cert 0.2` (parse + emit X.509), `cms 0.2` (PKCS#7 SignedData ASN.1), `pkcs12 0.1` (parse `.p12`/`.pfx` with PBES2-AES + HMAC-SHA-256), `der 0.7` for ASN.1 encoding, `sha2 0.11` already present.
- **Signing flow:**
  1. Embed a `/Sig` field with a placeholder `/Contents <00...00>` (16 KB hex) into the PDF using `lopdf 0.40` (already a workspace dep).
  2. Compute `/ByteRange` = `[0 sig_start (sig_end) (file_len - sig_end)]` — skips the hex bytes of `/Contents`.
  3. SHA-256 the two byte ranges.
  4. Build PKCS#7 SignedData over that digest, sign with the loaded key.
  5. Hex-encode the DER signature, splice into the `/Contents` placeholder.
- **Verify flow:**
  1. Parse `/AcroForm` and walk signature fields.
  2. For each `/Sig`: recompute the SHA-256 over `/ByteRange`, parse the `/Contents` PKCS#7 SignedData, extract signer cert + algorithm + signing time, verify the embedded digest matches the recomputed one, verify the signature against the signer's public key.
  3. Walk the cert chain back to a self-signed root; mark trust as `SelfSigned` / `Untrusted` / `Trusted` (system roots loaded lazily via `rustls-native-certs` on macOS/Windows, `/etc/ssl/certs` on Linux).
- **Visible appearance:** signature widget rendered as an XObject Form containing the signer's drawn ink (PNG, embedded as a Form XObject) + a text block with "Digitally signed by NAME / Date: ISO-8601 / Reason: …". User can drag-place on any page from the Signet panel; widget is the same dimension model as the existing `pdf::stamp_annotations` module.
- **Self-signed cert generator:** if user has no `.p12`, panel can mint a fresh RSA-2048 cert valid 1 year with their name + email as Subject. Encrypted with a passphrase, written to `~/.slab/certs/<name>-<date>.p12`. This unblocks every first-run user.
- **PAdES-B-B compliance:** subFilter `/ETSI.CAdES.detached`, signed attributes include `contentType`, `messageDigest`, `signingTime`, `ESS signing-certificate-v2`. No RFC 3161 timestamp in v2.7.0 (deferred to v2.7.1 — keeps tick scope sane). Adobe Reader accepts this as "Signed, validity unknown" → upgrades to ✅ when the user adds the cert to Adobe's trust store.
- **Tauri commands (6):** `slab_signet_inspect`, `slab_signet_sign`, `slab_signet_verify`, `slab_signet_generate_cert`, `slab_signet_load_p12`, `slab_signet_list_certs`.
- **Frontend:** new `SignetPanel.svelte` with three tabs — **Sign** (cert picker + reason field + drag-to-place preview), **Verify** (per-signature status pills + cert chain tree), **Manage** (cert list + generate + import).
- **Wow:** **gold wax-seal stamp animation** on successful sign — 320ms cubic-bezier `(0.34, 1.56, 0.64, 1)` `scale(0)→scale(1.08)→scale(1)` + radial-gradient gold glow that ripples outward and dissipates; the signature widget itself fades in with a 180ms blur-in. Reduced-motion safe (instant placement, no glow).

**Tech Stack:** Rust 1.86 / Tauri v2 / Svelte 5 (runes) / `lopdf 0.40` (existing) / `rsa 0.9` / `p256 0.13` / `x509-cert 0.2` / `cms 0.2` / `pkcs12 0.1` / `der 0.7` / `sha2 0.11` (existing) / `rustls-native-certs 0.7` (system trust on verify only).

**Out of scope for v2.7.0** (deferred):
- RFC 3161 timestamping (v2.7.1).
- Long-Term Validation / PAdES-B-LT (DSS + VRI dictionaries) (v2.7.2).
- Smart-card / YubiKey signing via PKCS#11 (v2.8.0).
- Multi-signature workflow with field locking by version (v2.8.0).

> **Decision:** v2.7.0 Signet uses pure-Rust crypto (rsa 0.9 / p256 0.13 / cms 0.2 / x509-cert 0.2 / pkcs12 0.1). We did NOT use `openssl` (cross-compile pain, GPL-with-openssl-exception licensing friction on Linux distros) and we did NOT use `ring` (no PKCS#7 / ASN.1 helpers, would have to handroll DER). We document this in the release notes. Self-signed-cert generation is a v2.7.0 feature precisely so first-run users have a working flow without buying a $200/yr code-signing cert.

```rust
pub struct SignOptions {
    pub reason: Option<String>,
    pub location: Option<String>,
    pub page: u32,
    pub rect: [f32; 4],  // [llx, lly, urx, ury] in PDF units
}

impl Default for SignOptions {
    fn default() -> Self {
        Self { reason: None, location: None, page: 1, rect: [50.0, 50.0, 250.0, 110.0] }
    }
}

pub fn sign_pdf(input: &[u8], cert: &LoadedCert, opts: &SignOptions) -> SignetResult<Vec<u8>> {
    // 1. Load PDF with lopdf::Document::load_mem
    // 2. Build a /Sig dict with /Contents = 16384 hex-zero placeholder, /ByteRange = [0 0 0 0] placeholder
    // 3. Build a widget annotation rect on opts.page pointing to /Sig
    // 4. Add or create /AcroForm with /Fields = [sig_obj_ref]
    // 5. Save to a Vec<u8> via doc.save_to(&mut cursor)
    // 6. Find the byte offsets of /Contents <...> and /ByteRange [...]
    // 7. Compute real /ByteRange and overwrite the placeholder bytes in-place
    // 8. SHA-256 the two byte ranges (skipping the /Contents hex window)
    // 9. Build PKCS#7 SignedData via cms::builder::SignedDataBuilder
    //    - encapContentInfo: detached (no content)
    //    - signerInfo: cert.cert_der, sha256, RsaSha256/EcdsaP256Sha256
    //    - signed attrs: contentType, messageDigest, signingTime, signingCertificateV2
    // 10. Encode DER, hex-uppercase, pad to placeholder length, overwrite /Contents window
    // 11. Return bytes
}

pub(crate) fn extract_byterange(pdf: &[u8]) -> SignetResult<(u64, u64, u64, u64)> { ... }
pub(crate) fn extract_contents_hex(pdf: &[u8]) -> SignetResult<String> { ... }
```

Two key utility helpers — `find_placeholder_window` (locates `/Contents <000…>` in the saved buffer) and `update_byterange_in_place` (rewrites `[0 0 0 0]` to real numbers without changing the buffer length — pad with leading spaces to preserve byte offsets). This is the classic "incremental update" sign trick.

```rust
#[derive(serde::Serialize, Clone, Debug)]
pub struct VerifyReport {
    pub signatures: Vec<SignatureInfo>,
}

#[derive(serde::Serialize, Clone, Debug)]
pub struct SignatureInfo {
    pub field_name: String,
    pub signer_name: String,
    pub signer_email: Option<String>,
    pub signing_time: Option<chrono::DateTime<chrono::Utc>>,
    pub algorithm: SigAlgorithm,
    pub digest_valid: bool,
    pub trust: TrustStatus,
    pub reason: Option<String>,
    pub location: Option<String>,
    pub cert_chain: Vec<CertSummary>,
}

#[derive(serde::Serialize, Clone, Debug)]
pub enum TrustStatus {
    Trusted,
    SelfSigned,
    Untrusted,
    Tampered,
    Expired,
}

pub fn verify_pdf(pdf: &[u8]) -> SignetResult<VerifyReport> { ... }
```

Implementation walks `/AcroForm /Fields`, filters by `/FT == /Sig`, extracts `/ByteRange` and `/Contents`, recomputes the SHA-256, parses the PKCS#7 via `cms::content_info::ContentInfo::from_der`, pulls out signer cert + signed attrs, compares the `messageDigest` attribute against the recomputed digest. Trust = `SelfSigned` if `issuer == subject`, `Trusted` if chain validates against system roots, `Untrusted` otherwise, `Tampered` if digest mismatches.

#[test]
fn end_to_end_cli_round_trip() {

**Real cryptographic signatures for PDFs. Free. Offline. Cross-platform.**

## How it works

Slab embeds a PKCS#7 detached SignedData blob inside a `/Sig` field in
your PDF, with a `/ByteRange` digest covering the entire file minus the
signature bytes. Adobe Reader, Foxit, and macOS Preview will recognise
the signature and validate the tamper-evident hash.

   automatically by every major reader.
