# v3.30.0 "Quill Smart Fill" Implementation Plan

> **For Hermes:** Use `subagent-driven-development` skill to implement this plan task-by-task on a fresh feature branch `feature/v3.30.0-quill-smart-fill`. One vertical slice per tick. Quality gates batched at end of tick.

**Goal:** Drag a source document (resume, prior-year tax form, invoice, contact card, vendor record) onto a blank AcroForm PDF and have **Beacon AI map source fields → form fields locally**, fill them in via the existing `forms::fill` engine, and present a pre-fill diff the user confirms before saving. The Quill arc's killer wow.

**Why it's a buy-button feature:** Acrobat Pro ($239/yr) has no offline source→form mapping. PDF Expert has none. Foxit's AI form-fill needs a cloud subscription. Slab does it for free, offline, with full preview-before-commit. This is the feature a paralegal will screenshot.

**Architecture (3 sentences):**
- New backend module `pdf/forms_smart_fill.rs` extracts text from any source doc (PDF / TXT / Markdown / CSV row), inspects the target's AcroForm fields via existing `forms::inspect`, and asks the configured `AiProvider` to return a JSON `{field_name: value}` map keyed on the target's known field names + types.
- Result is a `SmartFillProposal` (per-field source confidence + extracted value), surfaced in a new `QuillSmartFillPanel.svelte` with line-by-line accept/reject toggles before calling the existing `slab_forms_fill` Tauri command.
- Provider abstraction reuses `Arc<dyn AiProvider>` from `crate::ai`; no new HTTP code, no new heavy deps. Local-by-default via Ollama `llama3.2:3b`.

**Tech Stack:** Rust (`lopdf`, `serde_json`, existing `ai::AiProvider`), Tauri 2 commands, Svelte 5 (runes), TailwindCSS, existing Quill Hub shell.

```rust
use crate::pdf::PdfError;
use std::path::Path;

const MAX_CHARS: usize = 32_000;

/// Extract plain text from any supported source doc. PDF → existing extract pipeline,
/// TXT/MD → raw bytes (utf-8 lossy), CSV → flattened "k: v" lines.
pub fn extract_source_text(path: &Path) -> Result<String, PdfError> {
    let ext = path.extension().and_then(|s| s.to_str()).unwrap_or("").to_ascii_lowercase();
    let raw = match ext.as_str() {
        "pdf" => crate::pdf::extract::extract_all_text(path)?,
        "txt" | "md" | "markdown" | "text" => {
            let bytes = std::fs::read(path).map_err(PdfError::Io)?;
            String::from_utf8_lossy(&bytes).into_owned()
        }
        "csv" => extract_csv_as_kv(path)?,
        other => return Err(PdfError::Unsupported(format!("source ext: {other}"))),
    };
    Ok(truncate_chars(&raw, MAX_CHARS))
}

fn truncate_chars(s: &str, max: usize) -> String {
    if s.len() <= max { s.to_string() } else { s.chars().take(max).collect() }
}

fn extract_csv_as_kv(path: &Path) -> Result<String, PdfError> {
    let mut rdr = csv::Reader::from_path(path).map_err(|e| PdfError::Other(e.to_string()))?;
    let headers = rdr.headers().map_err(|e| PdfError::Other(e.to_string()))?.clone();
    let mut out = String::new();
    if let Some(row) = rdr.records().next() {
        let row = row.map_err(|e| PdfError::Other(e.to_string()))?;
        for (h, v) in headers.iter().zip(row.iter()) {
            out.push_str(h); out.push_str(": "); out.push_str(v); out.push('\n');
        }
    }
    Ok(out)
}
```

```rust
use crate::ai::{AiProvider, ChatMessage, ChatOpts, ChatRole};
use serde::{Deserialize, Serialize};
use std::sync::Arc;

#[derive(Debug, Clone, Serialize)]
pub struct FieldSpec {
    pub name: String,
    pub kind: String,       // "text" | "checkbox" | "choice" | "signature"
    pub hint: Option<String>,
}

#[derive(Debug, Clone, Serialize)]
pub struct ProposalEntry {
    pub field: String,
    pub value: Option<String>,
    pub confidence: f32,    // 0.0–1.0
    pub source_span: Option<String>, // optional quoted source text
}

#[derive(Debug, Clone, Serialize)]
pub struct SmartFillProposal {
    pub entries: Vec<ProposalEntry>,
    pub warnings: Vec<String>,
    pub provider: String,
}

pub async fn propose_fills(
    provider: Arc<dyn AiProvider>,
    source_text: &str,
    fields: &[FieldSpec],
) -> Result<SmartFillProposal, crate::ai::AiError> {
    if fields.is_empty() {
        return Ok(SmartFillProposal { entries: vec![], warnings: vec![], provider: provider.name().into() });
    }
    let field_list = serde_json::to_string_pretty(fields).unwrap_or_default();
    let prompt = format!(
        "You map a SOURCE document to a list of PDF form FIELDS.\n\
         Return STRICT JSON: an object whose keys are exactly the field `name` values, \
         and whose values are strings (or null if no good match). No prose. No code fences.\n\n\
         FIELDS:\n{field_list}\n\nSOURCE:\n{source_text}"
    );
    let msgs = vec![ChatMessage { role: ChatRole::User, content: prompt }];
    let opts = ChatOpts { temperature: 0.1, max_tokens: 1500, ..Default::default() };
    let resp = provider.chat(msgs, opts).await?;
    let body = resp.collect_text().await.unwrap_or_default();
    let map: serde_json::Map<String, serde_json::Value> = match serde_json::from_str(&body) {
        Ok(m) => m,
        Err(_) => {
            return Ok(SmartFillProposal {
                entries: fields.iter().map(|f| ProposalEntry {
                    field: f.name.clone(), value: None, confidence: 0.0, source_span: None,
                }).collect(),
                warnings: vec![format!("AI returned non-JSON; could not parse mapping")],
                provider: provider.name().into(),
            });
        }
    };
    let entries = fields.iter().map(|f| {
        let value = map.get(&f.name).and_then(|v| v.as_str()).map(|s| s.to_string());
        let confidence = if value.is_some() { 0.85 } else { 0.0 };
        ProposalEntry { field: f.name.clone(), value, confidence, source_span: None }
    }).collect();
    Ok(SmartFillProposal { entries, warnings: vec![], provider: provider.name().into() })
}
```

```svelte
<script lang="ts">
  import { invoke } from '@tauri-apps/api/core';
  let target = $state<string | null>(null);
  let source = $state<string | null>(null);
  let proposal = $state<SmartFillProposal | null>(null);
  let busy = $state(false);

  async function onDropSource(e: DragEvent) {
    const path = (e.dataTransfer?.files?.[0] as any)?.path;
    if (!path || !target) return;
    source = path;
    busy = true;
    try {
      proposal = await invoke('slab_quill_smart_fill_propose', { targetPdf: target, sourcePath: path });
    } finally { busy = false; }
  }

  async function commit() {
    const overrides = Object.fromEntries(
      proposal!.entries.filter(e => e.accepted && e.value).map(e => [e.field, e.value!])
    );
    await invoke('slab_forms_fill', { input: target, fieldOverrides: overrides });
  }
</script>
```
