# v3.31.0 "Atlas Lite" Implementation Plan

> **For Hermes:** Use subagent-driven-development to execute task-by-task,
> OR have a single off-hours cron tick fold Slices 1-2 into one BIG ship
> (≥4 commits, ≥600 LOC, end-to-end), then Slice 3-4 in the next tick.

**Goal:** Make Slab feel like it remembers you. Open the app → see a beautiful
Recents view with thumbnails, pinned items, last-position resume, and quick
filters. Adobe and PDF Expert both stumble here; Slab nails it on first launch.

**Architecture:** Frontend-only feature, no backend schema changes needed. The
existing `src/lib/recent.ts` already persists path/name/openedAt/pinned to
localStorage. We extend it with `lastPage` + `pageCount` + `totalPages`, add a
thumbnail capture path on first render, and wire a new `RecentsHome.svelte`
that replaces the current empty "drop a PDF here" landing state. When the user
re-opens a recent file, the reader jumps to `lastPage` automatically.

**Tech Stack:** Svelte 5 (runes), TypeScript, Tailwind, Tauri 2, pdfium-render
for the existing thumbnail command (`slab_pdf_thumbnail`).

**Buy-Button test:** Pick-us test — Acrobat's Home tab is universally hated;
PDF Expert's recents are flat with no resume. A user who opens Slab on Monday
morning and lands directly on the page they left off Friday will not go back.
**Wow moment:** the "Continue reading" hero card with progress dots that pulse
when the file is reopened.

**Step 3: Implement**

In `src/lib/recent.ts`:

```ts
export type RecentFile = {
  path: string;
  name: string;
  openedAt: number;
  pageCount?: number;
  pinned?: boolean;
  lastPage?: number;     // 1-indexed last viewed page
  totalPages?: number;   // duplicate of pageCount but always set when progress known
};

export function recordRecentProgress(
  path: string,
  progress: { lastPage: number; totalPages: number },
) {
  const cur = read();
  const idx = cur.findIndex((r) => r.path === path);
  if (idx < 0) return;
  const next = [...cur];
  next[idx] = {
    ...next[idx],
    lastPage: progress.lastPage,
    totalPages: progress.totalPages,
    pageCount: progress.totalPages,
  };
  write(next);
}
```

Update `recordRecent` to preserve `lastPage`/`totalPages` from existing entry
(same pattern as `pinned`).

Update the array filter in `read()` to allow optional numeric fields through.

## Task 2: Wire reader to emit progress updates

**Objective:** Each time the user changes page in ReaderPanel (or scrolls past
a page boundary), call `recordRecentProgress`. Debounced 800ms.

**Files:**
- Modify: `src/lib/panels/ReaderPanel.svelte` — find the page-change handler
  (`currentPage` reactive or `goto(page)` function), add the call.

**Step 1: Add a debounce helper at top of <script>**

```ts
let progressTimer: ReturnType<typeof setTimeout> | null = null;
function scheduleProgressSave(path: string, page: number, total: number) {
  if (progressTimer) clearTimeout(progressTimer);
  progressTimer = setTimeout(() => {
    recordRecentProgress(path, { lastPage: page, totalPages: total });
  }, 800);
}
```

**Step 2:** Find where `currentPage` is set after navigation and call

**Files:**
- Modify: `src/lib/panels/ReaderPanel.svelte` — after the doc is loaded and we
  know `totalPages`, look up the recent record and call `goto(lastPage)` if
  set and ≤ totalPages.

**Step 1: Add to the post-load effect**

```ts
import { listRecent } from "$lib/recent";

// after document loaded:
const saved = listRecent().find((r) => r.path === currentPath);
if (saved?.lastPage && saved.lastPage > 1 && saved.lastPage <= totalPages) {
  goto(saved.lastPage);
  showResumeToast(saved.lastPage, totalPages);
}
```

**Step 2: Add a toast call** so user knows why they didn't land on page 1.

```ts
function showResumeToast(page: number, total: number) {
  notify({
    kind: "info",
    title: "Resumed where you left off",
    message: `Page ${page} of ${total}`,
    actionLabel: "Go to page 1",
    onAction: () => goto(1),
  });
}
```

(Use the existing notify API from `src/lib/notify.ts`; check its shape first
and adapt.)

**Step 3:** Manual verification path: open a PDF, scroll to page 5, close,
