## Slice 0: HOTFIX — `.gitattributes` LF normalization (ships on `main`)

**Objective:** Make v2.0.1's `include_str!` produce byte-identical content
on Linux, macOS, AND Windows so the bundled-plugin sha256 verification
passes in CI. This is a 3-commit hotfix that ships *before* any v2.0.2
work, on a fresh tag `v2.0.1+ci.1` (we keep `v2.0.1` itself — releases
are immutable; we re-tag as `v2.0.2-pre.1` if you'd rather just roll into
v2.0.2 directly).

**Decision:** Roll the hotfix straight into v2.0.2 as Slice 0. The v2.0.1
GitHub release stays as-is (artifacts already published from earlier CI
run `26145461445`'s actually it was v2.0.0's run — but v2.0.1's tag was
auto-published already if the workflow's release job ran; otherwise we
hand-finalize on v2.0.2). **TL;DR:** v2.0.1 stays tagged but un-released
on GH if CI never finished; v2.0.2 will ship binaries for both.

### Files

- **Create:** `.gitattributes`
- **Touch (renormalize):** every text file under git tracking (one
  `git add --renormalize .` after .gitattributes lands)
- **No source edits** — the sha256 in `manifest.toml` is already computed
  for the LF bytes, which is what we want.

### Step 1.2: Implement `IndexEntryV2`

In `src-tauri/src/marketplace/index.rs`, below `IndexEntry`:

```rust
/// v2 index entry. Wraps v1 unchanged + adds discovery metadata that
/// powers the Browse-tab UI (categories, tags, install counters,
/// screenshot carousel). Signing payload `IndexEntryUnsignedV2` puts
/// v1 fields first, in declaration order, so the wire format is a
/// strict superset of v1.
///
/// **Why a wrapper, not an extension of `IndexEntry`?** Existing
/// signed v1 indices must continue to verify. If we mutated
/// `IndexEntry` itself, every old index would need re-signing. The
/// `flatten` attribute keeps the JSON shape flat (no `v1: { ... }`
/// nesting on the wire) while the type system keeps the boundary
/// crisp for the verifier and the maintainer signing tool.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct IndexEntryV2 {
    #[serde(flatten)]
    pub v1: IndexEntry,
    /// Curated category slugs (e.g. "productivity", "ai", "developer").
    /// Used by the Browse tab to render chip filters. Plain strings —
    /// the host doesn't enforce a closed enum; the maintainer signs
    /// whatever they want, the UI shows the union, the user filters.
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub categories: Vec<String>,
    /// Free-form tags for full-text search. Lowercase, dash-separated
    /// by convention but unenforced.
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub tags: Vec<String>,
    /// HTTPS URLs to PNG/WebP/JPG screenshots. Browse tab renders a
    /// carousel in the detail drawer.
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub screenshots: Vec<String>,
    /// Approximate install count, snapshotted by the maintainer at
    /// index-publishing time. Not real-time; not a leaderboard;
    /// social proof only.
    #[serde(default, skip_serializing_if = "is_zero_u64")]
    pub installs: u64,
}

fn is_zero_u64(v: &u64) -> bool { *v == 0 }

/// v2 canonical signing payload. Flattens v1 (declaration order
/// preserved) and appends the v2 fields in declaration order.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct IndexEntryUnsignedV2 {
    #[serde(flatten)]
    pub v1: IndexEntryUnsigned,
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub categories: Vec<String>,
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub tags: Vec<String>,
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub screenshots: Vec<String>,
    #[serde(default, skip_serializing_if = "is_zero_u64")]
    pub installs: u64,
}

impl IndexEntryV2 {
    /// Strip `signature` (lives on `v1`), return v2 canonical payload.
    pub fn to_unsigned(&self) -> IndexEntryUnsignedV2 {
        IndexEntryUnsignedV2 {
            v1: self.v1.to_unsigned(),
            categories: self.categories.clone(),
            tags: self.tags.clone(),
            screenshots: self.screenshots.clone(),
            installs: self.installs,
        }
    }
}
```

```rust
/// Embedded seed-index that ships with the Slab binary. Powers a
/// useful Browse tab on first launch, before the user's first
/// network fetch completes. Bundled plugins are listed here as
/// `bundled://` entries so the UI can show "Open" instead of
/// "Install" for them.
const EMBEDDED_SEED_INDEX_BYTES: &[u8] =
    include_bytes!("../../../assets/marketplace/seed-index.json");

pub fn embedded_seed_index() -> Result<Index, FetchIndexError> {
    serde_json::from_slice::<Index>(EMBEDDED_SEED_INDEX_BYTES)
        .map_err(|e| FetchIndexError::Parse(e.to_string()))
}
```

Then in `fetch_index_with_cache`, on the `NoCacheAndNoNet` branch fall
through to `embedded_seed_index()` and tag the result with
`IndexSource::EmbeddedSeed` so the UI can show a "Showing built-in

### Step 3.4: Bypass Ed25519 verification for `BUNDLED` entries

`src-tauri/src/marketplace/verify.rs`:

```rust
/// Sentinel signature value used by bundled entries. The verifier
/// trusts them implicitly because they ship in-binary; using the
/// real maintainer key here would force a build-time signing step
/// during `cargo build` which we'd rather avoid.
const BUNDLED_SENTINEL: &str = "BUNDLED";

// In verify_entry, before the Ed25519 check:
if entry.v1.signature == BUNDLED_SENTINEL
    && entry.v1.download_url.starts_with("bundled://")
{
    return Ok(());  // trusted by construction
}
```

    if (!marketplace.index) return [];

        }
    }
    return [...counts.entries()]
        .map(([slug, count]) => ({ slug, count }))
        .sort((a, b) => b.count - a.count || a.slug.localeCompare(b.slug));

let searchQuery = $state<string>("");

let fuseInstance = $derived.by(() => {

            { name: "author", weight: 0.5 },

    if (!searchQuery.trim() || !fuseInstance) {

```typescript
function highlightMatches(
    text: string,
    matches: readonly Fuse.FuseResultMatch[],
    key: string
): { plain: string; isMatch: boolean }[] {
    const match = matches.find((m) => m.key === key);
    if (!match || !match.indices) return [{ plain: text, isMatch: false }];
    const parts: { plain: string; isMatch: boolean }[] = [];
    let cursor = 0;
    for (const [start, end] of match.indices) {
        if (start > cursor) parts.push({ plain: text.slice(cursor, start), isMatch: false });
        parts.push({ plain: text.slice(start, end + 1), isMatch: true });
        cursor = end + 1;
    }
    if (cursor < text.length) parts.push({ plain: text.slice(cursor), isMatch: false });
    return parts;
}
```
