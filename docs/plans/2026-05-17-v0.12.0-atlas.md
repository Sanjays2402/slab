# v0.12.0 "Atlas" — Library Mode Implementation Plan

> **For Hermes:** Backend-heavy version. Slice 1 (this plan) ships the library registry + scanner + query + Tauri commands in one tick. Subsequent slices add the UI (LibraryPanel), cross-doc Beacon chat, watch-folder daemon, saved searches, and smart bookmarks.

**Goal:** Slab stops being a single-doc reader and becomes a library tool — index folders of PDFs, tag/filter/search across the whole collection, and (in Slice 4) ask Beacon questions that span the entire library with multi-doc citations.

**Architecture:**

- `pdf::library::registry` — SQLite-backed CRUD on `library_folders`, `library_documents`, `library_tags`, `library_doc_tags`. Schema is migration-versioned (`PRAGMA user_version`). Single connection per app run.
- `pdf::library::scanner` — recursively walks a registered folder, finds `*.pdf` files, hashes (SHA-256 of contents + size + mtime quick-key), and upserts into `library_documents`. Skips unchanged files by `(size, mtime_ns)` quick-key — full hash only computed on first sight or quick-key mismatch.
- `pdf::library::query` — list / filter / sort docs by tag, folder, recent, content-substring. Returns `DocumentRecord` rows with attached tags array.
- `pdf::library::watch` (Slice 2) — `notify` crate filesystem watcher daemon. Not in Slice 1.
- Tauri commands in `lib.rs` — `slab_library_*` family wired into `invoke_handler!`. Library DB at `~/.slab/library.sqlite` (separate file from `beacon-index.sqlite`).

**Tech Stack:** `rusqlite` (already a dep), `sha2` (already a dep), `walkdir` (new — needed to traverse symlinks safely + skip broken paths). No new heavy deps.

**Why not reuse `EmbeddingIndex`'s sqlite file?** Library metadata is read on every app launch and on every panel open. Keeping it in its own DB file means we can VACUUM/migrate independently from the (much heavier) embedding index, and the user can `rm ~/.slab/library.sqlite` to reset their library without losing Beacon embeddings.

### Task 2: `pdf::library::registry`
- New module `src-tauri/src/pdf/library/mod.rs` + `registry.rs`
- Schema (versioned via `PRAGMA user_version`):
  ```sql
  CREATE TABLE library_folders (
      id INTEGER PRIMARY KEY,
      path TEXT NOT NULL UNIQUE,
      added_at INTEGER NOT NULL,
      last_scanned_at INTEGER
  );
  CREATE TABLE library_documents (
      id INTEGER PRIMARY KEY,
      folder_id INTEGER REFERENCES library_folders(id) ON DELETE CASCADE,
      path TEXT NOT NULL UNIQUE,
      title TEXT,
      hash TEXT NOT NULL,
      size_bytes INTEGER NOT NULL,
      mtime_ns INTEGER NOT NULL,
      pages INTEGER,
      added_at INTEGER NOT NULL,
      last_seen_at INTEGER NOT NULL
  );
  CREATE TABLE library_tags (
      id INTEGER PRIMARY KEY,
      name TEXT NOT NULL UNIQUE,
      color TEXT
  );
  CREATE TABLE library_doc_tags (
      doc_id INTEGER REFERENCES library_documents(id) ON DELETE CASCADE,
      tag_id INTEGER REFERENCES library_tags(id) ON DELETE CASCADE,
      PRIMARY KEY (doc_id, tag_id)
  );
  ```

  - `list_documents(filter) -> Vec<DocumentRecord>`

### Task 3: `pdf::library::scanner`
- New `src-tauri/src/pdf/library/scanner.rs`
- Public API:
  - `scan_folder(db: &mut LibraryDb, folder: &FolderRecord) -> Result<ScanReport>`
- Algorithm:
  - walk `folder.path` recursively with `walkdir` (follow_links=false, max_depth=12)
  - for each file with `.pdf` extension:
    - read `(size, mtime_ns)` quick-key from `std::fs::metadata`
    - lookup `library_documents` by path
    - if no row OR quick-key mismatch → compute SHA-256, read page count (from lopdf), call `upsert_document`
    - else → bump `last_seen_at` only
  - mark folder `last_scanned_at = now`
- `ScanReport { folder_id, files_scanned, files_added, files_updated, files_unchanged }`
- Tests:
  - scans_empty_folder
  - finds_pdfs_in_root
  - finds_pdfs_in_subdir
  - skips_non_pdf_files
  - quick_key_unchanged_skips_hash (using mtime fixture)
  - quick_key_changed_re_hashes
- Commit: `feat(atlas): library scanner — walk + hash + index`
