# v3.21.0 "Hopper Conditions" Implementation Plan

> **For Hermes/Cake (cron):** Use subagent-driven-development to execute this
> plan task-by-task, OR execute directly across 1-2 ticks of the off-hours
> autonomy loop (recommended — these tasks are small enough). Each task fits
> in 2-5 minutes of focused work and ends with a commit. Quality gates run
> ONCE at the end of each tick (cargo fmt/clippy/test --lib + pnpm check).

**Goal:** Upgrade Hopper from "one recipe per watched folder" to "**rule-based
routing**" so a single inbox can fan out: tax PDFs go through the bates+OCR
recipe and file into `~/Documents/Taxes/2026/`, scanned receipts go through
flatten+redact and file into `~/Documents/Receipts/`, everything else falls
through to a default. This is the feature that takes Hopper from "cool demo"
to "I run my whole document workflow on this."

**Architecture:**
- New `pdf::hopper::rules` module: a Rule = (predicate, action). Predicates
  evaluate against `RuleContext { filename, parent_dir, page_count, text_sample, size_bytes }`.
  Actions override the `Watch`'s default recipe_id / output_dir / rename_pattern.
- `pipeline::process_one` evaluates rules in priority order, picks the first
  match, and applies its action over the base `Watch` defaults.
- Rules persist as JSON in a new sqlite column `watches.rules_json` (nullable,
  default `[]`) — keeps the schema-migration story tiny.
- Frontend: HopperPanel grows a "Rules" section per-watch (add/reorder/delete),
  using the same Liquid Glass styling as the existing recipe picker. Each rule
  is a row: `IF [filename matches] [glob] THEN [recipe] [output] [rename]`.
- Run log gets a new optional `matched_rule` column so users can see *why* a
  file was routed where it was.

**Tech Stack:** Rust 1.81 (existing), `rusqlite` (existing), `globset = "0.4"`
(new dep — tiny, no transitive bloat), `regex = "1"` (already in tree),
Svelte 5 + TS (existing), Tauri 2 (existing).

```rust
use globset::Glob;
use regex::Regex;

/// Information about an arrived file that predicates evaluate against.
#[derive(Debug, Clone)]
pub struct RuleContext<'a> {
    pub filename: &'a str,
    pub parent_dir: &'a str,
    pub size_bytes: u64,
    pub page_count: Option<u32>,
    /// First ~2KB of extracted text (lowercased). `None` if extraction failed.
    pub text_sample: Option<&'a str>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(tag = "kind", rename_all = "kebab-case")]
pub enum RulePredicate {
    /// Filename matches a glob (e.g. `tax_*.pdf`, `*receipt*`).
    FilenameGlob { pattern: String },
    /// Filename matches a regex (case-insensitive).
    FilenameRegex { pattern: String },
    /// Extracted text contains ALL of these (case-insensitive) substrings.
    TextContainsAll { needles: Vec<String> },
    /// Page count in the given inclusive range.
    PageCountBetween { min: u32, max: u32 },
    /// File size larger than N bytes (useful: "scanned PDFs > 1 MB").
    SizeOver { bytes: u64 },
    /// Always matches — use as a catch-all fallback rule.
    Always,
}

impl Default for RulePredicate {
    fn default() -> Self { Self::Always }
}

impl RulePredicate {
    /// Returns true iff the predicate matches the context. Malformed
    /// glob/regex patterns evaluate to `false` (rule is silently skipped
    /// — surfaced via the UI test panel in Task 9).
    pub fn matches(&self, ctx: &RuleContext<'_>) -> bool {
        match self {
            Self::Always => true,
            Self::FilenameGlob { pattern } => Glob::new(pattern)
                .ok()
                .map(|g| g.compile_matcher().is_match(ctx.filename))
                .unwrap_or(false),
            Self::FilenameRegex { pattern } => {
                let p = format!("(?i){pattern}");
                Regex::new(&p).ok().map(|r| r.is_match(ctx.filename)).unwrap_or(false)
            }
            Self::TextContainsAll { needles } => {
                let Some(sample) = ctx.text_sample else { return false };
                needles.iter().all(|n| sample.contains(&n.to_lowercase()))
            }
            Self::PageCountBetween { min, max } => {
                ctx.page_count.is_some_and(|p| p >= *min && p <= *max)
            }
            Self::SizeOver { bytes } => ctx.size_bytes > *bytes,
        }
    }
}
```

```rust
use super::registry::Watch;

/// Resolved routing decision after rule evaluation.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ResolvedRouting {
    pub recipe_id: Option<String>,
    pub output_dir: String,
    pub rename_pattern: Option<String>,
    pub matched_rule: Option<String>,
}

impl Rule {
    /// Build the overlay action over the base watch, returning a ResolvedRouting.
    pub fn apply_over(&self, base: &Watch) -> ResolvedRouting {
        ResolvedRouting {
            recipe_id: self.action.recipe_id.clone().or_else(|| base.recipe_id.clone()),
            output_dir: self.action.output_dir.clone().unwrap_or_else(|| base.output_dir.clone()),
            rename_pattern: self.action.rename_pattern.clone().or_else(|| base.rename_pattern.clone()),
            matched_rule: Some(self.name.clone()),
        }
    }
}

/// Evaluate `rules` in order, returning the routing from the first match, or
/// the watch's defaults (with `matched_rule = None`) when nothing matches.
pub fn evaluate_rules(rules: &[Rule], base: &Watch, ctx: &RuleContext<'_>) -> ResolvedRouting {
    for r in rules {
        if r.predicate.matches(ctx) {
            return r.apply_over(base);
        }
    }
    ResolvedRouting {
        recipe_id: base.recipe_id.clone(),
        output_dir: base.output_dir.clone(),
        rename_pattern: base.rename_pattern.clone(),
        matched_rule: None,
    }
}
```

```rust
use super::rules::Rule;

impl HopperRegistry {
    pub fn set_rules(&mut self, id: i64, rules: &[Rule]) -> rusqlite::Result<()> {
        let json = serde_json::to_string(rules)
            .map_err(|e| rusqlite::Error::ToSqlConversionFailure(Box::new(e)))?;
        self.conn.execute(
            "UPDATE watches SET rules_json = ?1 WHERE id = ?2",
            params![json, id],
        )?;
        Ok(())
    }

    pub fn get_rules(&self, id: i64) -> rusqlite::Result<Vec<Rule>> {
        let json: Option<String> = self.conn
            .query_row("SELECT rules_json FROM watches WHERE id = ?1", params![id],
                       |r| r.get(0))
            .optional()?
            .flatten();
        let json = json.unwrap_or_else(|| "[]".into());
        serde_json::from_str(&json)
            .map_err(|e| rusqlite::Error::FromSqlConversionFailure(0, rusqlite::types::Type::Text, Box::new(e)))
    }
}
```

```rust
/// Test a single rule predicate against a real file on disk — returns
/// whether it matched plus a one-line "why". Used by the live preview UI.
#[tauri::command]
pub async fn hopper_test_rule(predicate: super::rules::RulePredicate, file_path: String)
    -> Result<RuleTestResult, String>
{
    let path = std::path::PathBuf::from(&file_path);
    let meta = std::fs::metadata(&path).map_err(|e| format!("stat failed: {e}"))?;
    let filename = path.file_name().and_then(|s| s.to_str()).unwrap_or("");
    let parent = path.parent().and_then(|p| p.to_str()).unwrap_or("");
    let pages = crate::pdf::page_count_of(&path).ok();
    let ctx = super::rules::RuleContext {
        filename, parent_dir: parent,
        size_bytes: meta.len(),
        page_count: pages,
        text_sample: None,  // v1: filename/size/page-count only in preview; text in v3.22.0
    };
    Ok(RuleTestResult { matched: predicate.matches(&ctx), filename: filename.into(), size_bytes: meta.len(), page_count: pages })
}

#[derive(serde::Serialize)]
pub struct RuleTestResult {
    pub matched: bool,
    pub filename: String,
    pub size_bytes: u64,
    pub page_count: Option<u32>,
}

/// Sample N files from the watch source_dir for the preview panel.
#[tauri::command]
pub async fn hopper_list_recent_inputs(state: tauri::State<'_, HopperState>, watch_id: i64, limit: usize)
    -> Result<Vec<String>, String>
{
    let watch = state.registry.lock().await.get(watch_id).map_err(|e| e.to_string())?
        .ok_or_else(|| format!("watch {watch_id} not found"))?;
    let mut entries: Vec<_> = std::fs::read_dir(&watch.source_dir).map_err(|e| e.to_string())?
        .filter_map(|e| e.ok())
        .filter(|e| e.path().extension().and_then(|s| s.to_str()).map(|s| s.eq_ignore_ascii_case("pdf")).unwrap_or(false))
        .map(|e| e.path().to_string_lossy().into_owned())
        .collect();
    entries.sort();
    entries.truncate(limit.max(1).min(50));
    Ok(entries)
}
```

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import {
    hopperGetRules, hopperSetRules, hopperTestRule, hopperListRecentInputs,
    type Rule, type RulePredicate, type RuleTestResult
  } from '$lib/hopper';

  export let watchId: number;
  export let recipes: { id: string; name: string }[] = [];

  let rules: Rule[] = [];
  let recentFiles: string[] = [];
  let matchMatrix: Map<string, RuleTestResult[]> = new Map();
  let saveTimer: ReturnType<typeof setTimeout> | null = null;

  onMount(async () => {
    rules = await hopperGetRules(watchId);
    recentFiles = await hopperListRecentInputs(watchId, 5);
    await recompute();
  });

  async function recompute() {
    matchMatrix = new Map();
    for (const f of recentFiles) {
      const row: RuleTestResult[] = [];
      for (const r of rules) row.push(await hopperTestRule(r.predicate, f));
      matchMatrix.set(f, row);
    }
    matchMatrix = matchMatrix; // svelte reactivity
  }

  function scheduleSave() {
    if (saveTimer) clearTimeout(saveTimer);
    saveTimer = setTimeout(async () => {
      await hopperSetRules(watchId, rules);
      await recompute();
    }, 600);
  }

  function addRule() {
    rules = [...rules, { name: 'New rule', predicate: { kind: 'always' }, action: { recipe_id: null, output_dir: null, rename_pattern: null } }];
    scheduleSave();
  }

  function removeRule(i: number) {
    rules = rules.filter((_, j) => j !== i);
    scheduleSave();
  }

  function moveUp(i: number) {
    if (i === 0) return;
    [rules[i - 1], rules[i]] = [rules[i], rules[i - 1]];
    rules = rules;
    scheduleSave();
  }

  function setPredicateKind(i: number, kind: RulePredicate['kind']) {
    const defaults: Record<RulePredicate['kind'], RulePredicate> = {
      'filename-glob':       { kind: 'filename-glob', pattern: '*.pdf' },
      'filename-regex':      { kind: 'filename-regex', pattern: '.*' },
      'text-contains-all':   { kind: 'text-contains-all', needles: [] },
      'page-count-between':  { kind: 'page-count-between', min: 1, max: 10 },
      'size-over':           { kind: 'size-over', bytes: 1_000_000 },
      'always':              { kind: 'always' },
    };
    rules[i].predicate = defaults[kind];
    rules = rules;
    scheduleSave();
  }

  function winningRuleIndex(file: string): number {
    const row = matchMatrix.get(file) ?? [];
    return row.findIndex(r => r.matched);
  }
</script>

      {/each}

  {/if}

  {#if recentFiles.length > 0}

      <ul>
        {#each recentFiles as f}

            {:else}
              <span class="match-chip grey">default</span>
            {/if}
```
