# v3.2.0 "Press" — PDF/X-4 Print Production Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task. ~1700 net LOC + ~550 test LOC across 9 slices + release. ~10 commits.

**Goal:** Convert any PDF into a fully ISO 15930-7 compliant **PDF/X-4** (and PDF/X-4p variant) print-production document — embed every font, embed/reference an output-intent ICC profile (FOGRA51 coated by default, GRACoL2013 for North America, opt-in custom), normalize colour to a single intent (CMYK or DeviceN), ensure every page declares `TrimBox` (and optionally `BleedBox` / `MediaBox` ≥ TrimBox + 3mm bleed), strip JavaScript / external references / encryption / live transparency *resolution* metadata, inject the required `pdfxid` XMP packet, rewrite the catalog with the `GTS_PDFX` OutputIntent, and validate the result against ISO 15930-7 rules — offline, free, cross-platform, one click. The result is something a print shop will accept without manual fixup.

**Architecture:** New `pdf::pdfx` Rust module owns the conversion pipeline as **7 ordered passes** over a `lopdf::Document`:

1. **sanitize** — strip `/JS`, `/JavaScript`, `/AA`, `/OpenAction`, `/Encrypt`, `/AcroForm` (if not signed), and any `/F`-key external file references.
2. **font-embed** — reuse v0.8's font-subsetter to ensure every `/Font` resource has a `/FontFile2` or `/FontFile3` stream and a `/ToUnicode` CMap.
3. **color-normalize** — rewrite stray `DeviceRGB`/`DeviceGray` ops to their ICC-tagged equivalents pointing at the output intent's profile; downsample 16-bit images to 8-bit; flatten un-tagged spot colours into `DeviceN` channels.
4. **geometry** — for every page, ensure `MediaBox` ≥ `TrimBox` and that `TrimBox` exists; synthesize `TrimBox` from `CropBox` (or `MediaBox` if no crop) when missing; optionally add 3mm `BleedBox` outset.
5. **metadata-inject** — write XMP packet with `pdfxid:GTS_PDFXVersion=PDF/X-4`, `pdfxid:GTS_PDFXConformance=PDF/X-4`, `xmp:CreateDate`, `dc:title`, plus mandatory `xmp:CreatorTool=Slab vX.Y.Z`.
6. **output-intent** — inject `OutputIntents` array in `/Catalog` with `/S /GTS_PDFX`, `/OutputConditionIdentifier`, `/RegistryName=http://www.color.org`, `/DestOutputProfile` (embedded ICC stream).
7. **validate** — run a 32-rule subset of ISO 15930-7's automatable checks and emit a `Report { passed, failed: Vec<Failure { rule_id, severity, fix_hint }> }`.

Each pass is a pure function on `&mut Document` so it's independently unit-testable with golden PDFs. Frontend gets a **`PressPanel.svelte`** with output-intent picker (FOGRA51 / GRACoL2013 / sRGB-as-Y / custom upload), pre-flight report (what's blocking compliance), and a one-click Convert button.

**Tech Stack:** lopdf 0.36 (workspace), `quick-xml 0.36` (XMP), `flate2 1.0` (already in tree), `chrono 0.4` (already), shipped CMYK ICC profiles (FOGRA51 coated `Coated_v2_300_FOGRA51.icc` 558KB, GRACoL2013 coated `GRACoL2013_CRPC6.icc` 472KB — both ECI/IDEAlliance freely redistributable under CMS-licence terms) vendored under `assets/icc/`. Zero new C deps. Pure Rust. Reuses 100% of v3.0.0 Bedrock's XMP packet writer and font-embedder (extracted into `pdf::icc` and `pdf::xmp` shared crates last release).

```markdown
# ADR: PDF/X target conformance is X-4 (default), X-1a (opt-in for legacy)

## Status
Accepted, 2026-05-22.

## Context
ISO 15930 defines eight parts:
- PDF/X-1a (2001/2003, PDF 1.3/1.4): flat CMYK, no transparency, no
  spot-colour mixing into other inks. Print shops with very old RIPs
  still require this.
- PDF/X-3 (2002/2003, PDF 1.4): allows ICC-tagged RGB/Gray in addition
  to CMYK. Largely superseded by X-4.
- PDF/X-4 (2008/2010, PDF 1.6): allows live transparency, layers,
  OpenType, all colour spaces with output-intent. Modern sweet spot.
- PDF/X-4p: like X-4 but the OutputIntent profile is *referenced* by URL
  rather than embedded. For shops with strict shared-profile workflows.
- PDF/X-5g / X-5n / X-5pg: niche (external graphics, N-channel, etc.).
- PDF/X-6 (2020, PDF 2.0): minor updates for PDF 2.0; adoption is <2%.

## Decision
- **Default target: PDF/X-4** with FOGRA51 (Europe) or GRACoL2013 (NA)
  output intent. Output intent default is per-locale: US → GRACoL2013,
  rest of world → FOGRA51.
- **Opt-in via radio button**: PDF/X-4p (referenced profile) and PDF/X-1a
  (flat CMYK legacy mode — triggers extra flatten pass).
- **Custom output-intent ICC upload** deferred to v3.2.1.

## Consequences
- Two CMYK ICC profiles vendored (FOGRA51 558KB, GRACoL2013 472KB).
  Total binary growth: ~1.0MB. Acceptable.
- Live transparency is allowed in X-4 → no need to flatten by default.
  X-1a mode reuses v2.0.3 Flatten internals as a pre-pass.
- Slab becomes one of the only free cross-platform tools that emits
  ISO-compliant PDF/X-4 from arbitrary input.
```

**Step 2: Write `sanitize.rs` skeleton**

```rust
//! Pass 1: strip JS / OpenAction / Encrypt / external refs / AcroForm.

use lopdf::{Document, Object};
use super::Result;

const FORBIDDEN_KEYS: &[&[u8]] = &[
    b"JS", b"JavaScript", b"AA", b"OpenAction", b"Encrypt",
];

pub fn run(doc: &mut Document) -> Result<()> {
    // Strip top-level catalog keys
    let catalog_id = doc.trailer.get(b"Root").and_then(Object::as_reference).ok();
    if let Some(id) = catalog_id {
        if let Ok(Object::Dictionary(catalog)) = doc.get_object_mut(id) {
            for &key in FORBIDDEN_KEYS {
                catalog.remove(key);
            }
            // AcroForm: only remove if unsigned. For Slice 1 just remove.
            catalog.remove(b"AcroForm");
        }
    }
    // Walk every annotation, strip /A and /AA dictionaries.
    for (_id, obj) in doc.objects.iter_mut() {
        if let Object::Dictionary(d) = obj {
            if d.get(b"Type").and_then(Object::as_name).ok() == Some(b"Annot") {
                d.remove(b"A");
                d.remove(b"AA");
            }
        }
    }
    // Trailer: remove Encrypt
    doc.trailer.remove(b"Encrypt");
    Ok(())
}
```

## Slice 3: Colour-normalize pass

### Task 3.1: Rewrite DeviceRGB/DeviceGray ops to ICC-tagged equivalents

**Objective:** Per ISO 15930-7 §6.2, every colour in a PDF/X-4 must reference either the output-intent profile or a tagged ICC colour space. Walk every content stream, replace `rg`/`RG`/`g`/`G` operators with `scn`/`SCN` after pushing a colour space.

**Files:**
- Create: `src-tauri/src/pdf/pdfx/color.rs`

**Step 1: Write the colour-rewrite logic**

```rust
//! Pass 3: normalize untagged colour to the output intent's colour space.

use super::{ConvertOptions, Result};
use crate::pdf::icc::OutputIntent;
use lopdf::{content::Content, Document, Object, ObjectId};

pub fn run(doc: &mut Document, opts: &ConvertOptions) -> Result<()> {
    // For X-4: install an ICC-based ColorSpace resource pointing at the
    // output-intent profile, then rewrite content stream operators.
    let cs_name = format!("/CS_OUT_{}", opts.output_intent.identifier()
        .replace([' ', '-', '.'], "_"));
    let pages: Vec<ObjectId> = doc.get_pages().into_values().collect();
    for page_id in pages {
        install_colour_space(doc, page_id, opts.output_intent, &cs_name)?;
        rewrite_page_content(doc, page_id, &cs_name)?;
    }
    Ok(())
}

fn install_colour_space(
    doc: &mut Document, page_id: ObjectId, intent: OutputIntent, cs_name: &str,
) -> Result<()> {
    // Build an ICCBased colour space stream
    let icc_stream_id = doc.add_object(lopdf::Stream::new(
        lopdf::dictionary! {
            "N" => match intent.colour_space() { "CMYK" => 4, _ => 3 },
            "Alternate" => match intent.colour_space() {
                "CMYK" => Object::Name(b"DeviceCMYK".to_vec()),
                _ => Object::Name(b"DeviceRGB".to_vec()),
            },
        },
        intent.bytes().to_vec(),
    ).with_compression(true));
    let cs_array = Object::Array(vec![
        Object::Name(b"ICCBased".to_vec()),
        Object::Reference(icc_stream_id),
    ]);
    // Attach to page Resources/ColorSpace
    let page_dict = doc.get_object_mut(page_id)?.as_dict_mut()?;
    let resources = page_dict.get_mut(b"Resources")
        .or_else(|_| {
            page_dict.set("Resources", lopdf::dictionary!{});
            page_dict.get_mut(b"Resources")
        })?.as_dict_mut()?;
    let csd = resources.get_mut(b"ColorSpace")
        .or_else(|_| {
            resources.set("ColorSpace", lopdf::dictionary!{});
            resources.get_mut(b"ColorSpace")
        })?.as_dict_mut()?;
    csd.set(cs_name.trim_start_matches('/').as_bytes(), cs_array);
    Ok(())
}

fn rewrite_page_content(doc: &mut Document, page_id: ObjectId, cs_name: &str) -> Result<()> {
    let content_data = doc.get_page_content(page_id)?;
    let mut content = Content::decode(&content_data)?;
    let mut new_ops = Vec::with_capacity(content.operations.len() * 2);
    for op in content.operations.drain(..) {
        match op.operator.as_str() {
            "rg" | "RG" => {
                // Replace device RGB with tagged colour
                new_ops.push(lopdf::content::Operation::new(
                    if op.operator == "rg" { "cs" } else { "CS" },
                    vec![Object::Name(cs_name.trim_start_matches('/').as_bytes().to_vec())],
                ));
                new_ops.push(lopdf::content::Operation::new(
                    if op.operator == "rg" { "scn" } else { "SCN" },
                    op.operands,
                ));
            }
            "g" | "G" => {
                let val = op.operands.first().and_then(|o| match o {
                    Object::Real(r) => Some(*r), Object::Integer(i) => Some(*i as f32), _ => None,
                }).unwrap_or(0.0);
                new_ops.push(lopdf::content::Operation::new(
                    if op.operator == "g" { "cs" } else { "CS" },
                    vec![Object::Name(cs_name.trim_start_matches('/').as_bytes().to_vec())],
                ));
                new_ops.push(lopdf::content::Operation::new(
                    if op.operator == "g" { "scn" } else { "SCN" },
                    vec![val.into(), val.into(), val.into()], // grey → equal RGB or CMY
                ));
            }
            _ => new_ops.push(op),
        }
    }
    content.operations = new_ops;
    let encoded = content.encode()?;
    doc.change_page_content(page_id, encoded)?;
    Ok(())
}
```

## Slice 4: Geometry pass — TrimBox + BleedBox synthesis

### Task 4.1: Ensure every page has TrimBox; optionally outset BleedBox

**Objective:** PDF/X-4 §6.6 requires every page to declare a `TrimBox` (or a `BleedBox`, but TrimBox is what print shops want). Synthesize from `CropBox` or `MediaBox` when missing. If `opts.bleed_mm` is set, outset by that many mm and write `BleedBox`.

**Files:**
- Create: `src-tauri/src/pdf/pdfx/geometry.rs`

**Step 1: Implementation**

```rust
//! Pass 4: ensure TrimBox exists on every page; optionally synthesize BleedBox.

use super::{ConvertOptions, Result};
use lopdf::{Document, Object};

const MM_TO_PT: f32 = 72.0 / 25.4;

pub fn run(doc: &mut Document, opts: &ConvertOptions) -> Result<()> {
    let pages: Vec<_> = doc.get_pages().into_values().collect();
    for page_id in pages {
        let page = doc.get_object_mut(page_id)?.as_dict_mut()?;
        let media: [f32; 4] = read_box(page, b"MediaBox").unwrap_or([0.0, 0.0, 595.0, 842.0]);
        let crop = read_box(page, b"CropBox").unwrap_or(media);
        let trim = read_box(page, b"TrimBox").unwrap_or(crop);
        write_box(page, b"TrimBox", trim);
        if let Some(bleed_mm) = opts.bleed_mm {
            let outset = bleed_mm * MM_TO_PT;
            let bleed = [trim[0] - outset, trim[1] - outset,
                         trim[2] + outset, trim[3] + outset];
            // Bleed must be inside MediaBox; grow MediaBox if needed.
            let new_media = [
                media[0].min(bleed[0]), media[1].min(bleed[1]),
                media[2].max(bleed[2]), media[3].max(bleed[3]),
            ];
            write_box(page, b"MediaBox", new_media);
            write_box(page, b"BleedBox", bleed);
        }
    }
    Ok(())
}

fn read_box(d: &lopdf::Dictionary, key: &[u8]) -> Option<[f32; 4]> {
    let arr = d.get(key).ok()?.as_array().ok()?;
    if arr.len() != 4 { return None; }
    let mut out = [0.0; 4];
    for (i, o) in arr.iter().enumerate() {
        out[i] = match o {
            Object::Real(r) => *r, Object::Integer(i) => *i as f32, _ => return None,
        };
    }
    Some(out)
}

fn write_box(d: &mut lopdf::Dictionary, key: &[u8], v: [f32; 4]) {
    d.set(key, Object::Array(v.iter().map(|x| (*x).into()).collect()));
}
```

**Step 2: Tests — 4 cases**

1. Page has only MediaBox → TrimBox synthesized to match.
2. Page has CropBox smaller than MediaBox → TrimBox matches CropBox.
3. `bleed_mm = Some(3.0)` → BleedBox outset by 8.5pt on each side; MediaBox grown.
4. Existing TrimBox is preserved.
