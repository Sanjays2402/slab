# v3.33.0 "Atlas Smart" Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan
> task-by-task. One task = one delegated subagent + spec review + code review.

**Goal:** Make Smart Collections discoverable, creatable, and editable from the
UI — plus drag-from-doc-card-to-collection — so users can build "Recent invoices"
or "Untagged scans" without writing JSON.

**Buy-Button Test (which one this passes):** **Pick-us test** — Adobe Acrobat
has no equivalent. PDF Expert has no equivalent. Smart Collections are the
"Smart Mailboxes" of PDF and are table-stakes for an enterprise PDF workstation.
Also passes **Tell-a-friend** when the count badge pulses live as you tag a doc.

**Architecture:**
- Backend already ships `slab_smart_collection_create / list / delete / expand`
  taking a `NewSmartCollection { name, icon, color, filter: LibraryFilter }`.
  We just need an UPDATE command (currently missing) plus a frontend modal.
- New Svelte component `SmartCollectionBuilder.svelte` mounted inside
  `CollectionsSidebar.svelte`. Form-driven: name, icon, color, then a stack of
  filter rows (tag IS, title CONTAINS, folder IS, sort).
- Drag-and-drop: doc cards in `LibraryPanel.svelte` already render with id;
  add `draggable` + dataTransfer; add drop zone to sidebar collection rows
  that calls `collectionAddDocs`. Smart collection rows show "not droppable"
  cursor (their membership is computed).
- Command palette entries: "New smart collection…", "Edit smart collection…".
- Keyboard shortcut: `Cmd/Ctrl+Shift+N` opens the builder.

**Tech Stack:** Rust (rusqlite + serde_json), Tauri command layer, Svelte 5
runes, existing Liquid Glass design tokens.

/// Update one or more fields on a smart collection. Each `Option` is
/// "don't touch this field" when `None`. Use `Some(Some(value))` to set,
/// `Some(None)` to clear a nullable column.
pub fn update_smart_collection(
    db: &mut LibraryDb,
    id: i64,
    name: Option<&str>,
    icon: Option<Option<&str>>,
    color: Option<Option<&str>>,
    filter: Option<&LibraryFilter>,
) -> Result<SmartCollectionRecord, LibraryError> {
    let conn = db.conn_mut();
    if let Some(n) = name {
        conn.execute(
            "UPDATE library_smart_collections SET name = ?1 WHERE id = ?2",
            params![n, id],
        )?;
    }
    if let Some(ic) = icon {
        conn.execute(
            "UPDATE library_smart_collections SET icon = ?1 WHERE id = ?2",
            params![ic, id],
        )?;
    }
    if let Some(c) = color {
        conn.execute(
            "UPDATE library_smart_collections SET color = ?1 WHERE id = ?2",
            params![c, id],
        )?;
    }
    if let Some(f) = filter {
        let json = serde_json::to_string(f).map_err(|e| {
            LibraryError::Db(rusqlite::Error::ToSqlConversionFailure(Box::new(e)))
        })?;
        conn.execute(
            "UPDATE library_smart_collections SET query_json = ?1 WHERE id = ?2",
            params![json, id],
        )?;
    }
    get_smart_collection(db, id)
}
```

#[derive(serde::Deserialize)]
pub struct SmartCollectionUpdate {
    pub name: Option<String>,
    /// `None` = don't change; `Some(None)` = clear; `Some(Some(_))` = set.
    pub icon: Option<Option<String>>,
    pub color: Option<Option<String>>,
    pub filter: Option<crate::pdf::library::query::LibraryFilter>,
}

#[tauri::command]
async fn slab_smart_collection_update(
    state: tauri::State<'_, AppState>,
    id: i64,
    patch: SmartCollectionUpdate,
) -> Result<CmdResult<crate::pdf::library::collections::SmartCollectionRecord>, ()> {
    let mut db = state.library_db.lock().await;
    let res = crate::pdf::library::collections::update_smart_collection(
        &mut db,
        id,
        patch.name.as_deref(),
        patch.icon.as_ref().map(|o| o.as_deref()),
        patch.color.as_ref().map(|o| o.as_deref()),
        patch.filter.as_ref(),
    );
    Ok(match res {
        Ok(rec) => CmdResult::ok(rec),
        Err(e) => CmdResult::err(e.to_string()),
    })
}
```

**Step 2: TypeScript wrapper**

In `src/lib/library.ts` after `smartCollectionDelete`:

```ts
export interface SmartCollectionPatch {
  name?: string;
  /** `undefined` = leave alone; `null` = clear; string = set. */
  icon?: string | null;
  color?: string | null;
  filter?: LibraryFilter;
}

export async function smartCollectionUpdate(
  id: number,
  patch: SmartCollectionPatch,
): Promise<SmartCollectionRecord> {
  // Convert the JS double-optional encoding to the Rust one.
  const rustPatch = {
    name: patch.name ?? null,
    icon: patch.icon === undefined ? null : { Some: patch.icon },
    color: patch.color === undefined ? null : { Some: patch.color },
    filter: patch.filter ?? null,
  };
  const res = await invoke<CmdResult<SmartCollectionRecord>>(
    "slab_smart_collection_update",
    { id, patch: rustPatch },
  );
  return unwrap(res);
}
```

NOTE: Serde defaults serialize `Option<Option<T>>` as `null | T` from JSON, so
the simpler shape `{ icon: patch.icon ?? null }` MAY work — verify by running
the integration test in Task 4. Use whichever serde accepts.

## Task 3: `SmartCollectionBuilder.svelte` modal

**Objective:** Modal for creating/editing a smart collection with a visual
filter builder (no JSON in sight).

**Files:**
- Create: `src/lib/panels/SmartCollectionBuilder.svelte`

**Step 1: Component skeleton**

Build a Svelte 5 component that takes `{ open, editing?: SmartCollectionRecord, onClose, onSaved }` props.

Required UI sections:

1. **Header**: "New smart collection" or "Edit «name»". Close button (X).
2. **Identity row**: text input for name, icon picker (8-12 hardcoded
   Lucide-style emoji glyphs: 📁 ⭐ 🧾 🧪 📚 🔬 📨 🗂️ 🏷️ 🕒), color swatches
   (8 from existing Liquid Glass palette: violet, sky, emerald, amber, rose,
   pink, indigo, slate).
3. **Filter rules** — repeating rows. Each row = `{ field, op, value }`:
   - `field`: select (Title, Tag, Folder)
   - `op`: select dependent on field (Title → contains; Tag → is any of /
     is none of; Folder → is)
   - `value`: input/select dependent on field (Title → text input; Tag →
     multi-select from `listTags()`; Folder → single-select from `listFolders()`)
   - Trash button to remove the row.
   - "+ Add rule" button at bottom.
4. **Sort row**: select (Recently added / Title A→Z / Recently opened).
5. **Live preview pane** on the right: re-runs `listDocuments(filterFromForm)`
   debounced 250ms, shows first 8 matches as compact cards + total count badge.
6. **Footer**: Cancel / Save buttons. Save calls
   `smartCollectionCreate({name, icon, color, filter})` or
   `smartCollectionUpdate(editing.id, {name, icon, color, filter})`.

**Step 2: Filter shape mapping**

The internal builder model is a flat array of rows. Convert to `LibraryFilter`
on each preview tick:

```ts
function buildFilter(rows: Rule[], sort: LibrarySortBy): LibraryFilter {
  const f: LibraryFilter = { sort };
  for (const r of rows) {
    if (r.field === "title" && r.op === "contains" && r.value)
      f.title_substring = r.value;
    if (r.field === "tag" && r.value?.length) f.tag_ids = r.value;
    if (r.field === "folder" && r.value != null) f.folder_id = r.value;
  }
  return f;
}
```

(LibraryFilter today only supports AND across `title_substring`,
`tag_ids`, `folder_id` — that's fine for v3.33.0. v3.34.0 can add NOT/OR.)

async function handleSave() {

**Step 2: Sidebar → drop target**

```svelte
<button
  class="cs-row"
  class:drag-over={dragOverId === c.id}
  ondragover={(e) => { e.preventDefault(); e.dataTransfer.dropEffect = "copy"; dragOverId = c.id; }}
  ondragleave={() => { if (dragOverId === c.id) dragOverId = null; }}
  ondrop={async (e) => {
    e.preventDefault();
    dragOverId = null;
    const raw = e.dataTransfer.getData("application/x-slab-doc-ids");
    if (!raw) return;
    const ids = JSON.parse(raw) as number[];
    const added = await collectionAddDocs(c.id, ids);
    window.dispatchEvent(new CustomEvent("library-changed"));
    toast(`Added ${added} doc${added === 1 ? "" : "s"} to "${c.name}"`);
  }}
>
```
