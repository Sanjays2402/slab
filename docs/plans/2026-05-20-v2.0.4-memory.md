# v2.0.4 "Memory" Implementation Plan

> **For Hermes (Cake / cron):** Execute via subagent-driven-development —
> one fresh subagent per slice, two-stage review (spec compliance → code
> quality), proceed only when both pass.
>
> **Branch:** `feature/v2.0.4-memory` (cut from `main` AFTER v2.0.3 ships;
> see scheduling note at the end of this plan).

**Goal:** Slab remembers where you left off. Reopen any recent file and
you land on the exact page (and zoom level) you closed at. The Recents
grid shows a progress ring per card, the bottom of the Reader shows a
live percent-read, and the command palette gets a "Resume reading…"
entry. Adobe Acrobat and PDF Expert both ship this — Slab currently
doesn't, and the gap is the single most-noticed regression for anyone
switching away from those products.

**Architecture (3 sentences):**
- Extend the existing `RecentFile` shape in `src/lib/recent.ts` with three
  optional fields — `lastPage`, `pageCount`, `lastZoom` — and a new
  per-tick localStorage namespace `slab.reading.positions.v1` keyed by
  absolute path. No backend changes; reading position is a frontend
  concern only.
- `ReaderPanel.svelte` subscribes to `pagechanging` + `scalechanging`
  events (already wired) and debounce-writes the new position 500ms
  after the user stops paging/zooming. On `loadBytes`, after pdfjs
  reports `pagesinit`, we restore the saved page + zoom *if* the path
  matches a stored position and the page is still in range.
- Visual payoff lives in three places: a thin SVG progress ring on each
  Recents card (replacing the bottom-aligned "X pages · Yh ago" text
  line with a stacked layout), a `Reader %` chip in the Reader toolbar
  (right of the page-number input), and a command-palette "Resume
  reading…" entry that lists the top 3 in-progress documents.

**Tech Stack:**
- Frontend only: Svelte 5 runes, existing localStorage helpers, existing
  `notify.ts`, existing `t()` i18n. **No new runtime dependencies.**
- Pure-TypeScript unit tests via `vitest` (already configured for
  `src/lib/recent.test.ts` and friends — verify in Slice 0).
- No Rust changes. No Tauri commands. No new IPC surface.

**Buy-Button verdict (release level):**
- **Pick-us PASS** — Adobe / PDF Expert / Foxit all remember last page.
  A returning customer who tried Slab and noticed "it dropped me on
  page 1 of my 400-page textbook" will install one of the paid products
  instead. Closing this gap is a hard prerequisite for the v1.0.0
  launch narrative.
- **Notice-it PASS** — Anyone who upgrades and reopens *any* file they
  had open in v2.0.3 sees the new behaviour the moment the file
  finishes loading: pdfjs jumps to their last page. Returning users
  also see new progress rings on every Recents card.
- **Tell-a-friend PASS** — The progress-ring grid is genuinely
  screenshot-worthy. "Look, my PDF reader shows me which of my 12
  recent textbooks I've actually read most of" — that's a /r/macapps
  + Twitter-grade demo image.

**WOW moment (Slice 4):** Open Slab → Recents grid renders → every
in-progress document shows a circular progress ring superimposed on the
thumbnail with a percentage label. A 312-page PDF you're 47% through
shows a thick, accent-tinted arc filling 47% of the ring. Hover and the
ring tooltip says "Page 147 of 312". Click it → land on page 147.
**That's the user's reading life, visualized.**

```ts
// Per-file reading-position store, backed by localStorage.
//
// Slab's "remember where I left off" behaviour. Distinct from `recent.ts`
// (which is a *listing* of recently opened files) — this module owns
// per-path scroll-state only, so a future Pro-tier sync layer can drop
// in a different backend without touching the recents grid.
//
// Storage shape: `Record<absolutePath, ReadingPosition>` under the key
// `slab.reading.positions.v1`. Bounded to MAX_ENTRIES paths; the oldest
// (by `updatedAt`) is evicted when we exceed the cap.

const KEY = "slab.reading.positions.v1";
const MAX_ENTRIES = 200; // ~50 KB worst case at ~250 B / entry

export type ReadingPosition = {
  /** 1-indexed page the user was viewing when they last paused. */
  page: number;
  /** Total pages in the document at the time of the last save. Used to
   *  compute progress percent without re-opening the PDF. */
  pageCount: number;
  /** pdfjs `currentScaleValue` — either a named token ("page-width",
   *  "auto") or a numeric string ("1.25"). Restored verbatim. */
  zoom: string;
  /** unix ms — when we last wrote this entry. Used for eviction order. */
  updatedAt: number;
};

type Store = Record<string, ReadingPosition>;
type Listener = (path: string, pos: ReadingPosition | null) => void;
const listeners = new Set<Listener>();

function read(): Store {
  if (typeof localStorage === "undefined") return {};
  try {
    const raw = localStorage.getItem(KEY);
    if (!raw) return {};
    const parsed = JSON.parse(raw);
    if (!parsed || typeof parsed !== "object") return {};
    // Defensive: drop any entry that doesn't match the shape.
    const out: Store = {};
    for (const [k, v] of Object.entries(parsed)) {
      if (
        v &&
        typeof v === "object" &&
        typeof (v as ReadingPosition).page === "number" &&
        typeof (v as ReadingPosition).pageCount === "number" &&
        typeof (v as ReadingPosition).zoom === "string" &&
        typeof (v as ReadingPosition).updatedAt === "number"
      ) {
        out[k] = v as ReadingPosition;
      }
    }
    return out;
  } catch {
    return {};
  }
}

function cap(store: Store): Store {
  const entries = Object.entries(store);
  if (entries.length <= MAX_ENTRIES) return store;
  // Sort by updatedAt desc, keep newest MAX_ENTRIES.
  entries.sort((a, b) => b[1].updatedAt - a[1].updatedAt);
  return Object.fromEntries(entries.slice(0, MAX_ENTRIES));
}

function write(store: Store) {
  if (typeof localStorage === "undefined") return;
  const capped = cap(store);
  try {
    localStorage.setItem(KEY, JSON.stringify(capped));
  } catch {
    // Quota crash. Halve entries (oldest first) and retry once.
    const entries = Object.entries(capped).sort(
      (a, b) => b[1].updatedAt - a[1].updatedAt,
    );
    const half = Object.fromEntries(entries.slice(0, Math.floor(entries.length / 2)));
    try {
      localStorage.setItem(KEY, JSON.stringify(half));
    } catch {
      try { localStorage.removeItem(KEY); } catch { /* give up */ }
    }
  }
}

/** Read the saved position for one path. `null` if none saved. */
export function getReadingPosition(path: string): ReadingPosition | null {
  return read()[path] ?? null;
}

/** Persist a new position. Replaces any prior entry for the same path. */
export function setReadingPosition(path: string, pos: Omit<ReadingPosition, "updatedAt">) {
  const store = read();
  const next: ReadingPosition = { ...pos, updatedAt: Date.now() };
  store[path] = next;
  write(store);
  for (const l of listeners) l(path, next);
}

/** Drop the saved position for one path. No-op if absent. */
export function clearReadingPosition(path: string) {
  const store = read();
  if (!(path in store)) return;
  delete store[path];
  write(store);
  for (const l of listeners) l(path, null);
}

/** Read all stored positions. Order is unspecified. */
export function listReadingPositions(): Record<string, ReadingPosition> {
  return read();
}

/** Progress percentage 0-100, rounded to nearest int. Returns 0 when
 *  pageCount is 0 (defensive, should not happen in practice). */
export function progressPercent(pos: ReadingPosition): number {
  if (pos.pageCount <= 0) return 0;
  const pct = (pos.page / pos.pageCount) * 100;
  return Math.max(0, Math.min(100, Math.round(pct)));
}

/** Subscribe to position changes. Fired with `(path, null)` on clear,
 *  `(path, pos)` on set. */
export function subscribeReadingPosition(fn: Listener): () => void {
  listeners.add(fn);
  return () => listeners.delete(fn);
}
```

```ts
import { describe, it, expect, beforeEach } from "vitest";
import {

    const all = listReadingPositions();

    expect(progressPercent(pos(50, 100))).toBe(50);
    expect(progressPercent(pos(1, 3))).toBe(33);
    expect(progressPercent(pos(2, 3))).toBe(67);
  });

  it("progressPercent clamps to 0..100 on degenerate input", () => {
    const pos = { page: 999, pageCount: 0, zoom: "auto", updatedAt: 0 };
    expect(progressPercent(pos)).toBe(0);
  });

  it("ignores malformed entries in storage", () => {

      "/b.pdf": "not an object",
```

```ts
/** Debounced save of the current reading position. Called from
 *  pagechanging + scalechanging handlers. Cheap (localStorage only)
 *  so we don't need to defer further than 500ms. */
function scheduleSavePosition() {
  if (!doc) return;
  if (pendingSaveTimer !== null) clearTimeout(pendingSaveTimer);
  pendingSaveTimer = setTimeout(flushSavePosition, POSITION_SAVE_DELAY_MS);
}

/** Synchronous flush. Safe to call multiple times. Used both by the
 *  debounced timer and by tearDownDoc to make sure no pending save
 *  is dropped when the user closes the doc. */
function flushSavePosition() {
  if (pendingSaveTimer !== null) {
    clearTimeout(pendingSaveTimer);
    pendingSaveTimer = null;
  }
  if (!doc || !pdfViewer) return;
  const zoom = pdfViewer.currentScaleValue || "auto";
  const sig = `${doc.path}|${currentPage}|${zoom}`;
  if (sig === lastSavedSig) return; // no-op
  setReadingPosition(doc.path, {
    page: currentPage,
    pageCount: doc.pageCount,
    zoom,
  });
  lastSavedSig = sig;
}
```

```ts
eventBus.on("pagesinit", () => {
  // Default zoom — overwritten below if a saved position exists.
  pdfViewer.currentScaleValue = "page-width";
  // v2.0.4 Memory — restore last reading position if we have one for
  // this path AND the saved page is still in range. (If the document
  // shrank since last open, restoring page 300 of a 50-page PDF would
  // crash pdfjs; we silently fall back to page 1 in that case.)
  if (doc) {
    const saved = getReadingPosition(doc.path);
    if (saved && saved.page >= 1 && saved.page <= doc.pageCount) {
      // Apply zoom first so the page-width recalculation uses the
      // saved scale, not page-width.
      try {
        pdfViewer.currentScaleValue = saved.zoom;
      } catch {
        // Invalid stored zoom — leave the default in place.
      }
      pdfViewer.currentPageNumber = saved.page;
      currentPage = saved.page;
      // Pre-seed the dedup signature so the immediate auto-save
      // triggered by the restore itself doesn't write a no-op entry.
      lastSavedSig = `${doc.path}|${saved.page}|${saved.zoom}`;
    }
  }
  syncZoom();
});
```

```ts
    // v2.0.4 Memory — top 3 in-progress documents. Surfaced near the
    // top of the palette so a user can Cmd+K → Resume → Enter in 3
    // keystrokes. We intersect with `listRecent()` so a doc the user
    // deleted from Recents doesn't ghost-haunt the palette.
    const positions = listReadingPositions();
    const recents = listRecent();
    const recentByPath = new Map(recents.map((r) => [r.path, r] as const));
    const inProgress = Object.entries(positions)
      .filter(([path, pos]) => {
        if (!recentByPath.has(path)) return false;
        const pct = progressPercent(pos);
        // Skip entries that are trivially fresh (< 2%) or already done
        // (>= 99%) — "resume reading" should feel meaningful.
        return pct >= 2 && pct < 99;
      })
      .sort((a, b) => b[1].updatedAt - a[1].updatedAt)
      .slice(0, 3);

    for (const [path, pos] of inProgress) {
      const rec = recentByPath.get(path)!;
      const pct = progressPercent(pos);
      out.push({
        id: `resume:${path}`,
        title: t("palette.resume.title", { name: rec.name }),
        subtitle: t("palette.resume.subtitle", {
          page: pos.page,
          total: pos.pageCount,
          percent: pct,
        }),
        icon: "📖",
        group: t("palette.resume.group"),
        run: () => {
          window.dispatchEvent(
            new CustomEvent("slab:open-recent", { detail: rec }),
          );
        },
        keywords: `resume reading continue ${rec.name} ${path} ${pct}% page ${pos.page}`,
```

## Risk + rollback

**Risk: pdfjs `currentScaleValue` doesn't accept all the values we
saved.**
pdfjs accepts named tokens (`"auto"`, `"page-width"`, `"page-fit"`,
`"page-actual"`) and numeric strings (`"1.25"`). Slice 2.4 wraps the
restore in a `try { ... } catch {}` so an invalid stored zoom falls
back to `"page-width"` cleanly. If we see field reports of "zoom
ignored on restore", the catch arm logs to `console.warn` and the
user just gets default zoom — no data loss.

**Risk: localStorage quota crash with 200 entries.**
Slice 1's `write()` catches the QuotaExceededError, halves the store
(oldest first), and retries once. Worst case the user loses
positions for the older half of their library. The store key is
namespaced (`slab.reading.positions.v1`) so a future migration to
SQLite is a one-time copy.

**Risk: surface collision with concurrent v2.0.2 / v2.0.3 PRs on
`i18n/en.json`.**
See "Scheduling note" above — serialize releases, don't parallelize.

**Rollback plan if quality gates fail post-merge:**
```bash
git checkout main && git reset --hard ORIG_HEAD
# Log the failure to .cron-state/STATE.md, fix on feature branch
# next tick, re-attempt the merge.
```
