# v2.0.3 "Flatten Raster" Implementation Plan (closes #24)

> **For Hermes:** Use subagent-driven-development to implement task-by-task.

**Goal:** Add a 150 DPI raster-flatten path to Slab's existing annotation flattener so legal/compliance users can produce fully-uneditable PDFs offline — closing the Acrobat $239/yr and KillerPDF parity gap explicitly called out in issue #24.

**Architecture:** Extend `pdf::flatten` with a `FlattenMode` enum (`Annotations` | `Raster { dpi }`). The raster path shells out to `pdftoppm` (already a Slab dependency via `ai::vision::render_page_image`), one PNG per page, then rebuilds the PDF page-by-page using `lopdf` — each new page is a `/MediaBox`-sized container whose only content is a `Do` operator referencing a `/Subtype /Image /Filter /FlateDecode` XObject. Annotations are burned in *before* rasterizing (we reuse the existing `flatten_doc` pipeline as Stage A). No `/Font`, no `/Annot`, no `/AcroForm` survive Stage B.

**Tech stack:** Rust (lopdf 0.40, image 0.25, tempfile 3, pdftoppm via Command), Svelte 5 (FlattenPanel.svelte), Tauri 2 (slab_flatten command extended).

**Acceptance criteria mapping (from issue #24):**
- ✅ Annotation flatten path — *already shipped pre-v2.0.3*, this plan extends the report assertions
- ✅ Raster flatten path — Tasks 2-5 (every page becomes one ImageXObject, zero `/Font` survives)
- ✅ CLI exposure — Task 6 (`slab flatten input.pdf --raster --dpi 150 -o out.pdf`)
- ✅ Unit tests both paths — Task 2 (annot baseline), Tasks 3-5 (raster)
- ✅ Docs in `docs/features/flatten.md` — Task 8

pub fn flatten(input: &Path, output: &Path, opts: FlattenOpts) -> Result<FlattenReport, PdfError> {
    if !input.exists() {
        return Err(PdfError::InputMissing(input.display().to_string()));
    }
    let mut doc = Document::load(input)?;
    let mut report = flatten_doc(&mut doc, &opts)?;

    if let FlattenMode::Raster { dpi } = opts.mode {
        if dpi < 36 || dpi > 600 {
            return Err(PdfError::Other(format!(
                "dpi {dpi} out of range (36–600)"
            )));
        }
        // Save Stage A to a temp file so pdftoppm can read it back.
        let tmp = tempfile::tempdir()?;
        let stage_a = tmp.path().join("stage_a.pdf");
        doc.save(&stage_a)?;
        let mut raster_doc = Document::load(&stage_a)?;
        let n = rasterize_doc(&mut raster_doc, &stage_a, dpi)?;
        report.pages_rasterized = n;
        report.dpi = dpi;
        if let Some(parent) = output.parent() {
            if !parent.as_os_str().is_empty() {
                std::fs::create_dir_all(parent)?;
            }
        }
        raster_doc.compress();
        raster_doc.save(output)?;
        return Ok(report);
    }

    if let Some(parent) = output.parent() {
        if !parent.as_os_str().is_empty() {
            std::fs::create_dir_all(parent)?;
        }
    }
    doc.compress();
    doc.save(output)?;
    Ok(report)
}

```rust
fn rasterize_doc(doc: &mut Document, stage_a: &Path, dpi: u32) -> Result<u32, PdfError> {
    let pages: Vec<(u32, ObjectId)> = doc.get_pages().into_iter().collect();
    if pages.is_empty() {
        return Ok(0);
    }
    let tmp = tempfile::tempdir()?;
    let prefix = tmp.path().join("p");
    let status = std::process::Command::new("pdftoppm")
        .arg("-r").arg(dpi.to_string())
        .arg("-png")
        .arg(stage_a)
        .arg(&prefix)
        .status()
        .map_err(|e| PdfError::Other(format!(
            "pdftoppm not found ({e}). Install poppler: `brew install poppler` / `apt install poppler-utils`."
        )))?;
    if !status.success() {
        return Err(PdfError::Other(format!(
            "pdftoppm exited {}", status.code().unwrap_or(-1)
        )));
    }
    let mut pngs: Vec<std::path::PathBuf> = std::fs::read_dir(tmp.path())?
        .filter_map(|e| e.ok())
        .map(|e| e.path())
        .filter(|p| p.extension().is_some_and(|x| x == "png"))
        .collect();
    pngs.sort();
    if pngs.len() != pages.len() {
        return Err(PdfError::Other(format!(
            "pdftoppm produced {} PNGs for {} pages", pngs.len(), pages.len()
        )));
    }
    // Page rebuilding happens in Task 4; for now just count.
    rebuild_pages_from_pngs(doc, &pages, &pngs, dpi)?;
    Ok(pages.len() as u32)
}

## Task 4: Implement `rebuild_pages_from_pngs` — swap content stream for ImageXObject Do

**Objective:** For each page, register a `/Subtype /Image` XObject built from the PNG, replace `/Contents` with `q W H 0 0 0 0 cm /Img Do Q`, drop `/Resources /Font`.

**Files:**
- Modify: `src-tauri/src/pdf/flatten.rs` (replace `rebuild_pages_from_pngs` stub)

**Step 1: Implement**

```rust
fn rebuild_pages_from_pngs(
    doc: &mut Document,
    pages: &[(u32, ObjectId)],
    pngs: &[std::path::PathBuf],
    _dpi: u32,
) -> Result<(), PdfError> {
    for ((_num, page_id), png_path) in pages.iter().zip(pngs.iter()) {
        // Decode PNG → raw RGB8 + dims
        let img = image::open(png_path)
            .map_err(|e| PdfError::Other(format!("decode {}: {e}", png_path.display())))?;
        let rgb = img.to_rgb8();
        let (w, h) = (rgb.width(), rgb.height());
        let raw = rgb.into_raw();

        // FlateDecode the RGB bytes (image dep already brings flate2 transitively;
        // we explicitly use flate2 which is in Cargo.toml).
        use flate2::write::ZlibEncoder;
        use flate2::Compression;
        use std::io::Write;
        let mut enc = ZlibEncoder::new(Vec::new(), Compression::default());
        enc.write_all(&raw).map_err(|e| PdfError::Other(format!("flate: {e}")))?;
        let compressed = enc.finish().map_err(|e| PdfError::Other(format!("flate: {e}")))?;

        // Build the ImageXObject
        let img_dict = dictionary! {
            "Type" => "XObject",
            "Subtype" => "Image",
            "Width" => w as i64,
            "Height" => h as i64,
            "ColorSpace" => "DeviceRGB",
            "BitsPerComponent" => 8,
            "Filter" => "FlateDecode",
        };
        let img_stream = Stream::new(img_dict, compressed);
        let img_id = doc.add_object(Object::Stream(img_stream));

        // Get MediaBox to know the page size in points
        let media_box = page_media_box(doc, *page_id)?;
        let pw = media_box[2] - media_box[0];
        let ph = media_box[3] - media_box[1];

        // New content stream: scale image to MediaBox
        let content = Content {
            operations: vec![
                Operation::new("q", vec![]),
                Operation::new("cm", vec![
                    pw.into(), 0.into(), 0.into(), ph.into(),
                    media_box[0].into(), media_box[1].into(),
                ]),
                Operation::new("Do", vec![Object::Name(b"Img".to_vec())]),
                Operation::new("Q", vec![]),
            ],
        };
        let content_bytes = content.encode()
            .map_err(|e| PdfError::Other(format!("encode content: {e}")))?;
        let content_id = doc.add_object(Object::Stream(Stream::new(
            dictionary! {}, content_bytes,
        )));

        // Replace page /Contents + /Resources (Font dropped, XObject = {Img})
        let page = doc.get_object_mut(*page_id)?.as_dict_mut()?;
        page.set("Contents", Object::Reference(content_id));
        let resources = dictionary! {
            "XObject" => dictionary! { "Img" => Object::Reference(img_id) },
            "ProcSet" => Object::Array(vec![
                Object::Name(b"PDF".to_vec()),
                Object::Name(b"ImageC".to_vec()),
            ]),
        };
        page.set("Resources", Object::Dictionary(resources));
        // Drop /Annots (already cleared by Stage A but be defensive)
        page.remove(b"Annots");
    }
    Ok(())
}

fn page_media_box(doc: &Document, page_id: ObjectId) -> Result<[f32; 4], PdfError> {
    // Walk inherited /MediaBox up the page-tree if missing on this page.
    let mut current = page_id;
    loop {
        let dict = doc.get_object(current)?.as_dict()?;
        if let Ok(arr) = dict.get(b"MediaBox").and_then(|o| o.as_array()) {
            let v: Vec<f32> = arr.iter()
                .filter_map(|o| match o {
                    Object::Integer(i) => Some(*i as f32),
                    Object::Real(f) => Some(*f),
                    _ => None,
                })
                .collect();
            if v.len() == 4 {
                return Ok([v[0], v[1], v[2], v[3]]);
            }
        }
        match dict.get(b"Parent") {
            Ok(Object::Reference(pid)) => { current = *pid; }
            _ => return Ok([0.0, 0.0, 612.0, 792.0]), // Letter fallback
        }
    }
}
```

fn cmd_flatten(args: &[String]) -> Result<(), CliError> {
    let input = require_arg(args, 0, "<file>")?;
    let output = output_path(args)?;
    let include_widgets = !args.iter().any(|a| a == "--no-widgets");
    let raster = args.iter().any(|a| a == "--raster");
    let dpi: u32 = find_flag(args, "--dpi")
        .and_then(|s| s.parse().ok())
        .unwrap_or(150);
    let mode = if raster {
        slab_lib::pdf::flatten::FlattenMode::Raster { dpi }
    } else {
        slab_lib::pdf::flatten::FlattenMode::Annotations
    };
    let opts = FlattenOpts { include_widgets, mode };
    let report = do_flatten(&input, &output, opts)?;
    println!(
        "✓ flattened {}/{} annotation(s) ({} dropped) across {} page(s){}{} → {}",
        report.annotations_flattened,
        report.annotations_in,
        report.annotations_dropped,
        report.pages_with_annotations,
        if report.had_acroform { ", AcroForm removed" } else { "" },
        if report.pages_rasterized > 0 {
            format!(", {} page(s) rasterized @ {} DPI", report.pages_rasterized, report.dpi)
        } else { String::new() },
        output.display()
    );
    Ok(())
}

# Flatten

Slab's **Flatten** action makes a PDF un-editable. It's the same operation
Adobe Acrobat Pro charges $239/yr for; Slab does it offline, free.

## Two modes

### 1. Burn annotations only (default)

- Bakes every highlight, comment, signature, and form field into the page
- Removes `/Annots` arrays and the document-level `/AcroForm`
- **Text stays searchable** — selection, copy, and Beacon Q&A still work
- Fast: under a second on typical contracts

Use when: you want to lock down annotations but keep a searchable doc.

### 2. Full raster (legal-grade)

- First burns annotations (Stage A)
- Then re-renders every page at 150 or 300 DPI via Poppler (`pdftoppm`)
- Replaces each page's content stream with a single image XObject
- **Zero editable text remains** — no `/Font` dicts, no selectable glyphs
- Slow: ~1s per page at 150 DPI

Use when: legal/compliance/archival workflows that require a court-admissible
fully-flat PDF. Common in litigation discovery, FDA submissions, ISO archives.

> ⚠ Raster mode is **irreversible**. Save as a new file.

## CLI

```bash
slab flatten input.pdf -o output.pdf                    # annotations only
slab flatten input.pdf --raster -o output.pdf           # 150 DPI raster
slab flatten input.pdf --raster --dpi 300 -o output.pdf # 300 DPI raster
slab flatten input.pdf --no-widgets -o output.pdf       # skip form widgets
```

## Why it matters

Adobe Acrobat Pro ships flatten behind a $239/yr subscription. PDF Expert
$79/yr; Foxit $129/yr. The Open Source alternatives (pdftk, qpdf) handle
annotations but not raster, leaving you to chain four tools together. Slab
ships both modes in one button, offline, no telemetry.
