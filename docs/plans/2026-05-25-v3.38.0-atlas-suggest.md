# v3.38.0 "Atlas Suggest" — Implementation Plan

> **For Hermes:** Execute this plan task-by-task on a new branch
> `feature/v3.38.0-atlas-suggest`. One slice per cron tick, full TDD cycle
> per task. Commit after each task using `-F /tmp/msg.txt` and the cron
> author identity. Push at end of every tick. Final tick merges to main,
> tags v3.38.0, pushes with `--follow-tags`.

**Goal:** Slab observes the user's recent library searches and proactively
suggests new personal Smart Folders ("You searched 'invoice 2025' 8 times
this week — save it as a Smart Folder?") via local Beacon AI.

**Architecture:**
1. **Logging layer** — every library search writes one row into a new
   `library_search_log` table (schema v6→v7). Capped at 500 rows (LRU).
2. **Suggestion engine** — `ai::folder_suggest` takes the last 50 queries,
   asks the configured Beacon model (Ollama / OpenAI-compat) for a
   structured JSON list of `{name, icon, color, query_template, reason}`
   candidate folders. Falls back to a deterministic heuristic clusterer
   (TF-IDF on query tokens) if no AI provider is configured.
3. **Surface** — `SmartFoldersHubPanel` gains a "✨ Suggested for you"
   section above the existing list. Each suggestion shows a one-click
   "Add" button (creates a personal preset) and a "Dismiss" button (logs
   the rejection so we don't re-suggest the same cluster).

**Tech Stack:** Rust (rusqlite, serde_json), existing `ai::ollama` +
`ai::openai_compat` providers, Svelte 5 + TypeScript, Tauri commands.

**Buy-Button qualification:**
- **Pay-for-it** ✅ Acrobat's "Smart Search" is paid + cloud. Ours is local + free.
- **Notice-it** ✅ New "✨ Suggested" section in the hub, lights up after

pub struct Suggestion {
    pub name: String,
    pub icon: String,      // 1 char emoji picked by heuristic table
    pub color: String,     // #RRGGBB picked from rotating palette
    pub query_template: String,  // the dominant token, ready for preset.search
    pub reason: String,    // "You searched 'invoice' 8 times this week"

Algorithm: tokenize each query, drop stopwords (`the/and/of/a/to/in/for/with`), count token frequencies, group queries by their highest-frequency token. Any group with `support >= 3` → suggestion. Skip groups whose hash is in `library_suggestion_dismissed`. Return top 3 by support.
