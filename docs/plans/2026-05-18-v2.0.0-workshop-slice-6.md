# v2.0.0 "Workshop" — Slice 6: Document Lifecycle Events

> **For Hermes:** Active sub-plan inside `feature/v2.0.0-workshop`.
> Parent plan: `docs/plans/2026-05-18-v2.0.0-workshop.md` (slice index).
> This document is the full implementation arc for Slice 6 only.

**Goal:** Replace the `make_unavailable("Slice 4b")` stubs at `slab.document.{onOpen,onClose,getActive}` with a real event-dispatch system. Plugins should be able to register persistent JS callbacks at enable time, and have those callbacks invoked when the frontend opens or closes a PDF.

**Architecture:** Each enabled plugin gets a *long-lived* rquickjs `Runtime` + `Context` pinned to a single OS thread (rquickjs runtimes are not `Send` across Context calls — `Persistent<Function>` is `Send` but the runtime instance must be borrowed from the same thread it was created on). We adopt a **per-plugin actor model**: each plugin's runtime is owned by a dedicated worker thread that pulls `RuntimeCmd` messages off a `crossbeam-channel`. The host side (Tauri commands, Rust event emitters) sends `RuntimeCmd::DocumentOpened { path, name }` etc.; the worker thread invokes the matching `Persistent<Function>`s inside `Context::with`.

**Tech Stack:**
- `crossbeam-channel = "0.5"` for actor mailboxes (already an indirect dep via tracing).
- `std::thread` for the per-plugin worker — no tokio leak into the runtime layer.
- `rquickjs::Persistent<Function<'static>>` for stored callbacks.
- Tauri commands `slab_plugins_document_opened` / `slab_plugins_document_closed` that the frontend calls from `+page.svelte` whenever a doc enters/leaves the viewer.

**Why this is hard:**
1. `Context::with(|ctx| ...)` is the only way to execute JS, and the closure borrows the runtime — so all dispatch must happen on the runtime-owning thread.
2. `Persistent<Function>` is `Send + 'static`, but restoring it back into a `Function<'js>` requires a `&Ctx<'js>` from the same runtime.
3. We need to keep the runtime alive across multiple events, not drop it after the initial `enable_plugin` call like Slice 4 does.
4. Shutdown semantics: disabling a plugin must cleanly stop the worker, drain any in-flight events, and drop all `Persistent` handles *before* dropping the runtime (otherwise rquickjs aborts the process — see `Persistent::save` docs).

```rust
#[derive(Debug, Clone)]
pub enum RuntimeCmd {
    /// A PDF was loaded into the viewer. Invoke all `onOpen` callbacks.
    DocumentOpened(DocumentEvent),
    /// The active PDF was closed/replaced. Invoke all `onClose` callbacks.
    DocumentClosed(DocumentEvent),
    /// Gracefully drop all Persistents and exit the worker thread.
    Shutdown,

/// Payload for `DocumentOpened` / `DocumentClosed`.

    /// Absolute path of the PDF on disk.
    pub path: PathBuf,
    /// Display name (basename without extension) shown in plugin UIs.
    pub name: String,
}

    pub fn from_path(path: impl Into<PathBuf>) -> Self {
        let path = path.into();
        let name = path
            .file_stem()
            .and_then(|s| s.to_str())
            .unwrap_or("")
            .to_string();
        Self { path, name }
    }
}
```

```rust
use std::sync::{Arc, Mutex};
use std::thread::{self, JoinHandle};

use crossbeam_channel::{unbounded, Sender};

use super::{slab_global, Runtime, RuntimeError};
use crate::plugins::grants::PluginGrants;
use crate::plugins::manifest::Capabilities;

/// Handle to a running plugin actor. Drop = shutdown via channel
/// close (best-effort; explicit `send(Shutdown)` is preferred).
pub struct WorkerHandle {
    plugin_id: String,
    tx: Sender<RuntimeCmd>,
    join: Option<JoinHandle<()>>,
}

impl WorkerHandle {
    pub fn plugin_id(&self) -> &str {
        &self.plugin_id
    }

    pub fn send(&self, cmd: RuntimeCmd) -> Result<(), crossbeam_channel::SendError<RuntimeCmd>> {
        self.tx.send(cmd)
    }

    pub fn join(mut self) -> thread::Result<()> {
        let _ = self.tx.send(RuntimeCmd::Shutdown);
        if let Some(j) = self.join.take() {
            return j.join();
        }
        Ok(())
    }
}

impl Drop for WorkerHandle {
    fn drop(&mut self) {
        // Try to send a shutdown so the worker exits its select loop
        // promptly. Ignore errors — the channel may already be dead.
        let _ = self.tx.send(RuntimeCmd::Shutdown);
        if let Some(j) = self.join.take() {
            let _ = j.join();
        }
    }
}

/// Single-thread actor that owns one plugin's QuickJS runtime.
pub struct PluginActor;

impl PluginActor {
    /// Spawn the worker. Returns a handle once the thread has been
    /// created; the worker performs the initial `enable_plugin`-style
    /// evaluation inside its loop and may fail asynchronously. (Sync
    /// init-error surface lands in Task 6.5.)
    pub fn spawn(
        plugin_id: String,
        declared: Capabilities,
        granted: PluginGrants,
        source: String,
    ) -> Result<WorkerHandle, RuntimeError> {
        let (tx, rx) = unbounded::<RuntimeCmd>();
        let pid = plugin_id.clone();
        let join = thread::Builder::new()
            .name(format!("slab-plugin:{plugin_id}"))
            .spawn(move || {
                run_actor(plugin_id.clone(), declared, granted, source, rx);
            })
            .map_err(|e| RuntimeError::Init(format!("actor thread spawn: {e}")))?;

        Ok(WorkerHandle {
            plugin_id: pid,
            tx,
            join: Some(join),
        })
    }
}

/// Worker thread body. Owns the `Runtime` so that lifetime ends with
/// this function returning. All `Persistent`s must be cleared from
/// the host-bindings table before we exit, otherwise rquickjs aborts
/// on `Runtime` drop (Slice 6.5 enforces this on shutdown path).
fn run_actor(
    _plugin_id: String,
    _declared: Capabilities,
    _granted: PluginGrants,
    _source: String,
    rx: crossbeam_channel::Receiver<RuntimeCmd>,
) {
    // Task 6.5 will replace this body with a real Runtime + Context
    // owner. For now, just drain commands and exit on Shutdown so
    // tests can verify the channel/join machinery works.
    while let Ok(cmd) = rx.recv() {
        if matches!(cmd, RuntimeCmd::Shutdown) {
            break;
        }
    }
}
```

```rust
//! Per-plugin store of `Persistent<Function>` lifecycle callbacks.
//!
//! Slot semantics: each axis (onOpen, onClose) is *additive* — plugins
//! may register multiple handlers per axis and we call them in
//! registration order. This matches the Web `addEventListener` model
//! and lets plugins compose nicely.

use std::sync::{Arc, Mutex};

use rquickjs::{Function, Persistent};

/// Persistent function handles, keyed by lifecycle axis.
#[derive(Default)]
pub struct LifecycleRegistry {
    on_open: Vec<Persistent<Function<'static>>>,
    on_close: Vec<Persistent<Function<'static>>>,
}

impl LifecycleRegistry {
    pub fn push_on_open(&mut self, f: Persistent<Function<'static>>) {
        self.on_open.push(f);
    }
    pub fn push_on_close(&mut self, f: Persistent<Function<'static>>) {
        self.on_close.push(f);
    }
    pub fn on_open(&self) -> &[Persistent<Function<'static>>] {
        &self.on_open
    }
    pub fn on_close(&self) -> &[Persistent<Function<'static>>] {
        &self.on_close
    }
    /// Critical: must be called BEFORE the runtime is dropped, or
    /// rquickjs aborts.
    pub fn clear(&mut self) {
        self.on_open.clear();
        self.on_close.clear();
    }
    pub fn on_open_len(&self) -> usize {
        self.on_open.len()
    }
    pub fn on_close_len(&self) -> usize {
        self.on_close.len()
    }
}

pub type SharedLifecycle = Arc<Mutex<LifecycleRegistry>>;

pub fn new_shared() -> SharedLifecycle {
    Arc::new(Mutex::new(LifecycleRegistry::default()))
}
```

```rust
#[derive(Clone, Copy)]
enum LifecycleAxis {
    OnOpen,
    OnClose,
}

fn make_on_event<'js>(
    ctx: &Ctx<'js>,
    b: HostBindings,
    axis: LifecycleAxis,
) -> Result<Function<'js>> {
    Function::new(
        ctx.clone(),
        move |ctx: Ctx<'js>, callback: Function<'js>| -> Result<()> {
            let Some(reg) = b.lifecycle.as_ref() else {
                return Err(Exception::throw_message(
                    &ctx,
                    "slab.document.on* is not available outside of plugin enable context",
                ));
            };
            let persistent = Persistent::save(&ctx, callback);
            let mut guard = reg
                .lock()
                .map_err(|_| Exception::throw_internal(&ctx, "lifecycle mutex poisoned"))?;
            match axis {
                LifecycleAxis::OnOpen => guard.push_on_open(persistent),
                LifecycleAxis::OnClose => guard.push_on_close(persistent),
            }
            Ok(())
        },
    )
}
```

## Task 6.5 — Promote `Runtime::enable_plugin` → spawn-and-keep-alive

**Objective:** Replace the placeholder `run_actor` body from 6.2 with a real implementation that:
1. Creates a `Runtime` inside the worker thread.
2. Creates one long-lived `Context`.
3. Inside `Context::with`, installs the sandbox + slab global (with `lifecycle: Some(...)`, `active_doc: Some(...)`).
4. Evaluates the plugin source once (top-level eval).
5. Stashes the initial `Registrations` + logs into shared state the host can read.
6. Enters a loop: `select!` on `rx`; on `DocumentOpened` / `DocumentClosed`, enters a new `Context::with` and invokes every `Persistent` from the lifecycle registry.
7. On `Shutdown`, clears the lifecycle registry **before** dropping the runtime, then exits.

**Files:**
- Modify: `src-tauri/src/plugins/runtime/actor.rs`

**Step 1: Sketch the real `run_actor`**

```rust
fn run_actor(
    plugin_id: String,
    declared: Capabilities,
    granted: PluginGrants,
    source: String,
    rx: crossbeam_channel::Receiver<RuntimeCmd>,
    init_tx: std::sync::mpsc::SyncSender<Result<ActorStartup, RuntimeError>>,
    shared_state: ActorSharedState,
) {
    let rt = match rquickjs::Runtime::new() {
        Ok(r) => r,
        Err(e) => {
            let _ = init_tx.send(Err(RuntimeError::Init(format!("{e}"))));
            return;
        }
    };
    rt.set_memory_limit(super::MEMORY_LIMIT_BYTES);

    let ctx = match Context::full(&rt) {
        Ok(c) => c,
        Err(e) => {
            let _ = init_tx.send(Err(RuntimeError::Init(format!("context: {e}"))));
            return;
        }
    };

    // Top-level eval inside Context::with.
    let init_result = ctx.with(|ctx| -> Result<Registrations, RuntimeError> {
        // ... install console + slab global with lifecycle Some, active_doc Some ...
        // ... ctx.eval::<Value, _>(&source).catch(&ctx) ...
        // ... extract Registrations ...
    });

    match init_result {
        Ok(regs) => {
            let _ = init_tx.send(Ok(ActorStartup { registrations: regs }));
        }
        Err(e) => {
            // Drop lifecycle registry BEFORE the runtime drops — even
            // though it should be empty here, defensive clear.
            shared_state.lifecycle.lock().unwrap().clear();
            let _ = init_tx.send(Err(e));
            return;
        }
    }

    // Event loop.
    while let Ok(cmd) = rx.recv() {
        match cmd {
            RuntimeCmd::DocumentOpened(ev) => {
                *shared_state.active_doc.lock().unwrap() = Some(ev.clone());
                dispatch_lifecycle(&ctx, &shared_state.lifecycle, LifecycleAxis::OnOpen, &ev);
            }
            RuntimeCmd::DocumentClosed(ev) => {
                *shared_state.active_doc.lock().unwrap() = None;
                dispatch_lifecycle(&ctx, &shared_state.lifecycle, LifecycleAxis::OnClose, &ev);
            }
            RuntimeCmd::Shutdown => break,
        }
    }

    // Critical drop order: clear all Persistents BEFORE runtime drops.
    shared_state.lifecycle.lock().unwrap().clear();
    drop(ctx);
    drop(rt);
}
```

**Step 2: Helper `dispatch_lifecycle`**

```rust
fn dispatch_lifecycle(
    ctx: &Context,
    lifecycle: &SharedLifecycle,
    axis: LifecycleAxis,
    ev: &DocumentEvent,
) {
    ctx.with(|ctx| {
        let snap: Vec<_> = {
            let guard = lifecycle.lock().expect("lifecycle poisoned");
            match axis {
                LifecycleAxis::OnOpen => guard.on_open().to_vec(),
                LifecycleAxis::OnClose => guard.on_close().to_vec(),
            }
        };
        // Build a single { path, name } event object once per dispatch.
        let event_obj = Object::new(ctx.clone()).expect("event obj");
        let _ = event_obj.set("path", ev.path.to_string_lossy().to_string());
        let _ = event_obj.set("name", ev.name.clone());
        for persistent in snap {
            match persistent.restore(&ctx) {
                Ok(f) => {
                    // Per-callback try/catch — one buggy handler must
                    // not poison the rest.
                    if let Err(e) = f.call::<_, ()>((event_obj.clone(),)) {
                        tracing::warn!(
                            "[plugin lifecycle] callback threw: {e}"
                        );
                    }
                }
                Err(e) => {
                    tracing::warn!("[plugin lifecycle] restore failed: {e}");
                }
            }
        }
    });
}
```

**Step 3: Refactor `PluginActor::spawn` to use init handshake**

```rust
pub struct ActorStartup {
    pub registrations: Registrations,
}

pub struct ActorSharedState {
    pub lifecycle: SharedLifecycle,
    pub active_doc: SharedActiveDoc,
}

impl PluginActor {
    pub fn spawn(
        plugin_id: String,
        declared: Capabilities,
        granted: PluginGrants,
        source: String,
    ) -> Result<(WorkerHandle, ActorStartup, ActorSharedState), RuntimeError> {
        let (tx, rx) = unbounded::<RuntimeCmd>();
        let (init_tx, init_rx) = std::sync::mpsc::sync_channel::<Result<ActorStartup, RuntimeError>>(1);
        let lifecycle = lifecycle::new_shared();
        let active_doc = lifecycle::new_shared_active_doc();
        let shared = ActorSharedState {
            lifecycle: lifecycle.clone(),
            active_doc: active_doc.clone(),
        };
        let pid = plugin_id.clone();
        let join = thread::Builder::new()
            .name(format!("slab-plugin:{plugin_id}"))
            .spawn(move || {
                run_actor(plugin_id, declared, granted, source, rx, init_tx,
                          ActorSharedState { lifecycle, active_doc });
            })
            .map_err(|e| RuntimeError::Init(format!("actor thread spawn: {e}")))?;

        let startup = init_rx
            .recv()
            .map_err(|_| RuntimeError::Init("actor init channel closed".into()))??;

        let handle = WorkerHandle {
            plugin_id: pid,
            tx,
            join: Some(join),
        };
        Ok((handle, startup, shared))
    }
}
```

```rust
//! Process-global registry of live plugin actor handles.
//! Tauri owns one of these; commands look up by plugin_id.

use std::collections::HashMap;
use std::sync::Mutex;

use super::runtime::actor::{ActorSharedState, RuntimeCmd, WorkerHandle};

pub struct PluginRuntimeRegistry {
    inner: Mutex<HashMap<String, LiveEntry>>,
}

pub struct LiveEntry {
    pub handle: WorkerHandle,
    pub shared: ActorSharedState,
}

impl Default for PluginRuntimeRegistry {
    fn default() -> Self {
        Self { inner: Mutex::new(HashMap::new()) }
    }
}

impl PluginRuntimeRegistry {
    pub fn insert(&self, plugin_id: String, entry: LiveEntry) {
        if let Ok(mut guard) = self.inner.lock() {
            // Replace any existing entry: this is a re-enable.
            guard.insert(plugin_id, entry);
        }
    }
    pub fn remove(&self, plugin_id: &str) -> Option<LiveEntry> {
        self.inner.lock().ok().and_then(|mut g| g.remove(plugin_id))
    }
    pub fn broadcast(&self, cmd: RuntimeCmd) {
        if let Ok(guard) = self.inner.lock() {
            for entry in guard.values() {
                let _ = entry.handle.send(cmd.clone());
            }
        }
    }
    pub fn live_plugin_ids(&self) -> Vec<String> {
        self.inner.lock().ok().map(|g| g.keys().cloned().collect()).unwrap_or_default()
    }
}
```

## Drop-order safety invariant (RE-READ before shipping)

**`Persistent<Function>` MUST be dropped via explicit `LifecycleRegistry::clear()` before the owning `Runtime` drops.** If you skip this, rquickjs's `Drop` for `Runtime` will `abort()` the process when it sees outstanding refs to JS values.

The actor's exit path enforces this:
```rust
shared_state.lifecycle.lock().unwrap().clear();  // first
drop(ctx);                                        // second
drop(rt);                                         // last
```

If any of the contract tests panic with `Runtime had outstanding references`, this ordering is wrong.
