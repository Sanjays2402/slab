# Slab v2.1.1 "Notary II" 🕰️ — RFC 3161 Timestamping + LTV/DSS Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task. **Do not start until v2.1.0 Notary PKCS#7 signing lands.**

**Goal:** Make Slab-signed PDFs court-admissible for *decades* — not just until the signing cert expires.

**Architecture:** Three additions on top of v2.1.0 Notary: (1) RFC 3161 TSA client + embedded `signature-time-stamp` unsigned attribute in the CMS SignedData, (2) Document Security Store (`/DSS` dict per PDF 2.0 §12.8.4.3) carrying VRI entries with cert chains + OCSP responses + CRLs at sign time, (3) PAdES B-LT / B-LTA profile compliance via a second incremental save adding the DSS + a *document-level* timestamp. All pure-Rust, no OpenSSL. Offline-safe: if TSA/OCSP unreachable, gracefully downgrade B-LTA → B-LT → B-T → B-B with explicit user banner.

**Tech Stack:** Hand-rolled RFC 3161 over `cms 0.3` + `der 0.8` (4 ASN.1 structs), `ocsp 0.6`, `reqwest 0.12` (blocking, rustls-tls, gated `feature = "online"`). Reuses v2.1.0 `cms`, `x509-cert`, `der`. Frontend reuses v2.1.0 `TrustBanner` + `NotaryInspector`.

**Wow:** **"Verify in 2050" sandbox** — Settings → Notary panel button that simulates the year jumping to 2050 and walks the user through *why* a B-B sig fails there and a B-LTA sig passes. 380ms gold-ribbon-of-time scrub animation, cubic-bezier `(0.34, 1.56, 0.64, 1)`. Tell-a-friend bait.

**TDD cycle**:

```rust
#[test]
fn tsr_request_round_trips_sha256_imprint() {
    let data = b"hello slab notary";
    let req = build_tsr_request(data, HashAlg::Sha256, Some(0xDEADBEEF)).unwrap();
    let parsed = parse_tsr_request(&req).unwrap();
    assert_eq!(parsed.imprint_alg, oid::SHA_256);
    assert_eq!(parsed.imprint, sha256(data));
    assert_eq!(parsed.nonce, Some(0xDEADBEEF));
    assert!(parsed.cert_req);
}
```

Run: `cargo test -p slab-app notary::tsa::tsr_request_round_trips` → FAIL → implement → PASS.

Implement (hand-rolled, ~80 LOC core):
- `TsrRequest`, `TsrResponse`, `TstInfo` ASN.1 via `der::{Encode,Decode}` derive
- `build_tsr_request(data, alg, nonce) -> Vec<u8>`
- `post_tsr_request(url, body, timeout) -> Result<TsrResponse>` — `reqwest::blocking::post`, `Content-Type: application/timestamp-query`, 10s timeout, parse PKIStatusInfo + optional TimeStampToken CMS. +4 tests w/ `httpmock`.
- `verify_tsr(token, expected_imprint, trust_roots) -> Result<TsaVerification>` — imprint match, TSA cert chain, signature over TSTInfo, genTime sanity, nonce echo. +6 tests against FreeTSA fixture `tests/fixtures/tsa/freetsa-2025.tsr`.
- `embed_tsr_as_unsigned_attr(signed_data, token)` — OID `1.2.840.113549.1.9.16.2.14` (`id-aa-signatureTimeStampToken`). +2 tests.
- `default_tsa_endpoints() -> &'static [&'static str]` returns `["https://freetsa.org/tsr", "http://timestamp.digicert.com", "http://timestamp.sectigo.com"]`. +1 test.
