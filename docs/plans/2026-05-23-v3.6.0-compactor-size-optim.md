# v3.6.0 "Compactor" — Real PDF Size Reduction Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship Adobe Acrobat Pro DC's "Reduce File Size" feature — actually shrinks PDFs by downsampling images, recompressing JPEGs, dropping embedded thumbnails / unused fonts / metadata — not just re-flating streams. End-to-end: backend module + Tauri command + frontend panel with before/after preview + savings dial + presets (Screen / eBook / Printer / Prepress matching Ghostscript naming).

**Why it's the buy-button:** Today `src-tauri/src/pdf/compress.rs` only calls `lopdf::Document::compress()` which re-flates uncompressed streams. On a 47 MB scanned legal PDF (the typical Slab customer's pain point), that saves <2%. Adobe charges $239/yr partly because it can take that same 47 MB and produce a 4 MB email-able copy by downsampling 600 DPI scans to 150 DPI and re-encoding as JPEG q=75. Foxit / Smallpdf / iLovePDF charge $5-$15/mo for the same thing online (uploads your file to their server — privacy nightmare for legal). Slab will do it locally, free, with a live before/after dial showing exactly how much you'll save before you commit. This is the Pay-for-it test AND the Tell-a-friend test simultaneously.

**Architecture:**
- New module `src-tauri/src/pdf/compactor.rs` walks the document XRef, finds image XObjects (`/Subtype /Image`), decodes them with `image` crate, downsamples per preset DPI, re-encodes as JPEG (color/grayscale) or Flate-PNG (monochrome), writes back into the stream and updates `/Width /Height /Filter /DecodeParms`. Drops `/Thumb` entries, unused fonts (compute reachability from page resources), `/Metadata` (optional), embedded files (optional), and JS actions. Honors the existing `RedactRect` contract (refuses to recompact already-redacted files unless the redaction sanitize pass was applied — Veil guarantees this).
- Tauri command `slab_compact(input, output, preset_or_custom)` returns `CompactReport { original_bytes, new_bytes, ratio, per_kind_savings: {images, fonts, metadata, streams} }`.
- Frontend `CompactPanel.svelte` shows: preset dropdown (Screen 72dpi / eBook 150dpi / Printer 300dpi / Prepress 600dpi / Custom), checkboxes (drop thumbnails / strip metadata / strip embedded files / strip JS), a dry-run **estimate** button (no write, just measures), then **Compact**. After compact: animated savings dial (3.2 MB → 487 KB, 85% smaller), file-size sparkline, side-by-side first-page preview (visual quality check).

**Tech Stack:** Rust (lopdf 0.40, image 0.25, flate2 1), Tauri 2, Svelte 5, existing slab Liquid Glass design tokens.

```rust
//! v3.6.0 Compactor — real PDF size reduction via image downsample,
//! font subset/drop, metadata strip. Distinct from compress.rs which
//! only re-flates uncompressed streams (lossless, small savings).

use crate::pdf::PdfError;
use lopdf::{Document, Object, ObjectId};
use serde::Serialize;
use std::path::Path;

#[derive(Debug, Clone, Serialize)]
pub struct ImageRef {
    pub object_id_num: u32,
    pub object_id_gen: u16,
    pub width: u32,
    pub height: u32,
    pub bits_per_component: u8,
    pub filter: Option<String>,    // "DCTDecode" | "FlateDecode" | "CCITTFaxDecode" | ...
    pub color_space: Option<String>, // "DeviceRGB" | "DeviceGray" | "DeviceCMYK" | "Indexed"
    pub byte_size: usize,
}

pub fn list_image_xobjects(doc: &Document) -> Vec<ImageRef> {
    let mut out = Vec::new();
    for (id, obj) in &doc.objects {
        let Ok(stream) = obj.as_stream() else { continue };
        let dict = &stream.dict;
        let subtype = dict.get(b"Subtype").ok().and_then(|v| v.as_name().ok());
        if subtype != Some(b"Image") { continue; }
        let width  = dict.get(b"Width" ).ok().and_then(|v| v.as_i64().ok()).unwrap_or(0) as u32;
        let height = dict.get(b"Height").ok().and_then(|v| v.as_i64().ok()).unwrap_or(0) as u32;
        let bpc    = dict.get(b"BitsPerComponent").ok().and_then(|v| v.as_i64().ok()).unwrap_or(8) as u8;
        let filter = dict.get(b"Filter").ok().and_then(|v| match v {
            Object::Name(n) => Some(String::from_utf8_lossy(n).into_owned()),
            Object::Array(a) => a.first().and_then(|x| x.as_name().ok())
                                 .map(|n| String::from_utf8_lossy(n).into_owned()),
            _ => None,
        });
        let color_space = dict.get(b"ColorSpace").ok().and_then(|v| match v {
            Object::Name(n) => Some(String::from_utf8_lossy(n).into_owned()),
            Object::Array(a) => a.first().and_then(|x| x.as_name().ok())
                                 .map(|n| String::from_utf8_lossy(n).into_owned()),
            _ => None,
        });
        out.push(ImageRef {
            object_id_num: id.0, object_id_gen: id.1,
            width, height, bits_per_component: bpc,
            filter, color_space,
            byte_size: stream.content.len(),
        });
    }
    out
}
```

**Step 3: Implement `compact`**

Algorithm in pseudocode:

```rust
pub fn compact(input: &Path, output: &Path, opts: CompactOptions) -> Result<CompactReport, PdfError> {
    let original_bytes = std::fs::metadata(input)?.len();
    let mut doc = Document::load(input)?;

    let mut bytes_saved_images = 0i64;
    let images = list_image_xobjects(&doc);

    for img in &images {
        let target_dpi = match img.color_space.as_deref() {
            Some("DeviceGray") => opts.target_gray_dpi,
            _ if img.bits_per_component == 1 => opts.target_mono_dpi,
            _ => opts.target_color_dpi,
        };
        // Stage 1 heuristic: assume 8.5" wide page → target px = target_dpi * 8.5
        let target_px = (target_dpi as f32 * 8.5).round() as u32;
        if img.width <= target_px && img.filter.as_deref() == Some("DCTDecode") {
            continue; // already small enough + already JPEG
        }
        let id = (img.object_id_num, img.object_id_gen);
        let stream = doc.objects.get(&id).and_then(|o| o.as_stream().ok().cloned());
        let Some(stream) = stream else { continue };

        // Decode according to filter
        let decoded = decode_image_stream(&stream)?;  // returns image::DynamicImage
        let new_w = target_px.min(img.width);
        let new_h = (img.height as f32 * new_w as f32 / img.width as f32).round() as u32;
        let resized = decoded.resize(new_w, new_h, image::imageops::FilterType::Triangle);

        // Encode as JPEG (color/gray) or keep PNG (mono)
        let mut buf = Vec::new();
        let is_gray = matches!(resized, image::DynamicImage::ImageLuma8(_));
        let mut enc = image::codecs::jpeg::JpegEncoder::new_with_quality(&mut buf, opts.jpeg_quality);
        enc.encode_image(&resized).map_err(|e| PdfError::Generic(format!("jpeg encode: {e}")))?;

        let old_size = stream.content.len();
        let new_stream = build_image_stream(buf, new_w, new_h, is_gray);
        doc.objects.insert(id, Object::Stream(new_stream));
        bytes_saved_images += old_size as i64 - buf.len() as i64;
    }

    if opts.drop_thumbnails { strip_thumbnails(&mut doc); }
    if opts.strip_metadata { strip_metadata(&mut doc); }
    if opts.strip_embedded_files { strip_embedded_files(&mut doc); }
    if opts.strip_js { strip_javascript(&mut doc); }

    doc.compress();
    if let Some(p) = output.parent() { if !p.as_os_str().is_empty() { std::fs::create_dir_all(p)?; } }
    doc.save(output)?;
    let new_bytes = std::fs::metadata(output)?.len();
    Ok(CompactReport {
        original_bytes, new_bytes,
        ratio: new_bytes as f32 / original_bytes.max(1) as f32,
        bytes_saved_images,
        images_rewritten: images.len() as u32,
    })
}
```

Implement helpers:
- `fn decode_image_stream(s: &Stream) -> Result<DynamicImage, PdfError>` — match on Filter, use `image::load_from_memory_with_format` for DCT/JPEG; for Flate, decompress then read raw RGB by `Width*Height*3` and wrap in `RgbImage::from_raw`. For CCITTFax, return error "unsupported, skip".
- `fn build_image_stream(jpeg: Vec<u8>, w: u32, h: u32, gray: bool) -> Stream` — build dict with the right ColorSpace + Filter=DCTDecode + Length, set content to jpeg bytes. Use `Stream::new(dict, jpeg).with_compression(false)` so the dict's DCTDecode filter isn't double-encoded.
- `fn strip_thumbnails(doc)` — walk pages, remove `/Thumb` key.
- `fn strip_metadata(doc)` — remove `/Metadata` key from catalog + any object stream tagged as XMP.
- `fn strip_embedded_files(doc)` — remove `/Names /EmbeddedFiles` from catalog.
- `fn strip_javascript(doc)` — remove `/Names /JavaScript` + any `/AA` actions.

Wrap any decode errors in a "skip this image, log & continue" path — never fail the whole compact because one image is exotic (Slice 6 adds the warning surface).
