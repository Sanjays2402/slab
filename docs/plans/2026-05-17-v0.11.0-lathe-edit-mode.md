# Slab v0.11.0 "Lathe" — Edit Mode Implementation Plan

> **For Hermes:** Ship one vertical slice per cron tick. Each slice is end-to-end
> user-visible (backend + Tauri command + frontend if applicable + tests + commit + push).

**Goal:** Turn Slab from "PDF reader + AI sidekick" into a real PDF editor — page
operations get a polished visual UI, plus three new primitives (duplicate pages,
split-by-pattern, multi-PDF tabs) that unlock real workflows.

**Architecture:** Backend page-op kernels stay in `src-tauri/src/pdf/`. New kernel
modules: `pdf::duplicate`, `pdf::split_pattern`, `pdf::edit_text` (Slice 6 — uses
`lopdf` content-stream rewriting). Frontend gets one new fat panel `PagesVisualPanel.svelte`
that replaces the existing list-based `PagesPanel.svelte` with drag-reorder
thumbnails. Multi-tab is a layout change at `+page.svelte` level — each tab
holds its own ReaderPanel state.

**Tech Stack:** Rust (`lopdf`), TypeScript/Svelte 5 runes, Tauri 2, pdfjs-dist
for thumbnail rendering. No new runtime deps (lopdf, regex, serde already in tree).

**Step 1: kernel `pdf::duplicate::duplicate_pages`**

```rust
//! Clone a set of pages in place — useful for "duplicate slide", "make
//! 2-up handout from existing pages", or stamping a cover sheet on every
//! chapter break.

use crate::pdf::split::{extract_pages_to, page_count};
use crate::pdf::PdfError;
use std::path::Path;

/// Duplicate the given pages, inserting copies immediately after each source page.
/// Pages are 1-indexed. Each entry in `pages` is duplicated once.
/// Returns the new total page count.
pub fn duplicate_pages(input: &Path, pages: &[u32], output: &Path) -> Result<u32, PdfError> {
    if !input.exists() {
        return Err(PdfError::InputMissing(input.display().to_string()));
    }
    if pages.is_empty() {
        return Err(PdfError::Other("no pages specified for duplication".into()));
    }
    let total = page_count(input)?;
    for &p in pages {
        if p == 0 || p > total {
            return Err(PdfError::Other(format!(
                "page {p} out of range (1..={total})"
            )));
        }
    }
    let dup_set: std::collections::BTreeSet<u32> = pages.iter().copied().collect();
    let mut order: Vec<u32> = Vec::with_capacity(total as usize + dup_set.len());
    for p in 1..=total {
        order.push(p);
        if dup_set.contains(&p) {
            order.push(p);
        }
    }
    extract_pages_to(input, &order, output)?;
    Ok(order.len() as u32)
}
```

fn slab_duplicate_pages(input: PathBuf, pages: Vec<u32>, output: PathBuf) -> CmdResult<u32> {

        Ok(n) => CmdResult::ok(n),

}

## Slice 2: `split_by_pattern` backend (regex over per-page text)

**Files:** create `src-tauri/src/pdf/split_pattern.rs`; modify `pdf.rs`; modify `lib.rs`.

- Inputs: input path, regex string, output dir
- Algorithm: extract per-page text (reuse `pdf::extract::extract_text_per_page`),
  scan with `regex::Regex` to find chapter-start pages, then `split::split_by_ranges`.
- Bonus: if regex is empty, fall back to "split at outline headings" using `pdf::outline::collect_top_level_titles`.
- 5 tests including UTF-8 boundary, no-match-returns-error, outline fallback.
- Tauri command `slab_split_by_pattern`.

## Slice 6: In-place text editing — backend `pdf::edit_text`

**Files:** create `src-tauri/src/pdf/edit_text.rs`.

- `replace_text_span(input, page, span_index, new_text, output)` rewrites the
  page content stream replacing the Nth `Tj`/`TJ` operand with `new_text`,
  preserving the Tf/Tm/Td matrices.
- Font fallback: if `new_text` contains glyphs not in the page's current font,
  fall back to embedding a system font (Helvetica) via lopdf.
- 6 tests on synthetic content streams.

## Principles

- **TDD.** Every backend kernel ships with tests before/with the implementation.
- **DRY.** Reuse `extract_pages_to` and `split_by_ranges` rather than rebuilding.
- **YAGNI.** No editor-mode-toggle, no per-tab Beacon context, no font-picker
  UI until Slice 7 actually needs it.
- **Commits per slice**, not per file.
- **No PRs.** Direct merge to main when Slice 8 closes.
