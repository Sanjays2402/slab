# v3.23.0 "Stack" — Visual Redline Diff Implementation Plan

> **For Hermes (Cake):** Use `subagent-driven-development` to execute this plan
> task-by-task on a fresh `feature/v3.23.0-stack-visual-diff` branch. Two-stage
> review (spec compliance → code quality) after each task. Off-hours only.

**Goal:** Turn Slab's existing line-level text diff into a **word-level visual
redline** with side-by-side page-image rendering, Litera-Compare-style — fully
offline, free, with Beacon AI commentary already wired.

**Architecture:**
- Backend `src-tauri/src/pdf/diff.rs` already produces line-level `PageDiff`s.
  Layer a **word-level diff** on top (Myers diff over whitespace-split tokens
  of each changed-line pair) and emit `WordDiff` segments alongside `LineDiff`.
- Frontend `DiffPanel.svelte` gets two new modes:
  1. **Word-inline view** — current text view, but with `<ins>`/`<del>` token
     spans (green underline / red strikethrough), not whole-line tinting.
  2. **Visual side-by-side view** — pdfjs-dist renders the same page index from
     both PDFs at matched scale; a "change ribbon" gutter between them marks
     which pages have edits. Click ribbon → scroll-sync both panels.
- A new **Export Redline PDF** command rasterises the new PDF and overlays the
  inserted/deleted words as colored bounding-box outlines (using the existing
  `lopdf` content-stream injection helpers from `pdf/markup.rs`).
- Wire into the **command palette** (`Cmd/Ctrl+Shift+D` → "Stack: Compare two
  PDFs"), the **keyboard shortcut cheat-sheet**, and the **What's New** modal.

**Tech Stack:** Rust (`lopdf`, `imara-diff` already in workspace, otherwise
add `similar = "2"`), Svelte 5 runes, `pdfjs-dist` (already vendored),
`@tauri-apps/api/core` invokes.

```rust
//! Word-level diff using the `similar` crate. Splits on ASCII whitespace
//! boundaries while preserving the trailing whitespace on each token, so
//! re-joining the segments yields the original string byte-for-byte.

use super::diff::{WordDiff, WordOp};

/// Tokenise `s` into whitespace-suffixed words: `"foo  bar"` →
/// `["foo  ", "bar"]`. Re-joining the slice reconstructs `s` exactly.
pub fn tokenize(s: &str) -> Vec<&str> {
    let mut out = Vec::new();
    let mut start = 0;
    let bytes = s.as_bytes();
    let mut i = 0;
    while i < bytes.len() {
        // advance through a word
        while i < bytes.len() && !bytes[i].is_ascii_whitespace() { i += 1; }
        // then through trailing whitespace
        while i < bytes.len() && bytes[i].is_ascii_whitespace() { i += 1; }
        out.push(&s[start..i]);
        start = i;
    }
    out
}

/// Word-level diff between `old` and `new`.
pub fn diff_words(old: &str, new: &str) -> Vec<WordDiff> {
    let a = tokenize(old);
    let b = tokenize(new);
    let mut out: Vec<WordDiff> = Vec::new();
    let diff = similar::TextDiff::from_slices(&a, &b);
    for change in diff.iter_all_changes() {
        let op = match change.tag() {
            similar::ChangeTag::Equal => WordOp::Equal,
            similar::ChangeTag::Insert => WordOp::Insert,
            similar::ChangeTag::Delete => WordOp::Delete,
        };
        let text = change.value().to_string();
        // coalesce adjacent same-op segments
        if let Some(last) = out.last_mut() {
            if last.op == op {
                last.text.push_str(&text);
                continue;
            }
        }
        out.push(WordDiff { op, text });
    }
    out
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn tokenize_roundtrips_through_join() {
        let s = "The  quick brown\tfox";
        let toks = tokenize(s);
        assert_eq!(toks.concat(), s);
    }

    #[test]
    fn pure_insertion_marks_only_inserts() {
        let d = diff_words("hello world", "hello brave new world");
        let inserts: String = d.iter()
            .filter(|w| w.op == WordOp::Insert)
            .map(|w| w.text.as_str())
            .collect();
        assert!(inserts.contains("brave"));
        assert!(inserts.contains("new"));
        assert!(!d.iter().any(|w| w.op == WordOp::Delete));
    }

    #[test]
    fn pure_deletion_marks_only_deletes() {
        let d = diff_words("alpha beta gamma", "alpha gamma");
        assert!(d.iter().any(|w| w.op == WordOp::Delete && w.text.contains("beta")));
        assert!(!d.iter().any(|w| w.op == WordOp::Insert));
    }

    #[test]
    fn rejoin_equal_plus_insert_equals_new() {
        let d = diff_words("a b", "a x b");
        let rebuilt: String = d.iter()
            .filter(|w| matches!(w.op, WordOp::Equal | WordOp::Insert))
            .map(|w| w.text.as_str())
            .collect();
        assert_eq!(rebuilt, "a x b");
    }
}
```

```rust
fn attach_word_diffs(lines: &mut [LineDiff]) {
    let mut i = 0;
    while i + 1 < lines.len() {
        let (a, b) = lines.split_at_mut(i + 1);
        let prev = &mut a[i];
        let next = &mut b[0];
        if prev.op == DiffOp::Delete && next.op == DiffOp::Insert {
            let wd = crate::pdf::diff_words::diff_words(&prev.text, &next.text);
            // Split: deletes + equals go to prev.words; inserts + equals to next.words.
            prev.words = Some(wd.iter().filter(|w| w.op != WordOp::Insert).cloned().collect());
            next.words = Some(wd.into_iter().filter(|w| w.op != WordOp::Delete).collect());
            i += 2;
        } else {
            i += 1;
        }
    }
}
```
