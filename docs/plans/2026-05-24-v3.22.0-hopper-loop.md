# v3.22.0 "Hopper Loop" Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Close the Hopper-rules loop with batch backfill — apply current rules to PDFs already sitting in a watched folder, with a dry-run "Test on this folder" preview before committing.

**Architecture:** Reuse `hopper::pipeline` + the v3.21.0 rule engine. Add (a) a `backfill_folder` engine entry that walks an existing folder and routes each file through the rule chain, (b) a `dry_run` mode that returns a planned-action report without moving files, (c) a Tauri command surface, and (d) a frontend "Test on this folder" panel inside the Hopper rules editor with a results table + "Apply" / "Cancel".

**Tech Stack:** Rust 2024 (`src-tauri/src/hopper/`), Tokio for async walking, Svelte 5 + Liquid Glass UI for the panel, sqlite for run history.
