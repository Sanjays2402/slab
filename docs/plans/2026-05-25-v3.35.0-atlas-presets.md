# v3.35.0 "Atlas Presets" Implementation Plan

> **Status:** SHIPPED end-to-end on `feature/v3.35.0-atlas-presets` in a
> single off-hours tick (2026-05-25). Awaiting CI unblock (billing) +
> merge of v3.33 / v3.34 first.

**Goal:** One-click smart-collection templates so a brand-new user gets
value in <30 seconds without ever opening the rule builder.

**Architecture:** Static Rust `Preset` registry → builder fn returns
`LibraryFilter` (using v3.34 nested clause tree where it matters) →
Tauri commands expose list / apply / already-applied → Svelte
`PresetPicker.svelte` modal launched from sidebar ★ button,
Cmd+Shift+P shortcut, or command palette entry.

**Tech Stack:** Rust + rusqlite, Svelte 5, Tauri. Zero new deps.

---

### Slice 1 — Backend preset registry + tests

**Files:** `src-tauri/src/pdf/library/presets.rs` (new),
`src-tauri/src/pdf/library/mod.rs` (one line).

Built 11 templates: Recently added, Tax 2025 / 2024, Invoices,
Receipts, Contracts pending signature (Tag AND NotTag — uses the
v3.34 clause tree), Legal, Research papers, Manuals & guides,
Scanned documents, Untagged. Each has a stable id, display name,
icon, color, description, and a builder fn.

`ensure_tag()` auto-creates referenced tags case-insensitively so the
preset is usable on a fresh library. `apply_preset` materialises into
`library_smart_collections`. `presets_already_applied` lets the UI
grey out add buttons.

9 unit tests, all green. SHA: `72f1f3c`.

---

### Slice 2 — Tauri commands

**Files:** `src-tauri/src/lib.rs` (+ invoke handler registration).

- `slab_preset_list` → static `Vec<PresetInfo>`, no DB hit.
- `slab_preset_apply(presetId)` → emits `library-changed` on success.
- `slab_preset_already_applied` → reads smart-collection list.

SHA: `abc5feb`.

---

### Slice 3 — TS bindings + PresetPicker modal + sidebar wiring

**Files:** `src/lib/library.ts`, `src/lib/panels/PresetPicker.svelte`
(new, ~280 LOC), `src/lib/panels/CollectionsSidebar.svelte`.

PresetPicker: Liquid-glass modal with search filter, responsive card
grid (auto-fill 330px columns), icon emoji fallback, color-tinted
badges, busy / Added states, error banner. Esc + Done close it.

Sidebar: golden ★ button next to the existing "+" in the Smart
section, opens the picker. Cmd/Ctrl+Shift+P keyboard shortcut works
even when sidebar isn't focused. `openPresets()` exported for
external drivers.

SHA: `08293ab`.

---

### Slice 4 — Command palette + ShortcutsOverlay discoverability

**Files:** `src/lib/CommandPalette.svelte`,
`src/lib/panels/CollectionsSidebar.svelte`,
`src/lib/ShortcutsOverlay.svelte`.

Two new palette entries under the Library group:
- "Add smart collection from preset…" (dispatches
  `slab:open-preset-picker` window event)
- "New smart collection…" (dispatches `slab:open-smart-builder`)

CollectionsSidebar listens to both events and opens the corresponding
modal — works regardless of which panel was active when the palette
fired.

Added Library (Atlas) section to ShortcutsOverlay covering
Cmd+Shift+P, Cmd+Shift+N, Cmd+Shift+F.
