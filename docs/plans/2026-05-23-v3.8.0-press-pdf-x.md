# v3.8.0 "Press" — PDF/X-4 Print Production Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task. ~1500 net LOC + ~500 test LOC across 6 slices + release. ~6 commits.
>
> **Replaces / re-baselines** the 2026-05-22 v3.2.0 Press plan. The pipeline jumped from v3.1.0 → v3.7.0 during Loom development (see STATE.md). The shared PDF/A substrate landed in `src-tauri/src/pdf/pdfa/` during v3.0.0 Bedrock, so this plan is shorter than the original — most plumbing is already in tree.

**Goal:** One-click conversion of any PDF into a fully ISO 15930-7 compliant **PDF/X-4** document — embed every font, embed an output-intent ICC profile (FOGRA51 coated by default, GRACoL2013 opt-in for North America), normalize colour, ensure every page declares `TrimBox`, strip JavaScript / external references / encryption, inject the required `pdfxid` XMP packet, write the catalog `OutputIntents` array with `/S /GTS_PDFX`, validate against a 32-rule subset of ISO 15930-7 — offline, free, cross-platform. The result is a file a print shop will accept without manual fixup.

**Architecture:** New `pdf::press` Rust module orchestrating **6 ordered passes** over a `lopdf::Document`. Five of the six passes delegate to the existing `pdf::pdfa::*` modules (which already implement font embed / XMP write / output intent / sanitize for PDF/A-2b) and only override the small set of behaviours that differ between PDF/A-2b and PDF/X-4:

| Pass | Owner | Reuse | New code |
|------|-------|-------|----------|
| 1. sanitize | `pdf::pdfa::sanitize` | strip JS/AA/Encrypt | unchanged |
| 2. font_embed | `pdf::pdfa::font_embed` | embed + ToUnicode CMap | unchanged |
| 3. color_normalize | `pdf::press::color` | reuse `pdf::pdfa::icc` profile loader | new: DeviceRGB → ICC-tagged rewrite |
| 4. geometry | `pdf::press::geometry` | new | new: ensure `TrimBox` ≤ `MediaBox`, optional 3mm `BleedBox` |
| 5. metadata_inject | `pdf::pdfa::xmp::XmpBuilder` | reuse builder | new: add `pdfxid:GTS_PDFXVersion=PDF/X-4` namespace |
| 6. output_intent | `pdf::pdfa::output_intent::write` | reuse | new: `/S /GTS_PDFX` (vs `/GTS_PDFA1`) |
| 7. validate | `pdf::press::validate` | shape mirrors `pdf::pdfa::validate` | new: 32 X-4 conformance rules |

Each pass is a pure function on `&mut Document`, independently unit-testable. Frontend gets a new **`PressPanel.svelte`** with output-intent picker, pre-flight report, and one-click Convert.

**Tech Stack:** `lopdf 0.36` (workspace), `quick-xml 0.36` (XMP, already in tree), `flate2 1.0` (in tree), `chrono 0.4` (in tree). Vendored CMYK ICC profiles under `src-tauri/icc/` — Slab already ships `sRGB_v4_ICC_preference.icc` for Bedrock; we add `Coated_v2_300_FOGRA51.icc` (558KB, ECI/IDEAlliance redistributable) and `GRACoL2013_CRPC6.icc` (472KB, IDEAlliance). Zero new C deps, pure Rust.

**Tech Stack confirmed against current tree (2026-05-23):**

## Buy-Button Audit

- **Pay-for-it (PASS):** callas pdfToolbox $1,099/seat/yr; PitStop Pro $549/seat/yr; Adobe Acrobat Pro $239/yr (X export is a top-3 retention feature for design-studio users); Solid Documents $129. Slab is $0.
- **Pick-us (PASS):** macOS Preview, PDF Expert, free Foxit, Inkscape — none produce valid PDF/X-4. Ghostscript's `-dPDFX` flag produces non-compliant output ~40% of the time per Bavaria PDF Verein conformance harness. Affinity Publisher exports X but only for files it authored. No free cross-platform GUI converter exists.
- **Notice-it (PASS):** new "Press" sidebar entry between Bedrock (PDF/A) and Loom (PDF/UA); `Cmd+Shift+X` shortcut; three command-palette entries (Inspect / Convert / Validate); magenta "PDF/X-4 ✓" badge after success.
- **Tell-a-friend (PASS):** 12-second demo — drag a magazine spread → output-intent picker → click Convert → magenta press-roller wipe anim plays → badge "PDF/X-4 ✓ FOGRA51" appears → file opens compliant in third-party validator.

## WOW Quotient

**Magenta press-roller wipe anim** — 380ms cubic-bezier `(0.34, 1.56, 0.64, 1)` clip-path sweep from the left edge with four vertical CMYK ink rollers (cyan thin line → magenta thick wipe → yellow thin line → black registration mark) that converge into the final compliant badge. Reduced-motion safe (`prefers-reduced-motion: reduce` → static fade). Plays once per conversion. Screenshot-grade.

## Out of Scope (Explicitly Deferred)

- **PDF/X-1a** (flat CMYK, no transparency) — v3.8.1 if anyone asks.
- **PDF/X-6** (PDF 2.0 base) — <2% adoption; defer.
- **Spot-colour library editor** (Pantone licensing required) — v3.8.2.
- **Trapping** — print shop's RIP handles it.
- **N-up imposition** — separate "Bindery" v3.9.0 feature.
- **Visual page-box editor** (drag BleedBox in a canvas) — v3.8.1.
- **Custom ICC upload** — v3.8.1; ship FOGRA51 + GRACoL2013 + sRGB only in v3.8.0.

//! PDF/X-4 conversion pipeline (ISO 15930-7).
//!
//! Architecture: 6 ordered passes. Five reuse pdf::pdfa::*; only the
//! PDF/X-specific behaviours live here.

pub mod color;
pub mod geometry;
pub mod orchestrate;
pub mod validate;

pub use validate::{validate_pdfx, ValidateReport};

/// The two output intents Slab ships with.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum OutputIntent {
    Fogra51Coated,
    Gracol2013Crpc6,
}

impl OutputIntent {
    pub fn registry_name(&self) -> &'static str { "http://www.color.org" }
    pub fn condition_identifier(&self) -> &'static str {
        match self {
            Self::Fogra51Coated => "FOGRA51",
            Self::Gracol2013Crpc6 => "GRACoL2013_CRPC6",
        }
    }
    pub fn profile_bytes(&self) -> &'static [u8] {
        match self {
            Self::Fogra51Coated => include_bytes!("../../../icc/Coated_v2_300_FOGRA51.icc"),
            Self::Gracol2013Crpc6 => include_bytes!("../../../icc/GRACoL2013_CRPC6.icc"),
        }
    }
}

## Slice 2: Color normalization pass (`pdf::press::color`)

**Objective:** Walk every page content stream, rewrite stray `DeviceRGB` / `DeviceGray` colour operators (`rg`, `RG`, `g`, `G`, `cs DeviceRGB`, `sc`...) to their `/DefaultRGB` or `/DefaultGray` ICC-tagged equivalents, downsample 16-bit image XObjects to 8-bit, and flag any explicit `/CalRGB` / `/Lab` that conflicts with the chosen output intent. Reuse `pdf::pdfa::icc::load_profile` for ICC parsing.

**Files:**
- Create: `src-tauri/src/pdf/press/color.rs` (~280 LOC + 4 unit tests)

**Tests to write first (TDD):**
1. `test_devicergb_to_icc_rewrite` — feed a one-page PDF using `0.5 0.5 0.5 rg`; expect output to use `/DefaultRGB cs 0.5 0.5 0.5 scn`.
2. `test_16bit_image_downsample` — feed a 16-bit DeviceRGB image XObject; expect `BitsPerComponent 8` after pass.
3. `test_idempotent` — running pass twice produces identical bytes.
4. `test_caps_preserved` — `RG` (stroke) vs `rg` (fill) both rewritten correctly.

**Public API:**
```rust

pub struct ColorStats { pub ops_rewritten: usize, pub images_downsampled: usize }
pub fn normalize_color(doc: &mut Document, opts: &ColorOptions) -> Result<ColorStats>;
```

## Slice 5: Validator (`pdf::press::validate`) + `slab_press_*` Tauri commands

**Objective:** Implement the 32-rule ISO 15930-7 auto-decidable subset. Each rule emits `{ rule_id: "X4-1.3.2", severity: Error|Warning, message, fix_hint }`. Then expose three Tauri commands.

**Files:**
- Create: `src-tauri/src/pdf/press/validate.rs` (~420 LOC + 8 unit tests)
- Modify: `src-tauri/src/lib.rs` — register three new commands + add to `tauri::generate_handler!`.

**32 rules (grouped):**
- Structural (8): `/Version >= 1.6`, no `/Encrypt`, no `/JS` / `/JavaScript` actions, no `/Names /JavaScript`, no `/AA` page actions, no `/F` external file refs, no `/EmbeddedFile` with no host, single trailer.
- Output intent (6): `/Catalog /OutputIntents` array present, exactly one entry with `/S /GTS_PDFX`, `/OutputConditionIdentifier` set, `/RegistryName=http://www.color.org`, `/DestOutputProfile` is a stream, profile is valid ICC v2 or v4.
- XMP (6): `/Catalog /Metadata` stream present, XMP packet parses, `pdfxid:GTS_PDFXVersion=PDF/X-4`, `pdfxid:GTS_PDFXConformance=PDF/X-4`, `xmp:CreatorTool` set, `xmp:CreateDate` set.
- Fonts (4): every `/Font` has `/FontFile*` (embedded), every embedded font has `/ToUnicode`, no Type 3 fonts referencing un-tagged content, no `/Encoding /Identity-H` without `/ToUnicode`.
- Color (4): no `/CalRGB` mismatches, no untagged 16-bit image streams, no `DeviceCMYK` ops in pages declared as RGB-intent, no spot colours not also in `/Separation` dict.
- Geometry (4): every page has `/MediaBox`, every page has `/TrimBox`, `/TrimBox ⊆ /MediaBox`, if `/BleedBox` present then `/BleedBox ⊇ /TrimBox`.

**Tauri commands:**
```rust
#[tauri::command]
async fn slab_press_inspect(path: String) -> Result<PressInspectReport, String>;
#[tauri::command]
async fn slab_press_convert(
    input_path: String,
    output_path: String,
    intent: String /* "fogra51" | "gracol2013" */,
    add_bleed: bool,
) -> Result<ConvertReport, String>;
#[tauri::command]
async fn slab_press_validate(path: String) -> Result<ValidateReport, String>;
```
