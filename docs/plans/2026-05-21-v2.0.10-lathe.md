# v2.0.10 "Lathe" 🔧 — Annotation Edit Mode Implementation Plan

> **For Hermes:** Use `subagent-driven-development` to implement this plan task-by-task. Each slice = one delegated subagent. Two-stage review (spec compliance, then code quality) between slices.

**Goal:** Turn Slab's five annotation primitives (highlight from v2.0.6, ink from v2.0.7, four shapes from v2.0.8, freetext from v2.0.9) from *write-only* marks into *first-class editable objects* — click to select, drag to move, drag handles to resize, Cmd+Z to undo, Delete to remove, Cmd+C/V to copy-paste. Closes the five open-question deferrals stacked into v2.0.6–v2.0.9 in a single release.

**Architecture:** New thin `selection.ts` store (in-memory only — selection is *not* persisted across opens, same as a text editor) tracking `{ id, kind, page } | null`. New `SelectionLayer.svelte` paints 8-direction resize handles and a marching-ants border over the selected annotation, listening to the same `eventBus.pagerendered` hook v2.0.6–v2.0.9 already use. Pointer-down on an annotation hit-test (delegated from `DrawLayer`'s existing overlay) sets selection; pointer-down on a handle starts a resize gesture; pointer-down on the body starts a move gesture. New `history.ts` store implements a per-document **command-stack undo/redo** (not snapshot diff — too expensive for 200-annotation docs). Every mutating call to `annotations.ts` (`addX`, `updateX`, `removeX`) now routes through `history.apply(cmd)` which pushes its inverse onto the redo-able stack. Clipboard goes through the existing Tauri `clipboard:write-text` API serialized as Slab-flavored JSON (`slab/annotation-v1` mime); paste round-trips through a validator. **Zero new persistence formats**, **zero new Tauri commands**, **zero new third-party deps**.

**Tech Stack:** Svelte 4 (frontend), Rust 1.78 / Tauri 2 (backend — no new Rust modules; the burn-into-PDF path already handles all five variants from v2.0.6–v2.0.9), pdfjs-dist 4 `eventBus.pagerendered` (existing), pure-TS command pattern for undo/redo, browser `navigator.clipboard` (with Tauri fallback for cross-platform parity), CSS `transform: translate()` for live drag preview (avoids re-rendering pdfjs canvases until commit).

**Codename:** "Lathe" 🔧 — every mark on the page is now turnable: shape it, reshape it, peel a layer back. The annotation toolkit becomes a real editor.

```ts
// src/lib/selection.ts
export type SelectionRef = {
  id: string;
  kind: 'highlight' | 'note' | 'ink' | 'rect' | 'ellipse' | 'arrow' | 'line' | 'freetext';
  page: number;
  path: string;
};

type Listener = (v: SelectionRef | null) => void;

let current: SelectionRef | null = null;
const listeners = new Set<Listener>();

export const selection = {
  get: () => (current ? { ...current } : null),
};

export function select(ref: SelectionRef): void {
  current = { ...ref };
  for (const l of listeners) l(selection.get());
}

export function clear(): void {
  if (current === null) return;
  current = null;
  for (const l of listeners) l(null);
}

export function isSelected(id: string): boolean {
  return current?.id === id;
}

export function subscribe(l: Listener): () => void {
  listeners.add(l);
  l(selection.get());
  return () => listeners.delete(l);
}
```

**Step 3: Write failing test (`history.test.ts`) — 14 cases.**

Key cases enumerated:
1. `apply(cmd)` runs cmd.do and pushes onto undo stack.
2. `undo()` runs the most recent cmd.undo, pops it, and pushes onto redo stack.
3. `redo()` re-runs cmd.do from redo stack, pushes back onto undo.
4. New `apply()` clears the redo stack (branch-rewrite semantics, like every editor).
5. Stack depth caps at 200 by default; oldest entry evicted on overflow.
6. `clear(path)` flushes the per-path undo+redo stacks (called on document close).
7. Independent per-path stacks (undoing in doc A doesn't affect doc B).
8. `canUndo(path)` / `canRedo(path)` accurate booleans.
9. `apply` is reentrancy-safe (a cmd whose `.do` triggers another `.apply` doesn't double-push).
10. `undo` of `addX` correctly invokes `removeX`.
11. `undo` of `removeX` correctly invokes `addX` with the original payload.
12. `undo` of `updateX` correctly invokes `updateX` with the inverse patch.
13. `subscribe(path, listener)` fires on every apply/undo/redo so UI badges update.
14. `peekUndo(path)` returns the label of the next undo-able action ("Undo move", "Undo delete", etc.) for tooltip rendering.

**Step 4: Implement `history.ts`.**

```ts
// src/lib/history.ts
export type HistoryCommand = {
  label: string;          // human-readable, used in tooltips and a11y
  do: () => void;
  undo: () => void;
};

const MAX_DEPTH = 200;

type PerPath = {
  undo: HistoryCommand[];
  redo: HistoryCommand[];
  listeners: Set<() => void>;
};

const stacks = new Map<string, PerPath>();
let inFlight = false; // reentrancy guard

function stack(path: string): PerPath {
  let s = stacks.get(path);
  if (!s) {
    s = { undo: [], redo: [], listeners: new Set() };
    stacks.set(path, s);
  }
  return s;
}

export function apply(path: string, cmd: HistoryCommand): void {
  const s = stack(path);
  if (inFlight) { cmd.do(); return; } // nested calls run side-effect only
  inFlight = true;
  try {
    cmd.do();
    s.undo.push(cmd);
    if (s.undo.length > MAX_DEPTH) s.undo.shift();
    s.redo = [];
  } finally {
    inFlight = false;
  }
  fire(s);
}

export function undo(path: string): boolean {
  const s = stack(path);
  const cmd = s.undo.pop();
  if (!cmd) return false;
  inFlight = true;
  try { cmd.undo(); } finally { inFlight = false; }
  s.redo.push(cmd);
  fire(s);
  return true;
}

export function redo(path: string): boolean {
  const s = stack(path);
  const cmd = s.redo.pop();
  if (!cmd) return false;
  inFlight = true;
  try { cmd.do(); } finally { inFlight = false; }
  s.undo.push(cmd);
  fire(s);
  return true;
}

export function canUndo(path: string): boolean { return stack(path).undo.length > 0; }
export function canRedo(path: string): boolean { return stack(path).redo.length > 0; }
export function peekUndo(path: string): string | null { return stack(path).undo.at(-1)?.label ?? null; }
export function peekRedo(path: string): string | null { return stack(path).redo.at(-1)?.label ?? null; }

export function clear(path: string): void {
  const s = stack(path);
  s.undo = []; s.redo = [];
  fire(s);
}

export function subscribe(path: string, l: () => void): () => void {
  const s = stack(path);
  s.listeners.add(l);
  l();
  return () => s.listeners.delete(l);
}

function fire(s: PerPath): void { for (const l of s.listeners) l(); }
```

```ts
export function updateAnnotation(path: string, id: string, patch: Partial<Annotation>): void {
  const all = load(path);
  const idx = all.findIndex(a => a.id === id);
  if (idx < 0) return;
  all[idx] = { ...all[idx], ...patch } as Annotation;
  save(path, all);
  notify(path);
}

export function removeAnnotation(path: string, id: string): void {
  const all = load(path);
  const next = all.filter(a => a.id !== id);
  if (next.length === all.length) return; // not found, no-op
  save(path, next);
  notify(path);
}

export function getAnnotation(path: string, id: string): Annotation | undefined {
  return load(path).find(a => a.id === id);
}
```

## Slice 3 — Drag-to-move + drag-to-resize (the core editor mechanics)

**Objective:** Make the chrome actually do something. Pointer-down on annotation body → move gesture. Pointer-down on a handle → resize gesture. Live preview via CSS `transform`; commit via `history.apply()` so it's undo-able.

**Files:**
- Modify: `src/lib/panels/DrawLayer.svelte` (~140 LOC) — add `hitTestAnnotation(localPoint)` and pointer-down delegation when no create-sub-mode is active.
- Modify: `src/lib/panels/SelectionLayer.svelte` (~200 LOC) — add pointer-down handlers on body and handles; live preview via local state + `transform`; on pointer-up call `history.apply()` w/ a `MoveCommand` or `ResizeCommand`.
- Create: `src/lib/annotation-geometry.ts` (~120 LOC + ~140 LOC tests) — pure geometry: `bboxOf(annot)`, `translateAnnot(annot, dx, dy)`, `resizeAnnot(annot, handle, dx, dy)`, `unionBbox(strokes)`. Tested independently because this is where math-typo bugs hide.

**Design highlights:**
- During drag: don't mutate the annotation. Instead apply a CSS `transform: translate(Xpx,Ypx)` to the SelectionLayer SVG. The underlying annotation stays at its old position (rendered by DrawLayer). On pointer-up, compute the final delta in PDF points, build a `MoveCommand { do: () => updateAnnotation(...), undo: () => updateAnnotation(... inverse ...) }`, and `history.apply(path, cmd)`. This avoids any pdfjs re-rendering during the drag itself.
- For ink, "resize" means scale-from-anchor: if dragging the SE handle, anchor is NW. Each point in each stroke is mapped `(x,y) -> anchor + (point - anchor) * (newSize / oldSize)`.
- For lines/arrows, only the two endpoints exist (no bbox per se); the 8 handles collapse to 2 (start/end) when the selection is a line or arrow. Add this branch in `annotation-geometry.ts`.
- For freetext, resize updates `pdfRect` width/height; autofit logic from v2.0.9 kicks in on next render.
- Minimum bbox size = 8 PDF-pt × 8 PDF-pt. Clamp resize to that floor.
- ESC during drag cancels (restore selection-layer transform to identity, no `history.apply`).

```ts
function onKeyAction(action: ActionId, ev: KeyboardEvent) {
  const sel = selection.get();
  switch (action) {
    case 'annot_select_next': {
      const all = listAnnotations(activePath).filter(a => a.page === currentPage);
      const next = all[(all.findIndex(a => a.id === sel?.id) + 1) % all.length] ?? all[0];
      if (next) select({ id: next.id, kind: next.kind, page: next.page, path: activePath });
      ev.preventDefault();
      break;
    }
    case 'annot_select_prev': /* ... mirror ... */ break;
    case 'annot_delete': if (sel) deleteWithUndo(sel); ev.preventDefault(); break;
    case 'annot_duplicate': if (sel) duplicateOffset(sel, 10, 10); ev.preventDefault(); break;
    case 'annot_undo': if (canUndo(activePath)) { undo(activePath); ev.preventDefault(); } break;
    case 'annot_redo': if (canRedo(activePath)) { redo(activePath); ev.preventDefault(); } break;
    case 'annot_copy': if (sel) copyToClipboard(getAnnotation(activePath, sel.id)!); ev.preventDefault(); break;
    case 'annot_paste': void pasteAndPlace(activePath, currentPage); ev.preventDefault(); break;
```

```ts
// src/lib/clipboard-annot.ts
const MIME = 'application/x-slab-annot-v1+json';

export async function copyToClipboard(annot: Annotation): Promise<void> {
  const payload = JSON.stringify({ format: 'slab/annot', v: 1, annot });
  try {
    const blob = new Blob([payload], { type: MIME });
    await navigator.clipboard.write([new ClipboardItem({ [MIME]: blob, 'text/plain': new Blob([payload], { type: 'text/plain' }) })]);
  } catch {
    await navigator.clipboard.writeText(payload); // Linux/Wayland fallback
  }
}

export async function pasteFromClipboard(): Promise<Annotation | null> {
  try {
    const items = await navigator.clipboard.read();
    for (const item of items) {
      if (item.types.includes(MIME)) {
        const blob = await item.getType(MIME);
        return validate(JSON.parse(await blob.text()));
      }
    }
  } catch { /* fall through to text */ }
  try {
    const text = await navigator.clipboard.readText();
    return validate(JSON.parse(text));
  } catch { return null; }
}

function validate(raw: unknown): Annotation | null {
  if (typeof raw !== 'object' || !raw) return null;
  const r = raw as any;
  if (r.format !== 'slab/annot' || r.v !== 1) return null;
  const a = r.annot;
  if (!a?.kind || !KNOWN_KINDS.has(a.kind)) return null;
  return a;
}

const KNOWN_KINDS = new Set(['highlight','note','ink','rect','ellipse','arrow','line','freetext']);
```
