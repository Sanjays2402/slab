# v0.8.1 "Polyglot" Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Let Slab open Office (.docx/.xlsx/.pptx), HTML, EPUB, CSV/JSON/XML, images, and audio as input, convert them to Markdown via the Microsoft `markitdown` CLI, then pipe through the existing `pdf::md2pdf::render` to produce a PDF.

**Architecture:** New module `src-tauri/src/pdf/polyglot.rs`. Single public function `polyglot_to_pdf(input: &Path, output: &Path, opts: PolyglotOpts) -> Result<PolyglotReport, PdfError>`. Internally: (1) check input exists, (2) check extension is on allow-list, (3) check `markitdown` is on `$PATH`, (4) shell out to `markitdown <input>`, capture stdout as UTF-8, (5) hand the resulting Markdown to `crate::pdf::md2pdf::render`. Wire into the CLI as `slab polyglot <input> -o <out.pdf>` and the Tauri layer as `slab_polyglot`. Mirrors the OCR module's subprocess-based pattern exactly.

**Tech Stack:** Rust, `std::process::Command`, existing `pulldown-cmark` + `lopdf`. Zero new Rust deps. External: `markitdown` (Python, MIT, user-installed via `pipx install 'markitdown[all]'`).

```rust
/// Return a canonical short kind for accepted source files.
///
/// PDF is deliberately rejected — round-tripping PDF→MD→PDF would
/// silently degrade the document.
pub fn supported_extension(input: &Path) -> Option<&'static str> {
    let ext = input
        .extension()
        .and_then(|e| e.to_str())?
        .to_ascii_lowercase();
    match ext.as_str() {
        "docx" => Some("docx"),
        "pptx" => Some("pptx"),
        "xlsx" => Some("xlsx"),
        "xls" => Some("xls"),
        "html" | "htm" => Some("html"),
        "epub" => Some("epub"),
        "csv" => Some("csv"),
        "json" => Some("json"),
        "xml" => Some("xml"),
        "rtf" => Some("rtf"),
        "odt" => Some("odt"),
        "png" | "jpg" | "jpeg" | "gif" | "bmp" | "tif" | "tiff" | "webp" => Some("image"),
        "wav" | "mp3" | "m4a" | "flac" | "ogg" => Some("audio"),
        _ => None,
    }
}
```

```rust
use std::process::Command;

/// Verify `markitdown` is callable; otherwise return a structured error
/// pointing at the recommended install command.
fn require_markitdown() -> Result<(), PdfError> {
    match Command::new("markitdown").arg("--help").output() {
        Ok(out) if out.status.success() => Ok(()),
        Ok(out) => Err(PdfError::Other(format!(
            "markitdown exited {} during preflight",
            out.status.code().unwrap_or(-1)
        ))),
        Err(e) => Err(PdfError::Other(format!(
            "markitdown not found on PATH ({e}). Install with: \
             `pipx install 'markitdown[all]'` (recommended) or \
             `pip install 'markitdown[all]'`. See \
             https://github.com/microsoft/markitdown",
        ))),
    }
}

#[cfg(test)]
fn markitdown_available() -> bool {
    Command::new("markitdown")
        .arg("--help")
        .output()
        .map(|o| o.status.success())
        .unwrap_or(false)
}
```

### Task 4: Wire `polyglot_to_pdf` to markitdown subprocess + md2pdf

**Objective:** Replace the stub `polyglot_to_pdf` with the real pipeline: validate input, capture markitdown stdout, render through md2pdf.

**Files:**
- Modify: `src-tauri/src/pdf/polyglot.rs`

**Step 1: Implement**

```rust
use crate::pdf::md2pdf::{render as md2pdf_render, Md2PdfOpts};

pub fn polyglot_to_pdf(
    input: &Path,
    output: &Path,
    opts: PolyglotOpts,
) -> Result<PolyglotReport, PdfError> {
    if !input.exists() {
        return Err(PdfError::InputMissing(input.display().to_string()));
    }
    let kind = supported_extension(input).ok_or_else(|| {
        PdfError::Other(format!(
            "unsupported polyglot input: {} (try .docx, .xlsx, .pptx, \
             .html, .epub, .csv, .json, .xml, .rtf, .odt, image, or audio)",
            input.display()
        ))
    })?;
    require_markitdown()?;

    let out = Command::new("markitdown")
        .arg(input)
        .output()
        .map_err(|e| PdfError::Other(format!("run markitdown: {e}")))?;
    if !out.status.success() {
        let stderr = String::from_utf8_lossy(&out.stderr);
        let trimmed = stderr.trim();
        return Err(PdfError::Other(format!(
            "markitdown failed ({}): {}",
            out.status.code().unwrap_or(-1),
            if trimmed.is_empty() { "(no stderr)" } else { trimmed }
        )));
    }
    let markdown = String::from_utf8(out.stdout).map_err(|e| {
        PdfError::Other(format!("markitdown produced non-UTF-8 output: {e}"))
    })?;
    if markdown.trim().is_empty() {
        return Err(PdfError::Other(
            "markitdown returned empty document — input may be unreadable".into(),
        ));
    }
    let markdown_bytes = markdown.len() as u32;

    let page_size = if opts.page_size.is_empty() {
        "A4".to_string()
    } else {
        opts.page_size.clone()
    };
    let pages = md2pdf_render(
        &markdown,
        output,
        Md2PdfOpts {
            markdown: markdown.clone(),
            page_size,
        },
    )?;

    Ok(PolyglotReport {
        source_kind: kind.to_string(),
        pages,
        markdown_bytes,
    })
}
```
