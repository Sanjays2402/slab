# v3.36.0 "Atlas Personal Presets" Implementation Plan

> **For Hermes:** This plan is being executed by Cake (cron) directly,
> end-to-end in one tick. Sliced into 4 commits for git hygiene.

**Goal:** Let users save their hand-built smart collections as reusable
**personal presets**, and **export / import** preset packs as `.slabpresets`
JSON files so paralegals on a team can share their query libraries without
ever touching a server.

**Architecture:**

- A new `library_personal_presets` table stores user-saved presets as
  serialized `LibraryFilter` JSON + metadata (name, icon, color, description).
- A new `PresetPack` JSON schema (versioned) wraps any list of presets for
  export/import. Pack v1 = `{ version: 1, presets: PersonalPresetExport[] }`.
- The existing `PresetPicker` modal gains a "Personal" section above the
  built-ins; the sidebar "Save current as preset…" context-menu entry kicks
  off a small Save dialog reusing the icon/color picker from the smart
  collection builder.
- Sample pack `assets/preset-packs/legal-starter.slabpresets` ships with
  the app — three legal-focused presets (NDAs awaiting countersign,
  Litigation hold scope, Contract renewals < 90d).

**Tech Stack:** Rust (rusqlite), Tauri commands, Svelte 5, Liquid Glass.

**Buy-Button qualification:**

- **Pay-for-it** ✅ Team-wide preset packs are an *enterprise* feature
  competitors charge for (Adobe Acrobat Pro DC + Document Cloud).
- **Notice-it** ✅ "★ Personal" section in the preset picker.
- **Pick-us** ✅ Adobe has zero preset export/import; macOS Preview lol.
- **Tell-a-friend** ✅ "drop a `.slabpresets` file → 8 smart collections
  appear instantly" demoable in 5 seconds.

## Slice 1 — Personal preset storage (backend)

**Files:**
- Create: `src-tauri/src/pdf/library/personal_presets.rs`
- Modify: `src-tauri/src/pdf/library/registry.rs` (add table DDL)
- Modify: `src-tauri/src/pdf/library/mod.rs` (export module)

Schema:
```sql
CREATE TABLE IF NOT EXISTS library_personal_presets (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  icon TEXT,
  color TEXT,
  description TEXT,
  filter_json TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  sort_order INTEGER NOT NULL DEFAULT 0
);
```

Functions:
- `save_personal_preset`, `list_personal_presets`,
  `delete_personal_preset`, `apply_personal_preset`,
  `export_pack`, `import_pack` (with conflict policy: skip-or-rename).
- Unit tests for every function.

## Slice 2 — Tauri commands

Wire the backend through Tauri. Six commands:
- `slab_personal_preset_save(spec)`
- `slab_personal_preset_list()`
- `slab_personal_preset_delete(id)`
- `slab_personal_preset_apply(id)`
- `slab_presets_export_pack(personal_ids, path)`

Register them in `invoke_handler!`.
