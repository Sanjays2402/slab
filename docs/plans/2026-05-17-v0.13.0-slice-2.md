# v0.13.0 "Lens" — Slice 2 Implementation Plan: Library Auto-OCR Queue

> **For Hermes:** Drive this top-to-bottom in one tick. Big slice, 4-6 commits.

**Goal:** Make scanned PDFs in the Library discoverable as scanned and OCR-able in bulk — schema column, scanner integration, queue worker, IPC, and LibraryPanel UI in one vertical slice.

**Architecture:** Add an `ocr_state` column to `library_documents` (`unknown` | `text_native` | `scanned` | `mixed` | `ocr_pending` | `ocr_done` | `ocr_failed`). Scanner runs `scan_audit` on every freshly hashed/upserted PDF and writes the state. New backend module `pdf::library::ocr_queue` wraps `pdf::ocr` with retry-and-mark logic so a single Tauri command can chew through pending docs sequentially. LibraryPanel renders a colored pill per card and a sticky "Run OCR on N scanned docs" bulk-action button when scanned docs exist.

**Tech Stack:** Rust + lopdf + rusqlite for the backend; Svelte for the panel.

## Tasks

### Task 1: Schema migration v2 + `ocr_state` field

**Objective:** Add `ocr_state` column (default `'unknown'`), bump `SCHEMA_VERSION`, surface on `DocumentRecord`, write migration tests.

**Files:**
- Modify: `src-tauri/src/pdf/library/registry.rs`

**Steps:**
1. Bump `SCHEMA_VERSION` from 1 to 2. Add `if version < 2 { ALTER TABLE library_documents ADD COLUMN ocr_state TEXT NOT NULL DEFAULT 'unknown'; CREATE INDEX idx_documents_ocr_state ON library_documents(ocr_state); }` block.
2. Add `pub ocr_state: String` to `DocumentRecord`. Default in `document_from_row` via `row.get(10)?`.
3. Update `upsert_document` to keep ocr_state on update (don't overwrite) — use COALESCE pattern only on first insert.
4. Add new method `set_doc_ocr_state(doc_id, state)`.
5. New tests: `schema_v2_adds_ocr_state_column`, `set_ocr_state_round_trips`, `upsert_existing_doc_preserves_ocr_state`.
6. Verify all existing tests still pass.

### Task 2: Scanner classifies via `scan_audit`

**Objective:** When the scanner does heavy_inspect on a new/changed PDF, audit it and write an initial `ocr_state` (`text_native` / `scanned` / `mixed`).

**Files:**
- Modify: `src-tauri/src/pdf/library/scanner.rs`
- Modify: `src-tauri/src/pdf/library/registry.rs` (extend `upsert_document` to take optional ocr_state on first-insert)

**Steps:**
1. Add `ocr_state: Option<&str>` arg to `upsert_document` (use `Option<String>` actually — keep it ergonomic). When inserting fresh, write that value; when updating, only write if the existing is `unknown`.
2. In `heavy_inspect`, additionally call `crate::pdf::scan_audit::audit(path)` and map `Recommendation` → state string:
   - `Recommendation::None` → `text_native`
   - `Recommendation::OcrAll` → `scanned`
   - `Recommendation::OcrSome` → `mixed`
3. Pass that state through to `upsert_document`.
4. New tests in `scanner.rs`: `scans_text_pdf_marks_text_native`, `scans_image_only_pdf_marks_scanned`, `re_scan_does_not_overwrite_ocr_done`.

### Task 3: `ocr_queue` module — list + mark + run-next

**Objective:** Backend module that the IPC layer can call: enumerate pending scanned docs, optionally OCR a single doc with mark transitions.

**Files:**
- Create: `src-tauri/src/pdf/library/ocr_queue.rs`
- Modify: `src-tauri/src/pdf/library/mod.rs` (re-export)

**API:**
```rust
pub fn list_pending(db: &LibraryDb) -> Result<Vec<DocumentRecord>, LibraryError>;
// Returns docs where ocr_state in ('scanned', 'mixed') AND state != 'ocr_pending'/'ocr_done'.

pub struct OcrQueueResult { pub doc_id: i64, pub state_after: String, pub output_path: Option<PathBuf>, pub error: Option<String> }

pub fn run_one(db: &mut LibraryDb, doc_id: i64, opts: &OcrOpts) -> OcrQueueResult;
// Marks pending → runs OCR → writes searchable PDF next to input
// (basename + ".ocr.pdf") → marks ocr_done or ocr_failed. Never panics.
```

**Steps:**
1. Implement `list_pending` with a SQL query.
2. Implement `run_one` — state machine: set `ocr_pending`, run `pdf::ocr::ocr`, on success update path? (no, keep separate output file), mark `ocr_done` and record output_path in a new `ocr_output_path` TEXT column.
3. Decide: store output path in a new column `ocr_output_path` (NULL when not done). Add it in the same migration v2.
4. Tests (use scan_audit fixtures): `list_pending_returns_only_scanned`, `run_one_marks_ocr_done` (mock `pdf::ocr::ocr` by gating on existence of tesseract — if not installed, test asserts ocr_failed transitions cleanly).

**Note:** Tesseract may not be installed in CI. Guard `run_one` tests with `if which("tesseract").is_err() { return }` early-return so they pass on bare CI but exercise the happy path locally.
