# v1.4.0 "Bench" — Slices 5+6+7 Implementation Plan

> **For Hermes:** Single-tick vertical slice — wire backend marketplace into UI end-to-end.

**Goal:** Make the marketplace usable from the Slab UI: a Browse tab in the Plugins panel that lists curated plugins from the signed index, one-click installs to `~/.slab/plugins/`, and one-click uninstalls.

**Architecture:**
- **Slice 5 (Tauri):** Three new `slab_marketplace_*` commands sitting on top of the existing `marketplace::{fetch,verify,install}` modules. The install command verifies the signature **before** download, then triggers `PluginRegistry::discover` so the new plugin appears immediately in the Installed list. Index fetch is async (reqwest), install is async (download then sync extract via `spawn_blocking`).
- **Slice 6 (TS store):** `src/lib/marketplace.ts` is the single front-door for the panel — types mirror Rust serde output, the writable store carries `state: 'idle'|'loading'|'ready'|'error'` plus index/error/isStale. Browser-mode short-circuits to `idle` (won't break `pnpm dev`).
- **Slice 7 (UI):** `PluginsPanel.svelte` gains an Installed | Browse tab strip at the top. Browse shows a 2-column grid of plugin cards with metadata + install button. Cards become "Installed (vX.Y.Z)" or "Update available → vX.Y.Z" depending on registry state.

**Tech Stack:** Rust (tauri, reqwest, ed25519), TypeScript (svelte stores), Svelte 5 ($state, $effect, $derived).

```ts

  fetchError: string | null;
```
