# v1.4.0 "Bench" — Slice 8 Implementation Plan

> **For Hermes:** This plan ships as ONE tick (3 commits + gates). Execute in
> order; commit after each step block; run quality gates once at the end
> before pushing.

**Goal:** Ship the three biggest UX wins for the marketplace in one tick:
plugin detail drawer, install progress modal, and a cross-tab
"Update available" badge on Installed-tab rows.

**Architecture:**
- Two new Svelte 5 components under `src/lib/components/`:
  `PluginDetailDrawer.svelte` (right-side slide-in) and
  `InstallProgressModal.svelte` (centered modal). Both mirror the
  visual language of `DecryptModal.svelte`.
- All wiring lives in `PluginsPanel.svelte`. The Browse tab cards
  become click-to-open targets; install/update buttons stop event
  propagation so they don't double-fire.
- Cross-tab updates use the existing `marketplaceStore`. When the
  Installed tab renders, we look up each plugin id in
  `marketplace.index?.plugins` and compute `compareSemver(remote,
  installed)` to decide whether to show an "Update → vX" pill.
- No backend changes — Slice 8 is 100% frontend polish on top of the
  already-shipped Slice 5/6/7 backend.

**Tech Stack:**
- Svelte 5 runes (`$state`, `$derived`, `$effect`, `$props`).
- Tauri 2 (no new Rust deps).
- i18n (4 locales: en / es / fr / ar).

## Task 1: PluginDetailDrawer — slide-in panel with full info + actions

**Objective:** Click a Browse-tab card body → a right-side drawer opens

**Files:**

**Component shape (PluginDetailDrawer.svelte):**

```svelte
<script lang="ts">
  import type { IndexEntry } from "$lib/marketplace";
  import { formatBytes } from "$lib/marketplace";
  import { t, tStore } from "$lib/i18n";

  type Status = "install" | "installed" | "update";
  type Props = {
    entry: IndexEntry;
    status: Status;
    installedVersion: string | null;
    inFlight: boolean;
    onClose: () => void;
    onAction: () => void;
  };
  let { entry, status, installedVersion, inFlight, onClose, onAction }: Props = $props();

  function onKeydown(e: KeyboardEvent) {
    if (e.key === "Escape") {
      e.preventDefault();
      onClose();
    }
  }

  function shortHash(h: string): string {
    return h.length > 16 ? `${h.slice(0, 8)}…${h.slice(-8)}` : h;
  }
</script>

<svelte:window onkeydown={onKeydown} />

<div
  class="backdrop"
  role="dialog"
  aria-modal="true"
  aria-labelledby="drawer-title"
  onclick={(e) => { if (e.target === e.currentTarget) onClose(); }}
  onkeydown={(e) => { if (e.key === "Escape") onClose(); }}
  tabindex="-1"
>
  <aside class="drawer" role="document">
    <header>
      <div class="title-block">
        <h1 id="drawer-title">{entry.name}</h1>
        <p class="sub">
          {t("plugins.detail.byAuthor", { author: entry.author })}
          · <span class="mono">{entry.id}</span>
        </p>
      </div>
      <button type="button" class="ghost icon" aria-label={t("plugins.detail.close")} onclick={onClose}>✕</button>
    </header>

    <section class="version-row">
      <span class="chip ver-pill">v{entry.version}</span>
      {#if status === "installed" && installedVersion}
        <span class="chip status-installed">{$tStore("plugins.detail.installed")}</span>
      {:else if status === "update" && installedVersion}
        <span class="chip status-update">
          {t("plugins.detail.updateFrom", { from: installedVersion, to: entry.version })}
        </span>
      {/if}
    </section>

    <section class="desc-block">
      <p>{entry.description}</p>
    </section>

    <dl class="meta-grid">
      <dt>{$tStore("plugins.detail.size")}</dt>
      <dd>{formatBytes(entry.size_bytes)}</dd>
      <dt>{$tStore("plugins.detail.compat")}</dt>
      <dd><code>{entry.slab_compat}</code></dd>
      <dt>{$tStore("plugins.detail.sha256")}</dt>
      <dd class="mono" title={entry.sha256}>{shortHash(entry.sha256)}</dd>

      <button type="button" class="ghost" onclick={onClose} disabled={inFlight}>
        {$tStore("plugins.detail.close")}
      </button>
      {#if status === "installed"}
        <button type="button" class="ghost danger" onclick={onAction} disabled={inFlight}>
          {inFlight ? $tStore("plugins.browse.uninstalling") : $tStore("plugins.browse.uninstall")}
        </button>
      {:else if status === "update"}
        <button type="button" class="primary" onclick={onAction} disabled={inFlight}>

        </button>
      {:else}
        <button type="button" class="primary" onclick={onAction} disabled={inFlight}>
          {inFlight ? $tStore("plugins.browse.installing") : $tStore("plugins.browse.install")}

      {/if}
    </footer>
  </aside>
</div>
```

## Task 2: InstallProgressModal — phased progress + outcome toast

**Objective:** While a marketplace install is in flight, show a
centered progress modal with phased status text ("Verifying
signature…" → "Downloading…" → "Extracting…") and a final outcome
state. Outcome auto-dismisses after 2s on success.

**Files:**
- Create: `src/lib/components/InstallProgressModal.svelte`
- Modify: `src/lib/panels/PluginsPanel.svelte` (install flow wraps
  with modal state)
- Modify: `src/lib/i18n/en.json` + es/fr/ar (new keys under
  `plugins.install.*`)

**Component:**

```svelte
<script lang="ts">
  import { t, tStore } from "$lib/i18n";
  import type { IndexEntry } from "$lib/marketplace";
  import { formatBytes } from "$lib/marketplace";

  type Phase = "verifying" | "downloading" | "extracting" | "done" | "error";

  type Props = {
    entry: IndexEntry;
    phase: Phase;
    error: string | null;
    bytesDone?: number;
    onDismiss: () => void;
  };

  let { entry, phase, error, bytesDone, onDismiss }: Props = $props();

  let phaseLabel = $derived.by(() => {
    switch (phase) {
      case "verifying": return $tStore("plugins.install.verifying");
      case "downloading": return $tStore("plugins.install.downloading");
      case "extracting": return $tStore("plugins.install.extracting");
      case "done": return t("plugins.install.done", { name: entry.name });
      case "error": return $tStore("plugins.install.failed");
    }
  });
</script>

<div class="backdrop" role="dialog" aria-modal="true" aria-labelledby="install-title">
  <div class="modal" role="document">
    <header>
      <div class="icon" aria-hidden="true">
        {#if phase === "done"}✓{:else if phase === "error"}✕{:else}⏳{/if}
      </div>
      <div>
        <h1 id="install-title">{entry.name}</h1>
        <p class="sub">v{entry.version} · {formatBytes(entry.size_bytes)}</p>
      </div>
    </header>

    <div class="phase">
      <p class:done={phase === "done"} class:err={phase === "error"}>{phaseLabel}</p>
      {#if phase !== "done" && phase !== "error"}
        <div class="bar" aria-hidden="true"><div class="bar-fill"></div></div>
      {/if}
      {#if phase === "error" && error}
        <pre class="err-detail">{error}</pre>
      {/if}
    </div>

    {#if phase === "done" || phase === "error"}
      <div class="actions">
        <button type="button" class="primary" onclick={onDismiss}>
          {$tStore("plugins.detail.close")}
        </button>
      </div>
    {/if}
  </div>
</div>
```

Styles: 400px modal, centered, indeterminate progress bar with a
flowing `linear-gradient` animation (CSS keyframe — no JS). On done,
the bar is replaced with a static green checkmark. On error, the bar
is replaced with the red error pre block.

**Wiring in PluginsPanel:**

```ts
type InstallModalState = {
  entry: IndexEntry;
  phase: "verifying" | "downloading" | "extracting" | "done" | "error";
  error: string | null;
} | null;

let installModal = $state<InstallModalState>(null);

async function onInstall(entry: IndexEntry) {
  if (!marketplaceAvailable()) { /* unchanged */ return; }
  installModal = { entry, phase: "verifying", error: null };
  // Phase timers — heuristic until backend emits real progress events.
  const downloadTimer = setTimeout(() => {
    if (installModal?.entry.id === entry.id && installModal.phase === "verifying") {
      installModal = { ...installModal, phase: "downloading" };
    }
  }, 400);
  const extractTimer = setTimeout(() => {
    if (installModal?.entry.id === entry.id && installModal.phase === "downloading") {
      installModal = { ...installModal, phase: "extracting" };
    }
  }, 2000);
  try {
    await installPlugin(entry);
    await refreshPlugins();
    clearTimeout(downloadTimer); clearTimeout(extractTimer);
    installModal = { entry, phase: "done", error: null };
    setTimeout(() => {
      if (installModal?.entry.id === entry.id && installModal.phase === "done") {
        installModal = null;
      }
    }, 1800);
    notify.success(t("plugins.notify.installOk", { name: entry.name }));
  } catch (e) {
    clearTimeout(downloadTimer); clearTimeout(extractTimer);
    const msg = e instanceof Error ? e.message : String(e);
    installModal = { entry, phase: "error", error: msg };
    notify.error(t("plugins.notify.installFailed"), { detail: msg });
  }
}

function dismissInstallModal() { installModal = null; }
```

Mount the modal:
```svelte
{#if installModal}
  <InstallProgressModal
    entry={installModal.entry}
    phase={installModal.phase}
    error={installModal.error}
    onDismiss={dismissInstallModal}
  />
{/if}
```

## Task 3: Cross-tab "Update available" badge on Installed tab

**Objective:** When the marketplace index is loaded and contains a
plugin with a newer version than what's installed, surface an
"Update → v{x}" pill on the Installed-tab row. Clicking it jumps to
the Browse tab AND opens the detail drawer for that entry.

**Files:**
- Modify: `src/lib/panels/PluginsPanel.svelte` (helper +
  conditional pill in the Installed list)
- Modify: `src/lib/i18n/en.json` + es/fr/ar (1 new key
  `plugins.installed.updateBadge`)

**Helper:**

```ts
let availableUpdates = $derived.by<Record<string, IndexEntry | null>>(() => {
  const out: Record<string, IndexEntry | null> = {};
  if (marketplace.phase !== "ready" || !marketplace.index) return out;
  for (const p of snap.plugins) {
    const installed = p.manifest?.version;
    if (!installed) continue;
    const entry = marketplace.index.plugins.find((e) => e.id === p.id);
    if (!entry) continue;
    if (compareSemver(entry.version, installed) > 0) {
      out[p.id] = entry;
    }
  }
  return out;
});

function jumpToUpdate(entry: IndexEntry) {
  selectTab("browse");
  drawerEntry = entry;
}
```

**Pill placement in row meta:**

Insert between `byAuthor` and `id` (or as a sibling chip):

```svelte
    onclick={() => jumpToUpdate(availableUpdates[p.id]!)}

{/if}
```
