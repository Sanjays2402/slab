# v3.39.0 "Atlas Tag-Suggest" Implementation Plan

> **For Hermes (cron):** Use subagent-driven-development to implement this
> plan slice-by-slice. Each slice is one tick's worth of work and must end
> with passing quality gates + a commit on `feature/v3.39.0-atlas-tag-suggest`.

**Goal:** Slab proposes 3-5 relevant tags for every untagged document in the
library, computed locally from the doc's title + filename + co-occurrence
with tags the user already applies elsewhere. One-click "accept" attaches
the tag; one-click "dismiss" suppresses that suggestion forever.

**Architecture:**

- New heuristic engine `pdf/library/tag_suggest.rs` mirrors the pattern of
  the v3.38.0 `folder_suggest.rs`: pure-Rust, deterministic, no network.
  Inputs: target doc's `title` + `path` (basename) + the global tag
  vocabulary + tag co-occurrence stats. Output: ranked `Vec<TagSuggestion>`.
- New table `library_tag_suggestion_dismissed (doc_id, tag_name)` (schema
  v7 → v8) so per-doc dismissals stick.
- Five Tauri commands: `library_tag_suggestions_for_doc`,
  `library_tag_suggestion_accept`, `library_tag_suggestion_dismiss`,
  `library_tag_suggestions_bulk_for_untagged`, and
  `library_tag_suggestion_undismiss_all` (settings escape hatch).
- UI: a "✨ Suggested tags" chip row inside the existing document detail
  panel (or library row hover card if detail panel is unavailable on the
  active branch). Animated entrance, slide-out on accept/dismiss, honors
  `prefers-reduced-motion`.
- Existing `auto_tagger.rs` (AI-powered tag assignment from page content)
  remains untouched. This release is the **suggestion** surface — cheap,
  always-on, runs over thousands of docs in milliseconds. AI assignment
  is the **commit** surface — slower, opt-in, kept as-is.

**Tech Stack:** Rust (rusqlite + serde), Svelte 5 + TS, Tauri v2.

## Slice 2: Heuristic tag suggester core

**Objective:** Pure function `suggest_tags_for_doc(db, doc_id) -> Vec<TagSuggestion>`
with no AI dependency. Ranks candidates by three signals:
1. **Vocabulary match** — tokens of (title ∪ basename) intersected with
   existing `library_tags.name` (fuzzy: lowercased, punctuation-stripped).
2. **Co-occurrence boost** — for each candidate tag T, count `library_doc_tags`
   rows where T appears alongside any tag *that doc already has*. Strong
   prior that pulls in the user's actual taxonomy.
3. **Domain hints** — small built-in dictionary (`invoice`, `receipt`,
   `contract`, `manual`, `paper`, `slides`, `recipe`, `lease`, `tax`,
   `resume`, `report`, `notes`, `letter`, `form`) seeded if a token matches.
   These auto-create as a `library_tag` row when accepted.

```rust
use super::registry::LibraryDb;
use super::LibraryError;
use rusqlite::params;
use serde::{Deserialize, Serialize};
use std::collections::HashMap;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct TagSuggestion {
    pub tag_name: String,
    pub score: i64,
    /// "vocabulary" | "cooccurrence" | "domain"
    pub source: String,
    /// True if a `library_tags` row already exists with this name.
    pub existing: bool,
}

const STOPWORDS: &[&str] = &[
    "the","a","an","of","and","or","to","in","on","for","with","is",
    "by","at","pdf","doc","document","file","scan","scanned","copy",
];

const DOMAIN_HINTS: &[(&str, &[&str])] = &[
    ("invoice",  &["invoice","inv","bill","billing"]),
    ("receipt",  &["receipt","rcpt"]),
    ("contract", &["contract","agreement","mou","nda"]),
    ("manual",   &["manual","handbook","guide","userguide"]),
    ("paper",    &["paper","arxiv","preprint"]),
    ("slides",   &["slides","deck","keynote","pptx"]),
    ("recipe",   &["recipe","cookbook"]),
    ("lease",    &["lease","rental","tenancy"]),
    ("tax",      &["tax","irs","w2","w9","1099"]),
    ("resume",   &["resume","cv","curriculum"]),
    ("report",   &["report","quarterly","annual","summary"]),
    ("notes",    &["notes","note"]),
    ("letter",   &["letter","memo"]),
    ("form",     &["form","application"]),
];

pub const SUGGEST_LIMIT: usize = 5;

pub fn suggest_tags_for_doc(
    db: &LibraryDb,
    doc_id: i64,
) -> Result<Vec<TagSuggestion>, LibraryError> {
    let conn = db.conn();
    // 1. Fetch doc title + path
    let (title, path): (Option<String>, String) = conn.query_row(
        "SELECT title, path FROM library_documents WHERE id = ?1",
        params![doc_id],
        |r| Ok((r.get(0)?, r.get(1)?)),
    )?;
    let basename = std::path::Path::new(&path)
        .file_stem().and_then(|s| s.to_str()).unwrap_or("").to_string();
    let tokens = tokenize(&format!("{} {}", title.unwrap_or_default(), basename));

    // 2. Existing tags on this doc (skip suggesting tags already present)
    let mut already: std::collections::HashSet<String> = std::collections::HashSet::new();
    let mut already_ids: Vec<i64> = Vec::new();
    let mut stmt = conn.prepare(
        "SELECT t.id, t.name FROM library_tags t
         INNER JOIN library_doc_tags dt ON dt.tag_id = t.id
         WHERE dt.doc_id = ?1",
    )?;
    for row in stmt.query_map(params![doc_id], |r| Ok((r.get::<_, i64>(0)?, r.get::<_, String>(1)?)))? {
        let (id, name) = row?;
        already_ids.push(id);
        already.insert(name.to_lowercase());
    }

    // 3. Dismissed set
    let mut dismissed_stmt = conn.prepare(
        "SELECT tag_name FROM library_tag_suggestion_dismissed WHERE doc_id = ?1",
    )?;
    let dismissed: std::collections::HashSet<String> = dismissed_stmt
        .query_map(params![doc_id], |r| r.get::<_, String>(0))?
        .filter_map(|r| r.ok().map(|s| s.to_lowercase()))
        .collect();

    // 4. Vocabulary match — load all tag names once
    let mut vocab_stmt = conn.prepare("SELECT id, name FROM library_tags")?;
    let vocab: Vec<(i64, String)> = vocab_stmt
        .query_map([], |r| Ok((r.get::<_, i64>(0)?, r.get::<_, String>(1)?)))?
        .filter_map(|r| r.ok())
        .collect();

    let mut scores: HashMap<String, (i64, &'static str, bool)> = HashMap::new(); // name → (score, source, existing)
    for (_, name) in &vocab {
        let lname = name.to_lowercase();
        if already.contains(&lname) || dismissed.contains(&lname) { continue; }
        if tokens.iter().any(|t| t == &lname) {
            scores.entry(lname.clone()).or_insert((0, "vocabulary", true)).0 += 20;
        }
    }

    // 5. Co-occurrence — for each tag the doc already has, find sibling tags
    if !already_ids.is_empty() {
        let placeholders: String = already_ids.iter().map(|_| "?").collect::<Vec<_>>().join(",");
        let sql = format!(
            "SELECT t.name, COUNT(*) as cnt
             FROM library_doc_tags dt
             INNER JOIN library_tags t ON t.id = dt.tag_id
             WHERE dt.doc_id IN (
                 SELECT DISTINCT doc_id FROM library_doc_tags
                 WHERE tag_id IN ({ph}) AND doc_id != ?
             )
             AND t.id NOT IN ({ph})
             GROUP BY t.name
             ORDER BY cnt DESC
             LIMIT 20",
            ph = placeholders,
        );
        let mut stmt = conn.prepare(&sql)?;
        let mut bind: Vec<&dyn rusqlite::ToSql> =
            already_ids.iter().map(|x| x as &dyn rusqlite::ToSql).collect();
        bind.push(&doc_id);
        for id in &already_ids { bind.push(id as &dyn rusqlite::ToSql); }
        let rows = stmt.query_map(rusqlite::params_from_iter(bind), |r| {
            Ok((r.get::<_, String>(0)?, r.get::<_, i64>(1)?))
        })?;
        for row in rows {
            let (name, cnt) = row?;
            let lname = name.to_lowercase();
            if dismissed.contains(&lname) { continue; }
            let entry = scores.entry(lname).or_insert((0, "cooccurrence", true));
            entry.0 += 5 * cnt; // amplify by co-occurrence count
        }
    }

    // 6. Domain hints — only if no vocab/cooccurrence match for that hint
    for (canonical, aliases) in DOMAIN_HINTS {
        let lcanon = canonical.to_string();
        if already.contains(&lcanon) || dismissed.contains(&lcanon) { continue; }
        if scores.contains_key(&lcanon) { continue; }
        if tokens.iter().any(|t| aliases.contains(&t.as_str())) {
            let existing = vocab.iter().any(|(_, n)| n.to_lowercase() == lcanon);
            scores.insert(lcanon, (10, "domain", existing));
        }
    }

    // 7. Sort + truncate
    let mut out: Vec<TagSuggestion> = scores
        .into_iter()
        .map(|(name, (score, source, existing))| TagSuggestion {
            tag_name: name, score, source: source.to_string(), existing,
        })
        .collect();
    out.sort_by(|a, b| b.score.cmp(&a.score).then(a.tag_name.cmp(&b.tag_name)));
    out.truncate(SUGGEST_LIMIT);
    Ok(out)
}

pub fn dismiss_tag_suggestion(
    db: &LibraryDb,
    doc_id: i64,
    tag_name: &str,
) -> Result<(), LibraryError> {
    let now = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_secs() as i64).unwrap_or(0);
    db.conn().execute(
        "INSERT OR IGNORE INTO library_tag_suggestion_dismissed
         (doc_id, tag_name, dismissed_at) VALUES (?1, ?2, ?3)",
        params![doc_id, tag_name.to_lowercase(), now],
    )?;
    Ok(())
}

pub fn is_tag_suggestion_dismissed(
    db: &LibraryDb,
    doc_id: i64,
    tag_name: &str,
) -> Result<bool, LibraryError> {
    let n: i64 = db.conn().query_row(
        "SELECT COUNT(*) FROM library_tag_suggestion_dismissed
         WHERE doc_id = ?1 AND tag_name = ?2",
        params![doc_id, tag_name.to_lowercase()],
        |r| r.get(0),
    )?;
    Ok(n > 0)
}

pub fn undismiss_all_for_doc(
    db: &LibraryDb,
    doc_id: i64,
) -> Result<usize, LibraryError> {
    let n = db.conn().execute(
        "DELETE FROM library_tag_suggestion_dismissed WHERE doc_id = ?1",
        params![doc_id],
    )?;
    Ok(n)
}

fn tokenize(text: &str) -> Vec<String> {
    text.to_lowercase()
        .split(|c: char| !c.is_alphanumeric())
        .filter(|t| t.len() >= 3)
        .filter(|t| !STOPWORDS.contains(t))
        .filter(|t| !t.chars().all(|c| c.is_ascii_digit()))
        .map(|s| s.to_string())
        .collect()
}
```

```rust
pub struct BulkTagSuggestion {
    pub doc_id: i64,
    pub title: Option<String>,
    pub path: String,
    pub suggestions: Vec<TagSuggestion>,
}

pub fn suggest_for_untagged(
    db: &LibraryDb,
    limit: usize,
) -> Result<Vec<BulkTagSuggestion>, LibraryError> {
    let conn = db.conn();
    let mut stmt = conn.prepare(
        "SELECT d.id, d.title, d.path
         FROM library_documents d
         LEFT JOIN library_doc_tags dt ON dt.doc_id = d.id
         WHERE dt.tag_id IS NULL
         ORDER BY d.last_seen_at DESC
         LIMIT ?1",
    )?;
    let rows = stmt.query_map(params![limit as i64], |r| {
        Ok((r.get::<_, i64>(0)?, r.get::<_, Option<String>>(1)?, r.get::<_, String>(2)?))
    })?;
    let mut out = Vec::new();
    for row in rows {
        let (doc_id, title, path) = row?;
        let suggestions = suggest_tags_for_doc(db, doc_id)?;
        if suggestions.is_empty() { continue; }
        out.push(BulkTagSuggestion { doc_id, title, path, suggestions });
    }
    Ok(out)
}
```

```rust
use super::registry::TagRecord;

pub fn accept_tag_suggestion(
    db: &mut LibraryDb,
    doc_id: i64,
    tag_name: &str,
) -> Result<TagRecord, LibraryError> {
    let normalized = tag_name.trim().to_lowercase();
    // 1. Find or create the tag
    let tag = match db.find_tag_by_name(&normalized)? {
        Some(t) => t,
        None => db.add_tag(&normalized, Some(&pastel_for(&normalized)))?,
    };
    // 2. Compute union with existing doc tags
    let mut current_ids: Vec<i64> = db.tags_for_document(doc_id)?
        .into_iter().map(|t| t.id).collect();
    if !current_ids.contains(&tag.id) {
        current_ids.push(tag.id);
    }
    db.set_doc_tags(doc_id, &current_ids)?;
    Ok(tag)
}

fn pastel_for(name: &str) -> String {
    // FNV-1a 32 → HSL hue 0-359, fixed S/L for soft pastel.
    let mut h: u32 = 0x811c9dc5;
    for b in name.bytes() {
        h ^= b as u32;
        h = h.wrapping_mul(0x01000193);
    }
    let hue = h % 360;
    format!("hsl({}, 60%, 80%)", hue)
}
```

```svelte
<script lang="ts">
  import { onMount } from 'svelte';
  import { fly, scale } from 'svelte/transition';
  import { cubicOut } from 'svelte/easing';
  import {
    tagSuggestionsForDoc, acceptTagSuggestion, dismissTagSuggestion,
    type TagSuggestion,
  } from '$lib/api/libraryTagSuggest';

  export let docId: number;
  export let onAccepted: (tag: { id: number; name: string; color: string | null }) => void = () => {};

  let suggestions: TagSuggestion[] = [];
  let loading = true;
  let busy: string | null = null; // tag_name currently animating out

  async function load() {
    loading = true;
    try { suggestions = await tagSuggestionsForDoc(docId); }
    finally { loading = false; }
  }

  onMount(load);

  async function accept(s: TagSuggestion) {
    busy = s.tag_name;
    const tag = await acceptTagSuggestion(docId, s.tag_name);
    suggestions = suggestions.filter(x => x.tag_name !== s.tag_name);
    busy = null;
    onAccepted(tag);
  }

  async function dismiss(s: TagSuggestion) {
    busy = s.tag_name;
    await dismissTagSuggestion(docId, s.tag_name);
    suggestions = suggestions.filter(x => x.tag_name !== s.tag_name);
    busy = null;
  }

  const sourceIcon = (src: string) =>
    src === 'cooccurrence' ? '🔗' : src === 'domain' ? '🏷️' : '✨';
</script>

{#if suggestions.length > 0 || loading}
  <div class="suggested-tags-row" transition:fly={{ y: 4, duration: 220 }}>
    <span class="label">✨ Suggested tags</span>
    {#if loading}
      <span class="skeleton" />
    {:else}
      {#each suggestions as s (s.tag_name)}
        <div class="chip" transition:scale={{ duration: 180, easing: cubicOut }}>
          <span class="icon" title={s.source}>{sourceIcon(s.source)}</span>
          <span class="name">{s.tag_name}</span>
          <button class="accept" on:click={() => accept(s)} title="Add tag"
                  disabled={busy === s.tag_name}>✓</button>
          <button class="dismiss" on:click={() => dismiss(s)} title="Never suggest"
                  disabled={busy === s.tag_name}>✗</button>
        </div>
      {/each}
    {/if}
  </div>
{/if}
```
