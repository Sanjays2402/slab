# v2.0.0 "Workshop" — Slice 7: Network capability + `slab.fetch` shim

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task on `feature/v2.0.0-workshop`. Parent plan: `docs/plans/2026-05-18-v2.0.0-workshop.md`. Previous slice plan: `docs/plans/2026-05-18-v2.0.0-workshop-slice-6.md`.

**Goal:** Land a sandboxed `slab.fetch(url, init?)` host API that plugins can call from JS to perform host-mediated HTTP. Capability- and allowlist-gated, never bypasses TLS, never exposes cookies/file URLs, never blocks the JS event loop, never blocks the actor's command loop.

**Architecture:**

- Plugin JS calls `slab.fetch(url, init?)` → host function returns a JS `Promise`.
- Inside the actor's worker thread, the host function:
  1. Pre-flight gate via `enforce(declared, granted, &NetFetch { host })` — synchronous, fast-fail on `NotDeclared` / `GrantTooNarrow`.
  2. Builds a `FetchRequest` payload (owned `String`s / `Vec<u8>`) and `Persistent`-ifies the `resolve` + `reject` `Function`s out of a freshly-created JS `Promise`.
  3. Sends `RuntimeCmd::Fetch { request, resolve, reject }` through the **existing** `crossbeam_channel::Sender` back to the **same** worker thread's recv loop. (We do NOT introduce a second thread; the actor already lives off the Tauri runtime.)
  4. The recv-side handler enters an inline `tokio::runtime::Handle` block-on against a process-shared `reqwest::Client` (lazy-static), produces a `FetchResponse` payload, and calls the corresponding `Persistent<Function>` to resolve/reject the Promise in JS land.
- Yes, the actor thread blocks on each `fetch` while it's in flight. That's fine for Slice 7 (correctness first, throughput later) and matches QuickJS's own single-threaded model. Slice 7b can promote to a tokio task pool if profiling shows it matters; for now plugins serialise their network calls naturally.
- Allowlist enforcement happens twice: at pre-flight (synchronous deny) and again after URL parse (the gate gets the lowercased host). Belt-and-braces because URL parsing can normalise hosts in surprising ways.

**Tech Stack:**

- Rust: `reqwest 0.12` (already in `src-tauri/Cargo.toml` — `json`, `rustls-tls`, `stream` features), `tokio 1` (already a dep), `rquickjs 0.11` (already in tree), `url 2` (transitive via reqwest — add as a direct dep here for parsing).
- `crossbeam-channel 0.5` already wires the actor; we extend `RuntimeCmd`.
- `once_cell` 1 (already in tree) for the lazy-static `reqwest::Client`.
- Frontend: nothing this slice. The fetch shim is purely JS-side host API; the Cabinet consent modal already handles `net` capability prompts via Slice 5c.

**Out of scope for Slice 7:**

- Streaming bodies / `ReadableStream` — bodies are `Vec<u8>` buffered in/out.
- `AbortSignal` / cancellation — first cut blocks until completion or 30s timeout.
- WebSocket / SSE — these would each need their own slice.
- Cookie jar — explicitly off (we set `.cookie_store(false)`).
- HTTP/3 — let `reqwest` default decide.
- Custom CA bundle — system roots only.

//! Slice 7 — host-side fetch executor.
//!
//! `slab.fetch` lands here. We expose a single process-wide
//! `reqwest::Client` (cookies OFF, TLS via rustls, system root certs)
//! and a `do_fetch` async helper that turns a `FetchRequest` into a
//! `FetchResponse`. The actor recv loop block-ons this helper on the
//! Tauri tokio runtime.

use std::sync::Arc;
use std::time::Duration;

use once_cell::sync::Lazy;
use reqwest::header::{HeaderMap, HeaderName, HeaderValue};

use super::actor::{FetchRequest, FetchResponse};

/// Caps body size at 16 MiB to keep a runaway plugin from OOMing the
/// host. Plugins that need larger downloads can split into ranges
/// (slice 7b) or stream via a future Slab API.
pub const MAX_BODY_BYTES: usize = 16 * 1024 * 1024;

/// Lazy, shared `reqwest::Client`. `Arc` so the `Lazy` cell can hand
/// out cheap clones to every fetch call.
static CLIENT: Lazy<Arc<reqwest::Client>> = Lazy::new(|| {
    let c = reqwest::Client::builder()
        .user_agent(concat!("Slab/", env!("CARGO_PKG_VERSION"), " (+plugins)"))
        .cookie_store(false)
        .https_only(false) // plugins MAY hit http://localhost during dev
        .redirect(reqwest::redirect::Policy::limited(10))
        .timeout(Duration::from_secs(30))
        .connect_timeout(Duration::from_secs(10))
        .build()
        .expect("reqwest client build (default config should never fail)");
    Arc::new(c)
});

/// Public accessor for the shared client. Cheap (`Arc::clone`).
pub fn shared_client() -> Arc<reqwest::Client> {
    Arc::clone(&CLIENT)
}

/// Execute `request` and produce a `FetchResponse`. Bounded by
/// `request.timeout_ms` and `MAX_BODY_BYTES`. Errors are stringified
/// for the JS reject path; we deliberately discard the source chain
/// (plugin authors don't need it).
pub async fn do_fetch(request: FetchRequest) -> Result<FetchResponse, String> {
    let client = shared_client();

    let method = reqwest::Method::from_bytes(request.method.as_bytes())
        .map_err(|e| format!("invalid method: {e}"))?;

    let mut headers = HeaderMap::new();
    for (k, v) in &request.headers {
        let name = HeaderName::from_bytes(k.as_bytes())
            .map_err(|e| format!("invalid header name '{k}': {e}"))?;
        let val = HeaderValue::from_str(v)
            .map_err(|e| format!("invalid header value for '{k}': {e}"))?;
        headers.insert(name, val);
    }

    let mut req = client
        .request(method, &request.url)
        .timeout(Duration::from_millis(request.timeout_ms))
        .headers(headers);
    if let Some(body) = request.body {
        req = req.body(body);
    }

    let resp = req.send().await.map_err(|e| format!("network: {e}"))?;
    let status = resp.status();
    let status_text = status.canonical_reason().unwrap_or("").to_string();
    let url = resp.url().to_string();
    let mut resp_headers = Vec::with_capacity(resp.headers().len());
    for (k, v) in resp.headers() {
        let v_str = v.to_str().unwrap_or("").to_string();
        resp_headers.push((k.as_str().to_string(), v_str));
    }

    // Pull the body but cap the size. `bytes()` allocates a single
    // contiguous buffer; we check the content-length hint first.
    if let Some(cl) = resp.content_length() {
        if cl as usize > MAX_BODY_BYTES {
            return Err(format!(
                "response body too large: {cl} bytes > {MAX_BODY_BYTES} cap"
            ));
        }
    }
    let body_bytes = resp.bytes().await.map_err(|e| format!("body: {e}"))?;
    if body_bytes.len() > MAX_BODY_BYTES {
        return Err(format!(
            "response body too large: {} bytes > {} cap",
            body_bytes.len(),
            MAX_BODY_BYTES
        ));
    }

    Ok(FetchResponse {
        status: status.as_u16(),
        status_text,
        url,
        headers: resp_headers,
        body: body_bytes.to_vec(),
        ok: status.is_success(),
    })
}

mod tests {

    }

    #[test]
    fn shared_client_builds_without_panic() {
        let c = shared_client();
        let _ = c.get("https://example.com/");
    }
}
```

/// Parse `raw_url`, reject non-http(s) schemes, return the host in
/// lowercase. Used by the capability gate so the allowlist check is
/// always against the normalised authority.
pub fn extract_host(raw_url: &str) -> Result<String, String> {
    let parsed = url::Url::parse(raw_url).map_err(|e| format!("invalid url: {e}"))?;
    match parsed.scheme() {
        "http" | "https" => {}
        other => return Err(format!("scheme '{other}' not allowed (use http or https)")),
    }
    let host = parsed
        .host_str()
        .ok_or_else(|| "url has no host".to_string())?;
    Ok(host.to_lowercase())
}
```

```rust
/// `slab.fetch(url, init?)` → Promise<Response>.
///
/// `init` is the standard web Fetch init bag, minus streaming bodies,
/// signals, credentials (always omitted), and cache (host decides).
/// Supported fields:
///   - `method`: string, default "GET"
///   - `headers`: object (string → string) OR array of [k, v] tuples
///   - `body`: string OR ArrayBuffer OR Uint8Array OR null
///   - `timeoutMs`: number, default 30_000, max 120_000
fn make_fetch<'js>(ctx: &Ctx<'js>, b: HostBindings) -> Result<Function<'js>> {
    Function::new(
        ctx.clone(),
        move |ctx: Ctx<'js>, url: String, init: Opt<Object<'js>>| -> Result<Value<'js>> {
            // 1. Parse URL + extract host (must succeed before capability gate).
            let host = match crate::plugins::runtime::fetch::extract_host(&url) {
                Ok(h) => h,
                Err(e) => return reject_now(&ctx, &e),
            };

            // 2. Capability gate.
            if let Err(e) = gate(&ctx, &b, &CapabilityRequest::NetFetch { host: &host }) {
                return Err(e);
            }

            // 3. Build the request from init.
            let request = match build_fetch_request(&ctx, url, init.into_inner()) {
                Ok(r) => r,
                Err(e) => return reject_now(&ctx, &e),
            };

            // 4. Create a JS Promise, take ownership of resolve/reject.
            let (promise, resolve, reject) = make_promise(&ctx)?;
            let resolve_p = Persistent::save(&ctx, resolve);
            let reject_p = Persistent::save(&ctx, reject);

            // 5. Send to the actor recv loop. Drop on send failure is
            //    silent (the actor has shut down — Promise stays pending
            //    forever, which is fine because the runtime is going
            //    away too).
            let _ = b.cmd_tx.send(RuntimeCmd::Fetch {
                request,
                resolve: Some(resolve_p),
                reject: Some(reject_p),
            });

            Ok(promise.into_value())
        },
    )
}

/// Build a fresh JS Promise and pull out its resolve/reject functions
/// using the `Promise` constructor pattern: `new Promise((res, rej) => { ... })`.
fn make_promise<'js>(
    ctx: &Ctx<'js>,
) -> Result<(Object<'js>, Function<'js>, Function<'js>)> {
    let globals = ctx.globals();
    let promise_ctor: Function<'js> = globals.get("Promise")?;

    // Capture resolve/reject by writing them onto a JS object the
    // executor closure mutates. Simpler than juggling Rust-side
    // OnceCells across the `Persistent` boundary.
    let store: Object<'js> = Object::new(ctx.clone())?;
    let store_in_executor = store.clone();
    let executor = Function::new(
        ctx.clone(),
        move |_ctx: Ctx<'js>, resolve: Function<'js>, reject: Function<'js>| -> Result<()> {
            store_in_executor.set("resolve", resolve)?;
            store_in_executor.set("reject", reject)?;
            Ok(())
        },
    )?;
    let promise: Object<'js> = promise_ctor.construct((executor,))?;
    let resolve: Function<'js> = store.get("resolve")?;
    let reject: Function<'js> = store.get("reject")?;
    Ok((promise, resolve, reject))
}

/// Return a Promise that's already rejected with `msg`. Used for
/// pre-flight errors (bad URL, bad headers) where we want to give
/// the plugin a Promise to await on instead of throwing synchronously.
fn reject_now<'js>(ctx: &Ctx<'js>, msg: &str) -> Result<Value<'js>> {
    let globals = ctx.globals();
    let promise_ctor: Object<'js> = globals.get("Promise")?;
    let reject_fn: Function<'js> = promise_ctor.get("reject")?;
    let err_val = ctx.throw_to_value(msg)?; // helper: wraps msg in Error
    let rejected: Value<'js> = reject_fn.call((err_val,))?;
    Ok(rejected)
}

/// Translate a JS `init` object into a `FetchRequest`.
fn build_fetch_request<'js>(
    ctx: &Ctx<'js>,
    url: String,
    init: Option<Object<'js>>,
) -> Result<FetchRequest, String> {
    let init = match init {
        Some(o) => o,
        None => {
            return Ok(FetchRequest {
                method: "GET".to_string(),
                url,
                headers: vec![],
                body: None,
                timeout_ms: 30_000,
            });
        }
    };

    let method = init
        .get::<_, Option<String>>("method")
        .map_err(|e| format!("init.method: {e}"))?
        .unwrap_or_else(|| "GET".to_string())
        .to_uppercase();

    let headers = parse_headers(ctx, &init).map_err(|e| format!("init.headers: {e}"))?;
    let body = parse_body(ctx, &init).map_err(|e| format!("init.body: {e}"))?;

    let timeout_ms = init
        .get::<_, Option<u64>>("timeoutMs")
        .map_err(|e| format!("init.timeoutMs: {e}"))?
        .unwrap_or(30_000)
        .clamp(1, 120_000);

    Ok(FetchRequest {
        method,
        url,
        headers,
        body,
        timeout_ms,
    })
}

fn parse_headers<'js>(
    ctx: &Ctx<'js>,
    init: &Object<'js>,
) -> Result<Vec<(String, String)>> {
    let h: Option<Value<'js>> = init.get("headers")?;
    let Some(h) = h else { return Ok(vec![]); };
    if h.is_object() {
        let obj = h.as_object().unwrap();
        let mut out = Vec::new();
        for k in obj.keys::<String>() {
            let k = k?;
            let v: String = obj.get(&k)?;
            out.push((k.to_lowercase(), v));
        }
        return Ok(out);
    }
    // (Tuple-array form is web-Fetch-compatible but uncommon; defer to a
    // future cleanup slice if plugins ever ask for it.)
    Ok(vec![])
}

fn parse_body<'js>(
    _ctx: &Ctx<'js>,
    init: &Object<'js>,
) -> Result<Option<Vec<u8>>> {
    let b: Option<Value<'js>> = init.get("body")?;
    let Some(b) = b else { return Ok(None); };
    if b.is_null() || b.is_undefined() {
        return Ok(None);
    }
    if b.is_string() {
        let s: String = b.get()?;
        return Ok(Some(s.into_bytes()));
    }
    // ArrayBuffer / Uint8Array — defer to subagent implementation
    // detail. rquickjs exposes `TypedArray` and `ArrayBuffer` types;
    // both reach a `Vec<u8>` via `.as_bytes()` or `.as_raw()`. The
    // implementer should look at `rquickjs::TypedArray` docs and pick
    // the cleanest path; falling back to string-only for v1 is also
    // acceptable.
    Ok(None)

RuntimeCmd::Fetch { request, resolve, reject } => {
    let result = tokio::runtime::Handle::try_current()
        .map(|h| h.block_on(super::fetch::do_fetch(request)))
        .unwrap_or_else(|_| {
            // No tokio runtime context (shouldn't happen under Tauri,
            // but tests sometimes spawn the actor outside one). Use
            // a one-shot runtime — slow but correct.
            tokio::runtime::Builder::new_current_thread()
                .enable_all()
                .build()
                .map_err(|e| format!("runtime: {e}"))
                .and_then(|rt| rt.block_on(super::fetch::do_fetch(request)))
        });

    // Settle the Promise. Both resolve and reject are `Persistent`s
    // owned by us; restoring requires a `Ctx<'_>` so we do it inside
    // a `with` block.
    ctx.with(|ctx| {
        match (result, resolve, reject) {
            (Ok(resp), Some(r), _) => {
                if let Ok(resp_val) = response_to_js(&ctx, &resp) {
                    if let Ok(resolve_fn) = r.restore(&ctx) {
                        let _ = resolve_fn.call::<_, Value>((resp_val,));
                    }
                }
            }
            (Err(msg), _, Some(rj)) => {
                if let Ok(reject_fn) = rj.restore(&ctx) {
                    let err = ctx.eval::<Value, _>(format!(
                        "new Error({:?})",
                        msg
                    ));
                    if let Ok(err) = err {
                        let _ = reject_fn.call::<_, Value>((err,));
                    }
                }
            }
            _ => {} // missing callbacks (test fixtures) — drop silently
        }
    });
}
```

Add a sibling helper:

```rust
/// Translate a `FetchResponse` into a JS plain object matching the
/// minimal web Fetch surface.
fn response_to_js<'js>(
    ctx: &rquickjs::Ctx<'js>,
    resp: &FetchResponse,
) -> rquickjs::Result<rquickjs::Value<'js>> {
    let obj = rquickjs::Object::new(ctx.clone())?;
    obj.set("status", resp.status)?;
    obj.set("statusText", resp.status_text.clone())?;
    obj.set("url", resp.url.clone())?;
    obj.set("ok", resp.ok)?;

    let headers = rquickjs::Object::new(ctx.clone())?;
    for (k, v) in &resp.headers {
        headers.set(k.as_str(), v.clone())?;
    }
    obj.set("headers", headers)?;

    // `text()` and `json()` as functions over the captured body. We
    // copy the bytes once into a Rust closure so the JS object can be
    // queried lazily.
    let body_bytes = resp.body.clone();
    let body_for_text = body_bytes.clone();
    let text_fn = rquickjs::Function::new(ctx.clone(), move || -> String {
        String::from_utf8_lossy(&body_for_text).into_owned()
    })?;
    obj.set("text", text_fn)?;

    let body_for_json = body_bytes.clone();
    let json_fn = rquickjs::Function::new(
        ctx.clone(),
        move |ctx: rquickjs::Ctx<'_>| -> rquickjs::Result<rquickjs::Value<'_>> {
            let s = std::str::from_utf8(&body_for_json)
                .map_err(|e| rquickjs::Error::new_from_js_message("json", "utf8", e.to_string()))?;
            ctx.json_parse(s)
        },
    )?;
    obj.set("json", json_fn)?;

    Ok(obj.into_value())
}
```

(Implementer note: `rquickjs::Error::new_from_js_message` may not be the exact constructor — check 0.11 docs for the right error builder; the goal is a `rquickjs::Error` value that surfaces as a JS Error when `json()` is awaited.)

## Risk register

| Risk | Mitigation |
|---|---|
| Persistent<Function<'static>> lifetime mismatch on rquickjs 0.11 | The `Persistent::save(&ctx, fn)` API on 0.11 returns the static-lifetimed form automatically. If the implementer hits "expected 'static, found 'js" errors, the fix is to call `.save(&ctx, …)` rather than transmuting. Cross-ref `runtime/lifecycle.rs` which already does this. |
| `block_on` inside actor thread deadlocks on the Tauri tokio reactor | The actor thread is NOT a tokio worker — it's a stdlib `std::thread::spawn`. `Handle::try_current()` returns the Tauri runtime's handle, `block_on` on that runtime from outside its workers is supported and standard. Verified pattern in `src-tauri/src/beacon/*` (existing code). |
| 16 MiB cap too low for real PDF downloads | Plugins downloading PDFs are an anti-pattern this slice (the host handles PDFs). If a plugin author genuinely needs large bodies, raise the cap as a config-knob in 7b. |
| `mockito` not in workspace | Add as dev-dep. Already used widely in the Rust ecosystem; zero footprint. |
| Test flakiness due to `thread::sleep(500ms)` waiting for Promise settle | If flaky on CI: bump sleep to 2s and accept the test-suite cost. Real fix is a `WorkerHandle::wait_for_global(name, timeout)` synchronous helper added alongside — implementer should add it if any test flakes. |
