**Sub-tasks:**

#### Task A1: Create `src/lib/panels/FlattenPanel.svelte` skeleton

**Files:**
- Create: `src/lib/panels/FlattenPanel.svelte`

**Step 1: Copy EncryptPanel structure as the base** — same `<script>` / `<header>` / `<section class="panel">` shape. Strip the dual-mode tabs (flatten has one action).

**Step 2: Define state**

```ts
import { invoke } from "@tauri-apps/api/core";
import { open, save } from "@tauri-apps/plugin-dialog";
import { idle, basename, stripExt, type CmdResult, type Status } from "$lib/types";

type FlattenOpts = { include_widgets: boolean };
type FlattenReport = {
  annotations_in: number;
  annotations_flattened: number;
  annotations_dropped: number;
  pages_with_annotations: number;
  had_acroform: boolean;
};

let input = $state<string | null>(null);
let includeWidgets = $state(true);
let status = $state<Status>(idle);
let report = $state<FlattenReport | null>(null);
```

**Step 3: Wire `pickInput` / `run`**

```ts
async function run() {
  if (!input) { status = { kind: "err", msg: "Pick a PDF first." }; return; }
  const output = await save({
    defaultPath: `${stripExt(basename(input))}-flat.pdf`,
    filters: [{ name: "PDF", extensions: ["pdf"] }],
  });
  if (typeof output !== "string") return;
  status = { kind: "working", msg: "Flattening…" };
  report = null;
  try {
    const res = await invoke<CmdResult<FlattenReport>>("slab_flatten", {
      input, output, opts: { include_widgets: includeWidgets },
    });
    if (res.kind === "ok") {
      report = res.value;
      status = { kind: "ok", msg: `Flattened → ${basename(output)}` };
    } else {
      status = { kind: "err", msg: res.message };
    }
  } catch (e) { status = { kind: "err", msg: String(e) }; }
}
```

**Step 4: Markup** — file card, `<label><input type="checkbox" bind:checked={includeWidgets}> Include form widgets</label>`, primary button, report block (only when `report` truthy).

### Feature D — Decrypt modal in Reader

**What it does:** When `ReaderPanel` fails to open a PDF because it's password-protected, surface a modal asking for the password. On submit, call `slab_decrypt` to a temp file, then re-open that temp file in the viewer.

**Why a modal, not a panel:** Decrypt is reactive (user opens a locked file in Reader) not proactive (user picks "Decrypt" from sidebar). EncryptPanel already covers the proactive case.

#### Task D1: Detect encrypted-PDF error in `ReaderPanel.svelte`

**Files:**
- Modify: `src/lib/panels/ReaderPanel.svelte` — wherever `slab_open` / `pdfjs.getDocument` is called.

**Step 1: Catch `PasswordException` from pdf.js** (and the equivalent backend error).
**Step 2: Set `passwordPromptForPath = path` on encryption error**, leave existing error path for other failures.

#### Task D2: Create `src/lib/components/DecryptModal.svelte`

**Files:** Create `src/lib/components/DecryptModal.svelte`

**Step 1: Backdrop + centered card** — copy modal styles from CommandPalette.svelte.

**Step 2: Single password input + Cancel / Unlock buttons + show/hide toggle.**

**Step 3: On submit:**

```ts
import { tempDir, join } from "@tauri-apps/api/path";
async function unlock() {
  const tmp = await join(await tempDir(), `slab-unlocked-${Date.now()}.pdf`);
  const res = await invoke<CmdResult<null>>("slab_decrypt", {
    input: lockedPath, output: tmp, password,
  });
  if (res.kind === "ok") onUnlocked(tmp);
  else status = { kind: "err", msg: res.message };
}
```

**Step 4: Props** — `{ open, lockedPath, onCancel, onUnlocked }`.

#### Task D3: Wire DecryptModal into ReaderPanel

**Files:** Modify `src/lib/panels/ReaderPanel.svelte`

```svelte
<DecryptModal
  open={passwordPromptForPath !== null}
  lockedPath={passwordPromptForPath ?? ""}
  onCancel={() => (passwordPromptForPath = null)}
  onUnlocked={(tmp) => {
    passwordPromptForPath = null;
    openFromPath(tmp);
  }}
/>
```

#### Task D4: Manual smoke

2. Launch app: `pnpm tauri dev`
3. Reader → Open → `/tmp/locked.pdf` → modal appears → type `secret` → reader renders unlocked.

## Risk log

- **`slab_decrypt` rejects RC4 vs AES handshake mismatch** — verify with a few real-world locked PDFs in `dev-fixtures/`. If our decrypt path is RC4-only (it is, per EncryptPanel subtitle), the modal must surface a clear "unsupported encryption" error instead of a generic failure.
- **Temp file leakage from DecryptModal** — pin the temp file in a per-session `TempDir` and unlink on app exit. Not blocking for v0.9.1 (manual cleanup is fine), but log a TODO.
- **Report grid getting noisy** — sanitize report has 8 fields. Hide zero rows (already in plan) so most "clean" PDFs show only 1-2 lines.
