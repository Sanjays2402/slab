# v2.0.0 "Workshop" — Slice 9 Implementation Plan: `@slab/plugin-sdk` npm package

> **For Hermes:** Use the `subagent-driven-development` skill to execute this
> plan task-by-task. Each task is bite-sized (2–5 min) with exact file paths,
> complete code samples, and verification commands.

**Goal:** Ship a typed TypeScript SDK (`@slab/plugin-sdk`) so plugin authors
get full IntelliSense + type-checking against the live `slab.*` global surface
without ever reading the Rust source.

**Architecture:** A standalone npm package living at `sdk/slab-plugin-sdk/`
inside the Slab monorepo. Source-of-truth types live in `src/types/` split by
domain (`beacon`, `ui`, `document`, `storage`, `fetch`, `manifest`). The
package ships **types-only** plus a tiny runtime helper (`definePlugin`,
`assertSlab`) for ergonomics. Built with `tsc` to dual ESM + CJS + `.d.ts`.

**Tech Stack:** TypeScript 5.6 (strict), `tsc` only (no bundler — keeps the
package boring + tree-shakeable + fast to build), `vitest` for tests.

**Buy-Button rationale:**
- **Pick-us test:** Acrobat ships no SDK to third-party developers (extensions
  require enterprise licensing). PDF Expert has no plugin model at all. Slab
  now has a public, typed, MIT-licensed SDK that any author can `npm install`
  and use today.
- **Tell-a-friend test:** "Look — Slab gave me full IntelliSense for their
  plugin API. I autocompleted `slab.fetch(...)` into a working PII redactor
  in 20 lines." That's the screenshot.

### Step 1: `src/define.ts` — `definePlugin` + `assertSlab`

```ts
import type { SlabGlobal } from "./types/global";

/**
 * Author a Slab plugin with full IntelliSense.
 *
 * Top-level your plugin script:
 *
 * ```ts
 * import { definePlugin } from "@slab/plugin-sdk";
 *
 * export default definePlugin({
 *   id: "my-plugin",
 *   onLoad(slab) {
 *     slab.ui.notify("Hello from my plugin!");
 *   },
 * });
 * ```
 *
 * The `onLoad` callback is invoked synchronously at plugin enable time
 * with the host-supplied `slab` global.
 */
export interface PluginDefinition {
  /** Stable plugin id — must match `manifest.id`. */
  id: string;
  /** Sync setup hook. Throwing here fails plugin enable cleanly. */
  onLoad?(slab: SlabGlobal): void;
}

export function definePlugin(def: PluginDefinition): PluginDefinition {
  if (typeof def.id !== "string" || def.id.length === 0) {
    throw new Error("definePlugin: `id` must be a non-empty string");
  }
  // Auto-bootstrap when running inside the Slab runtime — the global
  // is present and the host expects top-level side effects on eval.
  const g = (globalThis as { slab?: SlabGlobal }).slab;
  if (g && typeof def.onLoad === "function") {
    def.onLoad(g);
  }
  return def;
}

/**
 * Runtime narrowing — throws if `slab` isn't present (i.e. plugin is
 * being run outside the Slab runtime, e.g. unit-tested in node).
 */
export function assertSlab(): SlabGlobal {
  const g = (globalThis as { slab?: SlabGlobal }).slab;
  if (!g) {
    throw new Error(
      "slab global not found — this code only runs inside the Slab plugin runtime",
    );
  }
  return g;
}
```

### Step 2: storage-counter

Shows off `slab.storage.*` + `slab.ui.notify`. Increments a per-plugin counter
on every doc open.

```ts
import { definePlugin } from "@slab/plugin-sdk";

export default definePlugin({
  id: "storage-counter",
  onLoad(slab) {
    slab.document.onOpen(async (doc) => {
      const prev = Number((await slab.storage.get("count")) ?? "0");
      const next = prev + 1;
      await slab.storage.set("count", String(next));
      slab.ui.notify(`Opened ${doc.name} — total opens: ${next}`, "info");
    });
  },
});
```

### Step 3: url-fetch

Exercises `slab.fetch` + capability declaration. Pulls a URL and shows the
status in a notification.

```ts
import { definePlugin } from "@slab/plugin-sdk";

export default definePlugin({
  id: "url-fetch",
  onLoad(slab) {
    slab.ui.registerTool({
      id: "check-status",
      label: "Check example.com",
      invoke: async () => {
        try {
          const r = await slab.fetch("https://example.com", { timeoutMs: 5_000 });
          slab.ui.notify(`example.com → ${r.status} ${r.statusText}`, r.ok ? "info" : "warn");
        } catch (e) {
          slab.ui.notify(`Fetch failed: ${String(e)}`, "error");
        }
      },
    });
  },
});
```

Plus matching `manifest.toml` per example declaring the right capabilities
(`url-fetch` needs `net = "specific"` + `net_allow_hosts = ["example.com"]`).
