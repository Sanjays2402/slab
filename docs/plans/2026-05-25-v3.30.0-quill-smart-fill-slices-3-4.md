# v3.30.0 "Quill Smart Fill" — Slices 3 & 4 Implementation Plan

> **For Hermes:** Slices 1 + 2 already shipped on `feature/v3.30.0-quill-smart-fill`
> (extractor + mapper + Tauri command + drag-drop panel + Hub wiring + palette +
> keymap + global keydown). This plan covers the remaining two ticks: **Slice 3
> polish** (Settings AI hookup + shimmer wow + empty state + i18n) and
> **Slice 4 release** (version bump + merge to main + tag + finalize).

**Goal:** Close out v3.30.0 to a publishable state — Settings now lets the user
pick the model used by Smart Fill, the Propose button has a delightful
"thinking" animation, the empty state teaches the feature, and the build ships
as a public release with marketing notes + Docker image.

**Architecture (recap):**
- Smart Fill calls `slab_quill_smart_fill_propose` which uses
  `crate::ai::config::make_provider()` → so a new model picker just writes to
  `[beacon].chat_model` and Smart Fill picks it up next call. Zero backend
  changes needed for the picker.
- The shimmer is pure CSS keyframes scoped to `QuillSmartFillPanel.svelte`.
- The empty state already has the two drop zones; we need a friendly
  example/illustration row above when both zones are empty.
- Release pipeline reuses the existing MODE A → MODE B flow that shipped
  v3.29.0 last tick.

**Tech Stack:** Svelte 5 runes, Rust (no new deps), Tauri 2 commands, existing
`slab_beacon_config_read` / `slab_beacon_config_write`, existing CI release
workflow on tag push.

fn partial_update_only_changes_chat_model() {
    let tmp = TempDir::new().unwrap();
    let path = tmp.path().join("config.toml");
    let cfg = SlabConfig {
        beacon: BeaconConfig {
            provider: ProviderKind::Ollama,
            chat_model: Some("llama3.2:3b".into()),
            base_url: Some("http://localhost:11434".into()),
            ..Default::default()
        },
        ..Default::default()
    };
    save_to(&path, &cfg).unwrap();
    // Simulate a partial update: only change chat_model.
    let mut loaded = load_from(&path).unwrap();
    loaded.beacon.chat_model = Some("llama3.2:8b".into());
    save_to(&path, &loaded).unwrap();
    let reread = load_from(&path).unwrap();
    assert_eq!(reread.beacon.chat_model.as_deref(), Some("llama3.2:8b"));
    assert_eq!(reread.beacon.base_url.as_deref(), Some("http://localhost:11434"));
    assert_eq!(reread.beacon.provider, ProviderKind::Ollama);
}

```ts
// Thin wrapper around slab_beacon_config_{read,write}.
// Keeps the SettingsPanel free of Tauri-invoke plumbing and gives us a
// single place to add optimistic updates later.
import { invoke } from "@tauri-apps/api/core";
import { writable } from "svelte/store";
import type { CmdResult } from "$lib/types";

export type ProviderKind = "ollama" | "openai";

export interface BeaconCfg {
  provider: ProviderKind;
  chat_model: string | null;
  embed_model: string | null;
  base_url: string | null;
  api_key_env: string | null;
}

export interface SlabCfg {
  beacon: BeaconCfg;
  // We pass through unknown sections so write-back is non-destructive.
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  ui?: any;
  // eslint-disable-next-line @typescript-eslint/no-explicit-any
  keymap?: any;
}

/** A handful of well-known Ollama chat models. The user can also type a
 *  custom name — the input is a combo box. Numbers are last-pulled sizes
 *  on a typical dev machine. */
export const OLLAMA_CHAT_PRESETS: { id: string; label: string; hint: string }[] = [
  { id: "llama3.2:3b", label: "Llama 3.2 3B", hint: "fast · ~2 GB · default" },
  { id: "llama3.2:1b", label: "Llama 3.2 1B", hint: "fastest · ~1.3 GB" },
  { id: "llama3.1:8b", label: "Llama 3.1 8B", hint: "smarter · ~4.7 GB" },
  { id: "qwen2.5:7b", label: "Qwen 2.5 7B", hint: "great for forms · ~4.4 GB" },
  { id: "mistral:7b", label: "Mistral 7B", hint: "balanced · ~4.1 GB" },
];

const _store = writable<SlabCfg | null>(null);
export const beaconCfg = { subscribe: _store.subscribe };

export async function loadBeaconCfg(): Promise<SlabCfg> {
  const res = await invoke<CmdResult<SlabCfg>>("slab_beacon_config_read");
  if (res.kind !== "ok") throw new Error(res.message);
  _store.set(res.value);
  return res.value;
}

export async function saveBeaconCfg(patch: Partial<BeaconCfg>): Promise<void> {
  // Read-modify-write so we never clobber unrelated [ui]/[keymap] sections.
  const current = await loadBeaconCfg();
  const next: SlabCfg = {
    ...current,
    beacon: { ...current.beacon, ...patch },
  };
  const res = await invoke<CmdResult<null>>("slab_beacon_config_write", {
    config: next,
  });
  if (res.kind !== "ok") throw new Error(res.message);
  _store.set(next);
}
```
