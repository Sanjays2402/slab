# v3.0.1 "Loupe" — PDF/A Compliance Inspector (Implementation Plan)

> **For Hermes:** Single-tick ship. Buy-Button #1 PASS (Acrobat Preflight charges $239/yr).

**Goal:** Ship a one-click, non-destructive PDF/A compliance inspector that reports per-rule pass/fail against ISO 19005-2 levels 1b, 2b, 2u, 3b — with copy-as-markdown export for audit trails.

**Architecture:** Reuse `font_audit`, `sanitize` (dry-run via clone), and `validate` from the Bedrock pipeline. Wrap in a single `inspect_pdfa` orchestrator that returns a unified `InspectionReport` with per-level verdicts and actionable suggestions. Expose as `slab_pdfa_inspect` Tauri command. Frontend gets a new `LoupePanel.svelte` reachable from the sidebar nav + command palette + `Mod+Shift+I` shortcut.

**Tech Stack:** Rust (lopdf, serde), Svelte 5, Tauri 2, existing Bedrock crate code.

**Why this tick (buy-button):** Adobe Acrobat Pro DC Preflight is the #1 reason large firms keep their Acrobat licences. Slab Loupe gives them the same diagnostic — same ISO clause references, same severity grouping — for $0, offline, and exportable as a Markdown audit report. Records managers can paste it directly into compliance tickets.

Module skeleton:

```rust
//! Non-destructive PDF/A compliance inspector — Slab's answer to Adobe
//! Acrobat Preflight. Bundles font audit + sanitize dry-run + multi-level
//! validation into one report with per-level verdicts and actionable fixes.

use lopdf::Document;
use serde::{Deserialize, Serialize};
use std::path::Path;

use crate::pdf::PdfError;
use super::{
    audit_fonts, sanitize_dry_run, validate_doc, ConformanceLevel,
    FontAuditReport, SanitizeReport, ValidationReport,
};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Verdict {
    /// Fully compliant against this level.
    Pass,
    /// Will pass after Bedrock conversion runs (no manual work needed).
    AchievableWithFixes,
    /// Cannot be made compliant without external work (e.g. missing fonts).
    Fail,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LevelAssessment {
    pub level: ConformanceLevel,
    pub verdict: Verdict,
    pub blocking_errors: usize,
    pub auto_fixable: usize,
    pub validation: ValidationReport,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct InspectionReport {
    pub input_path: String,
    pub pdf_version: String,
    pub page_count: usize,
    pub file_bytes: u64,
    pub fonts: FontAuditReport,
    pub sanitize: SanitizeReport,           // dry-run, not mutated
    pub levels: Vec<LevelAssessment>,        // 1b, 2b, 2u, 3b
    pub suggestions: Vec<String>,            // human-readable actions
}

impl InspectionReport {
    /// Best level achievable today (passes or auto-fixable).
    pub fn best_achievable(&self) -> Option<ConformanceLevel> { /* ... */ }
}

pub fn inspect_pdfa(path: &Path) -> Result<InspectionReport, PdfError> { /* ... */ }
```

Verdict logic per level:
- Count `Severity::Error` findings.
- Auto-fixable = findings whose ISO section matches what Bedrock fixes during conversion (§6.6 sanitize, §6.7.1 XMP, §6.2.2 OutputIntent).
- `Pass` when errors == 0.
- `AchievableWithFixes` when every error is auto-fixable AND `fonts.all_embedded()`.
- `Fail` otherwise (e.g. unembedded fonts, encrypted document).

Suggestions:
- For each font missing embed: `"Embed font '<name>' (re-export source doc with 'embed all fonts')"`.
- If `sanitize.removed` is non-empty: `"<N> forbidden entries will be stripped during conversion (OpenAction, AA, JavaScript)"`.
- If encrypted: `"Decrypt the document before converting"`.
- If best achievable >= 2b: `"Run Bedrock to convert to <level>"`.

**Tests (in-module):**
1. Clean PDF (no fonts, no forbidden keys) → all 4 levels Pass.
2. PDF with `/OpenAction` → sanitize dry-run reports it; per-level verdict shows AchievableWithFixes (Bedrock strips it).
3. PDF with unembedded Helvetica → Fail across all levels; suggestion mentions embedding.
4. Encrypted doc → top-level error in report.

Design (Liquid Glass tier):

- Once loaded: top row shows file name, pages, size, PDF version.
- Big 4-column grid: PDF/A-1b, 2b, 2u, 3b — each a glass card with a green/amber/red verdict pill, error count, "what's wrong" expandable.
- Below: collapsible sections for Fonts (table: name, type, embedded ✓/✗, ToUnicode ✓/✗), Sanitize preview (chips of what'll be stripped), Suggestions (numbered list).
