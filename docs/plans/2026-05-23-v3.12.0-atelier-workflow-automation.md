# v3.12.0 "Atelier" — Workflow Automation Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship a workflow automation engine ("Atelier") that lets a user chain Slab's existing PDF actions — OCR → Auto-Redact → Bates → Batch-Sign → Export — into a single named recipe and run it over a folder of hundreds of PDFs unattended.

**Architecture:** A new crate-internal module `pdf::atelier` defines a `Recipe` (ordered list of `Step`s) plus a `run_recipe` driver that pipes a temp PDF through each step in order, emitting per-file/per-step progress to a Tauri channel. Recipes serialize to JSON so users can save, share, and re-run them. A Svelte panel ("Atelier") lets users drag-build a recipe, run it over an input folder, and watch a live progress matrix.

**Tech Stack:** Rust (existing pdf modules: `ocr`, `auto_redact`, `bates_batch`, `signet_pro::batch`, `watermark`, `flatten`, `compactor`, `forms`); `serde` for recipe serialization; `tauri::ipc::Channel` for streaming progress; Svelte 5 with Liquid Glass styling for the UI; existing keymap + command palette modules.

**Buy-Button test — passes #1, #3, #4:** A 500-person law firm paralegal processes 200 scanned discovery PDFs nightly. Today that's Adobe Acrobat Pro DC + Action Wizard ($239/yr/seat × 500 = $119,500/yr). Atelier gives them a saved recipe ("Nightly Discovery") that does it offline in one click. Customers screenshot this. Customers also leave Adobe over this.

**Wow moment:** Drag a folder of 200 scanned PDFs onto the Atelier panel → live grid lights up green left-to-right as each step completes per file → 4 minutes later, output folder has 200 OCR'd, redacted, bates-stamped, signed PDFs. Posted to Twitter as "this used to cost me $239/yr and an hour of clicking."

```rust
use crate::pdf::PdfError;
use crate::pdf::atelier::{Recipe, Step};
use serde::Serialize;
use std::path::{Path, PathBuf};

#[derive(Debug, Clone, Serialize)]
#[serde(tag = "event", rename_all = "kebab-case")]
pub enum Progress {
    Started { step_index: usize, total_steps: usize, kind: String },
    Completed { step_index: usize, kind: String },
    Failed { step_index: usize, kind: String, error: String },
}

#[derive(Debug, Clone, Serialize)]
pub struct RecipeReport {
    pub steps_completed: usize,
    pub output_path: PathBuf,
}

pub fn run_recipe(
    input: &Path,
    output: &Path,
    recipe: &Recipe,
    on_progress: &dyn Fn(Progress),
) -> Result<RecipeReport, PdfError> {
    let scratch = tempfile::tempdir().map_err(|e| PdfError::Io(e.to_string()))?;
    let mut current: PathBuf = input.to_path_buf();
    let total = recipe.steps.len();

    for (i, step) in recipe.steps.iter().enumerate() {
        let kind = step_kind(step);
        on_progress(Progress::Started {
            step_index: i, total_steps: total, kind: kind.clone(),
        });
        let next = scratch.path().join(format!("step-{}.pdf", i));
        let result = apply_step(&current, &next, step);
        match result {
            Ok(()) => {
                on_progress(Progress::Completed { step_index: i, kind });
                current = next;
            }
            Err(e) => {
                on_progress(Progress::Failed {
                    step_index: i, kind, error: e.to_string(),
                });
                return Err(e);
            }
        }
    }

    std::fs::copy(&current, output).map_err(|e| PdfError::Io(e.to_string()))?;
    Ok(RecipeReport { steps_completed: total, output_path: output.to_path_buf() })
}

fn step_kind(s: &Step) -> String {
    match s {
        Step::Ocr { .. } => "ocr",
        Step::AutoRedact { .. } => "auto-redact",
        Step::Bates { .. } => "bates",
        Step::Watermark { .. } => "watermark",
        Step::Flatten { .. } => "flatten",
        Step::Compactor => "compactor",
        Step::Sign { .. } => "sign",
    }.into()
}

fn apply_step(input: &Path, output: &Path, step: &Step) -> Result<(), PdfError> {
    match step {
        Step::Watermark { text, opacity } => {
            crate::pdf::watermark::apply(input, output, text, *opacity)?;
            Ok(())
        }
        Step::Flatten { dpi } => {
            crate::pdf::flatten::flatten(input, output, *dpi)?;
            Ok(())
        }
        Step::Compactor => {
            crate::pdf::compactor::compact(input, output)?;
            Ok(())
        }
        Step::Ocr { language } => {
            let opts = crate::pdf::ocr::OcrOpts { language: language.clone(), ..Default::default() };
            crate::pdf::ocr::ocr(input, output, &opts)?;
            Ok(())
        }
        Step::AutoRedact { patterns } => {
            crate::pdf::auto_redact::redact_patterns(input, output, patterns)?;
            Ok(())
        }
        Step::Bates { prefix, start, digits } => {
            crate::pdf::bates::stamp_single(input, output, prefix, *start, *digits)?;
            Ok(())
        }
        Step::Sign { profile_id, tsa_url } => {
            crate::pdf::signet::sign::sign_with_profile(input, output, profile_id, tsa_url.as_deref())?;
            Ok(())
        }
    }
}
```

```rust
use crate::pdf::PdfError;
use crate::pdf::atelier::{Recipe, run::{Progress, run_recipe}};
use rayon::prelude::*;
use serde::Serialize;
use std::path::{Path, PathBuf};
use std::sync::Mutex;

#[derive(Debug, Clone, Serialize)]
#[serde(tag = "event", rename_all = "kebab-case")]
pub enum BatchProgress {
    FileStarted { file_index: usize, path: PathBuf },
    StepProgress { file_index: usize, inner: Progress },
    FileCompleted { file_index: usize, path: PathBuf },
    FileFailed { file_index: usize, path: PathBuf, error: String },
}

#[derive(Debug, Clone, Serialize)]
pub struct BatchReport {
    pub total: usize,
    pub succeeded: usize,
    pub failed: usize,
    pub failures: Vec<(PathBuf, String)>,
}

pub fn run_recipe_batch(
    in_dir: &Path,
    out_dir: &Path,
    recipe: &Recipe,
    on_progress: &(dyn Fn(BatchProgress) + Sync),
) -> Result<BatchReport, PdfError> {
    std::fs::create_dir_all(out_dir).map_err(|e| PdfError::Io(e.to_string()))?;
    let inputs: Vec<PathBuf> = std::fs::read_dir(in_dir)
        .map_err(|e| PdfError::Io(e.to_string()))?
        .filter_map(|e| e.ok())
        .map(|e| e.path())
        .filter(|p| p.extension().and_then(|s| s.to_str()) == Some("pdf"))
        .collect();

    let failures: Mutex<Vec<(PathBuf, String)>> = Mutex::new(vec![]);
    let succeeded: Mutex<usize> = Mutex::new(0);

    inputs.par_iter().enumerate().for_each(|(idx, input)| {
        on_progress(BatchProgress::FileStarted {
            file_index: idx, path: input.clone(),
        });
        let out = out_dir.join(input.file_name().unwrap());
        let inner_cb = |p: Progress| {
            on_progress(BatchProgress::StepProgress { file_index: idx, inner: p });
        };
        match run_recipe(input, &out, recipe, &inner_cb) {
            Ok(_) => {
                *succeeded.lock().unwrap() += 1;
                on_progress(BatchProgress::FileCompleted {
                    file_index: idx, path: input.clone(),
                });
            }
            Err(e) => {
                failures.lock().unwrap().push((input.clone(), e.to_string()));
                on_progress(BatchProgress::FileFailed {
                    file_index: idx, path: input.clone(), error: e.to_string(),
                });
            }
        }
    });

    let failures = failures.into_inner().unwrap();
    let succeeded = succeeded.into_inner().unwrap();
    Ok(BatchReport {
        total: inputs.len(),
        succeeded,
        failed: failures.len(),
        failures,
    })
}
```

```rust
use crate::pdf::atelier::{Recipe, run_recipe_batch, BatchProgress};
use std::path::{Path, PathBuf};
use tauri::ipc::Channel;

pub fn save_recipe_to_dir(dir: &Path, recipe: &Recipe) -> std::io::Result<PathBuf> {
    std::fs::create_dir_all(dir)?;
    let safe = recipe.name.replace('/', "_").replace('\\', "_");
    let path = dir.join(format!("{}.json", safe));
    let json = serde_json::to_string_pretty(recipe).unwrap();
    std::fs::write(&path, json)?;
    Ok(path)
}

pub fn list_recipes_in_dir(dir: &Path) -> std::io::Result<Vec<Recipe>> {
    if !dir.exists() { return Ok(vec![]); }
    let mut out = vec![];
    for entry in std::fs::read_dir(dir)? {
        let p = entry?.path();
        if p.extension().and_then(|s| s.to_str()) != Some("json") { continue; }
        let s = std::fs::read_to_string(&p)?;
        if let Ok(r) = serde_json::from_str::<Recipe>(&s) { out.push(r); }
    }
    Ok(out)
}

fn recipes_dir(app: &tauri::AppHandle) -> PathBuf {
    use tauri::Manager;
    app.path().app_config_dir().unwrap().join("atelier").join("recipes")
}

#[tauri::command]
pub fn atelier_save_recipe(app: tauri::AppHandle, recipe: Recipe) -> Result<String, String> {
    let dir = recipes_dir(&app);
    save_recipe_to_dir(&dir, &recipe)
        .map(|p| p.to_string_lossy().into_owned())
        .map_err(|e| e.to_string())
}

#[tauri::command]
pub fn atelier_load_recipes(app: tauri::AppHandle) -> Result<Vec<Recipe>, String> {
    let dir = recipes_dir(&app);
    list_recipes_in_dir(&dir).map_err(|e| e.to_string())
}

#[tauri::command]
pub fn atelier_run_batch(
    in_dir: String,
    out_dir: String,
    recipe: Recipe,
    on_event: Channel<BatchProgress>,
) -> Result<crate::pdf::atelier::batch::BatchReport, String> {
    let cb = move |p: BatchProgress| { let _ = on_event.send(p); };
    run_recipe_batch(Path::new(&in_dir), Path::new(&out_dir), &recipe, &cb)
        .map_err(|e| e.to_string())
}
```

```typescript
  | { kind: 'flatten'; dpi: number }
  | { kind: 'compactor' }
  | { kind: 'sign'; profile_id: string; tsa_url: string | null };

export interface Recipe { name: string; version: number; steps: Step[]; }

export type BatchEvent =
  | { event: 'file-started'; file_index: number; path: string }
  | { event: 'step-progress'; file_index: number; inner: any }
  | { event: 'file-completed'; file_index: number; path: string }
  | { event: 'file-failed'; file_index: number; path: string; error: string };

export interface BatchReport { total: number; succeeded: number; failed: number; failures: [string, string][]; }

export async function listRecipes(): Promise<Recipe[]> {
  return invoke('atelier_load_recipes');
}
export async function saveRecipe(recipe: Recipe): Promise<string> {
  return invoke('atelier_save_recipe', { recipe });
}
export async function runBatch(
  inDir: string, outDir: string, recipe: Recipe, onEvent: (e: BatchEvent) => void
): Promise<BatchReport> {
  const ch = new Channel<BatchEvent>();
  ch.onmessage = onEvent;
  return invoke('atelier_run_batch', { inDir, outDir, recipe, onEvent: ch });
}
```
