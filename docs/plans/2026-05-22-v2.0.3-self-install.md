# v2.0.3 "Self-Install" Implementation Plan — Issue #25

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship a one-time first-launch "Install or Run" dialog that copies Slab to a canonical user-writable location (no admin/UAC), optionally registers it as the default PDF handler, and never asks again — across macOS, Windows, and Linux.

**Architecture:** A new pure-Rust module `src-tauri/src/first_launch/` with three thin OS-specific submodules (`macos.rs`, `windows.rs`, `linux.rs`) behind a unified `FirstLaunchPlatform` trait. The decision logic — *do we need to prompt?* — lives in `mod.rs` and is fully unit-testable on every host via a `Probe` trait abstracting the filesystem. Five new Tauri commands (`slab_first_launch_probe`, `slab_first_launch_install`, `slab_first_launch_skip`, `slab_first_launch_set_default_handler`, `slab_first_launch_unset_default_handler`) drive a new `FirstLaunchModal.svelte` shown at most once per machine. State persists in `~/.config/slab/launch.toml` (a path explicitly chosen to be separate from `~/.slab/config.toml` so a config wipe doesn't re-trigger the modal).

**Tech Stack:** Rust (`directories` crate already in tree, `std::os::unix::fs::PermissionsExt`, Windows `winreg` already pulled by tauri), Svelte 5 + TypeScript, Tauri 2, `vitest` (frontend), `cargo test --lib` (backend).

**Buy-Button verdict (Pick-us + Notice-it):** ✅ Pick-us — KillerPDF's #1 cited feature on Reddit; Adobe/PDF Expert ship installers, but no free OSS tool ships a *non-admin* self-installer. ✅ Notice-it — first thing every new user sees. ✅ Tell-a-friend — "no UAC, no sudo, no admin, just open it" is the demo line.

**Wow moment:** Slice 4 — a 420ms gold-accent "settling" animation (cubic-bezier `(0.34, 1.56, 0.64, 1)` scale-1.04→1.0 + opacity fade) on the modal's primary CTA as it transitions from "Install" → "Installing…" → "Done · Relaunching" with a 3-stage progress ring around the Slab icon. `LAST_WOW_TICK_AT:` candidate.

// src-tauri/src/first_launch/mod.rs
//! First-launch self-install flow (issue #25, v2.0.3).
//!
//! Decision module. OS-specific install code lives in submodules
//! gated by `cfg(target_os = "…")`. The `Probe` trait abstracts
//! filesystem queries so the decision logic is unit-testable on
//! any host without touching the user's real disk.

use serde::{Deserialize, Serialize};
use std::path::PathBuf;

pub mod state;
#[cfg(target_os = "macos")]
pub mod macos;
#[cfg(target_os = "windows")]
pub mod windows;
#[cfg(target_os = "linux")]
pub mod linux;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
#[serde(rename_all = "snake_case")]
pub enum LaunchDecision {
    /// First launch hasn't happened yet (or state file missing).
    #[default]
    Pending,
    /// User chose "Run from here" — never prompt again.
    RunFromHere,
    /// User chose "Install" — we relocated the binary.
    Installed,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct LaunchState {
    #[serde(default = "default_schema")]
    pub schema_version: u32,
    #[serde(default)]
    pub decision: LaunchDecision,
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub installed_at: Option<String>, // RFC 3339
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub installed_path: Option<PathBuf>,
}

fn default_schema() -> u32 { 1 }

impl Default for LaunchState {
    fn default() -> Self {
        Self { schema_version: 1, decision: LaunchDecision::Pending, installed_at: None, installed_path: None }
    }
}

/// Filesystem queries the decision logic needs. Implemented by the
/// real `OsProbe` and by `MockProbe` in tests.
pub trait Probe {
    fn current_exe(&self) -> std::io::Result<PathBuf>;
    fn state_path(&self) -> Option<PathBuf>;
    fn canonical_install_dir(&self) -> Option<PathBuf>;
}

// src-tauri/src/first_launch/state.rs
use super::LaunchState;
use std::io::Write;
use std::path::Path;

pub fn load(path: &Path) -> std::io::Result<LaunchState> {
    match std::fs::read_to_string(path) {
        Ok(s) => toml::from_str(&s).map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidData, e)),
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(LaunchState::default()),
        Err(e) => Err(e),
    }
}

pub fn save(path: &Path, state: &LaunchState) -> std::io::Result<()> {
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent)?;
    }
    let body = toml::to_string_pretty(state)
        .map_err(|e| std::io::Error::new(std::io::ErrorKind::InvalidData, e))?;
    let tmp = path.with_extension("toml.tmp");
    {
        let mut f = std::fs::File::create(&tmp)?;
        f.write_all(body.as_bytes())?;
        f.sync_all()?;
    }
    std::fs::rename(&tmp, path)?;
    Ok(())
}
```

/// Decide whether to show the install/run modal at startup.
/// Rules:
///   - Decision != Pending  → never prompt.
///   - exe is already inside canonical install dir → never prompt
///     (idempotency: re-running the installed copy is silent).
///   - Otherwise → prompt.
pub fn should_prompt<P: Probe>(probe: &P) -> bool {
    let state_path = match probe.state_path() {
        Some(p) => p,
        None => return false, // no HOME → can't store state → don't nag
    };
    let st = state::load(&state_path).unwrap_or_default();
    if !matches!(st.decision, LaunchDecision::Pending) {
        return false;
    }
    let exe = match probe.current_exe() { Ok(e) => e, Err(_) => return false };
    if let Some(install) = probe.canonical_install_dir() {
        if exe.starts_with(&install) {
            return false;
        }
    }
    true
}
```

// src-tauri/src/first_launch/macos.rs
//! macOS install: ~/Applications/Slab.app + LSRegisterURL.
use std::path::{Path, PathBuf};

/// Walk up from the current binary path to the `.app` bundle root.
/// `/path/Slab.app/Contents/MacOS/slab` → `/path/Slab.app`.
pub fn app_bundle_root(exe: &Path) -> Option<PathBuf> {
    let mut p = exe.parent()?; // MacOS
    p = p.parent()?;           // Contents
    p = p.parent()?;           // Slab.app
    if p.extension().and_then(|s| s.to_str()) == Some("app") {
        Some(p.to_path_buf())
    } else {
        None
    }
}

pub fn canonical_install_dir() -> Option<PathBuf> {
    dirs::home_dir().map(|h| h.join("Applications").join("Slab.app"))
}

pub fn install() -> std::io::Result<PathBuf> {
    let exe = std::env::current_exe()?;
    let src = app_bundle_root(&exe)
        .ok_or_else(|| std::io::Error::new(std::io::ErrorKind::InvalidData, "not running from an .app bundle"))?;
    let dest = canonical_install_dir()
        .ok_or_else(|| std::io::Error::new(std::io::ErrorKind::NotFound, "no HOME"))?;
    if let Some(parent) = dest.parent() { std::fs::create_dir_all(parent)?; }
    // Remove pre-existing copy (idempotent re-install).
    if dest.exists() { std::fs::remove_dir_all(&dest)?; }
    // Use `cp -R` because std::fs::copy is single-file and we need
    // to preserve symlinks/perms in the bundle.
    let status = std::process::Command::new("cp").arg("-R").arg(&src).arg(&dest).status()?;
    if !status.success() {
        return Err(std::io::Error::other("cp -R failed"));
    }
    // Register with Launch Services so Finder + Spotlight find it.
    let _ = std::process::Command::new("/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister")
        .arg("-f").arg(&dest).status();
    Ok(dest.join("Contents/MacOS/slab"))
}

pub fn set_default_pdf_handler() -> std::io::Result<()> {
    // duti is not always installed — fall back to defaultwebbrowser-style
    // LSSetDefaultRoleHandlerForContentType via a Swift one-liner. We
    // wrap in osascript to avoid bundling a binary.
    let script = r#"
        do shell script "/usr/bin/env defaults write com.apple.LaunchServices/com.apple.launchservices.secure LSHandlers -array-add '{LSHandlerContentType=com.adobe.pdf;LSHandlerRoleAll=dev.slab.slab;}'"
    "#;
    let status = std::process::Command::new("osascript").arg("-e").arg(script).status()?;
    if !status.success() {
        return Err(std::io::Error::other("failed to update LSHandlers"));
    }
    Ok(())
}

// src-tauri/src/first_launch/windows.rs
//! Windows install: %LOCALAPPDATA%\Programs\Slab + Start Menu shortcut.
//! All HKCU writes — never HKLM, never UAC.

use std::path::{Path, PathBuf};

pub fn canonical_install_dir() -> Option<PathBuf> {
    std::env::var_os("LOCALAPPDATA")
        .map(|v| PathBuf::from(v).join("Programs").join("Slab"))
}

pub fn install() -> std::io::Result<PathBuf> {
    let exe = std::env::current_exe()?;
    let src_dir = exe.parent()
        .ok_or_else(|| std::io::Error::other("exe has no parent"))?;
    let dest = canonical_install_dir()
        .ok_or_else(|| std::io::Error::new(std::io::ErrorKind::NotFound, "no LOCALAPPDATA"))?;
    std::fs::create_dir_all(&dest)?;
    // Robocopy /MIR equivalent in pure Rust — copy every file in
    // src_dir (non-recursive: NSIS/MSI Tauri builds put a flat
    // directory next to the .exe with WebView2Loader.dll etc.).
    for entry in std::fs::read_dir(src_dir)? {
        let entry = entry?;
        let ty = entry.file_type()?;
        if ty.is_file() {
            let from = entry.path();
            let to = dest.join(entry.file_name());
            std::fs::copy(&from, &to)?;
        }
    }
    let installed_exe = dest.join(exe.file_name().unwrap_or(std::ffi::OsStr::new("slab.exe")));
    create_start_menu_shortcut(&installed_exe)?;
    Ok(installed_exe)
}

fn create_start_menu_shortcut(target: &Path) -> std::io::Result<()> {
    let appdata = std::env::var_os("APPDATA")
        .ok_or_else(|| std::io::Error::new(std::io::ErrorKind::NotFound, "no APPDATA"))?;
    let lnk = PathBuf::from(appdata)
        .join(r"Microsoft\Windows\Start Menu\Programs\Slab.lnk");
    if let Some(parent) = lnk.parent() { std::fs::create_dir_all(parent)?; }
    let ps = format!(
        "$ws = New-Object -ComObject WScript.Shell; \
         $s = $ws.CreateShortcut('{}'); \
         $s.TargetPath = '{}'; \
         $s.WorkingDirectory = '{}'; \
         $s.IconLocation = '{},0'; \
         $s.Save()",
        lnk.display(),
        target.display(),
        target.parent().unwrap().display(),
        target.display(),
    );
    let status = std::process::Command::new("powershell")
        .args(["-NoProfile", "-Command", &ps])
        .status()?;
    if !status.success() {
        return Err(std::io::Error::other("powershell shortcut creation failed"));
    }
    Ok(())
}

pub fn set_default_pdf_handler() -> std::io::Result<()> {
    // HKCU-only registry writes — no admin required. We register a
    // ProgID `Slab.PDF` and bind `.pdf` to it in
    // `HKCU\Software\Classes\.pdf\OpenWithProgids`.
    use winreg::enums::*;
    use winreg::RegKey;
    let exe = std::env::current_exe()?;
    let hkcu = RegKey::predef(HKEY_CURRENT_USER);
    let (progid, _) = hkcu.create_subkey(r"Software\Classes\Slab.PDF\shell\open\command")?;
    let cmd = format!("\"{}\" \"%1\"", exe.display());
    progid.set_value("", &cmd)?;
    let (ext, _) = hkcu.create_subkey(r"Software\Classes\.pdf\OpenWithProgids")?;
    ext.set_value("Slab.PDF", &"")?;
    Ok(())
}

// src-tauri/src/first_launch/linux.rs
//! Linux install: ~/.local/bin/slab + ~/.local/share/applications/slab.desktop.
use std::io::Write;
use std::path::PathBuf;

pub fn canonical_install_dir() -> Option<PathBuf> {
    dirs::home_dir().map(|h| h.join(".local").join("bin"))
}

pub fn install() -> std::io::Result<PathBuf> {
    let exe = std::env::current_exe()?;
    let dest_dir = canonical_install_dir()
        .ok_or_else(|| std::io::Error::new(std::io::ErrorKind::NotFound, "no HOME"))?;
    std::fs::create_dir_all(&dest_dir)?;
    let dest = dest_dir.join("slab");
    std::fs::copy(&exe, &dest)?;
    // chmod +x
    use std::os::unix::fs::PermissionsExt;
    let mut perms = std::fs::metadata(&dest)?.permissions();
    perms.set_mode(0o755);
    std::fs::set_permissions(&dest, perms)?;
    write_desktop_file(&dest)?;
    let _ = std::process::Command::new("update-desktop-database")
        .arg(dirs::home_dir().unwrap_or_default().join(".local/share/applications"))
        .status();
    Ok(dest)
}

fn write_desktop_file(exe: &std::path::Path) -> std::io::Result<()> {
    let home = dirs::home_dir()
        .ok_or_else(|| std::io::Error::new(std::io::ErrorKind::NotFound, "no HOME"))?;
    let dir = home.join(".local/share/applications");
    std::fs::create_dir_all(&dir)?;
    let path = dir.join("slab.desktop");
    let body = format!(
        "[Desktop Entry]\n\
         Name=Slab\n\
         Comment=Local-first PDF workstation\n\
         Exec={} %F\n\
         Icon=slab\n\
         Terminal=false\n\
         Type=Application\n\
         Categories=Office;Viewer;\n\
         MimeType=application/pdf;\n\
         StartupWMClass=slab\n",
        exe.display(),
    );
    let mut f = std::fs::File::create(&path)?;
    f.write_all(body.as_bytes())?;
    Ok(())
}

pub fn set_default_pdf_handler() -> std::io::Result<()> {
    let status = std::process::Command::new("xdg-mime")
        .args(["default", "slab.desktop", "application/pdf"])
        .status()?;
    if !status.success() {
        return Err(std::io::Error::other("xdg-mime failed"));
    }
    Ok(())
}

struct OsProbe;

    fn state_path(&self) -> Option<std::path::PathBuf> {
        dirs::config_dir().map(|c| c.join("slab").join("launch.toml"))
    }

        #[cfg(target_os = "macos")]    { first_launch::macos::canonical_install_dir() }
        #[cfg(target_os = "windows")]  { first_launch::windows::canonical_install_dir() }
        #[cfg(target_os = "linux")]    { first_launch::linux::canonical_install_dir() }
        #[cfg(not(any(target_os = "macos", target_os = "windows", target_os = "linux")))] { None }
    }

#[derive(serde::Serialize)]
pub struct FirstLaunchProbeResult {
    pub should_prompt: bool,
    pub current_exe: Option<String>,
    pub canonical_install_dir: Option<String>,
    pub platform: &'static str,
}

#[tauri::command]
fn slab_first_launch_probe() -> CmdResult<FirstLaunchProbeResult> {
    let probe = OsProbe;
    let should = first_launch::should_prompt(&probe);
    Ok(FirstLaunchProbeResult {
        should_prompt: should,
        current_exe: probe.current_exe().ok().map(|p| p.display().to_string()),
        canonical_install_dir: probe.canonical_install_dir().map(|p| p.display().to_string()),
        platform: std::env::consts::OS,
    })
}

#[tauri::command]
fn slab_first_launch_install(set_default_handler: bool) -> CmdResult<String> {
    let new_exe: std::path::PathBuf;
    #[cfg(target_os = "macos")]    { new_exe = first_launch::macos::install().map_err(|e| e.to_string())?; }
    #[cfg(target_os = "windows")]  { new_exe = first_launch::windows::install().map_err(|e| e.to_string())?; }
    #[cfg(target_os = "linux")]    { new_exe = first_launch::linux::install().map_err(|e| e.to_string())?; }
    #[cfg(not(any(target_os = "macos", target_os = "windows", target_os = "linux")))]
    { return Err("unsupported platform".to_string()); }

    if set_default_handler {
        let _ = slab_first_launch_set_default_handler();
    }

    // Persist Installed state.
    let probe = OsProbe;
    if let Some(sp) = probe.state_path() {
        let st = first_launch::LaunchState {
            decision: first_launch::LaunchDecision::Installed,
            installed_at: Some(chrono::Utc::now().to_rfc3339()),
            installed_path: Some(new_exe.clone()),
            ..Default::default()
        };
        first_launch::state::save(&sp, &st).map_err(|e| e.to_string())?;
    }
    Ok(new_exe.display().to_string())
}

#[tauri::command]
fn slab_first_launch_skip() -> CmdResult<()> {
    let probe = OsProbe;
    if let Some(sp) = probe.state_path() {
        let st = first_launch::LaunchState {
            decision: first_launch::LaunchDecision::RunFromHere,
            ..Default::default()
        };
        first_launch::state::save(&sp, &st).map_err(|e| e.to_string())?;
    }
    Ok(())
}

#[tauri::command]
fn slab_first_launch_set_default_handler() -> CmdResult<()> {
    #[cfg(target_os = "macos")]   { first_launch::macos::set_default_pdf_handler().map_err(|e| e.to_string()) }
    #[cfg(target_os = "windows")] { first_launch::windows::set_default_pdf_handler().map_err(|e| e.to_string()) }
    #[cfg(target_os = "linux")]   { first_launch::linux::set_default_pdf_handler().map_err(|e| e.to_string()) }
    #[cfg(not(any(target_os = "macos", target_os = "windows", target_os = "linux")))]

    Ok(())
