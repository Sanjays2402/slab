# v3.28.0 "Quill Hub" Implementation Plan

> **For Hermes:** Use `subagent-driven-development` to implement this plan task-by-task. Ships **last** of the Quill quartet, AFTER v3.25.0 (Batch), v3.26.0 (Designer) and v3.27.0 (Auto-Detect) all land on `main`. Bundle Tasks 1-3 into Tick 1 (state store + tabbed shell). Tasks 4-6 into Tick 2 (Designer + Detect + Fill + Batch wired into the hub as tabs, command-palette rewrite). Tasks 7-8 into Tick 3 (onboarding empty-state, screenshots, version bump, MODE A merge → tag → release). Branch: `feature/v3.28.0-quill-hub`.

**Goal:** Turn the four scattered Quill panels (Designer, Auto-Detect, Fill, Batch) and four memorize-this shortcuts into **one unified "Forms" workspace** with a single entry point (`Cmd/Ctrl+Shift+Q`), a four-tab subnav, a shared "current PDF" state, and an opinionated **happy-path flow** that walks a brand-new user from "flat PDF" → "fillable PDF" → "filled PDF" → "200 filled PDFs" in under 60 seconds.

**Architecture:** New top-level Svelte panel `QuillHubPanel.svelte` replacing the legacy `FormsPanel.svelte` route. Internally it is a tabbed shell with four `<svelte:component>` slots — `QuillDesigner`, `QuillAutodetect`, `QuillFill`, `QuillBatch` — all reading/writing a shared store (`src/lib/quill.ts`) so the active PDF, the detected/drawn fields, and the in-memory `FormsReport` flow between tabs without re-picking files. A new "Next: …" bottom bar guides users between tabs (e.g. on the Auto-Detect tab after acceptance: "Next: Fill the form →"). No new Rust code — every command (`slab_forms_autodetect`, `slab_forms_design_add`, `slab_forms_fill`, `slab_quill_batch`) already exists from prior releases. This is **pure UX consolidation that turns four features into one product surface**.

**Tech Stack:** Svelte 5 runes, TypeScript, Tauri 2 (no Rust changes), CSS Liquid Glass tokens already in repo.

**Why it's the buy-button:** Without the Hub, the marketing claim "Slab is the form workstation Acrobat charges $239/yr for" requires the customer to discover four separate menu items, four shortcuts, and figure out the right order themselves. With the Hub, the customer drags a flat PDF onto **one** "Forms" tab and a guided three-click flow turns it into a batch-fillable form. This is the screenshot for the Show-HN landing: a single shell, four tabs labeled "Detect · Design · Fill · Batch", a progress chip showing "8 fields detected, 6 accepted", and a "Next: Fill →" call to action. Acrobat Pro's "Prepare Form" workflow is the headline of their $239/yr seat — this matches it AND beats it by also covering batch CSV fill, offline, free, on Linux + Windows + macOS. **Tell-a-friend tier**: a 30-second screencap of the four-tab flow is the marketing asset.

```ts
// src/lib/quill.ts
//
// v3.28.0 "Quill Hub" — shared state across the four sub-tabs
// (Detect · Design · Fill · Batch). All four panels read/write this
// store so users never re-pick a file mid-flow, and the bottom
// "Next: …" call-to-action can stay one step ahead of them.

import { writable, derived, get } from "svelte/store";

export type QuillTab = "detect" | "design" | "fill" | "batch";

export type FormsReport = {
  has_acroform: boolean;
  need_appearances: boolean;
  has_xfa: boolean;
  fields: Array<{ name: string; value?: string | null; type?: string }>;
};

export type DetectionReport = {
  candidates: Array<{ suggested_name: string; [k: string]: unknown }>;
  pages_scanned: number;
  already_has_acroform: boolean;
  warnings: string[];
};

export type QuillState = {
  input: string | null;
  formsReport: FormsReport | null;
  detection: DetectionReport | null;
  activeTab: QuillTab;
};

const initial: QuillState = {
  input: null,
  formsReport: null,
  detection: null,
  activeTab: "detect",
};

const _quill = writable<QuillState>({ ...initial });

export const quill = derived(_quill, ($s) => ({
  ...$s,
  suggestedNextTab: suggestNext($s),
}));

function suggestNext(s: QuillState): QuillTab {
  if (!s.input) return "detect";
  // A field with a non-null/non-empty value = user has started filling.
  if (s.formsReport?.fields?.some((f) => f.value)) return "batch";
  if (s.formsReport?.has_acroform) return "fill";
  if (s.detection && s.detection.candidates.length > 0) return "design";
  return "detect";
}

export function setInput(path: string) {
  _quill.update((s) => ({ ...s, input: path, formsReport: null, detection: null }));
}

export function recordDetection(d: DetectionReport) {
  _quill.update((s) => ({ ...s, detection: d }));
}

export function recordFormsReport(r: FormsReport) {
  _quill.update((s) => ({ ...s, formsReport: r }));
}

export function setActiveTab(t: QuillTab) {
  _quill.update((s) => ({ ...s, activeTab: t }));
}

export function resetQuill() {
  _quill.set({ ...initial });
}

export function snapshot(): QuillState {
  return get(_quill);
}
```

```svelte
   *   Detect (v3.27.0)   → propose form fields on a flat PDF

   * Shared state lives in `$lib/quill`; sub-tabs are dumb-ish components
   * that read store + dispatch back. The bottom CTA always points at the
   * next sensible tab so a brand-new user is never lost.
   */
  import { onMount } from "svelte";
  import { quill, setActiveTab, resetQuill, type QuillTab } from "$lib/quill";
  import { basename } from "$lib/types";

  import QuillAutodetectTab from "$lib/panels/quill/QuillAutodetectTab.svelte";
  import QuillDesignerTab from "$lib/panels/quill/QuillDesignerTab.svelte";
  import QuillFillTab from "$lib/panels/quill/QuillFillTab.svelte";
  import QuillBatchTab from "$lib/panels/quill/QuillBatchTab.svelte";

    { id: "detect", label: "Detect", sub: "Find fillable spots on a flat PDF" },
    { id: "design", label: "Design", sub: "Draw fields by hand" },
    { id: "fill", label: "Fill", sub: "Type values into a form" },
    { id: "batch", label: "Batch", sub: "Merge a CSV across many copies" },
  ];

  let state = $derived($quill);

  function go(t: QuillTab) {
    setActiveTab(t);
  }

  function chip(): string {
    if (!state.input) return "no file";
    if (state.formsReport?.fields.some((f) => f.value)) return "filled, ready to batch";
    if (state.formsReport?.has_acroform) return `${state.formsReport.fields.length} fields ready`;

      return `${state.detection.candidates.length} candidate${state.detection.candidates.length === 1 ? "" : "s"}`;
    return "flat PDF";
  }

  onMount(() => {
    // Deep-link: ?quill=detect|design|fill|batch
    const params = new URLSearchParams(window.location.search);
    const q = params.get("quill") as QuillTab | null;
    if (q && TABS.some((t) => t.id === q)) setActiveTab(q);
  });
</script>
```
