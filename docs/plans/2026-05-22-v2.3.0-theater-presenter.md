# v2.3.0 "Theater" — Presenter Mode Implementation Plan

> **For Hermes:** Use `subagent-driven-development` skill to implement this plan task-by-task. Fresh subagent per task, spec-compliance review then code-quality review, proceed only on dual green.

**Goal:** Ship a first-class presenter mode that turns any open PDF into a slide-style fullscreen presentation with next-slide preview, laser-pointer cursor, ink annotations (whiteboard-style), blackout/spotlight, and a presenter-display window — so lawyers can walk a jury through deposition exhibits and sales teams can pitch a contract without ever leaving Slab.

**Architecture:**
- Two synchronized windows via existing `slab_open_panel` window registry: **Theater (audience)** = fullscreen on chosen display, audience-facing, no UI chrome. **TheaterControl (presenter)** = current slide + next preview + speaker notes + timer + ink toolbar, on the operator's display.
- State sync over the existing Tauri event bus (`slab:theater-state`) — single source of truth in a new `theater` Rust module (current_page, total_pages, ink strokes, blackout flag, spotlight rect, elapsed_ms, started_at).
- Rendering reuses the existing pdfjs canvas pipeline from `ReaderPanel.svelte`; we extract a `<TheaterCanvas>` component that takes `{ path, page, fit: "contain", interactive: false }`.
- Ink overlay is a per-page SVG layer that captures pointer events on the *presenter* window only and broadcasts strokes to audience. On exit, strokes can be saved as PDF annotations via existing `pdf::annotations::add_ink_annotation`.
- Keyboard model is presenter-native: `→/Space/PageDown` next, `←/PageUp` prev, `Home/End` jump, `B` blackout, `W` whiteout, `.` spotlight cursor toggle, `L` laser pointer toggle, `I` ink mode, `Esc` exit.

**Tech Stack:** Rust 1.86 / Tauri v2 / Svelte 5 (runes) / pdfjs-dist 4.x / existing `windows::registry` for second-display + `pdf::annotations` for ink-save.

```rust
// src-tauri/src/theater/state.rs
use serde::{Deserialize, Serialize};
use std::path::PathBuf;

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct InkStroke {
    pub page: u32,
    pub points: Vec<[f32; 2]>, // normalized 0..1 in page space
    pub color: String,         // "#ff3b30" etc.
    pub width: f32,            // px at 1x
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct TheaterState {
    pub path: PathBuf,
    pub current_page: u32,
    pub total_pages: u32,
    pub blackout: bool,
    pub whiteout: bool,
    pub laser_on: bool,
    pub ink_mode: bool,
    pub spotlight_on: bool,
    pub ink_strokes: Vec<InkStroke>,
    pub started_at_ms: u64,
}

impl TheaterState {
    pub fn new(path: PathBuf, total_pages: u32) -> Self {
        Self {
            path,
            current_page: 1,
            total_pages: total_pages.max(1),
            blackout: false,
            whiteout: false,
            laser_on: false,
            ink_mode: false,
            spotlight_on: false,
            ink_strokes: Vec::new(),
            started_at_ms: now_ms(),
        }
    }
    pub fn next(&mut self) {
        if self.current_page < self.total_pages {
            self.current_page += 1;
        }
    }
    pub fn prev(&mut self) {
        if self.current_page > 1 {
            self.current_page -= 1;
        }
    }
    pub fn jump(&mut self, page: u32) {
        self.current_page = page.clamp(1, self.total_pages);
    }
}

fn now_ms() -> u64 {
    use std::time::{SystemTime, UNIX_EPOCH};
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0)
}
```

```rust
// src-tauri/src/theater/commands.rs
use super::state::{InkStroke, TheaterState};
use serde::{Deserialize, Serialize};
use std::collections::HashMap;
use std::path::PathBuf;
use std::sync::Mutex;

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum TheaterEvent {
    Next,
    Prev,
    Jump { page: u32 },
    ToggleBlackout,
    ToggleWhiteout,
    ToggleLaser,
    ToggleInk,
    ToggleSpotlight,
    PushStroke { stroke: InkStroke },
    ClearInk,
    End,
}

pub struct TheaterRegistry {
    inner: Mutex<HashMap<String, TheaterState>>,
}

impl TheaterRegistry {
    pub fn new() -> Self {
        Self {
            inner: Mutex::new(HashMap::new()),
        }
    }
    pub fn start(&self, path: PathBuf, total_pages: u32) -> String {
        let id = format!("theater-{}", uuid_like());
        let st = TheaterState::new(path, total_pages);
        self.inner.lock().unwrap().insert(id.clone(), st);
        id
    }
    pub fn get(&self, id: &str) -> Option<TheaterState> {
        self.inner.lock().unwrap().get(id).cloned()
    }
    pub fn apply(&self, id: &str, ev: TheaterEvent) -> Result<TheaterState, String> {
        let mut g = self.inner.lock().unwrap();
        let s = g.get_mut(id).ok_or_else(|| "unknown session".to_string())?;
        match ev {
            TheaterEvent::Next => s.next(),
            TheaterEvent::Prev => s.prev(),
            TheaterEvent::Jump { page } => s.jump(page),
            TheaterEvent::ToggleBlackout => s.blackout = !s.blackout,
            TheaterEvent::ToggleWhiteout => s.whiteout = !s.whiteout,
            TheaterEvent::ToggleLaser => s.laser_on = !s.laser_on,
            TheaterEvent::ToggleInk => s.ink_mode = !s.ink_mode,
            TheaterEvent::ToggleSpotlight => s.spotlight_on = !s.spotlight_on,
            TheaterEvent::PushStroke { stroke } => s.ink_strokes.push(stroke),
            TheaterEvent::ClearInk => s.ink_strokes.clear(),
            TheaterEvent::End => {
                g.remove(id);
                return Ok(TheaterState::new("".into(), 1));
            }
        }
        Ok(s.clone())
    }
}

fn uuid_like() -> String {
    use std::time::{SystemTime, UNIX_EPOCH};
    let n = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_nanos())
        .unwrap_or(0);
    format!("{:x}", n)
}

#[tauri::command]
pub fn slab_theater_start(
    path: String,
    total_pages: u32,
    state: tauri::State<TheaterRegistry>,
) -> String {
    state.start(path.into(), total_pages)
}

#[tauri::command]
pub fn slab_theater_event(
    id: String,
    event: TheaterEvent,
    state: tauri::State<TheaterRegistry>,
) -> Result<TheaterState, String> {
    state.apply(&id, event)
}

#[tauri::command]
pub fn slab_theater_state(
    id: String,
    state: tauri::State<TheaterRegistry>,
) -> Result<TheaterState, String> {
    state.get(&id).ok_or_else(|| "unknown session".into())
}
```

Then in `src-tauri/src/lib.rs` add `.manage(theater::commands::TheaterRegistry::new())` to the Tauri builder and register the three commands in `invoke_handler![...]`.

```svelte
  import { onMount, onDestroy } from 'svelte';
  import { listen } from '@tauri-apps/api/event';
  import { invoke } from '@tauri-apps/api/core';
  import TheaterCanvas from '$lib/components/TheaterCanvas.svelte';

  const id = params.get('id') ?? '';

  let unlisten: (() => void) | null = null;

  onMount(async () => {
    state = await invoke('slab_theater_state', { id });
    unlisten = await listen<any>('slab:theater-state', (e) => {
      if (e.payload?.id === id) state = e.payload.state;
    });
  });
  onDestroy(() => unlisten?.());
</script>

<div class="theater-root" class:blackout={state?.blackout} class:whiteout={state?.whiteout}>

            stroke-width={stroke.width / 1000}
            fill="none"
            stroke-linecap="round"
            stroke-linejoin="round"
          />

  {/if}
</div>

<style>
```

```ts
function handleKey(e: KeyboardEvent) {
  const map: Record<string, any> = {
    'ArrowRight': { kind: 'next' }, ' ': { kind: 'next' }, 'PageDown': { kind: 'next' },
    'ArrowLeft':  { kind: 'prev' }, 'PageUp':    { kind: 'prev' },
    'Home': { kind: 'jump', page: 1 },
    'End':  { kind: 'jump', page: state.total_pages },
    'b': { kind: 'toggle_blackout' }, 'B': { kind: 'toggle_blackout' },
    'w': { kind: 'toggle_whiteout' }, 'W': { kind: 'toggle_whiteout' },
    'l': { kind: 'toggle_laser' },    'L': { kind: 'toggle_laser' },
    'i': { kind: 'toggle_ink' },      'I': { kind: 'toggle_ink' },
    '.': { kind: 'toggle_spotlight' },
    'Escape': { kind: 'end' },
  };
  const ev = map[e.key];
  if (!ev) return;
  e.preventDefault();
  invoke('slab_theater_event', { id, event: ev }).then((s) => {
    state = s;
    emitTheaterState(id, s);
  });
}
```

`emitTheaterState` is a Rust helper added in `theater::commands` that emits `slab:theater-state` to all windows via `AppHandle::emit_all`.
