## Task 2: Add `slab lens tables <file> <page>` CLI command

**Objective:** Print all tables on `<page>` as CSV separated by `--- table N ---` markers.

**Args:** `slab lens tables <file> <page> [--min-rows N] [--min-cols N] [-o <out.csv>]`

**Behavior:**
- If `-o` not given → print all CSVs to stdout with delimiters.
- If `-o` given AND only 1 table → write that CSV.
- If `-o` given AND ≥2 tables → write `<stem>_t1.csv`, `<stem>_t2.csv`, ... and print the paths.

**Verification:** Errors when `pdftotext` is missing surface the same friendly message as the GUI.

## Task 3: Add `slab lens ocr-queue <subcmd>` CLI command

**Objective:** Operate on the Library OCR queue from the CLI.

**Subcommands:**
- `slab lens ocr-queue list` — pretty-print docs whose `ocr_state` ∈ {`scanned`, `mixed`}.
- `slab lens ocr-queue run <doc-id> [--lang eng] [--dpi 300]` — run OCR on one doc.
- `slab lens ocr-queue run-all [--lang eng] [--dpi 300]` — drain the queue.

**Output:** Each `run` line: `✓ ocr'd <path> → <output>` or `✗ failed <path>: <error>`. End: summary `K succeeded, F failed`.

**Verification:** With empty `~/.slab/library.sqlite`, `list` returns "no docs pending OCR".

## Task 4: Add `slab lens auto-tag <subcmd>` CLI command

**Objective:** Generate AI tags for library docs via Beacon provider.

**Subcommands:**
- `slab lens auto-tag <doc-id> [--max-tags 5]` — auto-tag one doc.
- `slab lens auto-tag --all [--max-tags 5]` — auto-tag every doc in the registry.

**Async:** Both invoke `tokio::runtime::Runtime::new().unwrap().block_on(auto_tag::run_one(...))` since `auto_tagger::run_one` is async. Provider built via `ai::config::load() → make_provider()`.

**Output:** `✓ doc <id>: <comma-joined tags>` or `✗ doc <id>: <error>`. End: summary.

**Verification:** Friendly error when Ollama is not running.
