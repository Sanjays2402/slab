# v2.0.5 "Bookmarks" Implementation Plan

> **For Hermes (Cake / cron):** Execute via subagent-driven-development —
> one fresh subagent per slice, two-stage review (spec compliance → code
> quality), proceed only when both pass.
>
> **Branch:** `feature/v2.0.5-bookmarks` (cut from `main` AFTER v2.0.4
> ships; see scheduling note at the end of this plan).

**Goal:** Slab gains real, persistent, per-document bookmarks. Press
`Cmd+D` on any page to drop a bookmark; a thumbnailed right-rail sidebar
lists every bookmark in the doc, lets you rename inline, drag to reorder,
and jump with a single click. The command palette gains three entries
(bookmark this page, jump to bookmark…, manage bookmarks). Adobe
Acrobat, PDF Expert, and Foxit all ship per-page user bookmarks —
Slab today only exposes the PDF's *embedded* outline (read-only TOC).
v2.0.4 "Memory" closed the "last-page" gap; v2.0.5 closes the
companion "save-my-spot" gap.

**Architecture (3 sentences):**
- Pure-frontend, no Tauri/Rust changes: a new `src/lib/bookmarks.ts`
  module owns a per-path `Bookmark[]` shape persisted to
  `localStorage` under `slab.bookmarks.v1` (mirrors the
  `readingPosition.ts` pattern from v2.0.4 — same eviction policy, same
  defensive write-with-retry).
- `ReaderPanel.svelte` grows a new `bookmarksOpen` sidebar toggle (next
  to the existing thumbs/outline toggles), a `Mod+D` action that
  appends/removes the current page from the active doc's bookmark
  list, and an inline edit-rename input on each sidebar entry.
- Drag-to-reorder is the WOW: bookmarks use the native HTML5 drag API
  with a 220ms ease-out slot animation; reordering writes back to the
  store immediately. Three new command-palette entries
  (`bookmarks.add`, `bookmarks.jump`, `bookmarks.manage`) keep the
  feature reachable in two keystrokes.

**Tech Stack:**
- Frontend only: Svelte 5 runes, existing localStorage helpers, existing
  `notify.ts`, existing `t()` i18n. **No new runtime dependencies.**
- One new keymap action (`bookmarks.toggle`, default `Mod+D`) — adds
  one `ActionId` variant + one `ACTIONS` row in
  `src-tauri/src/keymap/action.rs` (tiny Rust touch — see Slice 5).
- No new Tauri commands. No SQLite. No IPC.

**Buy-Button verdict (release level):**
- **Pick-us PASS** — Adobe / PDF Expert / Foxit all ship per-page user
  bookmarks. Slab today maps `Cmd+D` to nothing in the Reader and
  bookmarks have *zero* UI affordance. A returning user who tried
  Slab and noticed "I can't even save my place across sessions like
  Acrobat" will install one of the paid products instead. Closing
  this gap is a hard prerequisite for the v1.0.0 launch narrative.
- **Notice-it PASS** — Anyone who upgrades and reopens any document
  sees a new ⌘D toolbar button, a new "⊕ Bookmarks" sidebar toggle,
  and three new command-palette entries the moment they open Slab.
- **Tell-a-friend PASS** — Drag-to-reorder bookmarks with thumbnail
  previews and inline rename is genuinely uncommon in free PDF
  readers. /r/macapps + HN-grade screenshot of "my Slab bookmarks
  sidebar with thumbnails — try doing this in Preview."

**WOW moment (Slice 4):** Press `Cmd+D` on page 47 of a 312-page PDF.
The right-rail bookmarks sidebar springs open with a frosted-glass
slot containing a live page-47 thumbnail, "Page 47" as the auto-name
in an inline-editable text field, and the timestamp. Cmd+D again
removes it. Open three more bookmarks at pages 12, 200, 290; grab
the page-47 slot and drag it above page-12 — the slots slide with a
220ms ease-out and the new order persists. Click any slot → instant
jump. **That's "saving my spot" as a designed surface, not an
afterthought.**

## Slice 1: `src/lib/bookmarks.ts` — pure-TS store (~170 LOC)

**Objective:** A standalone, dependency-free per-path bookmark store
with the same shape, eviction policy, and defensive-write semantics
as `readingPosition.ts` from v2.0.4.

**Files:**
- Create: `src/lib/bookmarks.ts`

**Step 1.1: Write the module**

```ts
// src/lib/bookmarks.ts
//
// Per-document user bookmarks, persisted to localStorage under
// `slab.bookmarks.v1`. Keyed by absolute file path. Each bookmark is
// `{ id, page, name, createdAt }` — id is a per-path monotonic counter
// (collision-free without crypto.randomUUID), name is user-editable
// and defaults to "Page <N>", page is 1-indexed.
//
// Eviction: each path keeps at most BOOKMARK_LIMIT_PER_DOC entries
// (default 100). Cross-path cap = MAX_TOTAL_BOOKMARKS (default 2_000)
// — when total exceeds the cap, oldest documents (by openedAt in
// `slab.recent.v1`) shed first.
//
// Subscriptions: `subscribeBookmarks(path, fn)` returns an
// unsubscribe; `fn` fires with the current list any time *that path's*
// bookmarks change. Listeners for other paths are not woken.

const KEY = "slab.bookmarks.v1";
const BOOKMARK_LIMIT_PER_DOC = 100;
const MAX_TOTAL_BOOKMARKS = 2_000;

export type Bookmark = {
  id: number;
  page: number;
  name: string;
  createdAt: number;
};

type Store = Record<string, Bookmark[]>;
type Listener = (list: Bookmark[]) => void;

const listeners = new Map<string, Set<Listener>>();

function read(): Store {
  if (typeof localStorage === "undefined") return {};
  try {
    const raw = localStorage.getItem(KEY);
    if (!raw) return {};
    const parsed = JSON.parse(raw) as Store;
    if (!parsed || typeof parsed !== "object") return {};
    return parsed;
  } catch {
    return {};
  }
}

function write(store: Store) {
  if (typeof localStorage === "undefined") return;
  try {
    localStorage.setItem(KEY, JSON.stringify(store));
  } catch {
    // Quota crash — drop half the paths (oldest first by lowest
    // bookmark createdAt) and retry once. Same belt-and-braces as
    // readingPosition.ts.
    try {
      const halved = pruneStore(store, Math.floor(Object.keys(store).length / 2));
      localStorage.setItem(KEY, JSON.stringify(halved));
    } catch {
      // Give up. Bookmarks are not load-bearing; better to drop than crash.
    }
  }
}

function pruneStore(store: Store, dropCount: number): Store {
  if (dropCount <= 0) return store;
  const entries = Object.entries(store).map(([path, list]) => {
    const earliest = list.reduce(
      (min, b) => Math.min(min, b.createdAt),
      Number.POSITIVE_INFINITY,
    );
    return [path, list, earliest] as const;
  });
  entries.sort((a, b) => a[2] - b[2]);
  const kept = entries.slice(dropCount);
  return Object.fromEntries(kept.map(([p, list]) => [p, list]));
}

function notify(path: string, list: Bookmark[]) {
  const set = listeners.get(path);
  if (!set) return;
  for (const fn of set) {
    try {
      fn(list);
    } catch (e) {
      // Listener bugs must not break the store.
      console.warn("[slab/bookmarks] listener threw", e);
    }
  }
}

function nextId(list: Bookmark[]): number {
  let max = 0;
  for (const b of list) if (b.id > max) max = b.id;
  return max + 1;
}

function clampPage(page: number): number {
  if (!Number.isFinite(page)) return 1;
  return Math.max(1, Math.floor(page));
}

/** Return the bookmarks for `path` (empty array if none). */
export function listBookmarks(path: string): Bookmark[] {
  const store = read();
  return store[path] ? [...store[path]] : [];
}

/**
 * Append a new bookmark at `page`. Returns the created bookmark.
 * No-op (returns existing) if a bookmark already exists at the same
 * page for this path — Cmd+D twice on the same page = idempotent.
 */
export function addBookmark(
  path: string,
  page: number,
  name?: string,
): Bookmark {
  const store = read();
  const list = store[path] ? [...store[path]] : [];
  const p = clampPage(page);
  const existing = list.find((b) => b.page === p);
  if (existing) return existing;
  const bookmark: Bookmark = {
    id: nextId(list),
    page: p,
    name: name?.trim() || `Page ${p}`,
    createdAt: Date.now(),
  };
  list.push(bookmark);
  // Per-doc cap: drop the oldest if we're over the limit.
  if (list.length > BOOKMARK_LIMIT_PER_DOC) {
    list.sort((a, b) => a.createdAt - b.createdAt);
    list.splice(0, list.length - BOOKMARK_LIMIT_PER_DOC);
  }
  store[path] = list;
  // Cross-path cap
  const total = Object.values(store).reduce((n, l) => n + l.length, 0);
  if (total > MAX_TOTAL_BOOKMARKS) {
    const pruned = pruneStore(store, 1);
    write(pruned);
    notify(path, pruned[path] ?? list);
    return bookmark;
  }
  write(store);
  notify(path, list);
  return bookmark;
}

/** Remove the bookmark at `page`. Returns true if one existed. */
export function removeBookmarkAtPage(path: string, page: number): boolean {
  const store = read();
  const list = store[path];
  if (!list || list.length === 0) return false;
  const next = list.filter((b) => b.page !== clampPage(page));
  if (next.length === list.length) return false;
  if (next.length === 0) {
    delete store[path];
  } else {
    store[path] = next;
  }
  write(store);
  notify(path, next);
  return true;
}

/** Remove the bookmark with the given id. */
export function removeBookmarkById(path: string, id: number): boolean {
  const store = read();
  const list = store[path];
  if (!list) return false;
  const next = list.filter((b) => b.id !== id);
  if (next.length === list.length) return false;
  if (next.length === 0) delete store[path];
  else store[path] = next;
  write(store);
  notify(path, next);
  return true;
}

/** True iff a bookmark exists at `page` for `path`. */
export function isBookmarked(path: string, page: number): boolean {
  return listBookmarks(path).some((b) => b.page === clampPage(page));
}

/** Toggle a bookmark at `page` — add if missing, remove if present. */
export function toggleBookmark(path: string, page: number, name?: string): boolean {
  if (isBookmarked(path, page)) {
    removeBookmarkAtPage(path, page);
    return false;
  }
  addBookmark(path, page, name);
  return true;
}

/** Rename the bookmark with the given id. Empty name → resets to "Page N". */
export function renameBookmark(path: string, id: number, name: string): boolean {
  const store = read();
  const list = store[path];
  if (!list) return false;
  let touched = false;
  const next = list.map((b) => {
    if (b.id !== id) return b;
    touched = true;
    const trimmed = name.trim();
    return { ...b, name: trimmed || `Page ${b.page}` };
  });
  if (!touched) return false;
  store[path] = next;
  write(store);
  notify(path, next);
  return true;
}

/**
 * Reorder the bookmark list for `path`. `orderedIds` must be a
 * permutation of the current list's ids — extras are ignored,
 * missing ids are appended at the end in original order.
 */
export function reorderBookmarks(path: string, orderedIds: number[]): boolean {
  const store = read();
  const list = store[path];
  if (!list || list.length === 0) return false;
  const byId = new Map(list.map((b) => [b.id, b] as const));
  const next: Bookmark[] = [];
  const seen = new Set<number>();
  for (const id of orderedIds) {
    const b = byId.get(id);
    if (!b || seen.has(id)) continue;
    next.push(b);
    seen.add(id);
  }
  for (const b of list) {
    if (!seen.has(b.id)) next.push(b);
  }
  store[path] = next;
  write(store);
  notify(path, next);
  return true;
}

/** Subscribe to bookmark changes for `path`. Returns an unsubscribe. */
export function subscribeBookmarks(
  path: string,
  fn: Listener,
): () => void {
  let set = listeners.get(path);
  if (!set) {
    set = new Set();
    listeners.set(path, set);
  }
  set.add(fn);
  // Fire once with the current snapshot so subscribers don't have to
  // pull manually after subscribing.
  try {
    fn(listBookmarks(path));
  } catch (e) {
    console.warn("[slab/bookmarks] initial listener threw", e);
  }
  return () => {
    set!.delete(fn);
    if (set!.size === 0) listeners.delete(path);
  };
}

/** Total bookmark count across all documents (for telemetry/UI badges). */
export function totalBookmarkCount(): number {
  const store = read();
  return Object.values(store).reduce((n, l) => n + l.length, 0);
}

// Limits exposed for tests + tuning.
export const __INTERNAL = {
  KEY,
  BOOKMARK_LIMIT_PER_DOC,
  MAX_TOTAL_BOOKMARKS,
};
```

```ts
  // v2.0.5 — render a small bookmark thumbnail. Returns a JPEG data
  // URL sized so the longest side is `maxSide` px. Uses the same
  // pdfjs `getPage(...).render(...)` path as the thumbs sidebar so
  // we don't ship a parallel thumbnail pipeline. Returns null on any
  // failure — the slot then renders a placeholder.
  async function renderBookmarkThumb(
    pageNum: number,
    maxSide: number = 120,
  ): Promise<string | null> {
    if (!pdfDoc) return null;
    try {
      const page = await pdfDoc.getPage(pageNum);
      const baseVp = page.getViewport({ scale: 1 });
      const scale = maxSide / Math.max(baseVp.width, baseVp.height);
      const vp = page.getViewport({ scale });
      const canvas = document.createElement("canvas");
      canvas.width = Math.floor(vp.width);
      canvas.height = Math.floor(vp.height);
      const ctx = canvas.getContext("2d");
      if (!ctx) return null;
      await page.render({ canvasContext: ctx, viewport: vp }).promise;
      return canvas.toDataURL("image/jpeg", 0.7);
    } catch (e) {
      console.warn("[slab/bookmarks] thumb render failed", e);
      return null;
    }
  }

  // Cache thumbs per page — re-rendering on every list-update flicker
  // would be miserable. Invalidate the cache on doc tear-down.
  let bookmarkThumbs = $state<Record<number, string>>({});

  async function ensureBookmarkThumb(pageNum: number) {
    if (bookmarkThumbs[pageNum]) return;
    const url = await renderBookmarkThumb(pageNum);
    if (url) bookmarkThumbs = { ...bookmarkThumbs, [pageNum]: url };
  }
```

**Step 4.1: Drag state**

In `<script>` near the other bookmark state:

```ts
  // v2.0.5 Slice 4 — drag-to-reorder
  let dragId = $state<number | null>(null);
  let dragOverIndex = $state<number | null>(null);
  // Whether the user is hovering above (insert before) or below
  // (insert after) the target slot — derived from pointer Y within
  // the row.
  let dragInsertPos = $state<"before" | "after">("before");

  function onBmDragStart(e: DragEvent, b: Bookmark) {
    if (!e.dataTransfer) return;
    dragId = b.id;
    e.dataTransfer.effectAllowed = "move";
    // Required for Firefox: must call setData with something, even if
    // we don't use it on drop.
    e.dataTransfer.setData("application/x-slab-bookmark", String(b.id));
  }

  function onBmDragOver(e: DragEvent, targetIndex: number) {
    if (dragId == null) return;
    e.preventDefault();
    if (e.dataTransfer) e.dataTransfer.dropEffect = "move";
    const target = e.currentTarget as HTMLElement;
    const rect = target.getBoundingClientRect();
    const midY = rect.top + rect.height / 2;
    dragInsertPos = e.clientY < midY ? "before" : "after";
    dragOverIndex = targetIndex;
  }

  function onBmDragLeave() {
    // Only clear if we're actually leaving the list — leaving for an
    // adjacent slot is fine because the next dragover fires immediately.
    // Use a microtask to give the next dragover a chance to claim.
    queueMicrotask(() => {
      // If no new dragover claimed the index, clear it.
      // We can't tell from here — let the next dragover overwrite or
      // the drop / dragend clear it.
    });
  }

  function onBmDrop(e: DragEvent) {
    e.preventDefault();
    if (dragId == null || dragOverIndex == null || !currentPath) {
      dragId = null;
      dragOverIndex = null;
      return;
    }
    const draggedIdx = bookmarks.findIndex((b) => b.id === dragId);
    if (draggedIdx === -1) {
      dragId = null;
      dragOverIndex = null;
      return;
    }
    // Compute the new id order.
    const ids = bookmarks.map((b) => b.id);
    const [moved] = ids.splice(draggedIdx, 1);
    // Adjust target index for the removed item if it was earlier.
    let insertAt = dragOverIndex;
    if (draggedIdx < dragOverIndex) insertAt -= 1;
    if (dragInsertPos === "after") insertAt += 1;
    insertAt = Math.max(0, Math.min(ids.length, insertAt));
    ids.splice(insertAt, 0, moved);
    void import("$lib/bookmarks").then(({ reorderBookmarks }) => {
      reorderBookmarks(currentPath!, ids);
    });
    dragId = null;
    dragOverIndex = null;
  }

  function onBmDragEnd() {
    dragId = null;
    dragOverIndex = null;
  }
```

## Risk + rollback

**Risk: `Mod+D` already claimed by the OS or by another app inside a
WebView.**
On macOS, `Cmd+D` is "Bookmark page" in every browser — Slab using it
is the most natural default. On Linux, `Ctrl+D` is "bookmark" in
Firefox too. If a user reports the binding conflicts with something
(unlikely, but possible inside a Tauri WebView with a specific OS
config), they can remap via Settings → Shortcuts because v2.0.5 added
it as a real keymap action, not a hardcoded handler.

**Risk: drag-and-drop misfires on touch / iPad layouts.**
The HTML5 drag API is mouse-first. Touch-event support is wider in
2026 but not universal. The drag handlers all gate on
`renamingId == null` and a `DataTransfer` check — if `dataTransfer`
is null, the handler bails. Worst case: drag doesn't work on a
touchscreen, but the bookmarks are still toggleable + clickable. A
future v2.0.6 polish can add `pointerdown` + manual reorder buttons
for touch users.

**Risk: `renderBookmarkThumb` blocks the UI while a giant page
rasterizes.**
The render is `await page.render(…).promise` — async but heavy. For
a 400-page text-heavy PDF, a single page renders in ~50 ms at
maxSide=120. The cache (`bookmarkThumbs`) means we only render each
page once per session. If a bookmark sidebar with 50 entries opens
and triggers 50 simultaneous renders, the user might see a brief
stutter — acceptable for a one-time cost, but if we hear complaints
in the field we can add a `Promise` queue around `ensureBookmarkThumb`
in v2.0.6.

**Risk: localStorage quota crash with 2000 entries.**
`bookmarks.ts` write() catches QuotaExceededError, prunes half the
docs (oldest first by earliest bookmark createdAt), and retries.
Worst case the user loses bookmarks for ~half of their recent
documents. The key is namespaced (`slab.bookmarks.v1`) so a future
migration to SQLite is a one-time copy.

**Risk: surface collision with concurrent v2.0.2 / v2.0.3 / v2.0.4
PRs on `ReaderPanel.svelte` / `CommandPalette.svelte` /
`i18n/en.json`.**
See "Scheduling note" below — serialize releases, don't parallelize.
