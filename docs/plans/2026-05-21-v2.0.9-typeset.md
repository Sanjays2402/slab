# v2.0.9 "Typeset" 📝 — FreeText (Typewriter) Annotation Implementation Plan

> **For Hermes:** Use `subagent-driven-development` to implement this plan task-by-task. Each slice = one delegated subagent. Two-stage review (spec compliance, then code quality) between slices.

**Goal:** Add the fifth annotation primitive — **free-floating editable text boxes** ("typewriter" annotations in Acrobat parlance) — joining Highlight + Note (v2.0.6), Ink (v2.0.7), and the four Shapes (v2.0.8). Closes the last table-stakes markup-toolkit gap vs Adobe Acrobat / PDF Expert / Foxit / Drawboard, all of which ship Typewriter as a paid feature.

**Architecture:** Pure additive variant extension of the v2.0.6 → v2.0.8 stack. Existing `Annotation` tagged union (Rust) and `annotations.ts` discriminated union (TS) gain ONE new variant — `FreeText` / `kind: "freetext"` — carrying `pdfRect` + `text` + font metadata (`family`, `size`, `color`, `bold`, `italic`, `align`). `DrawLayer.svelte` gains a sub-mode that drops a focused contenteditable `<div>` overlay; commit on `Enter`-without-shift / blur / `Esc`-cancel. Persisted via the same v2.0.6 per-doc sidecar JSON (200/doc, 3000/total eviction). Rust serialization emits ISO 32000-1 §12.5.6.6 `/FreeText` annotation dicts with `/DA`, `/Q`, and `/Contents`. Zero new persistence layers, zero new Tauri commands, zero new third-party deps.

**Tech Stack:** Svelte 4 (frontend), Rust 1.78 / Tauri 2 (backend), `lopdf 0.32` (PDF emission), pure-TS contenteditable + IME-safe `compositionend` handling, pdfjs-dist 4 `eventBus.pagerendered` (existing). No rich-text editor library — plain text with font-family + size + color + bold + italic + alignment is feature-parity with Acrobat's Typewriter, and a ProseMirror-tier dependency is YAGNI.

**Codename:** "Typeset" 📝 — drop text anywhere on the page, the way a typesetter pastes a correction strip on a galley proof.

**Buy-Button verdict (release level):**
- **Pick-us PASS** — Acrobat ($239/yr), PDF Expert ($79/yr), Foxit ($129/yr), Drawboard ($69/yr), and Bluebeam ($349/yr) all ship Typewriter as a core markup tool. Slab today ships zero. **Step 1: Write the failing test (~210 LOC).**

Cover, in order:
1. `addFreeTextAnnotation(path, page, pdfRect, text, fontSpec)` round-trips and returns an `id` matching `/^freetext-/`.
2. `updateFreeTextAnnotation(id, newText)` mutates the stored record and bumps an `updatedAt` epoch-ms field (so React-style consumers can dedupe).
3. Empty text (`""`) is **rejected** — passing `""` returns `null` instead of creating a phantom record (otherwise we'd litter the page on every accidental click).
4. Text is normalized to **NFC** before storage (so paste-in-from-Word `é` (U+00E9) and combining `e + ́` (U+0065 U+0301) compare equal).
5. Font family must be in the whitelist `{"Helvetica" | "Times-Roman" | "Courier" | "system-ui"}` — anything else throws `TypeError`. (PDF standard fonts only; `system-ui` is the in-app preview-only fallback that exports as Helvetica.)
6. Font size clamped to `[6, 144]` PDF-pt; out-of-range clamps with a warning, doesn't throw.
7. Color clamped to 6-digit hex (matches v2.0.6/v2.0.7/v2.0.8 convention); 8-digit alpha hex rejected with `TypeError`.
8. `align` ∈ `{"left" | "center" | "right"}`; default `"left"`; anything else throws.
9. `bold` and `italic` are independent booleans, both default `false`.
10. The 200/doc + 3000-total eviction cap from v2.0.6 still applies; eviction is kind-agnostic.
11. Each FreeText survives a JSON `serialize → parse` round trip.
12. `subscribeAnnotations(path)` fires when a FreeText is added AND when it is updated (one-call-per-mutation contract).
13. `clearAnnotations(path)` removes FreeTexts too.
14. `exportAnnotations(path)` produces a stable JSON envelope including FreeTexts with all font metadata.

```typescript
export const FREETEXT_FONT_FAMILIES = ["Helvetica", "Times-Roman", "Courier", "system-ui"] as const;
export type FreeTextFontFamily = typeof FREETEXT_FONT_FAMILIES[number];
export type FreeTextAlign = "left" | "center" | "right";

export interface FreeTextFontSpec {
  family: FreeTextFontFamily;
  size: number;          // 6..144 PDF-pt
  color: string;         // "#rrggbb"
  bold: boolean;
  italic: boolean;
  align: FreeTextAlign;
}

export interface FreeTextAnnotation extends AnnotationBase {
  kind: "freetext";
  pdfRect: PdfRect;
  text: string;          // NFC-normalized, non-empty
  font: FreeTextFontSpec;
}

// Extend the union:
export type Annotation =
  | HighlightAnnotation
  | NoteAnnotation
  | InkAnnotation
  | RectAnnotation
  | EllipseAnnotation
  | ArrowAnnotation
  | LineAnnotation
  | FreeTextAnnotation;

const HEX6 = /^#[0-9a-fA-F]{6}$/;
const ALIGNS: FreeTextAlign[] = ["left", "center", "right"];

export function addFreeTextAnnotation(
  path: string, page: number, pdfRect: PdfRect, text: string, font: FreeTextFontSpec,
): string | null {
  const nfc = text.normalize("NFC");
  if (nfc.length === 0) return null;
  if (!FREETEXT_FONT_FAMILIES.includes(font.family))
    throw new TypeError(`Unknown font family: ${font.family}`);
  if (!HEX6.test(font.color))
    throw new TypeError(`color must be 6-digit hex, got ${font.color}`);
  if (!ALIGNS.includes(font.align))
    throw new TypeError(`Unknown align: ${font.align}`);

  const size = clamp(font.size, 6, 144);
  if (size !== font.size) console.warn(`[freetext] clamped size ${font.size} → ${size}`);

  const rec: FreeTextAnnotation = {
    id: `freetext-${crypto.randomUUID()}`,
    kind: "freetext",
    path, page, pdfRect,
    text: nfc,
    font: { ...font, size },
    createdAt: Date.now(),
    updatedAt: Date.now(),
  };
  pushAnnotation(rec);
  return rec.id;
}

export function updateFreeTextAnnotation(id: string, newText: string): void {
  const nfc = newText.normalize("NFC");
  mutateAnnotation(id, (a) => {
    if (a.kind !== "freetext") throw new TypeError(`${id} is not a freetext`);
    a.text = nfc;
    a.updatedAt = Date.now();
  });
}
```

// in Annotation enum:
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum Annotation {
    Highlight { /* … */ },
    Note      { /* … */ },
    Ink       { /* … */ },
    Rect      { /* … */ },
    Ellipse   { /* … */ },
    Arrow     { /* … */ },
    Line      { /* … */ },
    FreeText {
        page: u32,
        rect: [f32; 4],                 // [llx, lly, urx, ury] in PDF-pt
        contents: String,               // NFC, non-empty
        font_family: String,            // "Helvetica" | "Times-Roman" | "Courier" | "system-ui"
        font_size: f32,                 // 6..144
        color: [f32; 3],                // RGB 0..1
        bold: bool,
        italic: bool,
        align: FreeTextAlign,
    },
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum FreeTextAlign { Left, Center, Right }

// in build_annotation_dict():
Annotation::FreeText { page, rect, contents, font_family, font_size, color, bold, italic, align } => {
    let mut dict = lopdf::Dictionary::new();
    dict.set("Type",    lopdf::Object::Name(b"Annot".to_vec()));
    dict.set("Subtype", lopdf::Object::Name(b"FreeText".to_vec()));
    dict.set("Rect", lopdf::Object::Array(rect.iter().map(|f| lopdf::Object::Real(*f)).collect()));
    dict.set("Contents", lopdf::Object::string_literal(contents.as_str()));
    dict.set("Q", lopdf::Object::Integer(match align {
        FreeTextAlign::Left => 0, FreeTextAlign::Center => 1, FreeTextAlign::Right => 2,
    }));
    // DA: default appearance string per §12.5.6.2
    let font_code = match font_family.as_str() {
        "Helvetica"   => "/Helv",
        "Times-Roman" => "/TiRo",
        "Courier"     => "/Cour",
        _             => "/Helv",      // system-ui falls back to Helvetica on burn
    };
    let da = format!("{font_code} {font_size} Tf {} {} {} rg", color[0], color[1], color[2]);
    dict.set("DA", lopdf::Object::string_literal(da));
    dict.set("F",  lopdf::Object::Integer(4));   // /Print flag
    // bold/italic encoded into font_code in v2.0.10 (defer — needs /Resources font sub-dict)
    let _ = (bold, italic);                       // suppress unused warnings
    dict
}

  export let subMode: DrawSubMode;   // existing union + "freetext"

  type DrawSubMode = "ink" | "rect" | "ellipse" | "arrow" | "line" | "freetext";

  let activeEditor: { x: number; y: number; el: HTMLDivElement } | null = null;
  let composing = false;

  function onPointerDown(ev: PointerEvent) {
    if (subMode !== "freetext") return;  // existing modes handle themselves
    if (activeEditor) commitActive();    // clicking elsewhere commits in-flight
    const layer = ev.currentTarget as HTMLDivElement;
    const rect = layer.getBoundingClientRect();
    activeEditor = { x: ev.clientX - rect.left, y: ev.clientY - rect.top, el: null! };
    requestAnimationFrame(() => activeEditor?.el?.focus());
  }

  function onKeyDown(ev: KeyboardEvent) {
    if (ev.key === "Escape")  { cancelActive(); ev.preventDefault(); return; }
    if (ev.key === "Enter" && !ev.shiftKey && !composing) {
      commitActive();
      ev.preventDefault();
    }
  }

  function onBlur() {
    if (activeEditor && activeEditor.el.innerText.trim().length > 0) commitActive();
    else cancelActive();
  }

  function commitActive() {
    if (!activeEditor) return;
    const text = activeEditor.el.innerText;
    const pdfRect = computePdfRectFromCss(activeEditor.x, activeEditor.y, activeEditor.el);
    const fontSpec = {
      family:  $settings.annotations.text.fontFamily,
      size:    $settings.annotations.text.fontSize,
      color:   $settings.annotations.text.color,
      bold:    $settings.annotations.text.bold,
      italic:  $settings.annotations.text.italic,
      align:   $settings.annotations.text.align,
    };
    const id = addFreeTextAnnotation(path, page, pdfRect, text, fontSpec);
    activeEditor = null;
    if (id) animateTypeIn(id);  // 220ms fade-in
  }

  function cancelActive() { activeEditor = null; }
</script>

<div class="draw-layer" on:pointerdown={onPointerDown}>
  {#if activeEditor && subMode === "freetext"}
    <div class="freetext-editor"
         contenteditable="true"
         bind:this={activeEditor.el}
         on:keydown={onKeyDown}
         on:blur={onBlur}
         on:compositionstart={() => composing = true}
         on:compositionend={() => composing = false}
         style="left:{activeEditor.x}px; top:{activeEditor.y}px;
                font-family: {$settings.annotations.text.fontFamily};
                font-size:   {$settings.annotations.text.fontSize}px;
                color:       {$settings.annotations.text.color};
                text-align:  {$settings.annotations.text.align};
                font-weight: {$settings.annotations.text.bold ? 'bold' : 'normal'};
                font-style:  {$settings.annotations.text.italic ? 'italic' : 'normal'};" />
  {/if}
  <!-- persistent FreeText painter rendered by ReaderPanel via pagerendered -->
</div>

function autofit(el: HTMLDivElement) {
  let size = $settings.annotations.text.fontSize;
  el.style.fontSize = `${size}px`;
  const maxW = el.parentElement!.clientWidth - el.offsetLeft - 8;
  while (el.scrollWidth > maxW && size > 6) {
    size -= 0.5;
    el.style.fontSize = `${size}px`;
  }
  if (size === 6 && el.scrollWidth > maxW) {
    // floor reached — grow the box height instead
    el.style.minWidth = `${maxW}px`;
    el.style.whiteSpace = "pre-wrap";

}

## Open questions for Sanjay

- **Resizable bounding box** — drag the bottom-right corner to manually resize the text box? Plan defers to v2.0.10 (needs a selection / edit-mode UX). v2.0.9 ships autofit-on-overflow as the primary sizing affordance.

- **Multi-line auto-shrink ceiling** — currently no max-height; long text grows indefinitely down the page. Should we cap at, say, page height − 20pt and force size-shrink before growing further? Plan ships unbounded growth; v2.0.10 can add a cap if reviewers complain.
- **Drag-to-move an existing FreeText** — once committed, the box is positioned permanently. Move would require a selection layer (also wanted by v2.0.6 highlights). Plan defers to v2.0.10's selection-handle pass.
