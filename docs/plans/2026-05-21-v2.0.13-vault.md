**Goal:** Replace Slab's visible-only "paint a black bar" redaction with **true
content-stream surgery** — text glyphs and image regions that fall under a
redaction rect are *physically deleted* from the PDF before re-saving. The
file no longer contains the redacted content, even when fed to a hex editor,
`pdftotext`, or another viewer.

**Architecture:** Three layers stitched into the existing redact module:

1. **Tokenizer (Rust, pure, no deps)** — walk every page content stream we
   touch, decode text-showing ops (`Tj`, `TJ`, `'`, `"`), maintain the CTM
   (current transformation matrix) + text matrix + Tm/Td state, and emit a
   stream of `(glyph_bbox, byte_span)` events. Reuses `lopdf::content::Content`
   for parse/encode roundtripping; we rewrite operands in-place.
2. **Surgery pass (Rust, pure)** — for each event, test bbox-overlap against
   user rects; for overlapping glyphs, replace the operand bytes with the
   empty literal `()` (zero-width) or splice the array entry out of `TJ`. For
   image XObjects whose painted bbox overlaps, replace `/XObject` invocation
   with a no-op `q Q` pair and strip the resource if no longer referenced.
3. **Polish layer (Rust + Svelte)** — annotation scrub (delete `/Annots` whose
   `/Rect` overlaps), metadata strip (`/Author`, `/Title`, `/Subject`,
   `/Keywords`, custom keys), then re-paint the opaque black bar on top so the
   rendered output is still visually redacted, plus an **8-step Vault-Door CSS
   wipe animation** on commit and an **X-ray reveal hover** that shows what
   *was* removed (pre-save only, in-app, never persisted).

**Tech Stack:** Rust (`lopdf 0.40` already pulled), Svelte 5 runes, CSS

```rust
// src-tauri/src/pdf/vault/tokenizer.rs
use crate::pdf::PdfError;
use lopdf::content::{Content, Operation};
use lopdf::Object;

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Bbox {
    pub x0: f32,
    pub y0: f32,
    pub x1: f32,
    pub y1: f32,
}

#[derive(Debug, Clone, Copy)]
pub struct Mat3 {
    pub a: f32, pub b: f32, pub c: f32,
    pub d: f32, pub e: f32, pub f: f32,
}

impl Mat3 {
    pub const IDENT: Mat3 = Mat3 { a: 1.0, b: 0.0, c: 0.0, d: 1.0, e: 0.0, f: 0.0 };

    pub fn mul(self, other: Mat3) -> Mat3 {
        Mat3 {
            a: self.a*other.a + self.b*other.c,
            b: self.a*other.b + self.b*other.d,
            c: self.c*other.a + self.d*other.c,
            d: self.c*other.b + self.d*other.d,
            e: self.e*other.a + self.f*other.c + other.e,
            f: self.e*other.b + self.f*other.d + other.f,
        }
    }

    pub fn translate(self, tx: f32, ty: f32) -> Mat3 {
        self.mul(Mat3 { a: 1.0, b: 0.0, c: 0.0, d: 1.0, e: tx, f: ty })
    }

    pub fn map_point(self, x: f32, y: f32) -> (f32, f32) {
        (self.a*x + self.c*y + self.e, self.b*x + self.d*y + self.f)
    }
}

#[derive(Debug, Clone)]
pub struct GlyphEvent {
    pub op_index: usize,        // index into Content.operations
    pub operand_path: OperandPath,
    pub glyph_index: usize,     // 0-based, unique per page
    pub byte_offset: usize,     // offset into the operand string
    pub byte_len: usize,        // 1 for single-byte fonts; >1 for CID
    pub bbox: Bbox,
}

#[derive(Debug, Clone)]
pub enum OperandPath {
    /// `(...) Tj` — the whole operand is one string.
    Tj,
    /// `' (...) ` (apostrophe op) — same as Tj after newline + Td.
    Apostrophe,
    /// `aw ac (...) "` (double-quote) — sets word/char spacing then Tj.
    DoubleQuote,
    /// `[ (a) -120 (b) ] TJ` — `arr_index` points to which array entry.
    Tj_Array { arr_index: usize },
}

pub fn tokenize_text(content: &Content, _page_size: [f32; 2])
    -> Result<Vec<GlyphEvent>, PdfError>
{
    let mut events = Vec::new();
    let mut ctm_stack: Vec<Mat3> = vec![Mat3::IDENT];
    let mut text_matrix = Mat3::IDENT;
    let mut text_line_matrix = Mat3::IDENT;
    let mut font_size: f32 = 12.0;
    let mut char_space: f32 = 0.0;
    let mut word_space: f32 = 0.0;
    let mut leading: f32 = 0.0;
    let mut horiz_scale: f32 = 1.0;
    let mut in_text_block = false;
    let mut glyph_idx = 0usize;

    for (op_index, op) in content.operations.iter().enumerate() {
        match op.operator.as_str() {
            "q" => {
                let top = *ctm_stack.last().unwrap();
                ctm_stack.push(top);
            }
            "Q" => {
                if ctm_stack.len() <= 1 {
                    return Err(PdfError::Other(
                        "vault: unbalanced Q (graphics-state pop with empty stack)".into()
                    ));
                }
                ctm_stack.pop();
            }
            "cm" => {
                let m = parse_mat3(&op.operands)?;
                let top = ctm_stack.last_mut().unwrap();
                *top = m.mul(*top);
            }
            "BT" => {
                in_text_block = true;
                text_matrix = Mat3::IDENT;
                text_line_matrix = Mat3::IDENT;
            }
            "ET" => {
                in_text_block = false;
            }
            "Tf" => {
                if let Some(Object::Integer(sz)) = op.operands.get(1) {
                    font_size = *sz as f32;
                } else if let Some(Object::Real(sz)) = op.operands.get(1) {
                    font_size = *sz;
                }
            }
            "Tc" => { char_space = read_num(&op.operands, 0)?; }
            "Tw" => { word_space = read_num(&op.operands, 0)?; }
            "Tz" => { horiz_scale = read_num(&op.operands, 0)? / 100.0; }
            "TL" => { leading = read_num(&op.operands, 0)?; }
            "Td" => {
                let tx = read_num(&op.operands, 0)?;
                let ty = read_num(&op.operands, 1)?;
                text_line_matrix = text_line_matrix.translate(tx, ty);
                text_matrix = text_line_matrix;
            }
            "TD" => {
                let tx = read_num(&op.operands, 0)?;
                let ty = read_num(&op.operands, 1)?;
                leading = -ty;
                text_line_matrix = text_line_matrix.translate(tx, ty);
                text_matrix = text_line_matrix;
            }
            "Tm" => {
                text_matrix = parse_mat3(&op.operands)?;
                text_line_matrix = text_matrix;
            }
            "T*" => {
                text_line_matrix = text_line_matrix.translate(0.0, -leading);
                text_matrix = text_line_matrix;
            }
            "Tj" if in_text_block => {
                let bytes = read_string(&op.operands, 0)?;
                emit_string(&bytes, op_index, OperandPath::Tj,
                            &ctm_stack, &mut text_matrix, font_size,
                            char_space, word_space, horiz_scale,
                            &mut glyph_idx, &mut events);
            }
            "TJ" if in_text_block => {
                let arr = match op.operands.first() {
                    Some(Object::Array(a)) => a,
                    _ => return Err(PdfError::Other("vault: TJ missing array".into())),
                };
                for (arr_index, entry) in arr.iter().enumerate() {
                    match entry {
                        Object::String(bytes, _) => {
                            emit_string(bytes, op_index,
                                        OperandPath::Tj_Array { arr_index },
                                        &ctm_stack, &mut text_matrix, font_size,
                                        char_space, word_space, horiz_scale,
                                        &mut glyph_idx, &mut events);
                        }
                        Object::Integer(adj) => {
                            // negative number = advance text matrix
                            let dx = (-(*adj as f32) / 1000.0) * font_size * horiz_scale;
                            text_matrix = text_matrix.translate(dx, 0.0);
                        }
                        Object::Real(adj) => {
                            let dx = (-adj / 1000.0) * font_size * horiz_scale;
                            text_matrix = text_matrix.translate(dx, 0.0);
                        }
                        _ => {}
                    }
                }
            }
            "'" if in_text_block => {
                text_line_matrix = text_line_matrix.translate(0.0, -leading);
                text_matrix = text_line_matrix;
                let bytes = read_string(&op.operands, 0)?;
                emit_string(&bytes, op_index, OperandPath::Apostrophe,
                            &ctm_stack, &mut text_matrix, font_size,
                            char_space, word_space, horiz_scale,
                            &mut glyph_idx, &mut events);
            }
            "\"" if in_text_block => {
                word_space = read_num(&op.operands, 0)?;
                char_space = read_num(&op.operands, 1)?;
                text_line_matrix = text_line_matrix.translate(0.0, -leading);
                text_matrix = text_line_matrix;
                let bytes = read_string(&op.operands, 2)?;
                emit_string(&bytes, op_index, OperandPath::DoubleQuote,
                            &ctm_stack, &mut text_matrix, font_size,
                            char_space, word_space, horiz_scale,
                            &mut glyph_idx, &mut events);
            }
            _ => {}
        }
    }
    if ctm_stack.len() != 1 {
        return Err(PdfError::Other(
            "vault: unbalanced q (graphics-state push with no matching Q)".into()
        ));
    }
    Ok(events)
}

#[allow(clippy::too_many_arguments)]
fn emit_string(
    bytes: &[u8],
    op_index: usize,
    path: OperandPath,
    ctm_stack: &[Mat3],
    text_matrix: &mut Mat3,
    font_size: f32,
    char_space: f32,
    word_space: f32,
    horiz_scale: f32,
    glyph_idx: &mut usize,
    events: &mut Vec<GlyphEvent>,
) {
    let ctm = *ctm_stack.last().unwrap();
    // Heuristic glyph width: 0.5em (we don't load font metrics in v1).
    // Good enough for redaction overlap at the per-rect granularity Slab uses.
    let glyph_w = 0.5 * font_size * horiz_scale;
    for (byte_offset, &b) in bytes.iter().enumerate() {
        let (px, py) = (text_matrix.e, text_matrix.f);
        let (x0, y0) = ctm.map_point(px, py);
        let (x1, y1) = ctm.map_point(px + glyph_w, py + font_size);
        events.push(GlyphEvent {
            op_index,
            operand_path: path.clone(),
            glyph_index: *glyph_idx,
            byte_offset,
            byte_len: 1,
            bbox: Bbox { x0: x0.min(x1), y0: y0.min(y1), x1: x0.max(x1), y1: y0.max(y1) },
        });
        *glyph_idx += 1;
        let space_extra = if b == b' ' { word_space } else { 0.0 };
        let advance = glyph_w + char_space + space_extra;
        *text_matrix = text_matrix.translate(advance, 0.0);
    }
}

fn read_num(operands: &[Object], i: usize) -> Result<f32, PdfError> {
    match operands.get(i) {
        Some(Object::Integer(n)) => Ok(*n as f32),
        Some(Object::Real(r)) => Ok(*r),
        _ => Err(PdfError::Other(format!("vault: expected number at operand {i}"))),
    }
}

fn parse_mat3(operands: &[Object]) -> Result<Mat3, PdfError> {
    Ok(Mat3 {
        a: read_num(operands, 0)?,
        b: read_num(operands, 1)?,
        c: read_num(operands, 2)?,
        d: read_num(operands, 3)?,
        e: read_num(operands, 4)?,
        f: read_num(operands, 5)?,
    })
}

fn read_string(operands: &[Object], i: usize) -> Result<Vec<u8>, PdfError> {
    match operands.get(i) {
        Some(Object::String(bytes, _)) => Ok(bytes.clone()),
        _ => Err(PdfError::Other(format!("vault: expected string at operand {i}"))),
    }
}
```

**Step 3: Implement** `apply_surgery(content: &Content, events: &[GlyphEvent], rects: &[Bbox]) -> (Content, u32)`. Algorithm:

```rust
pub fn apply_surgery(
    content: &Content,
    events: &[GlyphEvent],
    rects: &[Bbox],
) -> (Content, u32) {
    if rects.is_empty() {
        return (content.clone(), 0);
    }

    // Group affected events by op_index for fast lookup.
    let mut hits_by_op: HashMap<usize, Vec<&GlyphEvent>> = HashMap::new();
    let mut redacted_count = 0u32;
    for ev in events {
        if rects.iter().any(|r| bbox_overlap(*r, ev.bbox)) {
            hits_by_op.entry(ev.op_index).or_default().push(ev);
            redacted_count += 1;
        }
    }

    let mut new_ops = Vec::with_capacity(content.operations.len());
    for (i, op) in content.operations.iter().enumerate() {
        match hits_by_op.get(&i) {
            None => new_ops.push(op.clone()),
            Some(hits) => new_ops.push(rewrite_op(op, hits)),
        }
    }
    (Content { operations: new_ops }, redacted_count)
}

fn bbox_overlap(a: Bbox, b: Bbox) -> bool {
    a.x0 <= b.x1 && b.x0 <= a.x1 && a.y0 <= b.y1 && b.y0 <= a.y1
}

fn rewrite_op(op: &Operation, hits: &[&GlyphEvent]) -> Operation {
    match op.operator.as_str() {
        "Tj" | "'" | "\"" => rewrite_string_op(op, hits),
        "TJ" => rewrite_tj_array(op, hits),
        _ => op.clone(),
    }
}

fn rewrite_string_op(op: &Operation, hits: &[&GlyphEvent]) -> Operation {
    // Find the string operand position (last for ", first for Tj/').
    let str_idx = match op.operator.as_str() {
        "\"" => 2,
        _ => 0,
    };
    let mut new_ops = op.operands.clone();
    if let Object::String(bytes, fmt) = &op.operands[str_idx] {
        let mut hit_byte_offsets: Vec<(usize, usize)> = hits.iter()
            .map(|h| (h.byte_offset, h.byte_len))
            .collect();
        hit_byte_offsets.sort_by_key(|&(o, _)| o);
        let mut out = Vec::with_capacity(bytes.len());
        let mut cursor = 0;
        for (off, len) in hit_byte_offsets {
            if off > cursor {
                out.extend_from_slice(&bytes[cursor..off]);
            }
            cursor = off + len;
        }
        if cursor < bytes.len() {
            out.extend_from_slice(&bytes[cursor..]);
        }
        new_ops[str_idx] = Object::String(out, fmt.clone());
    }
    Operation::new(op.operator.clone(), new_ops)
}
```

## Slice 6: Image Redaction + Annotation Scrub + Metadata Strip

**Image redaction algorithm:**
1. Walk the same content stream looking for `Do` operator.
2. Resolve the XObject from the page's Resources/XObject dict.
3. If the XObject is an Image (`/Subtype /Image`), compute its painted bbox
   from the surrounding `cm` matrix.
4. If overlaps any redaction rect → replace the `Do` with a `q Q` no-op,
   mark the XObject for orphan-removal.
5. After all pages processed, walk all XObject references. Any image
   XObject with zero remaining references → delete from the doc.

## Open Questions / Deferred to v2.1.0 "Notary" 🪶

- **Glyph-width-from-font-metrics** — current code uses 0.5em heuristic.
  Good enough for UI-rect-granularity redaction (the user already snaps to
  text); precise metrics need `font-kit` or similar. Defer.
- **CID/Type0 multi-byte fonts** — Slice 1 sets `byte_len: 1` always. CID
  fonts emit 2-byte glyph IDs and need CMap-aware tokenization. Defer
  unless a fixture test catches a real-world failure.
- **Cryptographic redaction certification** — Adobe Pro signs the redacted
  output proving no recovery is possible. Pairs naturally with v2.1.0
  "Notary" PKCS#7 signing. Defer.
- **Form-field redaction** — AcroForm fields with values overlapping a rect
  should have their `/V` cleared. Advanced; defer to v2.0.13.1 patch if
  customer reports it.
- **Encrypted PDFs** — `lopdf` handles owner-password decrypt, but if doc is
  password-protected we should re-encrypt the output with the same password.
  Defer; emit a clear error in v2.0.13.
