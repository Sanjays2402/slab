# v3.26.0 "Quill Designer" Implementation Plan

> **For Hermes:** Use `subagent-driven-development` to implement this plan task-by-task. Bundle Tasks 1-4 into the first tick (Rust backend + tests). Tasks 5-7 the second tick (Tauri + Svelte UI). Tasks 8-9 the third tick (release). Branch: `feature/v3.26.0-quill-designer`. Sits **after** v3.25.0 Quill Pro Batch lands.

**Goal:** Ship a visual **AcroForm field designer** so users can ADD, EDIT, and DELETE text / checkbox / radio / dropdown / signature fields on any PDF — turning a flat PDF into a fillable form, offline, free.

**Architecture:** New `pdf::forms_design` module that builds well-formed AcroForm dictionaries from a `FieldDraft` DTO and edits existing fields in place. Reuses v3.9.0 `forms::inspect` for the editor's "current state" view. Tauri commands `slab_forms_design_add`, `slab_forms_design_edit`, `slab_forms_design_delete`. New Svelte panel `QuillDesignerPanel.svelte` overlays draggable field rectangles on a pdfjs canvas; `Cmd/Ctrl+Shift+F` opens it. After save, the document round-trips through `forms::inspect` so the user immediately sees the new fields populated in the existing `FormsPanel` ("Fill" view).

**Tech Stack:** Rust (`lopdf`), Tauri 2, Svelte 5 runes, `pdfjs-dist` (already on disk for v3.23.0/v3.24.0), TypeScript.

**Why it's the buy-button:** Acrobat Pro's headline feature ($239/yr) is the "Prepare Form" tool. PDF Expert ($79/yr) cannot create form fields. Foxit charges an "Editor" tier upgrade. Preview cannot do it at all. We give it away offline, with no telemetry, on three OSes.

use serde::{Deserialize, Serialize};

    Radio { group: String, value: String, default_selected: bool },

    /// PDF user-space rect [x0, y0, x1, y1].
    pub rect: [f32; 4],
    #[serde(default)]
    pub required: bool,
    #[serde(default)]
    pub read_only: bool,
    #[serde(default)]
    pub tooltip: Option<String>,
}

use crate::pdf::{atomic_save, PdfError};
use lopdf::{dictionary, Dictionary, Document, Object, ObjectId, Stream};
use std::path::Path;

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct DesignReport {
    pub added: Vec<String>,
    pub edited: Vec<String>,
    pub deleted: Vec<String>,
    pub errors: Vec<String>,
}

pub fn add_fields(input: &Path, drafts: &[FieldDraft], output: &Path) -> Result<DesignReport, PdfError> {
    if !input.exists() { return Err(PdfError::InputMissing(input.display().to_string())); }
    if output.as_os_str().is_empty() { return Err(PdfError::EmptyOutput); }
    let mut doc = Document::load(input)?;
    let report = add_fields_doc(&mut doc, drafts)?;
    let mut buf = Vec::new();
    doc.save_to(&mut buf)?;
    atomic_save(output, &buf)?;
    Ok(report)
}

fn add_fields_doc(doc: &mut Document, drafts: &[FieldDraft]) -> Result<DesignReport, PdfError> {
    let mut report = DesignReport::default();
    // Cache page list 1-based.
    let pages: Vec<ObjectId> = doc.page_iter().collect();
    // Ensure /AcroForm exists.
    let acroform_id = ensure_acroform(doc)?;
    for d in drafts {
        match install_one(doc, &pages, acroform_id, d) {
            Ok(()) => report.added.push(d.name.clone()),
            Err(e) => report.errors.push(format!("{}: {}", d.name, e)),
        }
    }
    Ok(report)
}

fn install_one(
    doc: &mut Document,
    pages: &[ObjectId],
    acroform_id: ObjectId,
    d: &FieldDraft,
) -> Result<(), PdfError> {
    let page_idx = (d.page as usize).checked_sub(1)
        .ok_or_else(|| PdfError::InvalidInput("page 0".into()))?;
    let page_id = *pages.get(page_idx)
        .ok_or_else(|| PdfError::InvalidInput(format!("page {} out of range", d.page)))?;

    let widget = build_widget_dict(d, page_id);
    let field_dict = build_field_dict(d, &widget);
    let field_id = doc.add_object(Object::Dictionary(field_dict));

    // Append /Annots on the page

fn build_field_dict(d: &FieldDraft, widget: &Dictionary) -> Dictionary {
    let mut dict = dictionary! {
        "T" => Object::string_literal(d.name.clone()),
        "Rect" => Object::Array(d.rect.iter().map(|f| Object::Real(*f)).collect()),
    };
    let mut ff: i64 = 0;
    if d.required  { ff |= 1 << 1; }
    if d.read_only { ff |= 1 << 0; }
    match &d.kind {
        DraftKind::Text { multiline, max_len, default } => {
            dict.set("FT", Object::Name(b"Tx".to_vec()));
            if *multiline { ff |= 1 << 12; }
            if let Some(m) = max_len { dict.set("MaxLen", Object::Integer(*m as i64)); }
            if let Some(v) = default {
                dict.set("V", Object::string_literal(v.clone()));
                dict.set("DV", Object::string_literal(v.clone()));
            }
        }
        DraftKind::Checkbox { default_checked } => {
            dict.set("FT", Object::Name(b"Btn".to_vec()));
            let state = if *default_checked { "Yes" } else { "Off" };
            dict.set("V",  Object::Name(state.as_bytes().to_vec()));
            dict.set("DV", Object::Name(state.as_bytes().to_vec()));
            dict.set("AS", Object::Name(state.as_bytes().to_vec()));
        }
        DraftKind::Radio { group: _, value, default_selected } => {
            dict.set("FT", Object::Name(b"Btn".to_vec()));
            ff |= 1 << 15; // Radio
            ff |= 1 << 14; // NoToggleToOff
            let v = if *default_selected { value.as_str() } else { "Off" };
            dict.set("V",  Object::Name(v.as_bytes().to_vec()));
            dict.set("AS", Object::Name(v.as_bytes().to_vec()));
        }
        DraftKind::Dropdown { options, default, editable } => {
            dict.set("FT", Object::Name(b"Ch".to_vec()));
            if *editable { ff |= 1 << 18; } // Combo + Edit
            ff |= 1 << 17;                   // Combo
            let opts: Vec<Object> = options.iter().map(|o| Object::string_literal(o.clone())).collect();
            dict.set("Opt", Object::Array(opts));
            if let Some(v) = default { dict.set("V", Object::string_literal(v.clone())); }
        }
        DraftKind::Signature => {
            dict.set("FT", Object::Name(b"Sig".to_vec()));
        }
    }
    if ff != 0 { dict.set("Ff", Object::Integer(ff)); }
    if let Some(t) = &d.tooltip { dict.set("TU", Object::string_literal(t.clone())); }
    // Merge widget annotation entries onto the field (allowed by spec).
    for (k, v) in widget.iter() {
        if dict.get(k).is_err() { dict.set(k.clone(), v.clone()); }
    }
    dict
}

fn build_widget_dict(d: &FieldDraft, page_id: ObjectId) -> Dictionary {
    dictionary! {
        "Type" => Object::Name(b"Annot".to_vec()),
        "Subtype" => Object::Name(b"Widget".to_vec()),
        "F" => Object::Integer(4),       // Print flag
        "Rect" => Object::Array(d.rect.iter().map(|f| Object::Real(*f)).collect()),
        "P" => Object::Reference(page_id),
        "Border" => Object::Array(vec![Object::Integer(0), Object::Integer(0), Object::Integer(1)]),
    }
}

## DRY / YAGNI / TDD notes

- **DRY:** Reuse `forms::inspect` for the "after-save reload" step rather than re-walking the catalog ourselves.
- **YAGNI:** No appearance-stream generation in this release. `/NeedAppearances=true` is enough — Acrobat / Preview / Chrome regenerate them on open. Custom appearance fonts are a v3.27.0 concern.
- **YAGNI:** No XFA design. AcroForm only.
- **TDD:** Every backend function gets a failing test first. UI is the exception (manual smoke on the test fixture PDF).
