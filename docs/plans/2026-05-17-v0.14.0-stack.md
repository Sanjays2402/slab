# v0.14.0 "Stack" — Diff & Compare Implementation Plan

> **For Hermes:** Cake ships this autonomously in cron ticks. One vertical slice per tick (3-6 commits).

**Goal:** Add PDF diff & compare to Slab — visual side-by-side, text line diff, change report, patch/merge, and a Beacon AI summary of changes.

**Architecture:**
- Backend `pdf::diff` module owns the diff engine. Pure-Rust, uses `similar = "2.6"` for LCS-based line diff.
- Each diff op is a small public function returning serializable DTOs.
- Tauri commands in `slab_diff_*` namespace.
- Frontend `DiffPanel.svelte` with side-by-side viewer + text diff pane + AI summary widget.

**Tech Stack:** lopdf (page text), similar (LCS diff), serde, tauri, Svelte 5 runes, existing Beacon AiProvider trait.

---

## Slice 1 — Backend text-diff foundation (THIS TICK)

**Objective:** Add `pdf::diff` module that compares two PDFs and produces a structured page-by-page line diff. Wire it up with a Tauri command and a minimal frontend panel with sidebar nav.

**Files:**
- Create: `src-tauri/src/pdf/diff.rs` (core diff engine + tests)
- Modify: `src-tauri/src/pdf.rs` (add `pub mod diff;`)
- Modify: `src-tauri/Cargo.toml` (add `similar = "2.6"`)
- Modify: `src-tauri/src/lib.rs` (add Tauri commands)
- Create: `src/lib/panels/DiffPanel.svelte`
- Modify: `src/routes/+page.svelte` (add sidebar nav entry)

**Steps:**
1. Add `similar = "2.6"` to Cargo.toml.
2. Create `pdf::diff` with:
   - `DiffOp` enum (`Equal | Insert | Delete | Replace`)
   - `LineDiff { op, old_line: Option<usize>, new_line: Option<usize>, text: String }`
   - `PageDiff { old_page: Option<u32>, new_page: Option<u32>, lines: Vec<LineDiff>, summary: DiffSummary }`
   - `DocDiff { old_path: PathBuf, new_path: PathBuf, pages: Vec<PageDiff>, total: DiffSummary }`
   - `DiffSummary { added: u32, removed: u32, changed: u32 }`
   - `diff_pdfs(old: &Path, new: &Path) -> Result<DocDiff, PdfError>` — aligns pages 1:1, then per-page LCS line diff.
3. Add unit tests:
   - Identical PDFs → 0 diffs everywhere
   - PDF B has extra page → unmatched page entries
   - Single-line change → 1 insert + 1 delete (or replace block)
   - Empty page text → no panic
4. Add Tauri command `slab_diff_pdfs(old, new) -> CmdResult<DocDiff>`.
5. Add `DiffPanel.svelte`:
   - Two file pickers (old / new)
   - "Compare" button → invokes `slab_diff_pdfs`
   - Renders each page section: stat line + colored line list (green +, red -, gray =)
6. Sidebar nav: `📐 Diff`.

**Commits this tick:**
- `feat(diff): pdf::diff backend module + tests`
- `feat(diff): slab_diff_pdfs Tauri command`
- `feat(diff): DiffPanel.svelte + sidebar nav entry`
