# v1.9.2 — Voice Mode: Polish 🎙 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Round out Beacon Voice Mode after the v1.9.0 Speak + v1.9.1 Listen MVP — give Windows users full dictation parity, let users cancel a bad recording, add a "say-to-send" shortcut for hands-free chat, and let power users pick a whisper model from the UI.

**Architecture:**
- **Native Windows STT** lives as a new cargo feature `windows-stt` gating a `windows_recorder` module. The shell-out path stays the default so non-Windows CI legs don't pull native Win32 deps. The capability probe gains a `recorder_kind: native | shell` field so the UI can stop saying "PowerShell" on Windows when the native path is active.
- **Cancel/discard** is a new `SttSession::cancel()` method (kills child, unlinks WAV, drops the slot) + a `slab_beacon_voice_stt_cancel` Tauri command. Mirrors the v1.9.1 single-slot kill-prev semantics; just no transcript returned. Frontend wires ESC-while-recording and right-click-on-mic to it.
- **Voice-driven send** is a small pure helper `detect_send_trigger(text, trigger) -> (cleaned_text, should_send)` that strips a trailing trigger phrase. Lives in `stt_session.rs` (testable without any audio). Wired into the chat panel's transcript handler: after `stop()` succeeds, if `should_send` is true we auto-call `send()` once focus returns to the textarea.
- **Model picker** extends `VoiceConfig` with `stt_engine: Option<String>` and `stt_model: Option<String>`, surfaces a model selector in `BeaconVoicePanel`, and feeds the chosen model into `transcribe_whisper_cpp` via the existing `WHISPER_MODEL` env override (read from config at command-invocation time rather than at process spawn).
- **Persistence**: All settings (engine choice, model, trigger word, send-on-trigger toggle) round-trip through `~/.slab/config.toml` via the existing `slab_beacon_config_read`/`_write` commands. `VoiceConfig::is_empty()` is updated to ignore the new fields when default-shaped.

**Tech Stack:** Rust (`tauri-2`, `serde`, existing `cfg(target_os = "windows")` gating), Windows-only crates `windows` (0.58, mod `Windows.Media.Capture`) gated behind `windows-stt`. Svelte 5 frontend. No new top-level dependencies on non-Windows builds.

```rust
/// Cancel the in-flight recording without transcribing. Best-effort:
/// kills the recorder, waits for reap, unlinks the WAV. No transcript
/// returned. No-op if no recording is in flight. Mirrors the
/// kill-prev-on-start semantics — except invoked explicitly.
///
/// Used by the `slab_beacon_voice_stt_cancel` Tauri command (v1.9.2
/// — ESC-while-recording, right-click-on-mic).
pub fn cancel(&self) {
    let mut slot = self.current.lock().expect("SttSession mutex poisoned");
    if let Some(prev) = slot.take() {
        cancel_inflight(prev);
    }
}
```

**Step 3: Implement the detector**

Add to `src-tauri/src/ai/stt_session.rs` (before `#[cfg(test)]`):

```rust
/// Pure helper: if `text` ends with `trigger` (case-insensitive,
/// word-boundary-aware, ignoring trailing punctuation), return the
/// text with the trigger stripped + `true`. Otherwise return the
/// text trimmed + `false`.
///
/// `trigger == None` always yields `(trimmed_text, false)` — that's
/// the "auto-send disabled" path.
///
/// Used by the chat panel after `stop()` to decide whether to invoke
/// `send()` automatically.
pub fn detect_send_trigger(text: &str, trigger: Option<&str>) -> (String, bool) {
    let trimmed = text.trim();
    let Some(trig) = trigger else {
        return (trimmed.to_string(), false);
    };
    let trig = trig.trim();
    if trig.is_empty() || trimmed.is_empty() {
        return (trimmed.to_string(), false);
    }

    // Strip a single trailing punctuation char (.,!?;:) so transcripts
    // like "...send it." still fire.
    let body = trimmed
        .strip_suffix(['.', ',', '!', '?', ';', ':'])
        .unwrap_or(trimmed)
        .trim_end();

    let body_lc = body.to_lowercase();
    let trig_lc = trig.to_lowercase();
    if !body_lc.ends_with(&trig_lc) {
        return (trimmed.to_string(), false);
    }
    // Word-boundary check: the char immediately before the suffix
    // must be whitespace or absent (whole-text-is-trigger case).
    let prefix_len = body_lc.len() - trig_lc.len();
    if prefix_len > 0 {
        let prev = body[..prefix_len].chars().next_back();
        match prev {
            Some(c) if c.is_whitespace() => {}
            _ => return (trimmed.to_string(), false),
        }
    }
    let cleaned = body[..prefix_len].trim_end().to_string();
    (cleaned, true)
}
```

```rust
/// One row in the model picker.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct WhisperModelInfo {
    /// Short id used in config + on the `whisper-cli -m` flag when
    /// `path` is None. e.g. `"base.en"`.
    pub id: String,
    /// Display label for the UI. e.g. `"Base · English · 142 MB"`.
    pub label: String,
    /// Absolute path to the `.bin`/`.gguf` file if found in
    /// `SLAB_MODELS_DIR` (default `~/.slab/models`). `None` means the
    /// id is a suggestion — whisper.cpp will resolve it relative to
    /// its own install root, or transcribing will fail.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub path: Option<String>,
    /// Convenience: `path.is_some()`. The frontend uses this to grey
    /// out non-installed suggestions and show a download hint.
    pub installed: bool,
}

/// Built-in suggestion set — the common whisper.cpp model names we
/// show even when the on-disk models dir is empty. Kept tiny (no large
/// or huge variants) because the goal is "pick the lightweight one
/// you have, or the lightweight one you should download next".
const BUILTIN_MODEL_SUGGESTIONS: &[(&str, &str)] = &[
    ("tiny.en", "Tiny · English · 77 MB · fastest"),
    ("base.en", "Base · English · 142 MB · default"),
    ("small.en", "Small · English · 466 MB · best quality"),
];

/// Directory we search for installed whisper models. Honours
/// `SLAB_MODELS_DIR` (tests redirect this); default is
/// `~/.slab/models`.
pub fn models_dir() -> std::path::PathBuf {
    if let Ok(p) = std::env::var("SLAB_MODELS_DIR") {
        if !p.is_empty() {
            return std::path::PathBuf::from(p);
        }
    }
    let home = std::env::var("HOME").unwrap_or_else(|_| ".".to_string());
    std::path::PathBuf::from(home).join(".slab").join("models")
}

/// List whisper-cpp model files in `models_dir()`, augmented with the
/// built-in suggestion set so the picker is never empty. The suggestion
/// set comes first; on-disk-only files (custom user models) follow.
pub fn list_whisper_models() -> Vec<WhisperModelInfo> {
    let dir = models_dir();
    // Index installed files by canonical id (strip ggml- prefix +
    // .bin/.gguf suffix).
    let mut installed: std::collections::HashMap<String, std::path::PathBuf> = Default::default();
    if let Ok(entries) = std::fs::read_dir(&dir) {
        for entry in entries.flatten() {
            let p = entry.path();
            let name = match p.file_name().and_then(|n| n.to_str()) {
                Some(n) => n,
                None => continue,
            };
            let lower = name.to_lowercase();
            if !(lower.ends_with(".bin") || lower.ends_with(".gguf")) {
                continue;
            }
            // Strip both ggml- prefix and the suffix to derive the id.
            let stem = name
                .trim_start_matches("ggml-")
                .trim_end_matches(".bin")
                .trim_end_matches(".gguf")
                .to_string();
            installed.insert(stem, p);
        }
    }

    let mut out = Vec::new();
    let mut seen = std::collections::HashSet::new();
    for (id, label) in BUILTIN_MODEL_SUGGESTIONS {
        let path = installed.get(*id).map(|p| p.to_string_lossy().into_owned());
        let installed_flag = path.is_some();
        out.push(WhisperModelInfo {
            id: (*id).into(),
            label: (*label).into(),
            path,
            installed: installed_flag,
        });
        seen.insert((*id).to_string());
    }
    // Surface any installed-but-not-suggested files (user custom models).
    for (id, p) in installed {
        if seen.contains(&id) {
            continue;
        }
        out.push(WhisperModelInfo {
            id: id.clone(),
            label: format!("{id} · custom"),
            path: Some(p.to_string_lossy().into_owned()),
            installed: true,
        });
    }
    out
}
```

```rust
/// Build the argv `whisper-cli` is invoked with. Split out so the
/// command-construction logic is unit-testable without spawning a
/// real subprocess.
///
/// Precedence for the `-m <model>` flag:
///   1. Explicit `model` argument (from `SttSession::start(engine, model)`),
///   2. else `$WHISPER_MODEL` env override,
///   3. else omit `-m` entirely and let whisper.cpp use its built-in default.
pub(crate) fn build_whisper_cmd(
    bin: &str,
    wav: &Path,
    model: Option<&str>,
) -> Vec<String> {
    let mut args: Vec<String> = vec![
        "-f".into(),
        wav.to_string_lossy().into_owned(),
        "-nt".into(),
        "-l".into(),
        "auto".into(),
    ];
    let resolved_model = model.map(str::to_owned).or_else(|| {
        std::env::var("WHISPER_MODEL")
            .ok()
            .filter(|s| !s.is_empty())
    });
    if let Some(m) = resolved_model {
        args.push("-m".into());
        args.push(m);
    }
    // `bin` is the executable; we keep it out of args.
    let _ = bin;
    args
}
```
