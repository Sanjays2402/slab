# v3.4.0 "Discovery" — Bates Numbering + Legal Stamps Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship a complete Bates-numbering + legal-stamp workstation that
end-to-end serves litigation paralegals: prefix + zero-padded counter, stamped
onto every page of one or many PDFs, with the counter monotonically increasing
across the whole production set, plus a CSV/JSON load-file index, plus the four
most-requested standard stamps (CONFIDENTIAL, ATTORNEY EYES ONLY, PRIVILEGED,
DRAFT) with caller-controlled custom text + color + position.

**Architecture:** The single-PDF stamping primitive already exists in
`src-tauri/src/pdf/bates.rs` (`apply_bates`, `BatesOpts`, `BatesReport`).
This release wires it into:

1. a **batch driver** (new `batch.rs`) that walks an ordered list of files,
   threads `next_start` between them, and emits a load-file index;
2. a **legal stamp module** (new `legal_stamp.rs`) that reuses the same
   text-stamping primitive for the four standard stamps + arbitrary text;
3. **Tauri commands** (`slab_bates_apply`, `slab_bates_batch`,
   `slab_legal_stamp_apply`) exposed to the frontend;
4. a **frontend panel** `BatesPanel.svelte` and `LegalStampPanel.svelte`,
   wired into the toolbar, command palette (Cmd+K), keyboard shortcuts
   (Cmd+Shift+B for Bates, Cmd+Shift+S for stamps), and settings.

**Tech Stack:** Rust 2021 / lopdf / serde / tauri 2.x / Svelte 5 / TypeScript /
Tailwind. No new crates.

**Buy-Button audit:**

  primarily for Bates. We give it away free, offline, with batch.
- ✅ Pick-us: Acrobat does ~5 docs at a time; Slab does a 10k-file production

- ✅ Notice-it: brand new top-level toolbar entry + Cmd+Shift+B.

```rust
pub fn apply_bates_batch(input: &BatchInput) -> Result<BatchReport, PdfError> {
    if input.inputs.is_empty() {
        return Err(PdfError::InvalidInput("batch inputs is empty".into()));
    }
    if !input.output_dir.is_dir() {
        return Err(PdfError::InvalidInput(format!(
            "output_dir is not a directory: {}",
            input.output_dir.display()
        )));
    }

    let mut per_file = Vec::with_capacity(input.inputs.len());
    let mut next = input.opts.start_at;
    let mut first_label = String::new();
    let mut last_label = String::new();
    let mut total_pages: u64 = 0;

    for src in &input.inputs {
        let basename = src.file_name().ok_or_else(|| {
            PdfError::InvalidInput(format!("source has no filename: {}", src.display()))
        })?;
        let dst = input.output_dir.join(basename);

        let mut opts = input.opts.clone();
        opts.start_at = next;
        let r: BatesReport = apply_bates(src, &dst, &opts)?;

        if first_label.is_empty() {
            first_label = r.first_label.clone();
        }
        last_label = r.last_label.clone();
        total_pages += r.pages_stamped as u64;

        per_file.push(FileReport {
            source: src.clone(),
            output: dst,
            first_label: r.first_label,
            last_label: r.last_label,
            pages: r.pages_stamped,
        });
        next = r.next_start;
    }

    let load_file_written = match &input.load_file {
        Some(lf) => Some(write_load_file(lf, &per_file)?),
        None => None,
    };

    Ok(BatchReport {
        files_processed: per_file.len() as u32,
        pages_stamped: total_pages,
        first_label,
        last_label,
        per_file,
        load_file_written,
    })
}

fn write_load_file(lf: &LoadFile, rows: &[FileReport]) -> Result<PathBuf, PdfError> {
    match lf {
        LoadFile::Csv { path } => write_csv(path, rows).map(|_| path.clone()),
        LoadFile::Json { path } => write_json(path, rows).map(|_| path.clone()),
    }
}

fn write_csv(path: &Path, rows: &[FileReport]) -> Result<(), PdfError> {
    use std::io::Write;
    let mut f = std::fs::File::create(path)
        .map_err(|e| PdfError::Io(format!("create {}: {e}", path.display())))?;
    writeln!(f, "source,output,first_label,last_label,pages")
        .map_err(|e| PdfError::Io(e.to_string()))?;
    for r in rows {
        // Escape commas/quotes in paths the cheap way: wrap in quotes,
        // double internal quotes.
        let s = csv_escape(&r.source.display().to_string());
        let o = csv_escape(&r.output.display().to_string());
        writeln!(
            f,
            "{},{},{},{},{}",
            s, o, r.first_label, r.last_label, r.pages
        )
        .map_err(|e| PdfError::Io(e.to_string()))?;
    }
    Ok(())
}

fn csv_escape(s: &str) -> String {
    let needs_quote = s.contains(',') || s.contains('"') || s.contains('\n');
    if !needs_quote {
        return s.to_string();
    }
    let escaped = s.replace('"', "\"\"");
    format!("\"{escaped}\"")
}

fn write_json(path: &Path, rows: &[FileReport]) -> Result<(), PdfError> {
    let s = serde_json::to_string_pretty(&rows)
        .map_err(|e| PdfError::Io(format!("serialize: {e}")))?;
    std::fs::write(path, s).map_err(|e| PdfError::Io(format!("write {}: {e}", path.display())))?;
    Ok(())
}
```
