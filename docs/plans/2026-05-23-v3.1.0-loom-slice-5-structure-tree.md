# v3.1.0 Loom — Slice 5: `structure_tree` Implementation Plan

> **For Hermes:** Use `subagent-driven-development` skill to implement this plan
> task-by-task. Off-hours ticks may bundle Tasks 1+2+3 or 4+5+6+7 into one
> ship-sized tick if SHIP-SIZE rules (≥4 commits, ≥600 LOC, end-to-end working
> capability) are still met.

**Goal:** Emit a valid PDF `/StructTreeRoot` (+ `/ParentTree`, marked-content
operators on every content stream, `/MarkInfo`, `/StructParents` on every page,
`/RoleMap` for our custom roles) so that screen readers (NVDA, VoiceOver, JAWS)
walk the logical document in correct order. This is the **heart of PDF/UA-1**
and the public-launch gate for v3.1.0 Loom.

**Architecture:** Single new module `src-tauri/src/pdf/loom/structure_tree.rs`
that takes a `(Document, StructTree, ReadingOrder, AltTextStats)` quad and
mutates the lopdf `Document` in place:

```
                       ┌─────────────────────────────────┐
   layout::extract ──▶ │ LayoutTree                      │
   classify::classify ▶│ StructTree (typed nodes)        │
   reading_order ─────▶│ ReadingOrder (per-page order)   │ ──┐
   alt_text::enrich ──▶│ Alt-text on Figure nodes        │   │
                       └─────────────────────────────────┘   │
                                                             ▼
        ┌──────────────────────────────────────────────────────────────────┐
        │ structure_tree::weave(doc, tree, order, opts)                    │
        │   1. Allocate StructTreeRoot, RoleMap, MarkInfo dicts.           │
        │   2. For each page: rewrite content stream wrapping every run    │
        │      in `/<Tag> << /MCID n >> BDC ... EMC` (artifacts use        │
        │      `/Artifact <<>> BDC ... EMC`).                              │
        │   3. Build StructElem dicts per StructNode, linking via /P, /K.  │
        │      Leaves contain `<< /Type /MCR /Pg <page_ref> /MCID n >>`.   │
        │   4. Build /ParentTree (NumberTree) mapping page StructParents → │
        │      StructElem array.                                           │
        │   5. Set catalog: /StructTreeRoot, /MarkInfo, /Lang fallback.    │
        └──────────────────────────────────────────────────────────────────┘
                                                             ▼
                                                  woven Document → bytes
```

**Tech Stack:** `lopdf 0.36` (already a workspace dep), zero new crates. Reuses
`Document::get_pages`, `Content::decode`/`encode`, `Stream`, `Dictionary`,
`Object::Reference` patterns already established in `pdf/nup.rs`,
`pdf/edit_text.rs`, `pdf/grayscale.rs`.

```rust
// src-tauri/src/pdf/loom/structure_tree.rs
//
// Slab Loom — Slice 5: PDF /StructTreeRoot emission.
//
// Public entry point: `weave(...)` mutates a lopdf Document in place by
// adding a structure tree, parent tree, role map, and rewriting page content
// streams to wrap content in marked-content sequences.

use lopdf::{dictionary, Dictionary, Document, Object, ObjectId};
use serde::{Deserialize, Serialize};

use super::classify::{NodeKind, StructNode, StructTree};
use super::reading_order::ReadingOrder;

/// A NumberTree builder for PDF `/ParentTree`.
///
/// PDF/UA requires the catalog's `/StructTreeRoot` to have a `/ParentTree`
/// NumberTree mapping `StructParents` integers (set on each page) to either a
/// single StructElem reference (page has one parent) or an array of refs (one
/// slot per MCID).
pub(crate) struct ParentTreeBuilder {
    entries: Vec<(i64, Vec<ObjectId>)>,
}

impl ParentTreeBuilder {
    pub fn new() -> Self {
        Self { entries: Vec::new() }
    }

    pub fn push(&mut self, key: i64, refs: Vec<ObjectId>) {
        self.entries.push((key, refs));
    }

    pub fn write_into(mut self, doc: &mut Document) -> ObjectId {
        self.entries.sort_by_key(|e| e.0);
        let mut nums: Vec<Object> = Vec::with_capacity(self.entries.len() * 2);
        for (k, refs) in self.entries {
            nums.push(Object::Integer(k));
            let arr: Vec<Object> = refs.into_iter().map(Object::Reference).collect();
            nums.push(Object::Array(arr));
        }
        doc.add_object(dictionary! {
            "Nums" => Object::Array(nums),
        })
    }
}
```

## Slice 5.3: Content-stream rewriter (Task 3) — the core algorithm

### Task 3: `rewrite_page_stream` injects BDC/EMC pairs around runs

**Objective:** For one page: decode its content stream, identify text-showing
operators (`Tj`, `TJ`, `'`, `"`) and image-drawing operators (`Do` for image
XObjects), and wrap each one in a marked-content sequence using the
StructTree's classification for that operator. Page artifacts get
`/Artifact << >> BDC ... EMC`; tagged content gets `/<TagName> << /MCID n >> BDC ... EMC`.

This is the **biggest algorithmic task** in the slice (~180 LOC including tests).

**Files:**
- Modify: `src-tauri/src/pdf/loom/structure_tree.rs`

**Design notes (read before coding):**
- Use `lopdf::content::Content::decode(&stream_bytes)` → `Vec<Operation>`.
- Walk in order. Maintain `mcid: u32 = 0`. For each operator:
  - If `Tj`/`TJ`/`'`/`"` → look up which `StructNode` claims this text by
    matching the run order (PDF stream order ≡ classify pass order). For v3.1.0
    we use the **simple matcher**: a `Vec<(NodeKind, mcid)>` produced in
    parallel by walking `StructTree` in classify's `RunOrder` (same as content
    stream order — Slice 1 preserves it). The current text-op index advances
    one slot per text-showing op.
  - If `Do <name>` AND the XObject is an Image → that's a Figure. Same emit
    pattern but check `xobject_name` matches.
  - Wrap by inserting `BDC` op BEFORE and `EMC` op AFTER.
- Artifacts get `/Artifact` tag with empty property dict.
- Re-encode via `Content { operations }.encode()` → write back into the page
  content stream (handle the common case where Page `/Contents` is a single
  stream ref; if it's an array, concat then split is **out of scope** — emit
  warning and tag the page as `/Artifact` wholesale).

```rust
/// Per-operator assignment produced by `plan_page` from the StructTree.
#[derive(Debug, Clone)]
pub(crate) struct RunMcid {
    pub tag: &'static str, // "P", "H1", ..., "Figure", "Artifact"
    pub mcid: u32,
}

/// Re-encode page's content stream, inserting BDC/EMC pairs around each
/// text-showing operator (Tj, TJ, ', ") and image XObject (Do).
pub(crate) fn rewrite_page_stream(
    doc: &mut Document,
    page_id: ObjectId,
    plan: &[RunMcid],
) -> Result<(), String> {
    use lopdf::content::{Content, Operation};

    // Resolve content stream id(s). Single-stream case for v3.1.0.
    let bytes = doc
        .get_page_content(page_id)
        .map_err(|e| format!("get_page_content: {}", e))?;
    let mut content = Content::decode(&bytes).map_err(|e| format!("decode: {}", e))?;

    let mut out: Vec<Operation> = Vec::with_capacity(content.operations.len() * 3);
    let mut cursor = 0usize;
    for op in content.operations.drain(..) {
        let is_text = matches!(op.operator.as_str(), "Tj" | "TJ" | "'" | "\"");
        let is_image_do = op.operator == "Do"; // could be a form XObject too — fine, we treat as content.
        if (is_text || is_image_do) && cursor < plan.len() {
            let mark = &plan[cursor];
            cursor += 1;
            let props = if mark.tag == "Artifact" {
                Object::Dictionary(Dictionary::new())
            } else {
                let mut d = Dictionary::new();
                d.set("MCID", Object::Integer(mark.mcid as i64));
                Object::Dictionary(d)
            };
            out.push(Operation::new(
                "BDC",
                vec![Object::Name(mark.tag.as_bytes().to_vec()), props],
            ));
            out.push(op);
            out.push(Operation::new("EMC", vec![]));
        } else {
            out.push(op);
        }
    }
    let new_bytes = Content { operations: out }
        .encode()
        .map_err(|e| format!("encode: {}", e))?;

    // Rewrite single-stream Contents.
    let page_dict = doc.get_dictionary(page_id).map_err(|e| e.to_string())?;
    let contents_obj = page_dict.get(b"Contents").map_err(|e| e.to_string())?.clone();
    let stream_id = match contents_obj {
        Object::Reference(r) => r,
        _ => return Err("multi-stream /Contents arrays not yet supported".into()),
    };
    if let Ok(Object::Stream(s)) = doc.get_object_mut(stream_id) {
        s.set_plain_content(new_bytes);
        // Re-flate.
        let _ = s.compress();
    }
    Ok(())
}
```

```rust
pub(crate) fn plan_page(page: &StructTreePage) -> Vec<RunMcid> {
    let mut out = Vec::new();
    let mut mcid: u32 = 0;
    fn walk(node: &StructNode, out: &mut Vec<RunMcid>, mcid: &mut u32) {
        // Containers — recurse without emitting.
        if matches!(node.kind, NodeKind::List | NodeKind::Section | NodeKind::Document) {
            for c in &node.children { walk(c, out, mcid); }
            return;
        }
        // Leaf — emit.
        if matches!(node.kind, NodeKind::Artifact) {
            out.push(RunMcid { tag: "Artifact", mcid: u32::MAX });
        } else {
            out.push(RunMcid { tag: tag_static(node.kind), mcid: *mcid });
            *mcid += 1;
        }
        for c in &node.children { walk(c, out, mcid); }
    }
    for n in &page.nodes { walk(n, &mut out, &mut mcid); }
    out
}

fn tag_static(k: NodeKind) -> &'static str {
    match k {
        NodeKind::Heading(1) => "H1",
        NodeKind::Heading(2) => "H2",
        NodeKind::Heading(3) => "H3",
        NodeKind::Heading(4) => "H4",
        NodeKind::Heading(5) => "H5",
        NodeKind::Heading(_) => "H6",
        NodeKind::Paragraph => "P",
        NodeKind::List => "L",
        NodeKind::ListItem => "LI",
        NodeKind::Figure => "Figure",
        NodeKind::Caption => "Caption",
        NodeKind::Section => "Sect",
        NodeKind::Document => "Document",
        NodeKind::Artifact => "Artifact",
    }
}
```

**Step 2: Implement (~180 LOC)**

```rust
#[derive(Debug, Clone, Default)]
pub struct WeaveOptions {
    /// Default document language (BCP-47). Set on the catalog if missing.
    pub fallback_lang: Option<String>,
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct WeaveStats {
    pub pages_processed: usize,
    pub bdc_pairs_injected: usize,
    pub struct_elems_created: usize,
    pub figures_with_alt_text: usize,
}

pub fn weave(
    doc: &mut Document,
    tree: &StructTree,
    _order: &ReadingOrder, // reserved — Slice 5 honours classify ordering;
                            // reading_order rearrangement is a Slice 6 task.
    opts: &WeaveOptions,
) -> Result<WeaveStats, String> {
    let mut stats = WeaveStats::default();

    // 1) Allocate empty top-level objects so children can /P reference them.
    let stroot_id = doc.add_object(Dictionary::new()); // fill at end
    let role_map = build_role_map(doc);

    // 2) Root StructElem (Document).
    let doc_elem = make_struct_elem(doc, stroot_id, "Document");

    // 3) Walk pages in order; produce per-page plan + content stream rewrite.
    let mut pt = ParentTreeBuilder::new();
    let pages: Vec<ObjectId> = doc.get_pages().into_values().collect();
    for (idx, page_id) in pages.iter().enumerate() {
        let Some(tree_page) = tree.pages.get(idx) else { continue; };
        let plan = plan_page(tree_page);

        // Rewrite content stream first — order matters: MCIDs the rewriter
        // injects must match the ones the StructElems reference.
        rewrite_page_stream(doc, *page_id, &plan)?;
        stats.bdc_pairs_injected += plan.iter().filter(|r| r.tag != "Artifact").count();

        // Build StructElems for this page's content. Per-node depth-first
        // mirrors classify's tree shape so /K kids contain either child
        // StructElems or MCR leaves.
        let parent_tree_key = idx as i64;
        let mut mcid_elems: Vec<ObjectId> = Vec::new();
        let mut mcid_counter: u32 = 0;
        for node in &tree_page.nodes {
            build_elems_for_node(doc, *page_id, doc_elem, node, &mut mcid_elems, &mut mcid_counter, &mut stats)?;
        }
        pt.push(parent_tree_key, mcid_elems);

        // /StructParents on the page dict.
        let page_dict = doc.get_dictionary_mut(*page_id).map_err(|e| e.to_string())?;
        page_dict.set("StructParents", Object::Integer(parent_tree_key));
        stats.pages_processed += 1;
    }

    let parent_tree_id = pt.write_into(doc);

    // 4) Fill the empty stroot dict we reserved up front.
    let stroot_dict = doc.get_dictionary_mut(stroot_id).map_err(|e| e.to_string())?;
    stroot_dict.set("Type", Object::Name(b"StructTreeRoot".to_vec()));
    stroot_dict.set("K", Object::Array(vec![Object::Reference(doc_elem)]));
    stroot_dict.set("ParentTree", Object::Reference(parent_tree_id));
    stroot_dict.set("ParentTreeNextKey", Object::Integer(stats.pages_processed as i64));
    stroot_dict.set("RoleMap", Object::Reference(role_map));

    // 5) Catalog wiring.
    let cat_id = doc.trailer.get(b"Root").map_err(|e| e.to_string())?.as_reference().map_err(|e| e.to_string())?;
    let cat = doc.get_dictionary_mut(cat_id).map_err(|e| e.to_string())?;
    cat.set("StructTreeRoot", Object::Reference(stroot_id));
    cat.set("MarkInfo", Object::Dictionary(dictionary! { "Marked" => true }));
    if !cat.has(b"Lang") {
        if let Some(l) = &opts.fallback_lang {
            cat.set("Lang", Object::string_literal(l.clone()));
        }
    }
    Ok(stats)
}

fn build_elems_for_node(
    doc: &mut Document,
    page_id: ObjectId,
    parent: ObjectId,
    node: &StructNode,
    mcid_elems: &mut Vec<ObjectId>,
    mcid_counter: &mut u32,
    stats: &mut WeaveStats,
) -> Result<(), String> {
    let role = tag_static(node.kind);
    if role == "Artifact" {
        // Artifacts are NOT in the structure tree — they are excluded.
        return Ok(());
    }
    let elem = make_struct_elem(doc, parent, role);
    stats.struct_elems_created += 1;

    // Attach /Alt for Figure if we have alt text from Slice 4.
    if matches!(node.kind, NodeKind::Figure) {
        if let Some(alt) = &node.alt_text {
            let d = doc.get_dictionary_mut(elem).map_err(|e| e.to_string())?;
            d.set("Alt", Object::string_literal(alt.clone()));
            stats.figures_with_alt_text += 1;
        }
    }
    if let Some(lang) = &node.lang {
        let d = doc.get_dictionary_mut(elem).map_err(|e| e.to_string())?;
        d.set("Lang", Object::string_literal(lang.clone()));
    }

    // Leaves emit an MCR; containers recurse.
    let is_leaf = matches!(
        node.kind,
        NodeKind::Heading(_) | NodeKind::Paragraph | NodeKind::ListItem
            | NodeKind::Figure | NodeKind::Caption
    );
    if is_leaf {
        let mcr = Object::Dictionary(dictionary! {
            "Type" => "MCR",
            "Pg"   => page_id,
            "MCID" => Object::Integer(*mcid_counter as i64),
        });
        push_kid(doc, elem, mcr)?;
        mcid_elems.push(elem);
        *mcid_counter += 1;
    }

    // Connect to parent.
    push_kid(doc, parent, Object::Reference(elem))?;

    for child in &node.children {
        build_elems_for_node(doc, page_id, elem, child, mcid_elems, mcid_counter, stats)?;
    }
    Ok(())
}
```

**Step 1: Command skeleton**

```rust
#[derive(Serialize)]
pub struct LoomTagResult {
    pub output_path: String,
    pub stats: crate::pdf::loom::structure_tree::WeaveStats,
}

#[tauri::command]
async fn slab_loom_tag_document(input: PathBuf) -> CmdResult<LoomTagResult> {
    use crate::pdf::loom::{classify, extract_layout, order_reading, enrich_with_alt_text,
                            structure_tree::{weave, WeaveOptions}, AltTextOptions};
    use lopdf::Document;

    let bytes = match std::fs::read(&input) {
        Ok(b) => b,
        Err(e) => return CmdResult::Err { message: format!("read: {}", e) },
    };
    let layout = match extract_layout(&bytes) {
        Ok(l) => l, Err(e) => return CmdResult::Err { message: e },
    };
    let mut tree = classify(&layout);
    let order = order_reading(&tree, &layout);
    // Best-effort alt-text — non-fatal on Beacon unavailability.
    let _ = enrich_with_alt_text(&mut tree, &layout, &AltTextOptions::default()).await;

    let mut doc = match Document::load_mem(&bytes) {
        Ok(d) => d, Err(e) => return CmdResult::Err { message: format!("load: {}", e) },
    };
    let stats = match weave(&mut doc, &tree, &order, &WeaveOptions { fallback_lang: Some("en-US".into()) }) {
        Ok(s) => s, Err(e) => return CmdResult::Err { message: e },
    };

    let out_path = input.with_extension("tagged.pdf");
    if let Err(e) = doc.save(&out_path) {
        return CmdResult::Err { message: format!("save: {}", e) };
    }
    CmdResult::Ok { value: LoomTagResult { output_path: out_path.display().to_string(), stats } }
}
```

## Risk + mitigation

1. **Multi-stream `/Contents` arrays** — some PDFs (especially Acrobat-saved
   ones) split a page's content across multiple streams. Slice 5 returns an
   error in that case; mitigation: concat→rewrite→write-back as Slice 5.8
   follow-up if any test corpus PDF trips it.
2. **MCID alignment drift** — if the classify pass changes run ordering vs
   layout, MCIDs in the stream won't match StructElem MCRs. Mitigation: Task 3
   tests explicitly assert sequential MCIDs match the plan order.
3. **lopdf re-encoding side effects** — `Stream::compress()` after rewrite may
   re-deflate poorly if the source was uncompressed. Mitigation: keep streams
   as-is if `compress()` returns an error (graceful degrade).
4. **PDF/UA validators (PAC 3, veraPDF) may still flag warnings** — Slice 5
   ships the structure tree but Slice 6 (metadata, /Lang, XMP) is required for
   full conformance. Document this in release notes for v3.1.0-rc1.
