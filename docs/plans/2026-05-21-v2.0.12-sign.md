# v2.0.12 "Sign" ✒️ — Digital Signatures + Preset Stamps Implementation Plan

> **For Hermes:** Use `subagent-driven-development` to implement this plan task-by-task. Each slice = one delegated subagent. Two-stage review (spec compliance, then code quality) between slices.

**Goal:** Ship the single biggest business-workflow gap remaining in Slab — **signatures and stamps**. After v2.0.12 a user can draw, type, or import their signature once, then drop it on any PDF in two clicks; and apply preset stamps (APPROVED, DRAFT, CONFIDENTIAL, custom-text, custom-image) with one keystroke. Adobe Sign is a $14.99/mo standalone product; DocuSign starts at $10/mo; PDF Expert charges $79/yr partly for the same capability. Slab gives it away free, offline, with zero telemetry.

**Architecture:** Add **two new annotation primitives** on top of v2.0.11's 8-kind tagged-union — `signature` (an embedded raster/vector glyph with creator identity + creation timestamp) and `stamp` (a presetted ink-pattern with optional date overlay). Both reuse v2.0.6 sidecar JSON, v2.0.10's edit mode (drag/resize/delete/undo), v2.0.11's rotation + multi-select + align. New **signature library** at `src/lib/signatures.ts` — a per-user store keyed under `slab.signatures.v1` holding up to 8 saved signatures with `{ id, name, kind: "drawn"|"typed"|"imported", payload, createdAt }`. Drawn sigs reuse v2.0.7's `DrawLayer` capture pipeline (RDP-simplified ink strokes); typed sigs render via Google-Fonts-style cursive WebFont baked in (`Caveat`, `Dancing Script`, `Great Vibes` — all OFL, ~25KB woff2 each, bundled); imported sigs accept PNG/JPG/SVG ≤ 512KB via drag-drop or file picker. New **stamp catalog** at `src/lib/stamps.ts` with 14 first-party stamps (APPROVED ✅, REJECTED ❌, DRAFT 📝, CONFIDENTIAL 🔒, FOR REVIEW 👀, RECEIVED 📥, SIGN HERE ✍️, VOID 🚫, PAID 💵, FINAL 🏁, COPY 📄, ORIGINAL ⭐, URGENT ⚡, NOT FOR DISTRIBUTION 🚷) plus user-extensible custom stamps. Rust gets two new `Annotation` enum variants and emits ISO 32000-1 §12.5.6.19 `/Subtype /Stamp` dicts; for signatures we DO NOT yet attempt cryptographic PDF signing (PKCS#7 / `/Sig` field) — that's a v2.1.0 "Notary" follow-up release tracked in open-questions. v2.0.12 ships *visual* signatures (rendered ink/glyph baked onto the page on burn) plus a sidecar `signedBy` metadata field so the JSON sidecar carries provable provenance. **Zero new Tauri commands** (reuses `slab_append_annotations`), **zero new Rust deps**, **one new frontend dep** (`@fontsource/caveat` + 2 siblings, total ~75KB woff2 self-hosted under MIT/OFL).

**Tech Stack:** Svelte 4 (frontend — new `SignatureLibraryPanel.svelte`, `SignatureCaptureModal.svelte`, `StampPaletteOverlay.svelte`), Rust 1.78 / Tauri 2 (backend — two new `Annotation` variants, two new `build_annotation_dict` arms), `@fontsource/{caveat,dancing-script,great-vibes}` for typed signatures (OFL, self-hosted, no Google CDN), pdfjs-dist 4 `eventBus.pagerendered` (existing render-layer hook), pure-TS RDP simplifier (already shipped in v2.0.7), CSS `transform` for live preview during signature placement gesture.

```typescript
// src/lib/signatures.ts
export const SIGNATURE_FONTS = ["Caveat", "Dancing Script", "Great Vibes"] as const;
export type SignatureFont = (typeof SIGNATURE_FONTS)[number];
export const MAX_SIGNATURES = 8;
const STORAGE_KEY = "slab.signatures.v1";
const MAX_IMPORT_BYTES = 512 * 1024;

export type DrawnSignature = {
  id: string;
  kind: "drawn";
  name: string;
  strokes: Array<Array<{ x: number; y: number; p?: number }>>;
  width: number;
  height: number;
  color: string;
  createdAt: number;
};
export type TypedSignature = {
  id: string;
  kind: "typed";
  name: string;
  font: SignatureFont;
  color: string;
  createdAt: number;
};
export type ImportedSignature = {
  id: string;
  kind: "imported";
  name: string;
  mime: "image/png" | "image/jpeg" | "image/svg+xml";
  data: string; // base64 (or raw SVG text)
  createdAt: number;
};
export type Signature = DrawnSignature | TypedSignature | ImportedSignature;

type Store = { signatures: Signature[]; defaultId: string | null };

function load(): Store {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    if (!raw) return { signatures: [], defaultId: null };
    return JSON.parse(raw);
  } catch {
    return { signatures: [], defaultId: null };
  }
}

function save(s: Store): void {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(s));
  for (const cb of subscribers) cb();
}

const subscribers = new Set<() => void>();
export function subscribeSignatures(cb: () => void): () => void {
  subscribers.add(cb);
  return () => subscribers.delete(cb);
}

function mkId(): string {
  return "sig_" + Math.random().toString(36).slice(2, 10) + Date.now().toString(36);
}

function enforceCapAndPush(store: Store, sig: Signature): void {
  store.signatures.push(sig);
  while (store.signatures.length > MAX_SIGNATURES) store.signatures.shift();
}

export function addDrawnSignature(input: Omit<DrawnSignature, "id" | "kind" | "createdAt" | "color"> & { color?: string }): string {
  if (!input.strokes || input.strokes.length === 0) throw new Error("drawn signature must have at least one stroke");
  const store = load();
  const id = mkId();
  enforceCapAndPush(store, {
    id, kind: "drawn", name: input.name, strokes: input.strokes,
    width: input.width, height: input.height,
    color: input.color ?? "#0a0a23", createdAt: Date.now(),
  });
  save(store);
  return id;
}

export function addTypedSignature(input: { name: string; font: SignatureFont; color: string }): string {
  if (!SIGNATURE_FONTS.includes(input.font)) throw new Error(`unsupported font: ${input.font}`);
  const store = load();
  const id = mkId();
  enforceCapAndPush(store, { id, kind: "typed", ...input, createdAt: Date.now() });
  save(store);
  return id;
}

export function addImportedSignature(input: { name: string; mime: ImportedSignature["mime"]; data: string }): string {
  if (input.data.length > MAX_IMPORT_BYTES) throw new Error(`signature payload exceeds 512KB limit (${input.data.length} bytes)`);
  const store = load();
  const id = mkId();
  enforceCapAndPush(store, { id, kind: "imported", ...input, createdAt: Date.now() });
  save(store);
  return id;
}

export function listSignatures(): readonly Signature[] {
  return load().signatures;
}

export function removeSignature(id: string): void {
  const store = load();
  store.signatures = store.signatures.filter((s) => s.id !== id);
  if (store.defaultId === id) store.defaultId = null;
  save(store);
}

export function getDefaultSignature(): Signature | null {
  const store = load();
  if (store.defaultId) {
    const found = store.signatures.find((s) => s.id === store.defaultId);
    if (found) return found;
  }
  return store.signatures.at(-1) ?? null;
}

export function setDefaultSignature(id: string | null): void {
  const store = load();
  if (id !== null && !store.signatures.find((s) => s.id === id)) throw new Error(`unknown signature: ${id}`);
  store.defaultId = id;
  save(store);
}
```

```rust
#[serde(rename = "signature")]
Signature {
    page: u32,
    /// Page-space rect [x1, y1, x2, y2] in PDF points

    page: u32,

    /// Accent color as 6-digit hex
```

- **Cloud signature sync across machines** → defer to v2.x Pro tier (the paid-tier hook).
- **Signature request workflow** (send PDF to someone, they sign, signed PDF comes back) → out of scope, would need server. Maybe v3.x.

- **Audit log** (who signed what when, exportable) → tracked alongside Notary.
- **Initials stamp** (single-character signature for "initial each page") → quick win for a v2.0.13 patch.
