# v1.9.1 — Voice Mode: Listen 🎙️ Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add Speech-to-Text (mic input → transcript) to Beacon Voice Mode so users can dictate questions to Slab via whisper.cpp, complementing the v1.9.0 TTS (Speak) direction.

**Architecture:**
- **Engine abstraction**: `SttEngine` trait mirroring v1.9.0's `TtsEngine` so future providers (Vosk, Deepgram, etc.) can plug in. First implementation is `WhisperCpp` shelling out to a bundled `whisper-cli` binary.
- **Recording**: Cross-platform mic capture via shelling out to native recorders (`sox` / `arecord` / PowerShell `MediaCapture`), writing 16-kHz mono WAV to a tempfile. No `cpal` dependency — same hermetic-CI pattern as TTS.
- **Session model**: Single-slot `SttSession` (only one recording at a time, like `VoiceSession`). Kill-prev-on-start semantics.
- **Privacy**: Audio tempfile is **deleted immediately** after transcription. We never keep audio bytes, never send them off-device. Whisper.cpp runs locally.
- **Tauri surface**: 4 new commands — `voice_stt_capabilities`, `voice_stt_start`, `voice_stt_stop`, `voice_stt_is_recording`. `stop` returns the transcript.
- **Frontend**: Mic-button on `BeaconChatPanel`, plus a "Listen Settings" row in `BeaconVoicePanel` letting the user pick the STT engine + model.

**Tech Stack:** Rust (`tauri-2`, `serde`, `tempfile`), shell-out to `sox`/`arecord`/PowerShell, shell-out to `whisper-cli` (from whisper.cpp). Svelte 5 frontend.

```rust
//! Slab Beacon — Voice Mode (STT).
//!
//! Speech-to-Text counterpart to `ai::voice` (TTS). v1.9.1 ships
//! whisper.cpp only; the enum + trait shape is ready for additional
//! providers later.

use serde::{Deserialize, Serialize};

/// Identifier for the underlying STT engine. Frontend uses this as a
/// stable string in config + on the API surface.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum SttEngine {
    /// whisper.cpp — local, hermetic, GGUF model files.
    WhisperCpp,
}

impl SttEngine {
    pub fn as_id(self) -> &'static str {
        match self {
            Self::WhisperCpp => "whisper-cpp",
        }
    }

    pub fn from_id(s: &str) -> Option<Self> {
        match s {
            "whisper-cpp" => Some(Self::WhisperCpp),
            _ => None,
        }
    }

    pub fn platform_default() -> Option<Self> {
        Some(Self::WhisperCpp)
    }

    /// Name of the binary we expect on `$PATH` (or `$WHISPER_CLI`).
    pub fn binary_name(self) -> &'static str {
        match self {
            // whisper.cpp's CLI is called `whisper-cli` since release v1.7.
            Self::WhisperCpp => "whisper-cli",
        }
    }
}

/// Result of a successful transcription.
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Transcript {
    /// Cleaned-up text (no whisper.cpp timestamps).
    pub text: String,
    /// Detected ISO 639-1 language code, if the engine reports it.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub language: Option<String>,
    /// Recording wall-clock duration in milliseconds.
    pub duration_ms: u64,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct SttEngineCapability {
    pub id: String,
    pub installed: bool,
    pub binary_path: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct SttCapabilities {
    pub engines: Vec<SttEngineCapability>,
    pub recorder_available: bool,
}

/// Probe each engine's binary on `$PATH`. Cheap (subprocess) — okay to
/// call on every settings-panel render.
pub fn capabilities() -> SttCapabilities {
    let whisper = which("whisper-cli");
    SttCapabilities {
        engines: vec![SttEngineCapability {
            id: SttEngine::WhisperCpp.as_id().into(),
            installed: whisper.is_some(),
            binary_path: whisper,
        }],
        recorder_available: recorder_binary().is_some(),
    }
}

/// Look up an executable on `$PATH`. Returns its absolute path if found.
pub(crate) fn which(name: &str) -> Option<String> {
    let path = std::env::var("PATH").ok()?;
    let sep = if cfg!(windows) { ';' } else { ':' };
    for dir in path.split(sep) {
        let candidate = std::path::Path::new(dir).join(name);
        if candidate.is_file() {
            return Some(candidate.to_string_lossy().into_owned());
        }
        if cfg!(windows) {
            let exe = std::path::Path::new(dir).join(format!("{name}.exe"));
            if exe.is_file() {
                return Some(exe.to_string_lossy().into_owned());
            }
        }
    }
    None
}

/// Pick the recorder for this OS: `sox` (mac), `arecord` (linux),
/// PowerShell (windows). Returns the absolute path or PowerShell stub.
pub(crate) fn recorder_binary() -> Option<String> {
    if cfg!(target_os = "macos") {
        which("sox").or_else(|| which("rec"))
    } else if cfg!(target_os = "linux") {
        which("arecord").or_else(|| which("sox"))
    } else if cfg!(target_os = "windows") {
        // PowerShell is always present on Win7+.
        Some("powershell".into())
    } else {
        None
    }
}
```
