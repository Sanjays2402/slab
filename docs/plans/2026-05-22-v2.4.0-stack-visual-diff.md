# v2.4.0 "Stack" — Visual PDF Diff Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship a side-by-side **visual** PDF diff workstation: render both revisions at the same DPI, overlay a red/green changed-pixel heatmap on top of the rasters, scroll-lock the two panes, jump between changes via `n` / `N`, and ship a Beacon-powered "Summarize the changes in 5 bullets" panel — all offline.

**Architecture:**

Three layers stacked on top of the existing line-level `pdf::diff` engine:

1. **Backend `pdf::visual_diff`** (new module, ~480 LOC + tests) — renders both PDFs via Poppler `pdftoppm` at the chosen DPI, computes a per-page pixel difference (luminance-Δ thresholded into binary mask, run-length encoded into change boxes), produces a `VisualDiff` DTO that bundles the existing line diff plus the new raster + change-box payload. Pure-Rust glue; Poppler is the only external dep (already a Slab requirement).
2. **Tauri command surface** — three new commands: `slab_visual_diff_pdfs(old, new, dpi)` (full visual diff), `slab_visual_diff_page(old, new, page, dpi)` (single-page incremental for the "load on demand as you scroll" path), `slab_visual_diff_export_html(diff, output)` (self-contained HTML report — opens in any browser, no Slab required to read).
3. **Frontend "Stack" tab** — a top-level tab type (sibling of the Reader tab) with a split-pane viewer: left = old raster, right = new raster, both scroll-locked, change boxes outlined in coral on the old side / mint on the new side. Navigation chrome: changed-pages strip down the left edge (mini-thumbnails with change-density bars), `n` / `N` jumps between change boxes, `Cmd/Ctrl+Shift+D` opens Stack from anywhere, palette entry `stack:open`, settings panel section with DPI + heatmap-intensity sliders. Beacon "Summarize changes" button calls the existing `slab_beacon_summarize_diff` command and renders in a slide-over.

**Tech Stack:**

- Rust: `image` 0.25 (already in tree via flatten raster mode), `similar` (already), `serde`, `lopdf` (page count). Optional `imageproc` 0.25 for the morphological dilate that smooths the change mask — vendored only if its tree adds < 200 KB; otherwise hand-rolled 3×3 max-filter (single pass, ~30 LOC).
- Frontend: Svelte 5 runes, existing Tauri bindings pattern. Coral / mint accent colors already in `src/app.css` as `--c-danger-soft` and `--c-success-soft`.
- Reuses: `pdf::extract::extract_text`, `pdf::diff::diff_pdfs`, `BeaconDiffSummary` DTO, Poppler shellout pattern from `pdf::flatten`.

use image::{GenericImageView, GrayImage, ImageBuffer, Luma, RgbaImage};

/// Per-pixel luminance delta. Both images must be the same size; if not,
/// the smaller dimensions win and the rest is ignored (treated as unchanged
/// region, since the UI will draw the size mismatch separately).
///
/// `threshold` is the absolute luma-delta cutoff (0..=255). 20 is a good
/// default — survives JPEG-ish anti-aliasing wiggles while catching a
/// re-flowed word.
pub fn mask_changes(a: &RgbaImage, b: &RgbaImage, threshold: u8) -> GrayImage {
    let w = a.width().min(b.width());
    let h = a.height().min(b.height());
    let mut out = ImageBuffer::from_pixel(w, h, Luma([0u8]));
    for y in 0..h {
        for x in 0..w {
            let pa = a.get_pixel(x, y).0;
            let pb = b.get_pixel(x, y).0;
            // Rec.709 luma.
            let la = (0.2126 * pa[0] as f32 + 0.7152 * pa[1] as f32 + 0.0722 * pa[2] as f32) as i32;
            let lb = (0.2126 * pb[0] as f32 + 0.7152 * pb[1] as f32 + 0.0722 * pb[2] as f32) as i32;
            if (la - lb).abs() >= threshold as i32 {
                out.put_pixel(x, y, Luma([255]));
            }
        }
    }
    dilate_3x3(&out)
}

/// 3×3 max-filter — fattens isolated change pixels into chunks so the
/// connected-component pass groups neighbouring edits into one box instead
/// of speckled confetti. Single-pass, no extra allocation beyond the output.
fn dilate_3x3(src: &GrayImage) -> GrayImage {
    let (w, h) = (src.width(), src.height());
    let mut out = ImageBuffer::from_pixel(w, h, Luma([0u8]));
    for y in 0..h {
        for x in 0..w {
            let mut hot = 0u8;
            for dy in -1i32..=1 {
                for dx in -1i32..=1 {
                    let nx = x as i32 + dx;
                    let ny = y as i32 + dy;
                    if nx < 0 || ny < 0 || nx >= w as i32 || ny >= h as i32 {
                        continue;
                    }
                    hot = hot.max(src.get_pixel(nx as u32, ny as u32).0[0]);
                }
            }
            out.put_pixel(x, y, Luma([hot]));
        }
    }
    out
}

/// Iterative flood-fill connected components on a binary mask, then
/// produces AABB-wrapped `ChangeBox`es. Drops boxes whose mass < `min_mass`.
pub fn aabb_components(mask: &GrayImage, min_mass: u32) -> Vec<ChangeBox> {
    let (w, h) = (mask.width(), mask.height());
    let mut visited = vec![false; (w * h) as usize];
    let mut boxes = Vec::new();
    for y0 in 0..h {
        for x0 in 0..w {
            let idx = (y0 * w + x0) as usize;
            if visited[idx] || mask.get_pixel(x0, y0).0[0] == 0 {
                continue;
            }
            // BFS from (x0, y0).
            let mut stack = vec![(x0, y0)];
            let (mut min_x, mut min_y, mut max_x, mut max_y, mut mass) =
                (x0, y0, x0, y0, 0u32);
            while let Some((x, y)) = stack.pop() {
                let i = (y * w + x) as usize;
                if visited[i] || mask.get_pixel(x, y).0[0] == 0 {
                    continue;
                }
                visited[i] = true;
                mass += 1;
                if x < min_x { min_x = x; }
                if y < min_y { min_y = y; }
                if x > max_x { max_x = x; }
                if y > max_y { max_y = y; }
                if x + 1 < w { stack.push((x + 1, y)); }
                if x > 0     { stack.push((x - 1, y)); }
                if y + 1 < h { stack.push((x, y + 1)); }
                if y > 0     { stack.push((x, y - 1)); }
            }
            if mass >= min_mass {
                boxes.push(ChangeBox {
                    x: min_x,
                    y: min_y,
                    w: max_x - min_x + 1,
                    h: max_y - min_y + 1,
                    mass,
                });
            }
        }
    }
    boxes
}
```

use crate::pdf::PdfError;
use image::ImageReader;
use std::path::Path;

/// Rasterize every page of `pdf` to RGBA at `dpi` using Poppler `pdftoppm`.
/// Returns one `RgbaImage` per page in page-order.
///
/// Requires `pdftoppm` on PATH. On absence, returns
/// `PdfError::ExternalToolMissing` so the caller can degrade gracefully
/// (the Tauri command surface translates this into a UI-friendly error).
pub fn render_pdf_pages(pdf: &Path, dpi: u32) -> Result<Vec<RgbaImage>, PdfError> {
    let tmp = tempfile::tempdir()
        .map_err(|e| PdfError::Io(format!("tempdir: {e}")))?;
    let prefix = tmp.path().join("page");
    let status = std::process::Command::new("pdftoppm")
        .arg("-r").arg(dpi.to_string())
        .arg("-png")
        .arg(pdf)
        .arg(&prefix)
        .status()
        .map_err(|e| PdfError::ExternalToolMissing(format!(
            "pdftoppm not found ({e}). Install poppler: \
             `brew install poppler` (macOS) / `apt install poppler-utils` (Linux)."
        )))?;
    if !status.success() {
        return Err(PdfError::Io(format!("pdftoppm exited {status}")));
    }
    // pdftoppm names files `<prefix>-N.png` where N is 1-based and zero-padded
    // to log10(page_count) digits. Collect, sort by the embedded number.
    let mut entries: Vec<PathBuf> = std::fs::read_dir(tmp.path())
        .map_err(|e| PdfError::Io(format!("readdir: {e}")))?
        .filter_map(|e| e.ok().map(|e| e.path()))
        .filter(|p| p.extension().and_then(|s| s.to_str()) == Some("png"))
        .collect();
    entries.sort();
    let mut out = Vec::with_capacity(entries.len());
    for p in entries {
        let img = ImageReader::open(&p)
            .map_err(|e| PdfError::Io(format!("open {}: {e}", p.display())))?
            .decode()
            .map_err(|e| PdfError::Io(format!("decode {}: {e}", p.display())))?
            .to_rgba8();
        out.push(img);
    }
    Ok(out)
}
```

use base64::{engine::general_purpose::STANDARD as B64, Engine as _};
use image::ImageFormat;
use std::io::Cursor;

fn rgba_to_png_b64(img: &RgbaImage) -> Result<String, PdfError> {
    let mut buf: Vec<u8> = Vec::with_capacity((img.width() * img.height()) as usize);
    img.write_to(&mut Cursor::new(&mut buf), ImageFormat::Png)
        .map_err(|e| PdfError::Io(format!("png encode: {e}")))?;
    Ok(B64.encode(&buf))
}

/// Full visual diff: 1:1 page alignment by index for v1.
///
/// - `dpi`: render DPI (96..=300 recommended; 150 is the UI default).
/// - `luma_threshold`: 0..=255 (20 default) — pixel-delta cutoff.
/// - `min_mass`: smallest connected-component size to keep (8 default) —
///   drops 1-2-pixel anti-alias jitter.
pub fn visual_diff_pdfs(
    old: &Path,
    new: &Path,
    dpi: u32,
    luma_threshold: u8,
    min_mass: u32,
) -> Result<VisualDiff, PdfError> {
    let old_pages = render_pdf_pages(old, dpi)?;
    let new_pages = render_pdf_pages(new, dpi)?;
    let n = old_pages.len().max(new_pages.len());
    let mut pages = Vec::with_capacity(n);
    for i in 0..n {
        let op = old_pages.get(i);
        let np = new_pages.get(i);
        let (w, h, changes, op_b64, np_b64) = match (op, np) {
            (Some(a), Some(b)) => {
                let mask = mask_changes(a, b, luma_threshold);
                let boxes = aabb_components(&mask, min_mass);
                (
                    a.width().min(b.width()),
                    a.height().min(b.height()),
                    boxes,
                    Some(rgba_to_png_b64(a)?),
                    Some(rgba_to_png_b64(b)?),
                )
            }
            (Some(a), None) => (
                a.width(), a.height(),
                vec![ChangeBox { x: 0, y: 0, w: a.width(), h: a.height(), mass: a.width() * a.height() }],
                Some(rgba_to_png_b64(a)?),
                None,
            ),
            (None, Some(b)) => (
                b.width(), b.height(),
                vec![ChangeBox { x: 0, y: 0, w: b.width(), h: b.height(), mass: b.width() * b.height() }],
                None,
                Some(rgba_to_png_b64(b)?),
            ),
            (None, None) => unreachable!("at least one side must have page i"),
        };
        pages.push(VisualPage {
            old_page: op.map(|_| (i + 1) as u32),
            new_page: np.map(|_| (i + 1) as u32),
            old_png_b64: op_b64,
            new_png_b64: np_b64,
            w,
            h,
            changes,
        });
    }
    let line_diff = crate::pdf::diff::diff_pdfs(old, new)?;
    Ok(VisualDiff {
        old_path: old.to_path_buf(),
        new_path: new.to_path_buf(),
        dpi,
        pages,
        line_diff,
    })
}

/// Write a single-file HTML report (data: URIs for PNGs, inline CSS) to
/// `output`. Self-contained — no Slab required to view, opens in any
/// browser. Returns the number of pages rendered.
pub fn export_html_report(diff: &VisualDiff, output: &Path) -> Result<u32, PdfError> {
    let mut html = String::new();
    html.push_str("<!doctype html><meta charset=\"utf-8\"><title>Slab visual diff</title>");
    html.push_str("<style>body{font:14px/1.4 -apple-system,system-ui,sans-serif;margin:24px;background:#0f1115;color:#e6e8ec}");
    html.push_str(".pg{display:grid;grid-template-columns:1fr 1fr;gap:16px;margin:24px 0;padding:16px;background:#161922;border-radius:12px}");
    html.push_str(".pg h3{margin:0 0 8px;font-size:13px;opacity:.7}");
    html.push_str(".pane{position:relative}.pane img{width:100%;height:auto;display:block;border-radius:8px}");
    html.push_str(".box{position:absolute;border:2px solid;border-radius:3px;pointer-events:none}");
    html.push_str(".box.old{border-color:#ff7a7a}.box.new{border-color:#7affb0}");
    html.push_str("h1{margin:0 0 8px}.meta{opacity:.6;font-size:12px;margin-bottom:24px}</style>");
    html.push_str(&format!(
        "<h1>Visual diff</h1><div class=\"meta\">{} → {} · {} DPI · {} page(s)</div>",
        diff.old_path.display(), diff.new_path.display(), diff.dpi, diff.pages.len()
    ));
    for p in &diff.pages {
        html.push_str("<div class=\"pg\">");
        for (side, png, label) in [
            ("old", &p.old_png_b64, "Old"),
            ("new", &p.new_png_b64, "New"),
        ] {
            html.push_str(&format!("<div><h3>{label}</h3><div class=\"pane\">"));
            if let Some(b64) = png {
                html.push_str(&format!("<img src=\"data:image/png;base64,{b64}\">"));
                for b in &p.changes {
                    let left = (b.x as f32 / p.w as f32) * 100.0;
                    let top = (b.y as f32 / p.h as f32) * 100.0;
                    let w = (b.w as f32 / p.w as f32) * 100.0;
                    let h = (b.h as f32 / p.h as f32) * 100.0;
                    html.push_str(&format!(
                        "<div class=\"box {side}\" style=\"left:{left}%;top:{top}%;width:{w}%;height:{h}%\"></div>"
                    ));
                }
            }
            html.push_str("</div></div>");
        }
        html.push_str("</div>");
    }
    std::fs::write(output, html).map_err(|e| PdfError::Io(format!("write report: {e}")))?;
    Ok(diff.pages.len() as u32)
}

  import { idle, type Status } from "$lib/types";

  let newPath = $state<string | null>(null);

  let diff = $state<VisualDiff | null>(null);

  let leftPane: HTMLDivElement | null = $state(null);
  let rightPane: HTMLDivElement | null = $state(null);
  let syncing = false;

  // Flat list of (pageIndex, boxIndex) tuples for n/N navigation.
  let cursor = $state(-1);

  function onScroll(src: "left" | "right") {
    if (syncing) return;
    const from = src === "left" ? leftPane : rightPane;
    const to   = src === "left" ? rightPane : leftPane;
    if (!from || !to) return;
    syncing = true;
    to.scrollTop = from.scrollTop;
    requestAnimationFrame(() => { syncing = false; });
  }

  function flatBoxes(): { page: number; box: ChangeBox }[] {
    if (!diff) return [];
    return diff.pages.flatMap((p, page) =>
      p.changes.map(box => ({ page, box }))
    );
  }

  function jumpTo(idx: number) {
    const all = flatBoxes();
    if (all.length === 0) return;
    cursor = ((idx % all.length) + all.length) % all.length;
    const { page, box } = all[cursor];
    // Compute pixel target inside the scroll container.
    const target = document.getElementById(`stack-pg-${page}`);
    if (!target || !leftPane) return;
    const pageTop = target.offsetTop;
    const pageH = target.offsetHeight;
    const boxYFrac = (box.y + box.h / 2) / (diff!.pages[page].h);
    const viewportH = leftPane.clientHeight;
    const desired = pageTop + boxYFrac * pageH - viewportH * 0.30;
    const reduced = matchMedia("(prefers-reduced-motion: reduce)").matches;
    leftPane.scrollTo({ top: desired, behavior: reduced ? "auto" : "smooth" });
    // scroll-lock listener mirrors to right pane.
  }

  function onKey(e: KeyboardEvent) {
    const t = e.target as HTMLElement | null;
    if (t && (t.tagName === "INPUT" || t.tagName === "TEXTAREA" || t.isContentEditable)) return;
    if (e.key === "n" && !e.shiftKey) { e.preventDefault(); jumpTo(cursor + 1); }
    else if (e.key === "N" || (e.key === "n" && e.shiftKey)) { e.preventDefault(); jumpTo(cursor - 1); }
  }

## Open questions (deferred to v2.4.1+)

1. **Reflow-aware alignment.** If a page is inserted at the front of `new`, every subsequent page mis-aligns. v2.4.1 should add a text-similarity-based page-pair matcher (Hungarian on bigram overlap, capped at O(n²) page pairs).
2. **Per-page incremental load.** For 500-page PDFs, base64-encoding every page upfront is wasteful. `slab_visual_diff_page(old, new, page, dpi)` returns one `VisualPage` and the UI fetches lazily.
3. **Annotation-aware diff.** Pure pixel diff misses moved highlights / form-field value changes. Future "Stack II" release.
4. **i18n.** fr/es/ar translations.
5. **Reflowable text-only diff mode.** For born-digital text PDFs, skip rasterization entirely and do glyph-position diff against `pdf::extract::extract_text` outputs.
6. **Hardware-accelerated rasterizer.** `pdftoppm` is CPU-only. Investigate `pdfium-render` for SIMD parallel rendering on multi-core.
