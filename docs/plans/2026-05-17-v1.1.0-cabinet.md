# Slab v1.1.0 "Cabinet" — Multi-Window Floating Panels Implementation Plan

> **For Hermes:** Use `subagent-driven-development` skill to implement this plan
> task-by-task. Each task is bite-sized (2-5 min focused work). Tasks are
> grouped into 8 sequential **slices**. Ship 1-2 slices per cron tick, run
> quality gates once per tick at the end, then commit + push.

**Goal:** Let any Slab panel (Beacon chat, Library, Reader tab, any tool
panel) be detached into its own native window with persistent geometry,
so users can pin Beacon next to their reader, keep the Library open on
a side monitor, or have two PDFs side-by-side in independent windows.

**Architecture:** Reuse a single SvelteKit frontend bundle across multiple
Tauri WebviewWindows. The route handles a query param `?panel=<id>&windowId=<wid>`
that mounts exactly one panel component (no sidebar, no tabs) in
**detached mode**. The main window remains a full host with all panels +
sidebar. A new Rust module `windows.rs` manages a `WindowRegistry`
that persists window state (label → {panel_id, geometry, target_doc}) to
`~/.slab/windows.json` and restores them on launch. Cross-window state
sync (recent docs, theme, keymap, Beacon chat history) flows through
events on the global Tauri event bus + the already-shared sqlite/JSON
on-disk stores. Each detached window is just another consumer of the
same `slab_*` Tauri commands; no IPC re-plumbing required.

**Tech Stack:**
- **Backend:** `tauri::WebviewWindowBuilder`, `tauri::Manager`, a new
  `windows.rs` module, `serde_json` for state persistence, the existing
  `dirs::home_dir()` helper for `~/.slab/`.
- **Frontend:** SvelteKit + Svelte 5 runes (`$state`, `$derived`),
  `URLSearchParams`, `@tauri-apps/api/webviewWindow`, a new `$lib/windows.ts`
  store, a new `$lib/components/DetachedShell.svelte` chrome.
- **Tests:** `cargo test --lib` for `windows::*` (geometry parsing, registry
  CRUD, race conditions), `svelte-check` for type safety. No headless
  Tauri tests — UI flows are smoke-tested manually by the user.

**Branch:** `feature/v1.1.0-cabinet`

**Slices:**
1. Plumbing — registry module + Tauri commands
2. Frontend detached-mode route + shell component
3. Detach-from-sidebar (one panel: Beacon chat) end-to-end
4. Persistence — `~/.slab/windows.json` save/restore
5. Generalize to all panels (parameterised detach)
6. Cross-window events — open file in detached Reader
7. Window menu + Command Palette entries
8. Version bump + release notes + Cabinet release

Each slice is **one cron tick** (3-6 commits). Run quality gates only
at the end of each tick.

```rust
// Append to src-tauri/src/windows.rs (before #[cfg(test)]):
use std::collections::HashMap;
use std::sync::Mutex;

pub struct WindowRegistry {
    inner: Mutex<HashMap<String, WindowState>>,
}

impl WindowRegistry {
    pub fn new() -> Self {
        Self { inner: Mutex::new(HashMap::new()) }
    }

    pub fn upsert(&self, s: WindowState) {
        self.inner.lock().unwrap().insert(s.label.clone(), s);
    }

    pub fn get(&self, label: &str) -> Option<WindowState> {
        self.inner.lock().unwrap().get(label).cloned()
    }

    pub fn remove(&self, label: &str) -> Option<WindowState> {
        self.inner.lock().unwrap().remove(label)
    }

    pub fn list(&self) -> Vec<WindowState> {
        let mut v: Vec<_> = self.inner.lock().unwrap().values().cloned().collect();
        v.sort_by(|a, b| a.label.cmp(&b.label));
        v
    }

    pub fn next_label(&self, panel_id: &str) -> String {
        let g = self.inner.lock().unwrap();
        let mut max_n = 0u32;
        let prefix = format!("panel-{}-", panel_id);
        for k in g.keys() {
            if let Some(rest) = k.strip_prefix(&prefix) {
                if let Ok(n) = rest.parse::<u32>() {
                    max_n = max_n.max(n);
                }
            }
        }
        format!("{}{}", prefix, max_n + 1)
    }
}

impl Default for WindowRegistry {
    fn default() -> Self { Self::new() }
}
```

```rust
use tauri::{AppHandle, Manager, WebviewUrl, WebviewWindowBuilder};

pub fn default_geometry_for_panel(panel_id: &str) -> Geometry {
    match panel_id {
        "library" => Geometry { x: 80, y: 80, width: 1000, height: 720 },
        "beacon"  => Geometry { x: 120, y: 100, width: 520, height: 760 },
        "reader"  => Geometry { x: 100, y: 100, width: 900, height: 760 },
        _         => Geometry { x: 140, y: 120, width: 720, height: 640 },
    }
}

#[tauri::command]
pub fn slab_window_open(
    app: AppHandle,
    state: tauri::State<'_, WindowRegistry>,
    panel_id: String,
    target_doc: Option<String>,
) -> Result<String, String> {
    let label = state.next_label(&panel_id);
    let geom = default_geometry_for_panel(&panel_id);

    let mut url = format!("/?panel={}&windowId={}", panel_id, label);
    if let Some(p) = &target_doc {
        // simple URL-encode of path
        let enc: String = p.chars()
            .map(|c| if c == ' ' { "%20".into() } else if c == '#' { "%23".into() } else { c.to_string() })
            .collect();
        url.push_str(&format!("&doc={}", enc));
    }

    let webview_url = WebviewUrl::App(url.into());
    let title = format!("Slab — {}", panel_id);

    let window = WebviewWindowBuilder::new(&app, &label, webview_url)
        .title(title)
        .inner_size(geom.width as f64, geom.height as f64)
        .position(geom.x as f64, geom.y as f64)
        .resizable(true)
        .decorations(true)
        .build()
        .map_err(|e| format!("failed to build window: {}", e))?;

    // Register
    state.upsert(WindowState {
        label: label.clone(),
        panel_id,
        geometry: geom,
        target_doc,
    });

    // Track close → remove from registry
    let app_clone = app.clone();
    let label_clone = label.clone();
    window.on_window_event(move |e| {
        if let tauri::WindowEvent::Destroyed = e {
            if let Some(reg) = app_clone.try_state::<WindowRegistry>() {
                reg.remove(&label_clone);
            }
        }
    });

    Ok(label)
}

#[tauri::command]
pub fn slab_window_close(
    app: AppHandle,
    state: tauri::State<'_, WindowRegistry>,
    label: String,
) -> Result<(), String> {
    if let Some(w) = app.get_webview_window(&label) {
        w.close().map_err(|e| e.to_string())?;
    }
    state.remove(&label);
    Ok(())
}

#[tauri::command]
pub fn slab_window_list(state: tauri::State<'_, WindowRegistry>) -> Vec<WindowState> {
    state.list()
}
```

```ts
import { invoke } from '@tauri-apps/api/core';
import { isInTauri } from './tauri';

export type Geometry = { x: number; y: number; width: number; height: number };
export type WindowState = {
  label: string;
  panelId: string;
  geometry: Geometry;
  targetDoc?: string | null;
};

export async function openPanelWindow(
  panelId: string,
  targetDoc?: string | null
): Promise<string | null> {
  if (!isInTauri()) {
    console.warn('[cabinet] detach unavailable outside Tauri');
    return null;
  }
  try {
    const label = await invoke<string>('slab_window_open', {
      panelId,
      targetDoc: targetDoc ?? null,
    });
    return label;
  } catch (e) {
    console.error('[cabinet] openPanelWindow failed:', e);
    return null;
  }
}

export async function closePanelWindow(label: string): Promise<void> {
  if (!isInTauri()) return;
  try {
    await invoke('slab_window_close', { label });
  } catch (e) {
    console.error('[cabinet] closePanelWindow failed:', e);
  }
}

export async function listPanelWindows(): Promise<WindowState[]> {
  if (!isInTauri()) return [];
  try {
    const raw = await invoke<Array<{
      label: string;
      panel_id: string;
      geometry: Geometry;
      target_doc?: string | null;
    }>>('slab_window_list');
    return raw.map(r => ({
      label: r.label,
      panelId: r.panel_id,
      geometry: r.geometry,
      targetDoc: r.target_doc,
    }));
  } catch (e) {
    console.error('[cabinet] listPanelWindows failed:', e);
    return [];
  }
}
```

```rust
use std::fs;
use std::path::PathBuf;

fn windows_json_path() -> Result<PathBuf, String> {
    let base = if let Ok(o) = std::env::var("SLAB_HOME_OVERRIDE") {
        PathBuf::from(o)
    } else {
        dirs::home_dir().ok_or_else(|| "no home dir".to_string())?.join(".slab")
    };
    fs::create_dir_all(&base).map_err(|e| e.to_string())?;
    Ok(base.join("windows.json"))
}

pub fn save_windows(states: &[WindowState]) -> Result<(), String> {
    let p = windows_json_path()?;
    let s = serde_json::to_string_pretty(states).map_err(|e| e.to_string())?;
    fs::write(p, s).map_err(|e| e.to_string())
}

pub fn load_windows() -> Result<Vec<WindowState>, String> {
    let p = windows_json_path()?;
    if !p.exists() { return Ok(vec![]); }
    let s = fs::read_to_string(&p).map_err(|e| e.to_string())?;
    let v: Vec<WindowState> = serde_json::from_str(&s).map_err(|e| e.to_string())?;
    Ok(v)
}
```

## Cross-Cutting Concerns

### Identifiers / labels

- Main window label: `main` (unchanged).
- Detached window labels: `panel-<id>-<n>` where `<id>` is the panel id
  and `<n>` is the next free integer for that id.
- Capability glob `panel-*` covers all of these.

### Why URL params instead of `tauri.localStorage` per-window

URL params survive reloads (Cmd+R), are inspectable in DevTools, work
identically in dev (`pnpm dev` over http) and prod (`tauri://localhost`),
and don't require a per-window IPC handshake to wake the panel.

### Why glob capability instead of per-window capability files

Less ceremony, no `capabilities/panel-N.json` churn per spawn. Tauri 2
supports glob windows in the windows array. If we ever need
**finer-grained per-panel permissions** (e.g. detached Library can't
write files), we revisit in v1.2.x.

### Performance

Each detached window spawns its own webview (~30-60MB RSS). Cap detached
window count at **6** in `slab_window_open`; reject extras with a toast.

### Tests we deliberately skip

- Headless Tauri integration. The project already skips these; we follow
  precedent.
- Visual regression of `DetachedShell`. Manual.
