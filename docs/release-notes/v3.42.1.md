# v3.42.1 — Bug Fixes

**Fixes for duplicated pages and malformed PDFs.**

## Fixed

- **Duplicated pages** — duplicating a page wrote a PDF in which one page object was referenced twice. Some readers reject that file. Each copy is now a separate page.
- **Table extraction** — a malformed PDF with NaN coordinates could crash the table detector. It now sorts safely.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
