# Slab v3.41.0 — Images & Blank Pages

**Turn pages into pictures, and sweep empty pages out of scans.**

## What's new

- **PDF → Images** — export any pages as PNG or JPEG at 36–600 DPI. Files are named `doc-01.png`, `doc-02.png`, … and saved to a folder next to your chosen location.
- **Remove Blank Pages** — Slab renders each page and measures how much of it is inked, ignoring scanner edge shadows. Pick Strict, Normal, or Lenient sensitivity, see exactly which pages are blank, then save a copy without them. Nothing is written if no page is blank.
- **CLI** — `slab to-images <file> <dir> [--format png|jpeg] [--dpi 150] [--pages 1,3]` and `slab remove-blank <file> -o <out> [--threshold] [--dry-run]`.
- **Server** — `POST /api/v1/to-images` (ZIP) and `POST /api/v1/remove-blank` (PDF, with an `x-slab-removed` header listing removed pages).

Both tools use Poppler's `pdftoppm`, the same dependency as OCR and Flatten: `brew install poppler` (macOS) or `apt install poppler-utils` (Linux).

## How to use it

Press `⌘K` and type "images" or "blank", choose a PDF, and follow the panel.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
