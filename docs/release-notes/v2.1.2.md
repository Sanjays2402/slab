# Slab v2.1.2 — Arranger 🗂️

The pdfarranger-killer release. Reorder, rotate, delete, duplicate, and undo every page operation — entirely offline, with a single atomic Save.

## What's new

### 50-deep undo / redo for every page operation
Every rotate, delete, duplicate, reorder, or page insert is recorded on a 50-op command stack. **Cmd/Ctrl+Z** backs out the last change; **Cmd/Ctrl+Shift+Z** redoes it. Push-after-undo collapses the redo branch (the model Linear, VS Code, and Figma all use).

No other free offline PDF tool ships per-op undo. Adobe Acrobat Pro ($239/yr) ships single-step revert. PDF Expert ($79/yr) and Foxit ($129/yr) ship session undo only. Slab ships 50 steps deep, free.

### Single-key hotkeys
The Pages (Visual) panel now hijacks the keyboard the way every serious editor should:

| Key | Action |
|-----|--------|
| **R** | Rotate selection 90° |
| **Shift+R** | Rotate selection 270° (counter-clockwise) |
| **D** | Duplicate selection |
| **Delete** / **Backspace** | Delete selection |
| **Cmd/Ctrl+Z** | Undo |
| **Cmd/Ctrl+Shift+Z** | Redo |
| **Escape** | Clear selection |

Shift-click and ⌘-click extend the selection. Hotkeys never fire inside inputs/textareas/contenteditable.

### ⭐ The rotate-tilt animation
Every rotate triggers a 280 ms cubic-bezier `(0.34, 1.56, 0.64, 1)` tilt with a gold-accent drop-shadow, then cascades a halo pulse to up to four neighbouring thumbnails (40 ms stagger). Delete pages slide out to the left over 220 ms. `prefers-reduced-motion` short-circuits everything.

### Permanent rotation (bakes geometry, strips /Rotate)
The new `slab rotate --permanent` CLI flag and `slab_rotate_permanent` Tauri command bake the rotation into page geometry via `q <matrix> cm` content-stream wrap + MediaBox swap, then strip the `/Rotate` viewer hint. Result: PDFs render correctly in every viewer, including the ones that quietly ignore the rotation hint (looking at you, legal e-filing systems).

### Image-to-page insertion
`slab insert` and `slab_insert` accept `InsertSource::Image { path, dpi }` — drop a PNG or JPG straight into the page tree as a single full-bleed page. Defaults to 150 DPI for legal-grade quality.

### Crash-safe atomic Save
Every multi-op apply now flushes through a tempfile cascade and lands the final result via `atomic_save` (tempfile + `fsync` + `rename(2)`). The host PDF on disk is touched **exactly once** at end of pipeline. Kill the app mid-Save; the original file is untouched.

`slab_apply_page_ops(input, ops[], output)` is the new batch entry point — TS and Rust share the `PageOp` shape verbatim across the IPC boundary (`#[serde(tag = "kind")]` + the TS discriminated union).

### Undo/Redo toolbar buttons
Two new buttons in the Pages panel show the next undo/redo label as a tooltip ("Undo Rotate page (⌘Z)"). Disabled when nothing's on the stack.
