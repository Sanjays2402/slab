# Slab v1.6.0 — "Citations" 📑

The next Beacon AI tool in the sidebar: **Citations**. Pick a PDF, click *Scan citations*, and Slab reads the body for inline cites (author-year, [12], or [smith2024]), extracts the bibliography from the end matter with the LLM, and shows you a structured References list with mention counts, expandable inline-cite chips, and one-click jump-to-page.

This is **Beacon Bonus Slice 12**, the next slice of the post-Bench roadmap focused on quick AI wins that ride existing infrastructure.

## What's new

### 📑 Citations panel in the sidebar

- New sidebar entry: **📑 Citations** (sits between PII Redact and Merge)
- Pick a PDF (or inherit from the Reader via `slab:open-recent`), click **Scan citations**
- Scans the full body for inline citations in three common styles:
  - **Author-year**: `(Smith 2024)`, `(Smith and Jones, 2023)`, `(Smith et al. 2024)`
  - **Bracket-number**: `[12]`, `[12,15]`, `[12-15]`
  - **Bracket-key**: `[smith2024]`, `[einstein1905]`
- Extracts the end-matter as a structured References table via the LLM (last 10% of pages, clamped to [3, 25])
- Links each inline mention to its reference; renders the references list with mention-count badges
- Click a reference to expand and see every inline mention as a chip → click a chip to jump to that page
- Orphan inline cites (no matching reference) collected in a separate collapsed block
- "Extract bibliography (LLM)" toggle for offline mode — regex inline-scan still works without Beacon

### Architecture

- New `ai::citations` module — regex scanner, liberal JSON parser, validation, dedupe, link counting, async entry point — 814 lines
- New `slab_beacon_find_citations` Tauri command — same provider plumbing as Beacon Outline/Summary
- Mirrors `ai::outline` layering exactly: scaffold → regex → parser → validate → link → entry → command → UI
- 18 new unit/integration tests pin: regex correctness across all three styles, liberal JSON parsing (fenced/chatty/JSON5 fallback), invalid-reference dropping, case-insensitive dedupe, inline-to-reference linking, end-matter slicing, MockProvider-driven happy-path + offline degraded mode

### Quality

- 611 tests passing (593 baseline + 18 new citation tests)
- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test --lib`, `pnpm check`, `pnpm build` all clean
- No new svelte-check warnings (baseline 23 preserved)

## Why this matters

Researchers and students live inside the citations of a paper. Manually following inline cites to the bibliography and back to the section you were reading breaks flow. Citations turns the whole reference apparatus into a navigable index: you can see at a glance which references are heavily cited, which citations are orphaned (often a sign of a typo or missing bibliography entry), and jump between bibliography and body in one click. It works offline (regex-only mode) so even users without Ollama get most of the value.
