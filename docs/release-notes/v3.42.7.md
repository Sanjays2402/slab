# v3.42.7 — Server Error Codes, Split Ranges & Accessibility

**Slab Server now reports bad input as a clear 400, Split accepts spaced ranges, and dozens of form-label and warning cleanups.**

## Fixed

- **Server error codes** — invalid input (a page out of range, an empty or wrong password) now returns `400` with a plain message instead of `500` with a Rust debug string. I/O and parse failures still return `500`.
- **Upload limit default** — `SLAB_MAX_UPLOAD_MB` now defaults to 256 outside Docker too, matching the docs and the Docker image (it was 200).
- **Bearer scheme** — `Authorization: bearer <key>` is accepted in any letter case.
- **Split page ranges** — `1 - 3` with spaces around the dash is accepted, as Merge already did.
- **Browser tools** — removing a page index that doesn't exist now says so instead of "cannot remove every page".

## Improved

- Form controls in Signet, Nup, Bedrock, Page Labels, Diff3, Grayscale, Markdown and Hopper rules are now associated with their labels for screen readers.
- Removed dead styles and deprecated event syntax; `svelte-check` warnings dropped from 104 to 26.
- README: quick links, server API-key setup, plugin and contributing sections.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
