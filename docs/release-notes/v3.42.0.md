# v3.42.0 — Update Check

**Know when a new Slab is out, without Slab phoning home.**

## What's new

- **Check for updates** — Settings → Updates → *Check for updates*. Slab asks GitHub's public releases API for the latest stable release, tells you whether you're current, and opens the release page so you can download it.
- **Optional daily launch check** — tick *Also check once a day at launch* and Slab shows a notification with a Download button when a newer version exists. Off by default.

## Privacy

Slab still never contacts anything on its own. A check is one anonymous request to `api.github.com`: no account, no machine ID, no document data. The release link is only opened if it points to the Slab repository on GitHub.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
