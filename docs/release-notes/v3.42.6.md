# v3.42.6 — Server Fixes, API Key & Rotation Fixes

**Pages no longer go missing from nested PDFs, the Docker image listens on the right port, and Slab Server can require an API key.**

## Fixed

- **Pages going missing** — reordering or extracting pages from a PDF with nested page trees dropped pages (3 in, 2 out). Fixed.
- **Docker image** — the container listened on the wrong port, so `docker run -p 8080:8080` and its healthcheck failed. It now uses `SLAB_BIND`, which defaults to port 8080. Scripts that set `SLAB_PORT` or `SLAB_HOST` still work.
- **Rotation with inherited settings** — a page that inherits a rotation from its page-tree parent rotates from that angle.
- **Remove Blank Pages on an all-blank scan** — the error explains the situation and suggests Lenient sensitivity.

## Added

- **`SLAB_API_KEY`** — set it to require a key on every API operation (`Authorization: Bearer <key>` or `X-Api-Key: <key>`). `/healthz` and `/api/v1/ops` stay public. Unset, the server stays open, as before.

This release includes the changes from v3.42.3, v3.42.4 and v3.42.5, whose builds failed and were never published.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
