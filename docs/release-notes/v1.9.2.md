# v1.9.2 — Voice Mode: Polish 🎙

Beacon's Voice Mode gets four sharp UX upgrades — all the rough edges
v1.9.1 left behind in the rush to ship Listen.

## What's new

- **Cancel a recording** — press **Esc** while recording, or **right-click** the mic button. The in-flight WAV is unlinked immediately and no transcript is produced. Your privacy guarantee is intact: nothing leaves your machine, not even briefly.
- **Voice-to-send** — Beacon now listens for a trailing trigger phrase (default `send it`, configurable) and auto-submits your dictated prompt. Hands-free chat finally clicks.
- **Whisper model picker** — switch between `tiny.en` / `base.en` / `small.en` (and any custom `ggml-*.bin` you drop into `~/.slab/models/` or `$SLAB_MODELS_DIR`) right from the Listen settings panel. Per-recording override + persisted default. Smaller models for quick dictation, larger ones for technical content.

## Settings round-trip

Every new knob persists through `~/.slab/config.toml` under `[beacon.voice]`:

```toml
stt_model = "base.en"
stt_trigger_word = "send it"
stt_send_on_trigger = true
```

Legacy v1.9.1 configs load cleanly — every new field is optional.

## Bug fixes

- **Settings panel never pre-populated from disk on v1.9.1.** The Listen
  panel was casting `slab_beacon_config_read` to the wrong shape and
  silently ignoring saved defaults on every launch. Fixed: it now
  reads `cfg.beacon.voice` correctly and writes back through the same
  path. Your saved STT engine / endpoint / API key now actually
  survive a relaunch.

## Privacy

Same as v1.9.0/v1.9.1. Audio bytes stay on your machine. WAV files
are deleted immediately after transcription or cancellation. Whisper
runs locally via whisper.cpp — no network round-trip for STT.

## Deferred to v1.9.3

The native Windows recorder (cargo feature `windows-stt`) was on the
v1.9.2 wishlist but didn't make this drop. The PowerShell shell-out
path from v1.9.1 still works on Windows 10/11; the native rewrite is
a perf-only delta (~30 ms vs ~1.5 s spawn) and lands next tick.

## Test count

release, +0 regressions).
