# v3.30.0 — Quill Smart Fill 🪄

> Drag a resume onto a job application. Slab maps the rest. Nothing leaves your machine.

## The wow

Smart Fill is the fifth tool in the **Forms** workspace — and it's the one
competitors charge extra for. Drop a source document (your resume, last year's
tax form, a contact-card markdown, a CSV row, anything) onto one drop-zone,
drop the target AcroForm PDF onto the other, hit **Propose with AI**, and
watch Slab map source content onto every fillable field with a confidence
score per row.

Accept the high-confidence rows, edit the marginal ones inline, reject the
guesses, then **Apply** — Slab writes a new filled PDF using the same engine
behind Quill's manual fill workflow. Same `/NeedAppearances=true` output;
every PDF reader on earth renders it correctly.

## What's behind the wow

- **100% local AI.** Smart Fill runs through your Beacon provider — Ollama
  by default. Your resume never touches Adobe's cloud, OpenAI's logs, or
  anyone's "anonymous telemetry."
- **A new keyboard shortcut.** `⌘⇧I` (Ctrl+Shift+I on Linux/Windows) from
  anywhere in the app jumps you straight to Smart Fill.
- **Confidence-coded diff UI.** Green ≥ 85%, amber ≥ 50%, red below. Scan
  a 50-field tax form in three seconds and you know which rows to audit.
- **Inline editing on every row.** The model proposes; you decide.
- **Accept All / Reject All.** For when the model nailed it (or didn't).
- **Provider footer.** Slab tells you exactly which model answered — e.g.
  `Generated by ollama (llama3.2:3b)`. Privacy you can read.

## Reach it three ways

| | |
|---|---|
| Keyboard | `⌘⇧I` |
| Command palette | `⌘K` → "Forms: Smart Fill" |
| Sidebar | Forms → Smart Fill tab |

## Why this matters

Adobe Acrobat ships AI form-filling behind their paid tier and a
"your data may be used to improve services" checkbox you can't fully turn
off. PDF Expert and Foxit don't ship offline AI form-fill at all.

Slab v3.30.0 makes the killer feature free, local, and one keystroke away.

## Under the hood

- 24 backend tests across `pdf::forms_smart_fill::{extract, mapper, propose}`
- New keymap action `quill.smartfill` with regression test
- Source extractors for PDF / TXT / MD / CSV / JSON
- JSON-contract prompt — the model's reply is parsed defensively and any
  shape error becomes a soft warning banner instead of a crash
