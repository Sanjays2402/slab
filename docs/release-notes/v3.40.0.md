# Slab v3.40.0 — Balanced Split

**Choose how many PDFs you need. Slab handles the page math.**

## What's new

- **Split into N files** — enter an exact number of output PDFs. Slab divides every page into contiguous, balanced parts; extra pages go into the first files. For example, a 10-page PDF split into three files produces 4, 3, and 3 pages.
- **Live output preview** — see filenames, page ranges, and page counts before saving in all three split modes: Into N files, Every N pages, and By ranges. Large plans show the first 20 outputs plus the remaining count.
- **Validation before saving** — fractional counts, excessive file counts, invalid ranges, and overlapping ranges are rejected. Range mode shows how many unselected pages will be omitted. The source PDF remains unchanged.

## Fixes and release maintenance

- Fixed duplicate rotation command definitions and registrations that prevented desktop compilation.
- Fixed Merge saving to an undefined output variable.
- Updated PDF.js cleanup calls and browser PDF downloads for current dependency types.
- Added frontend type checking, split-planner tests, and static builds to the build workflow. Node 22 is used for frontend builds.

## How to use it

Open **Split** from the toolbox or command palette, choose a PDF, select **Into N files**, and enter a file count. Review the output preview, choose an output folder, and press **Split**.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
