# Slab v3.29.0 — Forms Tour

**Open Forms, learn it in 30 seconds.**

The v3.28.0 release collapsed four Acrobat-killer features into one tabbed
Forms workspace. That was a huge win for power users — and a head-scratcher
for first-time visitors. Which tab solves my problem? Where do I start?

This release answers in 30 seconds, with style.

## The headline

The first time you click into Forms, a polished coachmark tour fires
automatically and walks you through all four tabs:

> 🍰 **Welcome to Forms** — four features, one workspace.
>
> ✨ **Detect** — start here for flat PDFs. Slab proposes fillable fields automatically.
>
> ✎ **Design** — draw fields by hand. Pixel-precise. Great for reusable templates.
>
> 📝 **Fill** — type values into an existing form. Fully offline, unlike Acrobat's cloud filler.
>
> ⋮ **Batch** — drop a CSV, get one filled PDF per row. 200 lease agreements in 200 seconds.

A glowing spotlight ring tracks each tab, the bubble eases into position
with cubic-bezier motion, and the whole thing is keyboard-driven: `→`
advances, `←` goes back, `Esc` dismisses. The tour only auto-fires on
your first visit — but you can replay it any time.

## Three ways to summon the tour

- **Automatic** on first visit to Forms.
- **Command palette** — `Cmd/Ctrl+K` → "Forms: Show welcome tour".
- **Keyboard** — `Cmd/Ctrl+Shift+/` from anywhere in the app.

## The little things

- 🎯 **Spotlight follows the active tab** with a 220ms cubic-bezier ease.
- 💫 **Pulsing glow ring** at 2.4s cadence keeps your eye on the target
  without feeling frantic.
- ⌨️ **Full keyboard navigation** — every primary action has a key.
- ♿ **`prefers-reduced-motion` respected** — animations gracefully disable.
- 💾 **Persisted per-user** — the tour never re-fires once you've seen it.
- 📌 **Pagination dots** double as click-targets for direct jumps.
