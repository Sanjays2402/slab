# Slab v3.25.0 — "Quill Pro"

**Mail-merge for PDFs.**

Drop a fillable PDF. Drop a CSV. Get one filled, named, sanitized PDF
per row — flattened on demand, optionally zipped, ready to ship.

Adobe Acrobat charges $20/month for Data Merge. PDF Expert doesn't have
it. Foxit gates it behind their Editor tier. Slab does it free, offline,
on every OS — and it finishes 250 onboarding packets in under ten
seconds.

## What's new

### Quill Batch — `Cmd/Ctrl + Shift + B`

A new sidebar entry under **Forms**. Three steps, three cards:

1. **Pick a template PDF.** Any fillable AcroForm — exported from
   Acrobat, Foxit, Slab's own Quill, or built by hand. We honor
   read-only fields and `/NeedAppearances` exactly like the
   single-fill flow does.
2. **Pick a CSV.** First row is headers. The panel previews the first
   five rows inline and surfaces a clickable chip for every detected
   column — tap a chip to drop `{column}` into the filename template.
3. **Pick an output folder + go.** Defaults to
   `~/Slab/QuillBatch/<timestamp>/` so nothing collides with anything
   else.

A live progress button counts down `N PDFs`. When the run finishes,
the hero card shows you exactly what shipped — filled, failed,
flattened, zipped — and a single "Open output folder" button reveals
the result set in the OS file manager.

### Filename templating that gets out of your way

```
{row}_{lastname}_{first_name}.pdf
```

- `{row}` → 1-indexed row number.
- `{<any-column>}` → that row's value.
- Filesystem-unsafe characters (`/ \ : * ? " < > |`) collapse to `_`.
- Missing `.pdf` extension? Appended for you.
- Unknown placeholder? Renders empty (matches Word/Excel mail-merge
  norms; doesn't crash mid-batch).

### One bad row never kills the batch

Every row's success or failure is captured independently. The driver
keeps going, then writes a `_slab_quill_batch_load_file.csv` next to
your PDFs with one line per row (`row, output, status, error`) so a
paralegal can do an instant pass/fail review without scrolling through
hundreds of files.

### Optional ZIP packaging

Flip the toggle, give it a name, get `<your-name>.zip` containing every
successful PDF — Deflate-compressed, no extra tools needed. Perfect for
shipping a discovery production to opposing counsel in a single
attachment.

### Flatten on the way out

Toggle "Flatten output PDFs" if your downstream consumers (DocuSign,
court filing portals, legacy mailers) don't like editable form widgets.
The output is locked-down rendered text.

## Why this matters

Mail-merging PDFs is the kind of grind that turns into a $20/month
Acrobat subscription that nobody questions. HR teams do it every
quarter. Legal discovery teams do it for every production. Government
forms processors do it constantly. Slab takes the whole motion out of
the SaaS column and puts it where it belongs: in a fast, local,
private desktop app that ships in your existing Slab install.

## Under the hood

Pure-Rust pipeline (`src-tauri/src/pdf/forms_batch.rs`) layered on the
existing `pdf::forms::fill()` primitive. The `csv` crate handles the
spreadsheet, `lopdf` handles the PDFs, the existing `zip` crate handles
packaging. 13 unit tests cover the template engine, the CSV parser,
and the driver's golden + error paths. The Tauri command hops onto
`spawn_blocking` so the UI stays buttery-smooth even when you're
generating a thousand PDFs.

Zero new native dependencies. Same single-blob desktop binary.
