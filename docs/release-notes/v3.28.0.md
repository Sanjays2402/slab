# Slab v3.28.0 — Quill Hub

Four features. One workspace. The end of "which Quill panel did I want again?"

Slab's form-handling story has been growing for the last four releases — auto-detect,
designer, fill, batch CSV merge. Each shipped as its own panel with its own
file picker and its own shortcut. Powerful, but four scattered tools instead
of one unified workflow.

**v3.28.0 fixes that.** The four panels are now four tabs of a single **Forms**
hub. Drop a PDF once, and the hub walks you from flat scan → fillable form →
filled form → 200 filled forms — without ever re-picking a file.

## The new Forms hub

Open it three ways:

- Sidebar → **Forms** (default landing on the smart-default tab)
- **⌘+⇧+F** — opens on the last-used tab
- **⌘+K → "forms"** — palette surfaces every sub-tab as its own action

Inside the hub you'll find four tabs:

| Tab | What it does | Buy-button reason |
| --- | --- | --- |
| **Detect** ✨ | Scans every page for blanks, lines and labels and proposes AcroForm fields | Acrobat's "Prepare Form" — but offline |
| **Design** ✎ | Draw and edit fields by hand on the page | Form authoring without a $239/yr seat |
| **Fill** 📝 | Type values into an existing AcroForm | Adobe Reader replacement |
| **Batch** ⋮ | Mail-merge a CSV across many copies | Acrobat doesn't even ship this |

A live status chip in the header tells you exactly where you are — `flat PDF`,
`8 candidates`, `12 fields ready`, `filled, ready to batch` — and a footer
CTA *"Next: Fill the form →"* always points at the next sensible step.

## Cross-tab awareness

The four tabs share a single state store. That means:

- Auto-detect a flat PDF on the **Detect** tab → switch to **Design**, your
  candidates are already there waiting to be committed.
- Inspect an AcroForm on the **Fill** tab → switch to **Batch**, the template
  is pre-loaded; just pick a CSV.
- The header chip and footer CTA update in real time as you work.

No more re-picking files. No more "wait, which panel had this PDF?"

## Discoverability

Every sub-tab is reachable in two keystrokes from anywhere:

- **⌘+K** then "auto-detect", "designer", "fill", or "batch"
- **⌘+/** shows the new **Forms (Quill Hub)** section in the keyboard cheat-sheet
- The three Quill shortcuts (**⌘+⇧+Y**, **⌘+⇧+D**, **⌘+⇧+B**) now open the
  Hub on the matching tab, replacing the four separate sidebar entries

## Why this matters

A paralegal who fills 50 W-9s a week opens Slab, sees one tab labeled
**Forms**, and finishes the job in four clicks. That's the workflow Acrobat
Pro charges $239/yr for — but unified, offline, and free.

## Under the hood

- New `src/lib/quill.ts` shared store with a derived `suggestedNextTab` so the
  Hub always knows where to send the user next.
- Existing `FormsPanel`, `QuillAutodetectPanel`, `QuillDesignerPanel` now
  mirror their state into the shared store via three small `quillSetInput` /
  `quillRecordReport` / `quillRecordDetection` calls.
- No Rust changes. All four Tauri commands (`slab_forms_autodetect`,
  `slab_forms_inspect`, `slab_forms_fill`, `slab_quill_batch`) ship as-is.
- 0 errors on `pnpm check`, all `cargo` gates green.
