# Slab v0.13.1 — Lens Patch 🔧

A small but meaningful **patch release** for the Lens line.

## What's in here

### 🐛 Windows build fix — `pdftotext` flavor detection

v0.13.0's table-extraction pipeline shelled out to `pdftotext -bbox-layout`
(a Poppler feature). The Windows GitHub Actions runner has the **xpdf**
flavor of `pdftotext` on PATH instead of Poppler — same binary name,
different vendor (Glyph & Cog), no `-bbox-layout` support.

Slab now does a **two-step capability probe**: first checks the binary
exists, then sniffs `pdftotext -h` for `-bbox-layout`. If the host has
the xpdf flavor, you get a clear, actionable error pointing you at
Poppler installs for every OS:

```
pdftotext on PATH does not support -bbox-layout (looks like the xpdf
flavor). Slab needs Poppler's pdftotext.
  macOS: `brew install poppler`
  Debian/Ubuntu: `sudo apt install poppler-utils`
  Windows: `scoop install poppler`
```

CI now passes on all three platforms.

### ✨ New: `slab lens preflight`

A single command to check whether your host has everything Lens needs:

```
$ slab lens preflight
Slab Lens dependency preflight

  ✓ Poppler pdftoppm (PDF→PPM rasterizer)
    features: OCR pipeline
    pdftoppm version 26.04.0

  ✓ Tesseract OCR
    features: OCR pipeline, Library auto-OCR queue
    tesseract 5.5.2

  ✓ Poppler pdftotext (with -bbox-layout)
    features: Table extraction
    pdftotext version 26.04.0

  · Ollama HTTP endpoint
    features: Beacon AI chat, summary, semantic search, vision Q&A, auto-tag
    Ollama not reachable at http://localhost:11434.
    Install: https://ollama.com/download — then `ollama pull llama3.2`.

3 / 4 checks OK
```

Flags:
- `--json` — machine-readable output for scripts
- `--ollama <url>` — override the probe URL (pass `""` to skip)

Exits non-zero if any check fails (CI-friendly).

Every probe is offline-safe — `Status::Missing` always carries an
actionable install hint with macOS / Debian / Windows variants. The
Ollama probe is a raw TCP-connect with a 500ms timeout (no HTTP parsing,
no new dependencies).

appropriate installer below.

v0.13.0, this release is the fix — but you still need Poppler
installed (`scoop install poppler`).
