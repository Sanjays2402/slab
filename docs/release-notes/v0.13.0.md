# v0.13.0 — Lens 🔍

> **Codename:** Lens — scanned PDFs become first-class citizens.

Lens teaches Slab to *see* PDFs the way you do. Image-only scans, complex tables, picture-heavy documents — all now searchable, extractable, and queryable. Slab still ships zero telemetry, runs every AI feature against your **local Ollama** by default, and never uploads a byte unless you point it at OpenAI yourself.

## ✨ Highlights

### 🔎 Scan Audit + Auto-OCR Banner
Open any PDF and Slab decides — *in a few milliseconds, with no rasterization* — whether each page is **text**, **image**, **mixed**, or **empty**. Image-heavy PDFs trigger a friendly banner in the Reader: *"This looks scanned — make it searchable?"* One click runs OCR; the result lands next to the original as `<stem>.ocr.pdf`.

- New `pdf::scan_audit` module — heuristic on extract_text + XObject Image refs
- 8 unit tests covering text-only / image-only / mixed / empty fixtures
- Cheap enough to run on every Reader open

### 📚 Library Auto-OCR Queue
Scanned docs imported into your library now show up in a **dedicated OCR queue**. Color-coded badges (Pending / Done / Failed) make state obvious. Per-card *Run OCR* button, bulk *OCR N pending* toolbar action, and `<stem>.ocr.pdf` naming that never overwrites your originals.

- Schema-versioned migration (v1 → v2) — existing libraries auto-upgrade
- `pdf::library::ocr_queue` with `list_pending` / `run_one` / `run_all`
- Continues past per-doc failures (one bad scan never aborts a bulk run)
- 3 new Tauri commands + TypeScript bindings

### 📊 Tables → CSV
Drag-select a page, pick row/column thresholds, and Slab extracts every table on it as CSV — copy to clipboard or save to disk. Powered by `pdftotext -bbox-layout` (poppler) plus a hand-rolled row/column clusterer.

- New `pdf::table_extract` module — XHTML word-bbox parsing, row banding, column gap detection
- Multi-table pages each save as `<stem>_t1.csv`, `<stem>_t2.csv`, ...
- Live 4-row preview in the Tables sidebar panel
- Friendly errors when `pdftotext` is missing (install hint: `brew install poppler`)

### 👁 Vision Q&A in Beacon
Ask questions *about* pages, not just *with* text. Press the **👁 Vision** chip in Beacon, pick a page (and optionally a region), and your local `llava:7b` model answers questions about diagrams, photos, scans, anything. Falls back gracefully if your provider doesn't support vision.

- New `ai::vision` module — `pdftoppm` rasterize + image downscale + base64 PNG
- `AiProvider::chat_with_images` trait method with default "vision unsupported" reply
- Ollama implementation reads `DEFAULT_VISION_MODEL = "llava:7b"`
- Slim wire format: zero overhead for text-only chat turns
- 14 new unit tests covering rect-crop, downscale, multi-image, error paths

### 🏷️ Auto-Tag on Import
Generate 3–5 AI-suggested tags per document with one click. Toolbar **🏷️ Auto-tag N** runs across the whole library; per-card and right-click options give you fine-grained control. **Additive only** — your hand-set tags are never removed.

- New `ai::auto_tag` module — deterministic (temp=0.1, max_tokens=64), short replies
- Robust parser strips bullets / quotes / numeric prefixes; dedupes case-insensitively
- 2 Tauri commands (`slab_library_auto_tag_one`, `slab_library_auto_tag_many`)
- Honest UX: confirm before bulk runs, summary banner with success/failure counts

### ⌨ CLI Surface — `slab lens`
Everything above, scriptable:

```bash
slab lens audit report.pdf                          # classify each page
slab lens tables form.pdf 3 -o table.csv            # extract tables → CSV
slab lens ocr-queue list                            # what's pending?
slab lens ocr-queue run-all --lang eng --dpi 300    # drain the queue
slab lens auto-tag --all --max-tags 5               # AI-tag every doc
```

Same backend modules, same exit codes, same error messages — perfect for cron, CI, or piping into other tools.

## 📥 Install

Pick your platform from the assets below:

- **macOS (Apple Silicon)** — `.dmg`
- **macOS (Intel)** — `.dmg`
- **Linux x64** — `.deb` or `.AppImage`
- **Windows x64** — `.msi` or `.nsis setup.exe`

**External dependencies (only if you use the matching feature):**

- `tesseract` + `pdftoppm` — required for OCR (`brew install tesseract poppler`)
- `pdftotext` — required for Tables → CSV (`brew install poppler`)
- `ollama` — required for Beacon AI / Vision / Auto-tag (`brew install ollama && ollama pull llama3.2:3b llava:7b nomic-embed-text`)
