# v3.42.4 — Rotation & Blank Page Fixes

**Two fixes from the latest bug pass.**

## Fixed

- **Rotation with inherited settings** — a page that inherits a rotation from its page-tree parent now rotates from that angle. Rotating by 90° twice gives 180°, not 90°.
- **Remove Blank Pages on an all-blank scan** — the error now explains that every page looks blank, and suggests trying Lenient sensitivity.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
