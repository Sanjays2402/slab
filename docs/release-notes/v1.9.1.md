# Slab v1.9.1 "Beacon Voice Mode: Listen" 🎙

Release date: 2026-05-18

## Overview

**Listen** completes Voice Mode. v1.9.0 gave Beacon a mouth; v1.9.1 gives
it ears. Tap the mic in Beacon Chat, dictate your question, and an
on-device whisper.cpp transcribes it straight into the composer — no
cloud round-trip, no audio uploaded anywhere, nothing persisted on disk
beyond the few hundred milliseconds it takes whisper to read the WAV.

## What's new

### On-device speech-to-text via whisper.cpp

Slab shells out to a locally installed whisper binary. Audio is captured
via your platform's standard recorder (`sox` on macOS, `arecord` on
Linux), piped to whisper as a temp WAV, transcribed, and the WAV is
unlinked unconditionally — even on error paths. Nothing leaves your
machine; nothing lingers on disk.

- **macOS** — `whisper-cpp` + `sox` (`brew install whisper-cpp sox`)
- **Linux** — `whisper-cpp` + `arecord` (`apt install whisper-cpp alsa-utils`)
- **Windows** — listed but currently treated as "not installed" by the
  capability probe; native support tracked for v1.9.2

If your platform default isn't available, the Beacon Voice panel tells
you exactly which binary to install.

### Mic button in Beacon Chat

A pulsing mic button sits between the composer textarea and Send. Tap
once to start recording (button turns red and pulses), tap again to stop
and transcribe. The result is **appended** to whatever's already in the
composer with a space-pad (so "Summarise: " + dictated text just works),
caret lands at the end, focus returns to the textarea — hit Enter to
send.

When STT capability is unavailable the mic button is **hidden
entirely**, not disabled with a tooltip. No broken affordances; the
install hint lives in the Beacon Voice panel.

### Listen section in Beacon Voice panel

The 🔊 nav entry now hosts a 🎙 Listen fieldset alongside the existing
Speak controls:

- Engine status badge (whisper-cpp installed / missing)
- Recorder status badge (sox/arecord installed / missing)
- Privacy callout ("audio never leaves this machine")
- Contextual install hints per OS — exact commands, copy-paste ready

### Single-slot STT session

Mirrors the v1.9.0 TTS session pattern. `Arc<SttSession>` managed Tauri
state, with `start()` / `stop() -> Transcript` / `is_recording()`. Two
independent slots (`VoiceSession` for output, `SttSession` for input) so
you can dictate while Slab is still speaking the previous answer — no
collision, no queueing.

### Tauri command surface

Four new commands for any panel/skill that wants to drive listen:

- `slab_beacon_voice_stt_capabilities` — probe what's installed
- `slab_beacon_voice_stt_start(engine?)` — start recording (engine
  optional; falls back to platform default)
- `slab_beacon_voice_stt_stop` — stop + transcribe, returns
  `Transcript { text, language?, duration_ms }`
- `slab_beacon_voice_stt_is_recording` — UI state poll

All wrapped in the `CmdResult<T>` envelope used elsewhere — Err carries
user-grade messages, not stack traces.

## Under the hood

- `src-tauri/src/ai/stt.rs` — `SttEngine` enum, capability probe,
  command builder, transcript parser. Unit-tested at the
  command-builder layer (CI-safe, no whisper binary required).
- `src-tauri/src/ai/stt_recorder.rs` — platform recorder selection
  (sox / arecord), temp-WAV lifecycle, unconditional cleanup.
- `src-tauri/src/ai/stt_session.rs` — `SttSession { current:
  Mutex<Option<RecordingHandle>> }` with kill-prev-on-start semantics.
- `src-tauri/src/lib.rs` — 4 new Tauri commands + state management +
  invoke_handler registration.
- `src/lib/panels/BeaconChatPanel.svelte` — mic button, recording state
  machine, transcript append-to-composer flow, pulsing-red CSS.
- `src/lib/panels/BeaconVoicePanel.svelte` — Listen fieldset, capability
  probe in onMount, install hints per OS.

## Privacy

Audio bytes never persist beyond the transcription call. The WAV is
unlinked in a Drop guard so process crashes, panics, or early-return
errors all clean up after themselves. No telemetry. No model downloads
happen automatically — you bring your own whisper binary and its
companion model file.

## Known limitations

- **Windows STT not yet supported** — capability probe lists it but
  marks both engine and recorder as missing
- whisper-cpp's first transcription after install may be slow while the
  model is paged in; subsequent calls are near-instant on Apple Silicon
- No mid-recording cancel UI yet — toggle button stops + transcribes; a
  separate "discard" affordance lands when we add the multi-button
  recording bar
