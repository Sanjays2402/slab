# v0.12.0 — Atlas 🗺️

> **Codename:** Atlas — your PDFs, indexed and navigable.

Atlas turns Slab from a one-PDF-at-a-time viewer into a real **library**. Point it at a folder, let it scan, and every PDF on your disk becomes searchable, taggable, and one click away.

## ✨ Highlights

### 📚 PDF Library
A dedicated **Library** view in the sidebar. Add folders, watch Slab index them in the background, and browse the result as a fast cards grid.

- **Folder management** — add/remove watched directories
- **Recursive scanning** — walks subfolders, dedupes by content hash (no double-counting copies)
- **Metadata extraction** — title, page count, file size, modified time
- **Tags** — create tags, attach them to documents, filter by tag
- **Search + sort** — filter by title, sort by name / date / page count
- **Per-card context menu** — Open, Add Tag, Remove (all without losing your place)
- **One-click handoff** — click a card to spawn a Reader tab

### 🔧 Under the hood

- New `~/.slab/library.db` SQLite registry with 4 normalized tables and `ON DELETE CASCADE` join semantics
- 11 new Tauri commands (`slab_library_*`)
- Pure backend: 38 unit tests on the registry + scanner
