# v3.41.1 — Page Range Fixes

**Bug-fix release.**

## Fixed

- **Delete pages** — page numbers that don't exist (including `0`) were silently ignored, the reported count was wrong, and an out-of-range number could bypass the "refusing to delete every page" guard. They are now rejected with a clear error.
- **Split every N** — a very large chunk size overflowed (a panic in debug builds).
- **Rotate and PDF → Images panels** — a huge range such as `1-4000000000` froze the window. Ranges past the end of the document are now rejected.
- **Server `/api/v1/to-images`** — images in the ZIP are now named after the uploaded file instead of `input-N`.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
