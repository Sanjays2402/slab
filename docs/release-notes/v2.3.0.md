# Slab v2.3.0 — Theater 🎬

**Present any PDF like it was built for the stage.**

Slab Theater turns any document into a two-screen presentation:
a clean fullscreen audience window on the projector, and a presenter
control surface on your laptop with notes, a session timer, current
and next-slide previews, and the full keyboard cheat-sheet.

Adobe Acrobat Pro DC charges $239/yr for Presenter mode. Slab ships
it free, offline, on macOS / Windows / Linux.

## What's new

- **Dual-window presenter mode** — `⇧⌘T` from any open PDF spawns a
  fullscreen audience window on your second display plus a presenter
  control panel on your primary display. Re-clicking Present focuses
  the existing pair (singleton windows).
- **Real-time control surface** — presenter window shows current slide,
  next slide thumbnail, slide notes (autosaved per-doc to localStorage),
  session timer, and the live keymap cheat-sheet.
- **Ink-on-slide** — press `I` to draw on the audience view live;
  perfect for litigators marking up an exhibit during deposition.
- **Blackout / whiteout** — `B` or `W` instantly mutes the audience
  screen while you switch context. `.` resumes.
- **Rebindable presenter shortcuts** — every Theater action lives in
  Settings → Keyboard → Theater. Map them to your projector remote's
  function keys and your wireless clicker becomes a Slab remote.
- **Onboarding step #7** — first-launch tour now demos Theater so new
  users discover it day one.

## Keyboard defaults

| Action            | Default          |
| ----------------- | ---------------- |
| Start Theater     | `Cmd/Ctrl+Shift+P` |
| Next slide        | `PageDown`       |
| Previous slide    | `PageUp`         |
| Blackout / resume | `B` / `.`        |
| Ink toggle        | `I`              |
| Exit Theater      | `Escape`         |

All rebindable. All offline. All free.

## Under the hood

- New `theater` module in `src-tauri` — geometry, state broadcast,
  open/close window commands.
- Two dedicated routes (`/theater`, `/theater-control`) keep the
  presenter keymap isolated from the main reader.
- Six new keymap action IDs wired through every window's `matches()`
  dispatcher so rebinds take effect everywhere instantly.
- 1057 Rust tests pass (+2 new Theater keymap locks).
