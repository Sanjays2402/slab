# Slab v1.5.0 — "Smart Outline" ✦

The first AI-powered authoring tool in the Outline Editor. Click **✦ Suggest (Beacon)** and Beacon reads the document, infers a clean H1/H2/H3 table-of-contents from the body text, and shows it next to your current outline. Accept the whole proposal, edit it inline, or reject it and try again.

This is **Beacon Bonus Slice 11**, the first slice of the post-Bench roadmap focused on quick AI wins that ride existing infrastructure.

## What's new

### ✦ Smart Outline in the Outline Editor

- New button in the editor header: **✦ Suggest (Beacon)**
- Beacon proposes a hierarchical outline (H1/H2/H3) inferred from the PDF content
- Page numbers are validated against the document (out-of-range pages dropped, near-duplicates collapsed within ±1 page)
- Proposal panel shows the model name, pages consumed, and how many weak entries were dropped — full transparency on what the LLM did
- Accept replaces the working tree; Reject clears it — you still click Save to persist (two-step destructive action)
- Works with whatever Beacon provider you've configured (Ollama local, OpenAI-compatible, or any plugin-contributed provider)

### Architecture

- New `ai::outline` module — pure logic for prompt building, JSON parsing, validation, dedupe, and tree assembly
- New `slab_beacon_propose_outline` Tauri command — same provider plumbing as Beacon Summary
- Reuses the existing `pdf::outline::write_outline` save path — the proposal type IS the outline type, no translation layer
- 12 new unit tests pin: liberal JSON parsing (fenced/chatty), invalid-page dropping, dedupe across case/whitespace, hierarchy assembly, MockProvider-driven happy/garbage/prompt-sanity paths

### Quality

- 593 tests passing (581 baseline + 12 new outline tests)
- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `pnpm check` all clean
- No new svelte-check warnings (baseline 23 preserved)

## Why this matters

Half the PDFs in the wild have no outline, or a 3-line garbage one. Manually building a TOC from a 200-page document is painful. Smart Outline reads the document body, proposes a structured outline, validates every page reference, and hands it to you ready to save in one click. The model can be wrong — that's why the proposal is shown side-by-side with the editable tree, not auto-applied.
