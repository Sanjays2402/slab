# v3.27.0 — Quill Auto-Detect

**Stop drawing every form field by hand.** Drop a flat PDF onto Slab and Quill
Auto-Detect scans the page geometry — horizontal rules become text fields,
checkbox glyphs become checkboxes, "Name:" style labels become field names.
Review the suggestions, untick the noise, hit **Commit accepted** and you've
got a real fillable AcroForm in one click.

## What's new

- **Heuristic form-field detector** — content-stream pass over each page picks
  up underlines, boxes, and labels that *look* like form prompts. Each
  candidate ships with a confidence score so you can filter noise.
- **New panel: Quill Auto-Detect** — pick a PDF, choose a page range, run the
  scan, review candidates side-by-side. Toggle individual candidates,
  bulk-accept high-confidence ones, and commit straight into a Designer
  document via the existing `slab_forms_design_add` pipeline.
- **Keyboard shortcut** — `⌘⇧Y` (or `Ctrl+Shift+Y`) opens the panel anywhere.

## Why this matters

Adobe Acrobat charges $239/yr partly because their "Prepare Form" auto-detect
is *good*. Slab now ships the same workflow — locally, free, and with a
confidence chip on every guess so you know which ones to trust.

## Under the hood

- New module `pdf::forms_detect` (845 lines, 15 unit tests) — pure-Rust,
  zero new deps, runs on the same `lopdf` content streams the rest of the
  pipeline uses.
- One new Tauri command (`slab_forms_autodetect`); commit path reuses the
  v3.26.0 Designer's `slab_forms_design_add` — no schema churn.

## Compatibility

Drop-in. Designer documents authored in v3.26.0 open and accept auto-detected
candidates without migration.
