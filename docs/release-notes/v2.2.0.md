# Slab v2.2.0 — Atlas 🗺️

**Search every PDF in your library in one keystroke. Offline. Free.**

Atlas is the feature that turns Slab from "a great PDF viewer" into "the one
place where all your PDFs live." Drop a folder, hit `Cmd+Shift+F`, type a
phrase — and watch every match across hundreds of documents light up in
ranked order, then click any hit and snap to that page with a golden halo.

No cloud. No subscription. No "Pro" lock. The same offline-first promise
that won you over in v2.0 now scales to your entire library.

---

## What's new

### 🔎 Cross-document full-text search

A new SQLite **FTS5** index runs in the background as your library scans.
Page-level granularity, BM25-ranked results, Unicode tokenization for
French / Spanish / Arabic / mixed-script docs. Snippets come back wrapped
in `<mark>` tags with the matched terms highlighted in gold.

- **Speed:** sub-100 ms across thousands of pages on a 2020 M1.
- **Privacy:** the index lives in `~/.config/slab/library.db`. Nothing ever
  leaves your machine.
- **Filter by folder** to scope a search to one collection.

### 🎯 Click-to-jump with golden halo

Click any search result and Slab opens (or reuses) the right document and
**jumps to the exact page** — with a 720 ms cubic-bezier `(0.34, 1.56, 0.64, 1)`
golden halo expanding from the match. Every occurrence on that page is
highlighted via the pdf.js find bar. Respects `prefers-reduced-motion`.

### ⌨️ Keyboard-first, palette-wired

- **`Cmd+Shift+F`** — open the Search Library panel from anywhere.
- **Command palette → "Search Library"** — discoverable + searchable.
- **Settings → Search** — quick-reference chip with the shortcut + a
  one-click "Open Search" CTA.
- **Onboarding tour step #5** — every new user discovers it in <60 s.

### 🌐 Translated everywhere

Six new i18n keys × four locales (English / Français / Español / العربية)
ship from day one. The Atlas surface speaks every language Slab speaks.

## Under the hood

- New `library_fts` virtual table (FTS5 + unicode61 tokenizer + porter
  stemming where supported).
- `migrate_v3()` co-located in `pdf/library/fts.rs` — runs once on
  first startup after upgrade, indexes existing library in place, no
  rescan required.
- AFTER-DELETE cascade trigger keeps the index in lock-step with file
  removals.
- New Tauri commands: `slab_library_search` (paginated + folder filter +
  1..500 limit clamp).
- 18 new unit tests pinning rank ordering, snippet shape, FTS5 escape
  rules, multi-page hits, and limit edges.

---

## Upgrade notes

- **First launch after upgrade** will spend ~1–5 s building the FTS index
  in the background. Slab is fully usable during this — search results
  populate as the index fills.
- The library DB is forward-compatible — downgrading to v2.1.x is safe;
  the FTS virtual table is simply ignored.
- All v2.1.x features (Arranger page ops, Notary signing, Vault redaction,
  self-install) carry forward unchanged.
