# Slab v3.24.0 — Stack Pro

**The Litera Compare killer. Free. Offline. Cross-platform.**

Litera Compare is the gold-standard three-way redline tool for law firms
— and it costs **$400 per seat per year**. Adobe Acrobat doesn't ship
three-way compare at all, only two-way. Slab v3.24.0 introduces
**Stack Pro**, a three-way PDF compare that delivers the same workflow
locally, for free, on macOS, Windows, and Linux.

## What Stack Pro does

Pick a **Base** document, a **Mine** revision, and a **Theirs**
revision. Slab renders a side-by-side, line-aligned diff and classifies
every line:

- **Both agree** — Mine and Theirs made the same edit. Green to merge.
- **Mine only** — your edit, Theirs left alone.
- **Theirs only** — their edit, you left alone.
- **Conflict** — both sides changed the same line differently. Red.

Pick which side wins each conflict, hit **Materialize Merged PDF**, and
Slab bakes out a clean merged document.

## The wow moment — shareable redline PDF

The capstone of this release: **Export redline PDF**. One click and Slab
produces a self-contained, colour-coded three-column redline (Base |
Mine | Theirs) that opens in any PDF viewer — Preview, Acrobat, Chrome
— with no Slab install required.

Email it to opposing counsel. Drop it into a deal-room. Print it for the
partner. The PDF carries its own header summary (conflicts, mine-only,
theirs-only, both-agree counts), conflict rows tinted red, and standard
PDF fonts so the file is tiny and universally readable.

Litera Compare bills $400/seat/year for this workflow. Acrobat doesn't
ship it. Slab does it free, locally, and the file never leaves your
machine.

## Why this matters

Legal review, contract negotiation, due diligence, regulatory filings —
any workflow with more than one editor needs three-way compare. Until
today the choices were:

- Buy Litera Compare ($400/seat/yr).
- Buy Workshare Compare (enterprise pricing).
- Make do with Acrobat's two-way (and lose your merge history).
- Ship your confidential drafts to a cloud SaaS.

Stack Pro retires all four options.

## Privacy

100% local. Documents never leave your machine. No cloud, no telemetry,
no SaaS dependency. The exported redline PDF is generated entirely on
your device.

## Under the hood

- New `pdf::diff3` module — three-way line diff over PDF text extraction.
- New `pdf::stack_redline` and `pdf::stack_diff3_export` modules — bake
  diffs to portable PDFs using standard-14 fonts (no embedding, tiny
  output, universal compatibility).
- Six new unit tests covering classification, rendering, line wrapping,
  and control-character sanitisation.
- New Tauri commands: `slab_diff3_pdfs`, `slab_diff3_materialize`,
  `slab_diff3_export_pdf`.
