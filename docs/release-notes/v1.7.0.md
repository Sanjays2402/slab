# Slab v1.7.0 — "Study Mode" 🎓

The next Beacon AI tool in the sidebar: **Study Mode**. Pick a PDF, click *Generate deck*, and Slab reads the doc, asks the LLM for Q&A pairs across the body, and turns them into a flashcard deck you review one card at a time with a 4-button ease scale. The scheduler is SM-2-lite, the cards persist in a local sqlite store, and every card carries the page it came from so you can jump straight back to the source.

This is **Beacon Bonus Slice 13**, the third slice of the post-Bench "quick AI wins" track that rides existing infrastructure (extraction → chunking → LLM → liberal JSON → validate → store).

## What's new

### 🎓 Study Mode panel in the sidebar

- New sidebar entry: **🎓 Study Mode** (sits with the other Beacon AI tools)
- Pick a PDF (or inherit from the Reader via `slab:open-recent`), click **Generate deck**
- LLM extracts Q&A pairs from the body in chunks, with capping + dedupe so a 200-page paper doesn't produce 4000 cards
- Cards stored in `~/.slab/study.sqlite`, schema-versioned via `PRAGMA user_version` (mirrors `pdf::library::registry`)
- Reveal-then-rate review flow: see the question, hit *Reveal*, then pick one of four buttons:
  - **Again** — failed, ease bottoms out at floor, due immediately
  - **Hard** — partial recall, EF drops a touch, short interval
  - **Good** — clean recall, standard SM-2 step-up
  - **Easy** — instant recall, longest interval bump
- Scheduler is **SM-2-lite**: ease ladder + EF floor 1.3 and cap 2.5, per-card history kept in a review log
- Footer stats: due now, total cards, accuracy, last review
- Click the page number on a card to jump straight to its source page in the Reader

### Architecture

- **`ai::sm2`** — pure scheduler module, 8 tests covering ease ladder + EF floor/cap, `Ease::{Again,Hard,Good,Easy}` enum with snake_case serde
- **`ai::study_store`** — sqlite-backed flashcard + review-log store, 6 tests via `:memory:` connections, schema migrations through `PRAGMA user_version`
- **`ai::study`** — generate_deck pipeline (extract → chunk → LLM Q&A → liberal JSON parse → validate → dedupe → cap → insert), 9 tests for parser + validator + dedupe + caps + budget
- **4 Tauri commands**: `slab_beacon_generate_deck`, `slab_beacon_study_due`, `slab_beacon_study_review`, `slab_beacon_study_stats` — all hashed per-PDF via reused `EmbeddingIndex::hash_file`
- **`BeaconStudyPanel.svelte`** — Svelte 5 ($state runes), pick PDF + generate + review-one-at-a-time UI with reveal-then-rate flow, footer stats, jump-to-page event dispatch
- Detach-window support: added to `DETACHABLE_PANELS` so you can pull Study Mode into a separate window

## Why this matters

Reading a 60-page paper is one thing; **remembering it next week** is another. Study Mode turns any PDF into a personalised flashcard deck without leaving Slab — the LLM does the question-writing, SM-2 handles the scheduling, and every card stays linked to the page it came from so you can always jump back to the source. It's the same recipe as Anki, except the deck-building step happens automatically and the cards are right next to the document they came from. Works offline once the deck is generated (review + scheduling is all local sqlite).
