# v0.11.0 "Lathe" 🔧

**Theme:** **Edit Mode.** Slab stops being a read-only PDF reader and starts letting you actually *change* PDFs — pages and (for the first time) text. Five user-visible features, all running locally with no flattening, no rasterization, no font re-embedding round-trips.

> **The pitch:** Stirling-PDF features locally, Liquid Glass UI, you can chat with your PDFs *and now edit them* without sending them anywhere.

## What's new

### ✎ Edit Text — in-place PDF text editing
The headline. A new sidebar panel that lets you rewrite the actual text inside a PDF, not just stamp annotations on top.

- **Pick a PDF.** Slab walks every page's content stream, finds every `Tj` / `TJ` text operator, and shows you a flat list of editable spans grouped by page.
- **Click + retype.** Each span gets an inline text input bound to the current value. Edited spans get an orange "edited" pill; pages with pending edits show a "•" dot on the page tab.
- **Apply.** One button writes a new PDF with your edits applied — content-stream byte-level rewrite, no flattening, no PDF-to-image-and-back, original fonts preserved.
- **Read-only badges with reasons.** Spans we can't safely edit yet show a "read-only" chip with a human-readable explanation: *"CID Type0 font — not supported yet"*, *"Non-ASCII glyphs"*, *"Text drawn with kerning (2 segments)"*. No silent failures.
- **Editable-only filter** to hide the noise on dense pages.
- **Iterative save.** After Apply, the panel auto-reloads the new file so you can continue editing on top of your previous edits.

What's editable in v0.11: ASCII text on Type1 / TrueType fonts, single-segment `Tj` and `TJ` ops. CID/Unicode fonts and multi-segment kerned text are read-only this release — that's v0.12 work. We're honest about it up front; no "supports everything" lies.

Backend: new `pdf::edit_text` module with 15 unit tests covering find/replace round-trip, font-subtype gating, ASCII validation, span-id parsing, multi-stream pages, and read-only branches. Two new Tauri commands: `slab_find_text_spans` + `slab_replace_text_span`.

### ▦ Pages (visual) — drag-reorder, duplicate, blank inserts, rotate
Promoted from "list of buttons" to a proper visual grid.

- **Drag thumbnails to reorder.** Multi-select with cmd-click.
- **Right-click menu** on any cell: Rotate (90/180/270°), Duplicate, Insert Blank (before/after), Delete.
- **Custom blank size** for inserts (Letter / A4 / match adjacent).
- **One-click Apply** runs the new `pages_build` composite kernel — permutations + duplicates + blank inserts + per-cell rotation in a single Tauri round-trip. No more 3-step manual pipelines.

The old list view is still around as `≣ Pages (list)` for keyboard-heavy users.

Backend: `pdf::pages_build` composite kernel with 14 unit tests. New Tauri command `slab_pages_build`.

### ✂ Split by Chapter — regex or outline-driven chapter splitting
Slice a long PDF into one file per chapter, no manual page-range picking.

- **Regex mode**: paste a pattern (`^Chapter\s+\d+`, `^CHAPTER\s+[IVXLCDM]+`, etc.) and Slab finds every page whose text matches; each match starts a new chunk.
- **Outline mode**: Slab walks the PDF's top-level outline (bookmarks) and produces one chunk per heading. Works on any book with a TOC.
- **5 one-click presets** for common book conventions.
- **Live preview** before commit — see exactly which pages will be chapter starts, with a "p1 (cover)" pill when the first match isn't page 1.
- **Friendly regex errors** ("missing closing paren" instead of `error: regex parse error: …`).

Backend: `pdf::split_pattern` + `slab_split_by_pattern`, `slab_find_matching_pages`, `slab_outline_starts` Tauri commands.

### ▥ Multi-PDF tabs in the Reader
Open as many PDFs as you want in one Slab window.

- **⌘T** new tab, **⌘W** close, **⌘1..9** jump to tab N, **Ctrl+Tab** / **Ctrl+Shift+Tab** to cycle.
- **Middle-click** a tab to close, **+** button to open.
- Each tab keeps its own pdf.js viewer alive across switches (zoom, scroll position, current page all preserved — no re-render storm when you tab back).
- Auto-titled from filename.

Pure-frontend change; the Reader panel gained `tabId` / `active` / `initialPath` / `onTitleChange` props so the shell can mount N instances side-by-side.

### Page duplication kernel
Foundation work that the Pages panel sits on. New `pdf::duplicate` module with a `duplicate_pages` kernel + `slab_duplicate_pages` Tauri command for programmatic page duplication outside the panel context (used by the Pages visual editor and any future plugin).

## Upgrade notes

- Edit Text replaces text **in place** at the same x/y as the original — a longer string will run past the right margin. Layout reflow is a v0.12 problem.
- Non-ASCII text edits are rejected with a clear error message. The font work to support Unicode rewrites (CMap rewriting, CID font subsetting) is intentionally out-of-scope here; it's the headline feature of v0.13 "Lens".
- The on-disk sqlite chat history at `~/.slab/chats.db` is unchanged from v0.10 — your Beacon conversations survive the upgrade.
- Cargo lock + svelte version bumps; no migration steps required.
