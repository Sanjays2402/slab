# v3.42.3 — Server Fixes & API Key

**Silent page loss fixed, Docker port fixed, and an optional API key for Slab Server.**

## Fixed

- **Pages going missing** — reordering or extracting pages from a PDF with nested page trees dropped pages (3 in, 2 out). Fixed.
- **Docker image** — the container listened on the wrong port, so `docker run -p 8080:8080` and its healthcheck failed. It now listens on `SLAB_BIND`, which defaults to port 8080 as the docs describe. Scripts that set `SLAB_PORT` or `SLAB_HOST` still work.

## Added

- **`SLAB_API_KEY`** — set it to require a key on every API operation (`Authorization: Bearer <key>` or `X-Api-Key: <key>`). `/healthz` and `/api/v1/ops` stay public. Unset, the server stays open, as before.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
