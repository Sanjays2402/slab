# v3.42.2 — Server Responsiveness

**Patch release for Slab Server.**

## Fixed

- **Stalls under load** — PDF processing ran on the server's main request threads. One large document could delay every other request, including health checks. Each PDF request now runs on its own worker thread, so the server stays responsive while a big file is processed.

Downloads are available for macOS (Apple Silicon and Intel), Windows, and Linux on this release. macOS builds use the repository's existing ad-hoc signing setup.
