Documents and the desktop app

Slab’s PDF workflows run on your computer. The app does not include project analytics or telemetry. Optional cloud AI providers can receive the prompts and document content you choose to send; local AI can run through Ollama. Plugins and services you configure may have separate data practices.

Website requests and hosting

This site does not add analytics or tracking cookies. GitHub Pages serves the site and GitHub hosts downloads. Loading the home page also requests Google Fonts and the public GitHub API for the star count. These providers may process connection information such as your IP address according to their own policies.

See GitHub’s privacy statement and Google’s privacy policy.

Appearance preference

Choosing a website accent saves a color name in this browser’s local storage so it can be restored on later visits. The site does not send that preference to the project. Clear this site’s browser storage to remove it. If storage is unavailable, the color picker still works for the current page.

Public support

GitHub issues are public. Do not post confidential files or credentials. For product questions, open an issue with a non-sensitive example.
