Eight pillars

Everything a PDF app should do.
Nothing it shouldn’t.

Jump to any tool from anywhere with the ⌘K command palette. Every operation below runs on your device — air-gap a laptop and Slab still works.

Read & navigate

Open PDFs, thumbnails, outline, find, highlights, sticky notes, recents.

Manipulate

Merge, split, pages, compress, extract, encrypt, watermark, sign, crop, insert, headers & footers, redact, N-up.

Document tools

Markdown→PDF, polyglot conversion (.docx/.xlsx/.epub/.html), flatten, sanitize, repair, edit text, grayscale, page labels.

OCR & vision

Hopper — automations

One inbox. Many destinations.
Zero clicks.

Point Hopper at a folder — ~/Downloads, a scanner output, a shared inbox — and pair it with a recipe. Every PDF that lands triggers the pipeline: flatten, OCR, redact PII, watermark, then Beacon suggests a filename and files it away. A live run log streams in real time. Press ⇧⌘H to open.

Conditional rules

Route each arriving PDF through a chain of rules you write once and forget. Six predicate kinds — first match wins, everything else falls through.

  • filename glob
  • regex
  • text contents
  • page count
  • file size
  • catch-all

Live preview

As you edit any predicate, green ✓ chips light up next to your actual recent files showing which rule will catch them. No deploy-test-squint loops.

Why not the others?

Hazel charges $42 and can’t see inside PDFs. Adobe AutoActions need an enterprise license and round-trip your files to the cloud. Slab does it free, locally, with offline AI.

Slab Server

Headless, self-hosted,
same Rust core.

The desktop app’s PDF engine wrapped in an HTTP API with a drag-drop web UI. Run it on a NAS, in Compose, behind a reverse proxy — scriptable and offline.

80 MB image at ghcr.io/sanjays2402/slab · full HTTP API · Compose example in docs/server.md

Foundry + Bench

Extend it without
writing Rust.

A declarative plugin system for themes, locales, commands, AI providers, and PDF actions. A typed TypeScript SDK (Workshop) ships three working example plugins right in the binary — sandboxed and source-readable — so you can poke at the system the moment you open the app. Bench is the signed, in-app marketplace.
